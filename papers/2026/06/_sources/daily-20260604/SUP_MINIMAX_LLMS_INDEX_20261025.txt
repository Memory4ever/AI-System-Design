# MiniMax Agent 文档

- [欢迎使用 MiniMax Code](https://agent.minimaxi.com/docs/code/welcome.md): MiniMax Code 是面向桌面端的 AI Agent 应用，支持代码开发、日常工作流、自动化任务和远程控制。
- [下载与安装](https://agent.minimaxi.com/docs/code/get-started/download.md): 下载 MiniMax Code 桌面端，并在 macOS 或 Windows 上完成安装。
- [创建第一个任务](https://agent.minimaxi.com/docs/code/get-started/first-task.md): 从首页输入目标、选择工作区并发送任务，让 MiniMax Code 开始工作。
- [Coding 与 Work 模式](https://agent.minimaxi.com/docs/code/workflows/modes.md): 了解 MiniMax Code 的两种桌面端工作模式，以及何时使用 Coding 或 Work。
- [工作区与项目上下文](https://agent.minimaxi.com/docs/code/workflows/workspace.md): 为任务选择本地项目目录，让 Agent 理解文件结构、代码约定和运行环境。
- [对话、任务与历史管理](https://agent.minimaxi.com/docs/code/workflows/tasks.md): 管理 MiniMax Code 中的任务、会话历史、置顶和归档。
- [对话协作](https://agent.minimaxi.com/docs/code/workflows/conversation-collaboration.md): 在对话中直接引用、评论和评价 Agent 回复。
- [代码审查](https://agent.minimaxi.com/docs/code/workflows/code-review.md): 使用内置代码审查指令审查本地代码变更。
- [权限与安全确认](https://agent.minimaxi.com/docs/code/workflows/permissions.md): 了解 Agent 执行文件、命令和外部操作时的权限确认机制。
- [无限画布](https://agent.minimaxi.com/docs/code/desktop/infinite-canvas.md): 把素材、灵感和生成结果铺在同一张画布上，和 Agent 一起完成多媒体创作。
- [内置浏览器](https://agent.minimaxi.com/docs/code/desktop/browser.md): 在 MiniMax Code 右侧面板打开网页、预览 HTML 产物并辅助调试。
- [电脑操控](https://agent.minimaxi.com/docs/code/desktop/computer-use.md): 让 MiniMax Code 直接操作电脑上的应用，完成需要图形界面交互的任务。
- [文件、变更与终端面板](https://agent.minimaxi.com/docs/code/desktop/panels.md): 使用 MiniMax Code 的文件、变更和终端面板查看任务执行过程。
- [界面外观](https://agent.minimaxi.com/docs/code/desktop/appearance.md): 调整 MiniMax Code 的明暗模式、主题风格、界面密度、字体和页面配色。
- [快捷键与快捷小窗](https://agent.minimaxi.com/docs/code/desktop/shortcuts.md): 使用全局快捷键、命令面板和快捷小窗更快发起任务。
- [应用更新与问题反馈](https://agent.minimaxi.com/docs/code/desktop/updates-feedback.md): 检查 MiniMax Code 更新，并通过统一的问题反馈流程提交工单。
- [目标功能](https://agent.minimaxi.com/docs/code/desktop/goal.md): 使用 Goal 为 MiniMax Code 设定可验证的最终目标，让任务持续推进直到达标或遇到阻塞。
- [Agent Team](https://agent.minimaxi.com/docs/code/agents/team.md): 使用 Agent Team 处理需要拆解、协作和校验的复杂任务。
- [自定义 Agent](https://agent.minimaxi.com/docs/code/agents/custom-agents.md): 创建具有固定角色、指令、技能和工作区的专属 Agent。
- [Mini App](https://agent.minimaxi.com/docs/code/agents/mini-apps.md): 把信息、工具和操作集中到一个页面中，并通过对话持续调整。
- [H3 Max 视频生成](https://agent.minimaxi.com/docs/code/agents/h3-max.md): 在 MiniMax Code 中，用文字和参考素材创作带声音的视频。
- [插件市场](https://agent.minimaxi.com/docs/code/agents/plugins.md): 在 MiniMax Code 中安装和使用领域插件。
- [插件开发与上架指南](https://agent.minimaxi.com/docs/code/agents/plugin-submission.md): MiniMax Plugin 的能力选择、目录结构、Manifest 字段、Skill 与 MCP 编写、包体限制和提交流程。
- [MCP 服务](https://agent.minimaxi.com/docs/code/agents/mcp.md): 将外部工具和数据源连接到 MiniMax Code。
- [记忆机制](https://agent.minimaxi.com/docs/code/agents/memory.md): MiniMax Code 通过记忆沉淀你的偏好、项目约定和长期经验。
- [定时任务](https://agent.minimaxi.com/docs/code/automation/schedules.md): 让 Agent 按计划自动执行重复任务。
- [远程控制](https://agent.minimaxi.com/docs/code/automation/remote-control.md): 在手机上连接桌面端 Agent，查看进度、补充指令和处理权限确认。
- [IM 连接](https://agent.minimaxi.com/docs/code/automation/im.md): 通过微信、飞书、Telegram 或 Lark 与 Agent 协作。
- [M Plan 与积分](https://agent.minimaxi.com/docs/code/account/usage.md): 查看 MiniMax Code 的订阅套餐、积分余额和用量额度。
- [MiniMax API 密钥](https://agent.minimaxi.com/docs/code/account/minimax-api.md): 在 MiniMax Code 中配置自己的 MiniMax API Key。
- [自定义模型 / BYOK](https://agent.minimaxi.com/docs/code/account/byok.md): 通过 Base URL、API Key 和模型名添加自定义模型供应商。
- [Agent 的 BYOK 模型配置指南](https://agent.minimaxi.com/docs/code/account/byok-agent-setup.md): 指导 Agent 配置自定义模型，并在 macOS 和 Windows 上通过 curl 验证真实回复。
- [常见问题](https://agent.minimaxi.com/docs/code/help/faq.md): MiniMax Code 桌面端常见问题。
- [问题反馈](https://agent.minimaxi.com/docs/code/help/feedback.md): 遇到问题时，通过问题反馈提交复现信息、截图和诊断信息。
- [快速开始](https://agent.minimaxi.com/docs/cli/quick-start.md): 安装 MiniMax Code CLI，登录账号并完成第一个终端任务。

- [配置与模型](https://agent.minimaxi.com/docs/cli/configuration.md): 配置 MiniMax Code CLI 的数据目录、账号来源、Provider、模型、代理、Skills、MCP 和 Plugin。
- [Headless 与 CI](https://agent.minimaxi.com/docs/cli/automation.md): 使用 mcode exec 接入 Shell、CI、批处理和评测，并处理结构化输出与退出码。

- [安全与权限](https://agent.minimaxi.com/docs/cli/security.md): 理解 MiniMax Code CLI 的权限模式、凭证保护和自动化安全边界。
- [常见问题](https://agent.minimaxi.com/docs/cli/faq.md): 排查 MiniMax Code CLI 的安装、登录、配置、自动化和终端问题。
