### DA-20260615-SERVICE-CONGESTION

### DA-20260615-ROUTING-TRUST
Privacy-preserving agentic routing requires a three-party trust split: the client constructs a protected query, the gateway routes without owning plaintext plus unverifiable forwarding authority, and the provider returns billable evidence. TLS identity, query privacy and billing verification remain distinct proof obligations.

### DA-20260615-KV-COMPOSITION
