7 Summary and Outlook
We proposed Reset-and-Discard, ReD, a new resetting-based query protocol of LLMs that improves coverage@cost at a fixed budget.
We mapped pass@kk to coverage@cost and showed that power-law behavior in pass@kk with 0<α<10<\alpha<1 leads to sublinear growth of coverage@cost. We proved that ReD always improves coverage@cost; particularly, in the case of 0<α<10<\alpha<1, ReD leads to a linear growth of coverage@cost and the optimal resetting protocol is ReD every attempt. We also showed that, given pass@kk, we can predict the amount of saving obtained by performing ReD every attempt. If pass@kk is not available, we showed that ReD can be used to estimate the power-law exponent without needing a full pass@kk evaluation. Finally, we demonstrated the performance of ReD on three LLMs of varying size on the HumanEval dataset of coding tasks. In a wide range of costs, measured in attempts, total cumulative tokens or USD, ReD led to improvement over the standard solve-to-completion baseline.
The implementation of ReD has profound implications for the commercial deployment of LLMs, specifically by enabling a shift from “Pay-per-Token” to “Outcome-as-a-Service.” Currently, users of commercial APIs bear the economic risk of model failure, paying for generations regardless of their validity. By utilizing ReD as a backend allocation strategy, similar to hierarchical routing proposals such as FrugalGPT (Chen et al., 2024b), providers can instead sell verified solutions. This aligns incentives: the user pays a premium only for solved tasks, while the provider maximizes profit by optimizing “Goodput” (valid tasks per USD), effectively using ReD to arbitrate between model costs and task difficulty without exposing the user to the complexity of the underlying search.
Beyond commercial servicing, ReD significantly enhances efficiency in research and edge computing domains. In the context of Reinforcement Learning algorithms like STaR (Zelikman et al., 2022) or ReST (Gulcehre et al., 2023), which rely on self-generated synthetic data, ReD can act as an active learning filter: Rather than wasting GPU hours uniformly sampling trivial or impossible problems, ReD focuses the compute budget on the “frontier of learnability,” yielding a larger set of successful trajectories for the same training cost. Finally, ReD can be used to select which question to send to smaller models first, and which to save for larger, more expensive models. In that sense, it automatically optimizes intelligence versus cost. This is particularly critical for mobile and edge applications (Bansal et al., 2025), where ReD provides a formal framework for resource-constrained inference, determining exactly when to stop attempting a query to, e.g., preserve battery life while maximizing the total utility delivered to the user.
Limitations and future work:
In this work, we considered only perfectly verifiable tasks. The topic of verification remains an open problem, and it would be of interest to study ReD under different verification methods such as Best-of-NN (Wang et al., 2023), majority vote, and reward models (Christiano et al., 2023).
Furthermore, we focused on a parallel sampling scheme, where trials are independent as a sufficient baseline. It has been shown, however, that in many cases it is more beneficial to perform sequential sampling (or backtracking) (Kumar et al., 2024; Qin et al., 2025; Muennighoff et al., 2023). In future work, it would be natural to extend the ReD framework to correlated inference attempts, where memory of the previous states is retained across the reasoning trajectory.
