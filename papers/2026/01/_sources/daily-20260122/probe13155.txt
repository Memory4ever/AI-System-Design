S3.SS2  3.2 Partial Attention Probing for MHA Empirically, MHA blocks in deeper layers primarily aggregate contextual information from preceding tokens into the last token, supporting subsequent content generation. Accordingly, under a fixed computation budget, token skipping in an MHA block can be formulated as the optimization problem in Eq. 3 , where the objective is to minimize the information loss in the last token. 𝒯 ^ active MHA = arg ​ min 𝒯 active ⊂ 𝒯 , | 𝒯 active | = M ⁡ ‖ 𝐘 ^ N − 𝐘 N ‖ 2 . \hat{\mathcal{T}}^{\mathrm{MHA}}_{\mathrm{active}}=\argmin_{\mathcal{T}_{\mathrm{active}}\subset\mathcal{T},|\mathcal{T}_{\mathrm{active}}|=M}||\hat{\bm{Y}}_{N}-\bm{Y}_{N}||_{2}. (3) However, this optimization problem is NP-hard, rendering exact solutions infeasible within a single forward propagation. Noting that attention mechanisms explicitly capture the information flow from preceding tokens to the last one, we probe a lightweight, attention-based signal as a practical surrogate to approximate each token’s contribution and guide the token skipping process. Specifically, we first compute the key projections for all tokens at the current layer as 𝑲 = 𝑿 ​ 𝑾 K \bm{K}=\bm{X}\bm{W}_{K} , while computing the query projection only for the last token as 𝒒 = 𝑿 N ​ 𝑾 Q \bm{q}=\bm{X}_{N}\bm{W}_{Q} , where 𝑾 Q \bm{W}_{Q} and 𝑾 K \bm{W}_{K} are projection matrices. We then calculate the softmax-normalized attention scores between 𝒒 \bm{q} and 𝑲 \bm{K} and average them across all attention heads to derive a token-wise contribution score, formally given by: S n MHA = 1 H ​ ∑ h = 1 H Softmax ⁡ ( 𝒒 h ​ 𝑲 h T d ) ​ [ n ] , S_{n}^{\mathrm{MHA}}=\frac{1}{H}\sum_{h=1}^{H}\mathrm{Softmax}(\frac{\bm{q}_{h}\bm{K}_{h}^{T}}{\sqrt{d}})[n], (4) where H H and d d denote the number of attention heads and the dimensionality per head, respectively. According to the contribution score, the top- M M tokens are selected, yielding the active indices as: 𝒯 active MHA = TopK ⁡ ( { S n MHA } n = 1 N , M ) . \mathcal{T}^{\mathrm{MHA}}_{\mathrm{active}}=\mathrm{TopK}(\{S_{n}^{\mathrm{MHA}}\}_{n=1}^{N},M). (5) Subsequently, in standard causal attention, the query and value projections are computed only for the selected tokens, while the corresponding key projections are retrieved from the precomputed matrix 𝑲 \bm{K} . This procedure reduces the computation of ℱ MHA ​ ( ⋅ ) \mathcal{F}_{\mathrm{MHA}}(\cdot) while preserving the dominant information flow within current layer. Moreover, this token skipping operation enables an on-the-fly KV Cache compression during the prefilling phase. As shown in Figure 2 (a), only the key and value projections of active tokens are cached, while skipped tokens can still contribute in subsequent layers. This selective caching further reduces memory footprint and lowers computational overhead during the decoding phase.

S3.SS4  3.4 Multi-Stage Delayed Token Pruning For clarity in this section, we use l l to denote the layer index, and all variables in Secs. 3.2 and 3.3 are instantiated in a layer-wise manner, e.g. 𝒯 l , 𝒯 active l \mathcal{T}^{l},\mathcal{T}^{l}_{\mathrm{active}} for the candidate and active sets, and M l M^{l} for the number of active tokens. Prior studies Yang et al. (2024) ; Cai et al. (2024) have observed that, as tokens propagate to deeper layers, semantically salient information tends to concentrate within a smaller subset, while the remaining tokens become increasingly redundant. Empirical analyses of token representations before and after the MHA and FFN blocks further reveal that the self-similarity of individual tokens consistently increases with network depth, highlighting the growing redundancy. These observations motivate a non-uniform token skipping strategy across layers. Notably, empirical evidence from long-context scenarios suggests that the number of informative tokens remains relatively stable in absolute terms, rather than scaling proportionally with the sequence length Shi et al. (2024) ; Long et al. (2025) . Motivated by this property, we adopt a fixed token budget at each stage instead of a fixed pruning ratio, enabling more consistent preservation of critical information. Specifically, we define M l = min ⁡ ( | 𝒯 l | , M fixed l ) M^{l}=\min(|\mathcal{T}^{l}|,M^{l}_{\mathrm{fixed}}) , where M fixed l M^{l}_{\mathrm{fixed}} is a predefined token budget. Furthermore, while retaining the full set of tokens as candidates intuitively helps keep the main information flow of each token, excessively preserving tokens in deeper layers introduces the issues of redundant computational overhead in probing Eqs. 4 and 14 and interference in score distributions reducing the effectiveness of top-token selection. To address these issues, we partition the token skipping layers of the network into multiple stages and introduce delayed token pruning at the end of each stage. Concretely, let ℒ s = { l s , l s + 1 , … , l s + L s } \mathcal{L}^{s}=\{l_{s},l_{s}\!+\!1,...,l_{s}\!+\!L_{s}\} denote the set of L s L_{s} consecutive layers forming the s s -th stage. All layers l ∈ ℒ s l\in\mathcal{L}^{s} share the same candidate token set 𝒯 l \mathcal{T}^{l} , with | 𝒯 l | = N s |\mathcal{T}^{l}|=N_{s} . At the end of stage s s , i.e. after the last layer l s + L s l_{s}\!+\!L_{s} , token pruning is conducted with the attention-based contribution scores defined in Eq. 4 , computed from the last layer of the stage, specifically S n l s + L s , MHA S_{n}^{l_{s}\!+\!L_{s},\mathrm{MHA}} . This yields a reduced candidate set forwarding to the subsequent layers: 𝒯 l = TopK ⁡ ( { S n l s + L s , MHA } n = 1 N s , N s + 1 ) , ∀ l ∈ ℒ s + 1 . \mathcal{T}^{l}=\mathrm{TopK}(\{S_{n}^{l_{s}\!+\!L_{s},\mathrm{MHA}}\}_{n=1}^{N_{s}},N_{s+1}),~\forall l\in\mathcal{L}^{s+1}. Concretely, following the official evaluation protocols, we report the F1 score for the Single- and Multi-Document QA tasks including Qasper, MultiFieldQA (MQA), HotpotQA (HPQA), 2WikiMultihopQA (2WiKi), MuSiQue; the Rouge-L score Lin (2004) for Summarization tasks including GovReport (GovRep), QMSum, MultiNews (MNews) and VCSUM; the exact match Accuracy (%) for Synthetic tasks including PassageCount (Count), PassageRetrieval (PassR); and the Edit Sim (Levenshtein distance) Svyatkovskiy et al. (2025) , we measure both the time to first token (TTFT) and the end-to-end (E2E) latency for decoding 16 tokens, and report the speedups via dividing the latency of the full model by the counterpart of each method, referred to as the TTFT Acceleration Ratio and the E2E Acceleration Ratio, respectively. S4.SS2  4.2 Main Results on Accuracy-Efficiency Trade-off We compare our proposed SPTS with a range of state-of-the-art long-context LLM acceleration methods. MInference Jiang et al. (2024) and FlexPrefill Lai et al. (2025) are sparse attention approaches, PyramidInfer Yang et al. (2024) , GemFilter Shi et al. (2024) , LazyLLM Fu et al. (2024) and SlimInfer Long et al. (2025) are token pruning methods, and FTP Xu et al. (2025) is a token skipping method. Notably, these approaches primarily target accelerating the prefilling phase; therefore, we conduct comparison under comparable average TTFT acceleration ratios. On Accuracy As illustrated in Table 1 , our method consistently achieves higher average scores while delivering more substantial TTFT speedups. Specifically, SPTS outperforms the second-best methods by 0.06%, 0.05% and 0.85% on LLaMA, Qwen and openPangu, respectively. Notably, while SlimInfer exhibits competitive in both accuracy and TTFT acceleration, it suffers from pronounced degradation in decoding speed, which will be discussed in detail in the subsequent paragraph. GemFilter and PyramidInfer prune tokens directly during prefilling, which may discard contextual information from critical tokens and result in notable performance degradation. Although FTP enables token skipping, it relies on outdated and redundancy affected proxy signals, thus resulting in significant accuracy loss under high acceleration ratios. Overall, these results indicate that, by enabling more comprehensive token skipping and leveraging more informative token selection signals, our method more effectively preserves and extracts critical information from long input sequences without relying on heavy auxiliary operations. Moreover, the consistent improvements across models of varying structures, scales, and diverse hardware platforms highlight the strong generalization capability of our approach. On Efficiency Following Long et al. (2025) , we sample input sequences of four different lengths ( 8 8 K, 16 16 K, 24 24 K and 32 32 K) from LongBench Bai et al. (2024) to assess inference efficiency. For each context length, 20 distinct sequences are sampled, and the corresponding latencies are measured and averaged, with all speed tests conducted after a warmup process. We evaluate both the TTFT acceleration ratio and the E2E acceleration ratio across different methods. The full model using dense FlashAttention Dao (2024) serves as the baseline. As shown in Figure 3 , our proposed SPTS consistently accelerates both the prefilling and decoding phases, with speedup ratios increasing as the context length grows. At a context length of 32 32 K, it achieves 2.46 × \times and 2.29 × \times acceleration for TTFT and E2E latencies, respectively. Importantly, these efficiency gains are obtained while maintaining state-of-the-art average accuracy in Table 1 , highlighting the significant efficiency potential of our method in long-context inference scenarios.
