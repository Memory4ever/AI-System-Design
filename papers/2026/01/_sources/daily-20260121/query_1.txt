# [Bug] A single corrupt session artifact prevents dsh web from booting (0.1.0-rc.6 / 0.1.1-rc.2) #1473

[Bug] A single corrupt session artifact prevents dsh web from booting (0.1.0-rc.6 / 0.1.1-rc.2) #1473

Aug 14, 2026 · 7 comments

ConradLu2740 Aug 14, 2026

### Summary

A single corrupted (or mis-framed) session artifact under `~/.dsh/sessions/<workspace>/` makes `dsh web` fail to boot entirely. During startup, `@deepseek-ai/dsh-workspace` calls `sessionPersistence.list()`, which reads/validates the first zstd frame of every session. When one artifact fails header validation, the throw propagates through `list()` → the `workspace` loader entry → the whole plugin tree fails to load and the process exits. --------------------------------------------------------------------------------
