# arXiv announcement 条件日期证据

核验于 2026-10-03；primary source：https://info.arxiv.org/help/availability.html 。本页是官方通用排程/ID赋予规则，**不是逐篇首次公开日志**。

官方原文必要句：The final arXiv identifier is assigned as part of the automated process when the work is announced. It is not possible to generate or to be provided with the arXiv identifier or DOI in advance.

官方同时说明 ID 不可 back-date，按首次 announcement 的月份赋予；质量检查可能延后，正文在 scheduled announcement 中公开。排程：Thursday 14:00–Friday 14:00 Eastern US → Sunday 20:00 Eastern US。2026-01-09 为 EST；本日通常 batch 下界 2026-01-12T09:00:00+08:00。

本轮独立 root 日期审查允许的推定：逐 ID 的正常 v1 Submitted 落上述 cutoff，配合同一 ID 的真实 DataCite registered 字段，且没有具名提前公开/延期异常信号，可写 `[2026-01-12T09:00:00+08:00, registered换算北京时间]` 为完全落窗的**推定公告区间**。registered 只为 ID 已存在/公开的上界，不冒充正文首次公开分秒；Updated/PDF Last-Modified 都不单独授公开时刻，created 不采用。若有反向信号须具名隔离。
