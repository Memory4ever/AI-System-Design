where [\,\cdot\,;\,\cdot\,] denotes feature concatenation. Layer Normalization (LN) stabilizes feature distributions, and three learnable MLPs (\text{MLP}_{i}^{Q}, \text{MLP}_{i}^{K}, \text{MLP}_{i}^{V}) project them into the attention space.
A standard cross-attention operation then computes attention weights between the mainstream Query and guidance Key, producing a weighted sum of Value vectors. The result is integrated into the mainstream feature via a residual connection:
\hat{p}_{i}^{m}=p_{i}^{m}+\text{CrossAttention}(Q_{i},K_{i},V_{i})
(19)
This mechanism enables the mainstream branch to dynamically query the guidance sub-branches and selectively integrate fine-grained and contextual information, rather than performing static feature fusion.
