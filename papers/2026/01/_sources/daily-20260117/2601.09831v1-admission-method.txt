2.1 PnP-PGD with Mismatched Denoiser
(PGD) alternates between a proximal operation on g and a gradient descent step on f, when f is differentiable. PnP methodology proposes to replace the proximal operator by a more general denosier \mathsf{D}(\cdot), such as BM3D or CNN. Then, (PGD) can be summarized as
(PnP-PGD)
\begin{cases}\boldsymbol{z}_{k+1}&=\boldsymbol{x}_{k}-\lambda\nabla f(\boldsymbol{x}_{k})\\
\boldsymbol{x}_{k+1}&=\mathsf{D}_{\sigma}(\boldsymbol{z}_{k+1}),\end{cases}
where by analogy to \tau in Eq. (2), we introduce the parameter \sigma>0 for controlling the relative strength of the denoiser \mathsf{D}_{\sigma}.
We denote the target distribution as p_{\boldsymbol{x}}, suppose that the denoiser \mathsf{D}_{\sigma} is a MMSE estimator for the AWGN denoising problem
(3)
\boldsymbol{v}=\boldsymbol{x}+\boldsymbol{e}\quad\text{with}\quad\boldsymbol{x}\sim p_{\boldsymbol{x}},\quad\boldsymbol{e}\sim\mathcal{N}(0,\sigma^{2}\boldsymbol{I}).
The MMSE denoiser is the conditional mean estimator for Eq. (3) and can be expressed as
(4)
\mathsf{D}_{\sigma}(\boldsymbol{v})\mathrel{\mathop{\ordinarycolon}}=\mathbb{E}[\boldsymbol{x}|\boldsymbol{v}]=\int_{\mathbb{R}^{n}}\boldsymbol{x}p_{\boldsymbol{x}|\boldsymbol{v}}(\boldsymbol{x}|\boldsymbol{v})\,\mathrm{d}\boldsymbol{x},
where p_{\boldsymbol{x|v}}(x|v)\propto G_{\sigma}(\boldsymbol{v}-\boldsymbol{x})p_{\boldsymbol{x}}(\boldsymbol{x}), with G_{\sigma} denoting the Gaussian density. Since the above integral is generally intractable, in practice, the denoiser corresponds to a deep model trained to minimize the mean squared error (MSE) loss
(5)
\mathcal{L}(\mathsf{D}_{\sigma})=\mathbb{E}\left[\|\boldsymbol{x}-\mathsf{D}_{\sigma}(\boldsymbol{v})\|_{2}^{2}\right].
where the solution of Eq. (5) satisfies Eq. (4).
When using a mismatched prior with a mismatched distribution \widehat{p}(\boldsymbol{x}), we replace the target denoiser \mathsf{D}_{\sigma} in (PnP-PGD) with
\boldsymbol{x}_{k+1}=\widehat{\mathsf{D}}_{\sigma}(\boldsymbol{z}_{k+1}),
where \widehat{\mathsf{D}}_{\sigma} is the mismatched MMSE denoiser.

2.2 Theoretical Analysis
Recently introduced Gradient-Step (GS) Denoiser (Hurault et al., 2022a; Cohen et al., 2021) writes
(6)
\mathsf{D}_{\sigma}=\nabla h_{\sigma},
with a potential
(7)
h_{\sigma}\mathrel{\mathop{\ordinarycolon}}\boldsymbol{x}\to\frac{1}{2}\|\boldsymbol{x}\|^{2}-g_{\sigma}(\boldsymbol{x}).
We first have that if h_{\sigma} is convex, the GS denoiser \mathsf{D}_{\sigma}=\nabla h_{\sigma} is linked to the proximal operator of some function (Gribonval and Nikolova, 2020)
(8)
\phi_{\sigma}\mathrel{\mathop{\ordinarycolon}}\mathbb{R}^{n}\to\mathbb{R}\cup\{+\infty\}\mathrel{\mathop{\ordinarycolon}}\forall\boldsymbol{x}\in\mathbb{R}^{n},D_{\sigma}(\boldsymbol{x})\in\mathsf{prox}_{\phi_{\sigma}}(\boldsymbol{x})=\mathop{\arg\min}_{\boldsymbol{z}}\frac{1}{2}\|\boldsymbol{x}-\boldsymbol{z}\|^{2}+\phi_{\sigma}(\boldsymbol{z}).
The next proposition shows that, if the residual \text{I}d-\mathsf{D}_{\sigma} is contractive, there exists a closed-form and smooth \phi_{\sigma} such that \mathsf{D}_{\sigma}=\mathsf{prox}_{\phi_{\sigma}} is single-valued.
Proposition 2.1 ((Hurault et al., 2022b)).
Let \mathcal{X} be an open convex subset of \mathbb{R}^{n} and g_{\sigma}\mathrel{\mathop{\ordinarycolon}}\mathcal{X}\to\mathbb{R} a \mathcal{C}^{k+1} function with k\geq 1 and \nabla g_{\sigma} L-Lipschitz with L<1. Then, for h_{\sigma}\mathrel{\mathop{\ordinarycolon}}\boldsymbol{x}\to\frac{1}{2}\|\boldsymbol{x}\|^{2}-g_{\sigma}(\boldsymbol{x}) and \mathsf{D}_{\sigma}\mathrel{\mathop{\ordinarycolon}}=\nabla h_{\sigma}=\text{I}d-\nabla g_{\sigma},
(i)
h_{\sigma} is (1-L)-strongly convex and \forall\boldsymbol{x}\in\mathcal{X}, J_{\mathsf{D}_{\sigma}}(\boldsymbol{x}) is positive define;
(ii)
\mathsf{D}_{\sigma} is injective, \mathrm{Im}(\mathsf{D}_{\sigma}) is open and, \forall\boldsymbol{x}\in\mathcal{X}, \mathsf{D}_{\sigma}(\boldsymbol{x})=\mathsf{prox}_{\phi_{\sigma}}(\boldsymbol{x}), with \phi_{\sigma}\mathrel{\mathop{\ordinarycolon}}\mathcal{X}\to\mathbb{R}\cup\{+\infty\} defined by
(9)
\phi_{\sigma}(\boldsymbol{x})\mathrel{\mathop{\ordinarycolon}}=\left\{\begin{array}[]{lc}\left.g_{\sigma}\left(\mathsf{D}_{\sigma}^{-1}(\boldsymbol{x})\right)\right)-\frac{1}{2}\left\|\mathsf{D}_{\sigma}^{-1}(\boldsymbol{x})-\boldsymbol{x}\right\|^{2}&\text{ if }\boldsymbol{x}\in\operatorname{Im}\left(\mathsf{D}_{\sigma}\right),\\
+\infty&\text{ otherwise },\end{array}\right.
(iii)
\phi_{\sigma} is \mathcal{C}^{k} on \mathrm{Im}(\mathsf{D}_{\sigma}) and \forall\boldsymbol{x}\in\mathsf{D}_{\sigma}, \nabla\phi_{\sigma}(\boldsymbol{x})=\mathsf{D}_{\sigma}^{-1}(\boldsymbol{x})-\boldsymbol{x}=\nabla g_{\sigma}(\mathsf{D}_{\sigma}^{-1}(\boldsymbol{x}));
(v)
\nabla\phi_{\sigma} is \frac{L}{1-L}-Lipschitz on \mathrm{Im}(\mathsf{D}_{\sigma}).
Remark 2.1.
Note that \phi_{\sigma} being possibly nonconvex, and also note that \mathsf{D}_{\sigma} is possibly not nonexpansive.
In the following, we study the convergence of the PnP-PGD with a target denoiser \mathsf{D}_{\sigma}=\mathsf{prox}_{\phi_{\sigma}} that corresponds to the proximal operator of a nonconnvex regularization function \phi_{\sigma}, as well as a mismatched denoiser \widehat{\mathsf{D}}_{\sigma} corresponds to a deep model trained to minimize the MSE loss. For that propose, we re-target the objective function
(10)
F_{\lambda,\sigma}\mathrel{\mathop{\ordinarycolon}}=\lambda f+\phi_{\sigma},
where f is a data-fidelity term, \lambda is a regularization parameter and \phi_{\sigma} is defined as in Proposition 2.1 from the function g_{\sigma} satisfying \mathsf{D}_{\sigma}=\text{I}d-\nabla g_{\sigma}. The analysis relies on the following set of assumptions that serve as sufficient conditions.
Assumption 2.1.
f\mathrel{\mathop{\ordinarycolon}}\mathbb{R}^{n}\to\mathbb{R}\cup\{+\infty\} differentiable with L_{f}-Lipschitz gradient.
This assumption is a standard assumption used in nonconvex optimization.
Assumption 2.2.
g_{\sigma}\mathrel{\mathop{\ordinarycolon}}\mathcal{X}\to\mathbb{R} a \mathcal{C}^{2} function and \nabla g_{\sigma} L-Lipschitz with L<1.
Instead of requiring \mathsf{D}_{\sigma} is contractive, Assumption 2.2 assumes that Id-\mathsf{D}_{\sigma} is contractive, which is a relaxed assumption as in (Ryu et al., 2019). Besides, If \nabla g_{\sigma} has Lipschitz constant L>1, we can introduce 0<\alpha<\frac{1}{L} and relax the denoising operation by replacing D_{\sigma} with D_{\sigma}^{\alpha}=\alpha D_{\sigma}+(1-\alpha)Id=Id-\alpha\nabla g_{\sigma}, then we can define \phi_{\sigma}^{\alpha} from \alpha g_{\sigma} and using the modified PnP-PGD x_{k+1}=D_{\sigma}^{\alpha}(x_{k}-\lambda\nabla f(x_{k})), then we can get the same convergence result of scenario with \nabla g_{\sigma} has Lipschitz constant L<1.
