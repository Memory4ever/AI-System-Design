Token consumption is only known after an LLM call completes, not during execution:\nL225: \nL226:  | $$c_{tok}(t)=\\begin{cases}\\text{unknown}&\\text{during API call}\\\\\nL227: c_{actual}&\\text{after API returns}\\end{cases}$$  |\nL228: Even streaming APIs provide total usage metadata only after generation completes.
