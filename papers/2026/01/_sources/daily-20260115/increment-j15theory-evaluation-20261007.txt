L371: ### IV-F Time Complexity
L372: HypHGT consists of two main components for heterogeneous graph representation learning: hyperbolic heterogeneous graph transformer and heterogeneous GNNs. As shown in Equation cite88†14 , the hyperbolic heterogeneous graph transformer performs an inner product between $K_{\epsilon}^{sT}$ and $V_{\epsilon}^{s}$ within the Lorentz model corresponding to each relation type $\epsilon$.
L373: This process has a time complexity of $O(|T_{\mathcal{E}}|\cdot d^{2}\cdot|\mathcal{T}|)$, where $T_{\mathcal{E}}$ and $\mathcal{T}$ denotes a set of relation types and target nodes, respectively. Subsequently, an inner product is performed between $Q_{\epsilon}^{s}$ and the output of $K^{{}^{s}T}_{\epsilon}V^{s}_{\epsilon}$, which has a time complexity of $O(|T_{\mathcal{E}}|\cdot d^{2}\cdot(|\mathcal{S}+\mathcal{T}|))$, where $\mathcal{S}$ denotes set of source nodes.
L374: Therefore, the total time complexity of hyperbolic heterogeneous graph transformer is $O(|\mathcal{S}+\mathcal{T}|)\approx O(N)$. Meanwhile, the time complexity of heterogeneous GNNs is $O(|T_{\mathcal{E}}|\cdot(N+E))$. Consequently, our proposed model HypHGT has a linear-time complexity overall, which enables efficient and scalable heterogeneous graph representation learning even on large-scale graphs.

L258: ### 3.4 From sparse learning to control: value sensitivity
L259: 
L260: Support recovery and parameter estimation are useful only insofar as they translate into control performance. We therefore isolate a generic condition under which policy/value performance is Lipschitz in the parameter vector.
