L364: ###### Lemma A.1 (Length-Invariant Owen Redistribution).
L365: 
L366: Let $y^{(g)}$ be a generated sequence of length $T$ from a Monte Carlo rollout with reward $R^{(g)}$. Following the REINFORCE algorithm (cite78†Williams, 1992b ; cite132†Kool et al., 2019 ; cite69†Shao et al., 2024a ) of sampling rollouts without replacement with baseline subtraction, define the sequence-level advantage as:
L367: 
L368:  | $$\hat{A}^{(g)}=R^{(g)}-\bar{R},\quad\text{where }\bar{R}=\frac{1}{G}\sum_{g^{\prime}=1}^{G}R^{(g^{\prime})},$$  |  | (9)
L369: is the mean reward across $G$ sampled rollouts. Let $\{\phi_{t}^{(g)}\}_{t=1}^{T}$ denote Owen values satisfying the efficiency axiom $\sum_{t=1}^{T}\phi_{t}^{(g)}=R^{(g)}$ (cite185†Cheng-Guo et al., 2014 ; cite107†Owen, 2014 ). Define the normalized Owen values as $\tilde{\phi}_{t}^{(g)}=\phi_{t}^{(g)}/\sum_{t^{\prime}=1}^{T}\phi_{t^{\prime}}^{(g)}$, and the redistributed token advantages as:
L370: 
L371:  | $$A_{t}^{(g)}=T\cdot\tilde{\phi}_{t}^{(g)}\cdot\hat{A}^{(g)}.$$  |  | (10)
L372: Then the average token advantage equals the original sequence-level advantage, independent of sequence length:
L373: 
L374:  | $$\frac{1}{T}\sum_{t=1}^{T}A_{t}^{(g)}=\hat{A}^{(g)}.$$  |  | (11)
L375: ###### Proof.
L376: 
L377: To prove this, starting from the definition of the redistributed token advantages, we compute the average:
L378: 
L379:  | $\displaystyle\frac{1}{T}\sum_{t=1}^{T}A_{t}^{(g)}$  | $\displaystyle=\frac{1}{T}\sum_{t=1}^{T}\left(T\cdot\tilde{\phi}_{t}^{(g)}\cdot\hat{A}^{(g)}\right)$  |  | (12)
L380:  |  | $\displaystyle=\frac{T}{T}\cdot\hat{A}^{(g)}\sum_{t=1}^{T}\tilde{\phi}_{t}^{(g)}$  |  | (13)
L381:  |  | $\displaystyle=\hat{A}^{(g)}\sum_{t=1}^{T}\tilde{\phi}_{t}^{(g)}.$  |  | (14)
L382: Now we evaluate the sum of normalized Owen values. By the definition of $\tilde{\phi}_{t}^{(g)}$:
L383:  | $\displaystyle\sum_{t=1}^{T}\tilde{\phi}_{t}^{(g)}$  | $\displaystyle=\sum_{t=1}^{T}\frac{\phi_{t}^{(g)}}{\sum_{t^{\prime}=1}^{T}\phi_{t^{\prime}}^{(g)}}$  |  | (15)
L384:  |  | $\displaystyle=\frac{1}{\sum_{t^{\prime}=1}^{T}\phi_{t^{\prime}}^{(g)}}\sum_{t=1}^{T}\phi_{t}^{(g)}$  |  | (16)
L385:  |  | $\displaystyle=\frac{\sum_{t=1}^{T}\phi_{t}^{(g)}}{\sum_{t^{\prime}=1}^{T}\phi_{t^{\prime}}^{(g)}}$  |  | (17)
L386:  |  | $\displaystyle=\frac{\sum_{t=1}^{T}\phi_{t}^{(g)}}{\sum_{t=1}^{T}\phi_{t}^{(g)}}$  |  | (18)
L387:  |  | $\displaystyle=1.$  |  | (19)
L388: Substituting this result back into equation (3), we obtain:
L389: 
L390:  | $$\frac{1}{T}\sum_{t=1}^{T}A_{t}^{(g)}=\hat{A}^{(g)}\cdot 1=\hat{A}^{(g)}.$$  |  | (20)
L391: 
L392: This equality holds for any sequence length $T>0$, proving that the redistribution scheme is length-invariant. ∎
L393: ###### Remark A.2.
L394: 
L395: Lemma cite133†A.1 guarantees three critical properties for OSPO’s credit assignment:
L396: 
L397:   1. 1.
L398: 
L399: Scale Preservation: The average token advantage matches the original sequence-level advantage $\hat{A}^{(g)}=R^{(g)}-\bar{R}$, ensuring gradient magnitudes in cite186†Equation 7 remain comparable across sequences of different lengths.
L400: 
L401:   2. 2.
L402: Length Invariance: A sequence’s total gradient contribution depends on its advantage $\hat{A}^{(g)}$ and Owen-based credit distribution $\{\tilde{\phi}_{t}^{(g)}\}$, not its verbosity. This eliminates the length bias where longer sequences (e.g., detailed user summaries with $T>100$) would otherwise receive disproportionately small gradient signals when Owen values are naively redistributed.
L403: 
L404:   3. 3.
L405: Credit Prioritization: High-value tokens (e.g., product-specific attributes) receive proportionally more advantage than low-value tokens (e.g., filler words or inconsistent reasoning), while maintaining consistency with the per-token policy gradient formulation. Specifically, if $\tilde{\phi}_{i}>\tilde{\phi}_{j}$, then $A_{i}^{(g)}>A_{j}^{(g)}$, preserving the ordinal ranking of token contributions.
L406: ###### Remark A.3 (Connection to the Efficiency Axiom).
L407: 
L408: The normalization step $\tilde{\phi}_{t}=\phi_{t}/\sum_{t^{\prime}}\phi_{t^{\prime}}$ is essential because Owen values satisfy the efficiency axiom: $\sum_{t=1}^{T}\phi_{t}=R^{(g)}$ (the terminal reward). Without the length multiplication factor $T$, a naive proportional redistribution $\tilde{A}_{t}=\hat{A}^{(g)}\cdot\tilde{\phi}_{t}$ would yield an average advantage of:
L409:  | $$\frac{1}{T}\sum_{t=1}^{T}\tilde{A}_{t}=\frac{\hat{A}^{(g)}}{T}\sum_{t=1}^{T}\tilde{\phi}_{t}=\frac{\hat{A}^{(g)}}{T},$$  |  | (21)
L410: 
L411: introducing a $1/T$ dilution effect where longer sequences receive significantly weaker gradient signals. The multiplication by $T$ precisely counteracts this dilution, ensuring that gradient magnitude depends on the quality of the generation (via $\hat{A}^{(g)}$) rather than its length.
L412: ### A.2 Length-Invariant Credit Redistribution for GRPO
L413: Group Relative Policy Optimization (GRPO) (cite69†Shao et al., 2024a ) computes sequence-level advantages by normalizing rewards within a sampled group, but assigns this advantage uniformly to all tokens in the sequence.
L414: This uniform assignment creates a fundamental tension: when combined with the standard per-token gradient normalization $\frac{1}{|y|}$, GRPO exhibits length-dependent bias where positive advantages produce stronger gradients for shorter sequences, while negative advantages under-penalize verbose failures (cite119†Liu et al., 2025 ). This bias is particularly problematic in recommendation tasks where response length varies significantly—from terse product queries to detailed user preference summaries.
L415: Our approach leverages Owen-Shapley values to redistribute the sequence-level GRPO advantage to individual tokens while explicitly eliminating length bias. Given a sequence $y$ with GRPO advantage $\hat{A}$ and Owen values $\{\Phi_{t}\}_{t=1}^{|y|}$ (obtained via the efficient approximation in cite11†Section 3.1 ), we face a redistribution challenge. A naive proportional approach would compute token advantages as $\tilde{A}_{t}=\hat{A}\cdot\frac{\Phi_{t}}{\sum_{t^{\prime}}\Phi_{t^{\prime}}}$.
L416: However, since Owen values satisfy the efficiency axiom ($\sum_{t}\Phi_{t}=R$, where $R$ is the terminal reward), this denominator equals the reward $R$, causing per-token advantages to scale as $\hat{A}/R$. For sequences with correlated advantages and rewards, this creates the same length bias as vanilla GRPO, where the average token advantage $\frac{1}{|y|}\sum_{t}\tilde{A}_{t}\propto\frac{1}{|y|}$.
L417: To eliminate this dependency, we propose two redistribution strategies that multiply the proportional allocation by sequence length $|y|$, ensuring the average token advantage equals the original GRPO advantage regardless of sequence length. This length normalization is critical: it decouples gradient magnitude from verbosity while preserving Owen-based prioritization of important tokens.
L418: ##### Proportional Owen Redistribution.
L419: 
L420: Our first approach uses Owen values directly as importance weights:
L421: 
L422:  | $$\tilde{A}_{t}^{\text{prop}}=\hat{A}\cdot\frac{\Phi_{t}}{\sum_{t^{\prime}}\Phi_{t^{\prime}}}\cdot|y|$$  |  | (22)
L423: This strategy assigns credit proportional to each token’s marginal contribution, as quantified by its Owen value. L254: ##### OSPO Demonstrates Superior Generalization
L255: Figure cite151†3 (right) reveals that OSPO (no-clip) exhibits stable improvement on test data throughout training (reaching NDCG $\approx$ 0.45), while GRPO shows catastrophic performance collapse around step 400-750. L256: Two behavioral markers explain this pattern: First, GRPO (cite69†Shao et al., 2024a ) systematically reduces thinking tokens (roughly around 300th step mark) compared to OSPO variants precisely when test performance degrades (See cite151†Figure 3 (left)) , while OSPO maintains consistently longer reasoning traces.
L257: Second, GRPO’s reward variance drops sharply toward 0.30 by training end, compared to OSPO’s maintained higher variance (0.34-0.36), indicating GRPO converges to consistent but limited solutions that exploit training patterns without transferring to unseen data.
L258: We additionally performed a cross-retriever evaluation to assess generalization across embedding spaces at test time. In the first setting, RL baselines trained on the ESCI domain with dense rewards from all-mpnet-base-v2 embeddings were evaluated under a retriever shift using SIMCSE-Large. In the reverse setting, these baselines trained on the H&M domain with a SIMCSE-Large FAISS index were tested using all-mpnet-base-v2.
L259: To provide a complete comparison, we also evaluated non-RL baselines and base models under the same shifts. As shown in cite152†Table 4 in Appendix cite45†A.5 , OSPO sustains strong ranking performance in both transfer directions, whereas GRPO degrades sharply, confirming that OSPO learns a more transferable and retriever-agnostic alignment signal.
L260: ##### Coalition Structure Drives OSPO Performance
L261: OSPO’s performance is governed by the interaction between coalition width, exploration depth, and contiguity. As shown in Fig. cite153†Figure 2 (left), moderately wide coalitions (w8–p96) strike the best balance between local compositional context and sampling diversity (NDCG 0.782). Narrow coalitions overfit to token-level co-occurrences, while overly wide coalitions dilute credit assignment and degrade performance (NDCG 0.595).
L262: Exploration is equally critical: reducing generations (rollouts) from eight to two (Fig. cite153†Figure 2 , middle) causes a sharp drop in accuracy, highlighting the need for sufficient Monte Carlo sampling. Finally, removing the contiguity constraint (Fig. cite153†Figure 2 , right) leads to a dramatic collapse in performance (NDCG 0.113), as non-contiguous coalitions disperse credit across unrelated segments.
L263: Overall, OSPO performs best with contiguous, moderately wide coalitions and adequate sampling, yielding more stable and generalizable credit assignment.

L269: ## 6 Conclusion and Future Work
L270: We introduced Owen–Shapley Policy Optimization (OSPO), a reinforcement learning framework that directly tackles the credit assignment problem in language-driven recommendation systems. By decomposing sequence-level rewards into segment-level attributions through cooperative game theory, OSPO enables precise gradient updates without relying on auxiliary value networks.
L271: Across product search and user summarization tasks, OSPO consistently outperforms both online and offline baselines, achieving ranking performance comparable to models an order of magnitude larger. This efficiency arises from its attribution-driven optimization, which focuses updates on the sequence segments that meaningfully influence task outcomes. Even with unseen retrievers, OSPO preserves robust performance, showing that its alignment signal transfers across feedback models and representation spaces.
L272: Ablation studies further highlight the importance of its coalition structure: moderate-width, contiguous, and sufficiently sampled coalitions act as an intrinsic regularizer that stabilizes learning and improves generalization. In summary, OSPO learns not by memorizing feedback patterns but by leveraging principled coalition-based attributions that promote stable, transferable, and interpretable behaviors.
L273: Future work can extend these ideas to multi-turn, agentic environments and broader reasoning domains such as code generation, dialogue planning, and interactive decision-making.

L241: #### Analysis of Fusing Strategies
L242: 
L243: We examine ORBIT’s fusing strategy by replacing on-policy fusion with offline distillation, where consolidation proceeds without additional on-policy rollouts, relying instead on a pre-sampled dataset from the exploration-stage frontier models. Both variants are initialized from the same merged model to minimize behavioral inconsistency.
L244: As shown in Figure cite76†4 , on-policy fusion achieves slightly higher performance than offline distillation, while overall stability and convergence remain comparable. This outcome can be attributed to the strong framework-level alignment in ORBIT: all teacher and student models share a sequential training with same base model trained on same data with same algorithm, effectively reducing policy mismatch and rendering offline distillation in this setting closer to a semi-offline procedure.
L245: Beyond performance, on-policy fusion provides operational advantages: it generates rollouts dynamically, adapts convergence on-the-fly, and integrates naturally with RL-based correctness signals. In contrast, offline distillation decouples dataset construction from training, allowing for scalable evaluation via pre-collected datasets, which can be leveraged in techniques like Rejection Fine-tuning.
L246: The choice between these strategies, or their combination, can be tailored depending on specific application requirements.

L254: ## 6 Related Work
L255: #### Reasoning Effort Adjustment in LRMs
L256: Existing works on reasoning effort adjustment primarily target overthinking through RL-based length penalties (cite65†Aggarwal and Welleck, 2025 ; cite66†Arora and Zanette, 2025 ; cite79†Yi et al., 2025 ; cite45†Zhang et al., 2025 ; cite67†Fang et al., 2025 ; cite43†Lou et al., 2025 ), verification training (cite80†Chen et al., 2025b ), early exit strategies (cite81†Yang et al., 2025a ; cite82†Jiang et al., 2025 ), or inference-time interventions (cite83†Wang et al., 2025 ).
L257: Few lines of methods tackle the underthinking problem by decoding time intervention (cite84†Muennighoff et al., 2025 ; cite49†Jin et al., 2025 ). ORBIT try to tackle these problems by offering flexible reasoning modes at inference time.
L258: #### Controllable Reasoning Generation
L259: Prior work for reasoning control can be boradly categroized in two main streams (1) Hard Token Budget Constraint: A common approach enforces reasoning efficiency through externally specified constraints, most notably by fixing explicit token budgets that cap the length of intermediate reasoning cite84†Muennighoff et al. (2025) ; cite85†Sun et al. (2025) ; cite65†Aggarwal and Welleck (2025) ; cite86†Anthropic (2025) , relying on an absolute tokenwise budget estimation across all inputs.
L260: (2) Discrete-Mode Systems: offer an intuitional discrete reasoning levels, enabling users to explicitly specify their preference for the efficiency-performance trade-off cite63†OpenAI (2025a) ; cite64†He et al. (2025) , representing a soft form of control based on model’s own capability.
L261: ## 7 Conclusion
L262: In this paper, we propose ORBIT, a fully on-policy training framework for controllable reasoning models that operates at a target reasoning level while maintaining high reasoning density under a given context. We leverage a simple yet effective truncation reward and adopt a one-time expansion-compression loop strategy to explore the reasoning frontier.
