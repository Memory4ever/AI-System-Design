How can the system guarantee that aggregate consumption respects the original constraint?\nL169: These questions have theoretical grounding in coordination theory. Malone and Crowston (1994) [cite50†37 ] identified managing shared resources as a fundamental coordination problem. We focus here on two typical control flow patterns, task routing and delegation decisions, since these are where contracts add the most value. Execution within any pattern can be sequential or parallel; these are orthogonal concerns that compose naturally (as we discuss below).\nL202: Routing. An input classifier directs requests to specialized handlers based on task characteristics, selecting the best-suited agent for each input and allocating the corresponding budget [cite97†3 ]. Budget is reserved per potential branch; unused allocations return to the pool. This enables separation of concerns— specialized agents outperform generalists on their specific tasks.\nL203: When specialists have explicit contracts, routing becomes more principled: the router matches task requirements against specialist capabilities, resource profiles, and success criteria.
