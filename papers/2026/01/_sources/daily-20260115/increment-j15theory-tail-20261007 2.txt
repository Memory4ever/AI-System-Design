L196: ### 3.2 Causal vs Epistemic Transitions
L197: 
L198: Definition 4 (causal transition): An operation that changes system state.
L199: 
L200: Definition 5 (epistemic transition): An operation that increases epistemic warrant of a proposition.
L201: 
L202: Key distinction: A tool call is causal by default and epistemically inert unless typed otherwise. Causal relevance (the tool changes system state) does not entail epistemic relevance (an increase in epistemic warrant).
L203:  | $$\text{causal\_inferences}(P_{2})\neq\text{epistemic\_inferences}(P_{2})$$  |
L204: 
L205: In particular, a tool boundary may causally transform $P_{1}$ into $P_{2}$ without providing any epistemic grounding for $P_{2}$.
L206: ### 3.3 Warrant Erosion Principle
L207: 
L208: Definition 6 (warrant erosion): Interpreting or generative operations do not automatically preserve epistemic warrant, since they may break the connection between a proposition and its truth-maker.
L209: Clarification: The Warrant Erosion Principle does not claim that all interpretation destroys knowledge or makes it impossible. It claims a weaker and architecturally significant position: epistemic warrant is not automatically preserved through interpreting or generative transformations unless the architecture specifies explicit epistemic guarantees for preserving the connection between proposition and truth-maker.
L210: Justification: Any epistemic access available to an agent is mediated — through cognitive, instrumental, or formal processes. This mediation means that the connection between a proposition and what makes it true is not automatically preserved through transformations; similar diagnostic concerns have been articulated in the Epistemic Suite [cite59†ref-kelly2025EpistemicSuitePostFoundational ], which surfaces confidence laundering and other epistemic distortions in AI outputs.
L211: Corollary 1: Gettier situations are not anomalies, but structural invariants of systems that generate epistemic claims through mediated processes without explicit warrant preservation.
L212: 
L213: Corollary 2: Improving generation quality (more coherent argumentation, better approximation) is not epistemically relevant if the observation set $O$ has not changed. Quality of generation $\neq$ quality of warrant.
L214: Connection to Gettier: Warrant erosion explains this gap: the connection to truth-makers is not preserved by default once justification passes through interpreting processes.
L215: ### 3.4 Theorem: Inevitable Self-Licensing
L216: 
L217: Theorem 1 (Inevitable Self-Licensing)
L218: Note on scope: This is an impossibility result under given architectural assumptions. The assumptions formulated below are not logically necessary, but they correspond to the dominant architectural pattern of contemporary agent frameworks ([cite50†ref-yao2023ReActSynergizingReasoning ], [cite51†ref-chase2022LangChain ], [cite52†ref-2026NVlabsToolOrchestra ], and similar). The theorem asserts that within this architectural paradigm, circular epistemic justification cannot be eliminated.
L219: 
L220: Assumptions:
L221: 
L222:   1. 1.
L223: Agent and tool outputs belong to the same proposition type $P$ and are treated by the architecture as interchangeable. Intuitively, this means that agent and tool outputs are processed by the architecture as elements of the same proposition space, without distinction by epistemic role.
L224: 
L225:   2. 2.
L226: 
L227: Tool call results are accepted as observations $O\subset P$ without regard to the epistemic type of the tool (see §3.5)
L228: 
L229:   3. 3.
L230: The architecture assigns epistemic status to propositions via a function $A:P\to\{\text{ASSERTIVE},\text{CONDITIONAL},\text{REFUSAL}\}$, and LLM-generated propositions may influence this assignment.
L231: 
L232: Claim: Under these assumptions, circular epistemic justification is inevitable.
L233: Limitation of the result: The theorem does not claim that self-licensing is logically necessary for all agent architectures, nor does it claim a universal ontological conclusion. It establishes the impossibility of eliminating circular epistemic justification within the dominant architectural pattern, where epistemic roles of tools are not explicitly distinguished.
L234: 
L235: Proof sketch:
L236: 
L237: Let $\text{LLM}_{1}$ be the agent, $\text{LLM}_{2}$ be an “expert” tool.
L238: 
L239:   1. 1.
L240: $\text{LLM}_{1}$ generates proposition $p_{1}\in P$
L241: 
L242:   2. 2.
L243: 
L244: Tool $T$ wraps $\text{LLM}_{2}$ call: $p_{2}=T(\text{LLM}_{2}(p_{1}))$
L245: 
L246:   3. 3.
L247: 
L248: By Assumption 2: $p_{2}$ is accepted as observation, i.e., $p_{2}\in O$
L249: 
L250:   4. 4.
L251: 
L252: By Assumption 3: $p_{2}$ is used as input to the epistemic status function $A(p_{1})$
L253: 
L254:   5. 5.
L255: 
L256: Since $p_{2}\in P$, the status of $p_{1}$ is determined by a proposition of the same type
L257: 
L258:   6. 6.
L259: Therefore, $A(p_{1})$ is influenced by an element of $P$ produced by the same epistemic process as $p_{1}$ itself
L260: 
L261: Circular epistemic justification arises: propositions participate in assigning their own epistemic status via architectural mediation. $\blacksquare$
L262: 
L263: Corollary 3: Evaluation in LLM-as-judge schemes is structurally unsound if the evaluator and the evaluated agent operate in the same proposition space without epistemic typing.
L264: Corollary 4: Increasing model capability (e.g., replacing $\text{LLM}_{2}$ with a stronger one) does not eliminate self-licensing: the problem is architectural, not generative.

L266: 
L267: The critical weakness of Assumption 2 is that all tools are treated by the architecture as homogeneous. In practice, tools differ fundamentally in their epistemic character.

L556: ## 5 SAC under Partial Observability (POMDP / Belief-SAC View)
L557: In real tool-augmented LLM agents, the controller does not observe the latent environment state $s_{t}$. Instead it observes an interaction history (prompt, intermediate tool outputs, retrieved snippets, etc.), from which an LLM constructs an internal representation that is then used for tool selection. This is naturally modeled as a POMDP. The goal of this part is to isolate exactly where the language model matters: only through the quality of the induced belief/representation.
L558: Once this quality is quantified, the sparse-control guarantees from Part I transfer with an explicit degradation term.
