L232: ### Introduction
L233: 
L234: Qwen3-TTS covers 10 major languages (Chinese, English, Japanese, Korean, German, French, Russian, Portuguese, Spanish, and Italian) as well as multiple dialectal voice profiles to meet global application needs. In addition, the models feature strong contextual understanding, enabling adaptive control of tone, speaking rate, and emotional expression based on instructions and text semantics, and they show markedly improved robustness to noisy input text. Key features:
L235:   * Powerful Speech Representation: Powered by the self-developed Qwen3-TTS-Tokenizer-12Hz, it achieves efficient acoustic compression and high-dimensional semantic modeling of speech signals. It fully preserves paralinguistic information and acoustic environmental features, enabling high-speed, high-fidelity speech reconstruction through a lightweight non-DiT architecture.
L236:   * Universal End-to-End Architecture: Utilizing a discrete multi-codebook LM architecture, it realizes full-information end-to-end speech modeling. This completely bypasses the information bottlenecks and cascading errors inherent in traditional LM+DiT schemes, significantly enhancing the model’s versatility, generation efficiency, and performance ceiling.
L237:   * Extreme Low-Latency Streaming Generation: Based on the innovative Dual-Track hybrid streaming generation architecture, a single model supports both streaming and non-streaming generation. It can output the first audio packet immediately after a single character is input, with end-to-end synthesis latency as low as 97ms, meeting the rigorous demands of real-time interactive scenarios.
L238:   * Intelligent Text Understanding and Voice Control: Supports speech generation driven by natural language instructions, allowing for flexible control over multi-dimensional acoustic attributes such as timbre, emotion, and prosody. By deeply integrating text semantic understanding, the model adaptively adjusts tone, rhythm, and emotional expression, achieving lifelike “what you imagine is what you hear” output.

L272: ## Quickstart
L273: ### Environment Setup
L274: 
L275: The easiest way to quickly use Qwen3-TTS is to install the `qwen-tts` Python package from PyPI. This will pull in the required runtime dependencies and allow you to load any released Qwen3-TTS model. We recommend using a fresh, isolated environment to avoid dependency conflicts with existing packages. You can create a clean Python 3.12 environment like this:
L276: 
L277:     conda create -n qwen3-tts python=3.12 -y
L278:     conda activate qwen3-tts
L279: 
L280: then run:
L281: 
L282:     pip install -U qwen-tts
L283: If you want to develop or modify the code locally, install from source in editable mode.
L284: 
L285:     git clone https://github.com/QwenLM/Qwen3-TTS.git
L286:     cd Qwen3-TTS
L287:     pip install -e .
L288: 
L289: Additionally, we recommend using FlashAttention 2 to reduce GPU memory usage.
L290: 
L291:     pip install -U flash-attn --no-build-isolation
L292: 
L293: If your machine has less than 96GB of RAM and lots of CPU cores, run:
L294: 
L295:     MAX_JOBS=4 pip install -U flash-attn --no-build-isolation
L296: Also, you should have hardware that is compatible with FlashAttention 2. Read more about it in the official documentation of the cite118†FlashAttention repository . FlashAttention 2 can only be used when a model is loaded in `torch.float16` or `torch.bfloat16`.
L297: ### Python Package Usage
L298: 
L299: After installation, you can import `Qwen3TTSModel` to run custom voice TTS, voice design, and voice clone. The model weights can be specified either as a Hugging Face model id (recommended) or as a local directory path you downloaded. For all the `generate_*` functions below, besides the parameters shown and explicitly documented, you can also pass generation kwargs supported by Hugging Face Transformers `model.generate`, e.g., `max_new_tokens`, `top_p`, etc.
L300: #### Custom Voice Generate
L301: For custom voice models (`Qwen3-TTS-12Hz-1.7B/0.6B-CustomVoice`), you just need to call `generate_custom_voice`, passing a single string or a batch list, along with `language`, `speaker`, and optional `instruct`. You can also call `model.get_supported_speakers()` and `model.get_supported_languages()` to see which speakers and languages the current model supports.
L302: 
L303:     import torch
L304:     import soundfile as sf
L305:     from qwen_tts import Qwen3TTSModel
L306: 
L307:     model = Qwen3TTSModel.from_pretrained(
L308:         "Qwen/Qwen3-TTS-12Hz-1.7B-CustomVoice",
L309:         device_map="cuda:0",
L310:         dtype=torch.bfloat16,
L311:         attn_implementation="flash_attention_2",
L312:     )
L313: 
L314:     # single inference
L315:     wavs, sr = model.generate_custom_voice(
L316:         text="其实我真的有发现，我是一个特别善于观察别人情绪的人。",
L317:         language="Chinese", # Pass `Auto` (or omit) for auto language adaptive; if the target language is known, set it explicitly.
L318:         speaker="Vivian",
L319:         instruct="用特别愤怒的语气说", # Omit if not needed.
L320:     )
L321:     sf.write("output_custom_voice.wav", wavs[0], sr)
L322: 
L323:     # batch inference
L324:     wavs, sr = model.generate_custom_voice(
L325:         text=[
L326:             "其实我真的有发现，我是一个特别善于观察别人情绪的人。",

L330:         speaker=["Vivian", "Ryan"],

L383: #### Voice Clone
L384: For the voice clone model (`Qwen3-TTS-12Hz-1.7B/0.6B-Base`), to clone a voice and synthesize new content, you just need to provide a reference audio clip (`ref_audio`) along with its transcript (`ref_text`). `ref_audio` can be a local file path, a URL, a base64 string, or a `(numpy_array, sample_rate)` tuple. L422: #### Voice Design then Clone

This is especially useful when you want a consistent character voice across many lines.
