20: 3. Methods
21: 3.1. Setting and Control Contract
22: We study generative OCR with a frozen vision-language model (VLM) used as a black-box generator. Given an image crop I ∈ ℐ I\in\mathcal{I} , a fixed prompt template p p , and a fixed deterministic decoding configuration δ \delta , the frozen backbone returns
23: y = G δ ​ ( I , p , θ ) ∈ 𝒴 , θ ​ frozen . y=G_{\delta}(I,p;\theta)\in\mathcal{Y},\qquad\theta\ \text{frozen}.
24: We treat G δ G_{\delta} as the black-box mapping induced by the frozen backbone under the fixed prompt-and-decoding setup; model internals are not used, and control relies only on queried image views and returned strings.
25: Our goal is not to modify the backbone, but to place it inside a selective accept–abstain contract. Accordingly, the deployed OCR system is
26: f : ℐ → 𝒴 ∪ { ⊥ } , f:\mathcal{I}\to\mathcal{Y}\cup\{\bot\},
27: where ⊥ \bot denotes abstention. The map f f is induced by an inference-time evidence protocol π \pi and an acceptance rule applied to that evidence.
28: Specifically, a protocol π \pi extracts from the input crop a candidate transcription y ^ ​ ( I ) ∈ 𝒴 \hat{y}(I)\in\mathcal{Y} together with an evidence summary e ⁡ ( I ) e(I) . An acceptance rule A A then determines whether the candidate is exposed:
29: f π ​ ( I ) = { y ^ ​ ( I ) , if ​ A ​ ( e ⁡ ( I ) ) = 1 , ⊥ , otherwise. f_{\pi}(I)=\begin{cases}\hat{y}(I),&\text{if }A\!\big(e(I)\big)=1,\\ \bot,&\text{otherwise.}\end{cases}
30: Conventional frozen-VLM OCR is recovered as the degenerate always-accept case, in which the protocol reduces to a single standard query and the returned output is always exposed.
31: 3.2. Evidence Protocol: Multi-view Geometric Probing
32: We instantiate π \pi through multi-view probing of the same input crop. Let 𝒯 \mathcal{T} denote a family of admissible image transforms that apply mild geometric perturbations, such as small translations, crop jitter, or scale variation, while preserving nominal text content.
33: A fixed protocol π \pi specifies the transform family 𝒯 \mathcal{T} , a view-selection rule, and the total number of queried views K K . The original crop is always included as the anchor view,
34: T 1 = Id , I 1 = I . T_{1}=\mathrm{Id},\qquad I_{1}=I.
35: The remaining views are
36: I k = T k ( I ) , k = 2 , … , K , I_{k}=T_{k}(I),\qquad k=2,\dots,K,
37: where the selection rule for { T k } k = 2 K \{T_{k}\}_{k=2}^{K} is part of the protocol. In our implementation, the non-anchor transforms are sampled from a fixed distribution over admissible transforms. Each view is queried with the same prompt template and decoding configuration as in Sec. 3.1:
38: y k = G δ ( I k , p ; θ ) , k = 1 , … , K . y_{k}=G_{\delta}(I_{k},p;\theta),\qquad k=1,\dots,K.
39: This yields the evidence record
40: R π ​ ( I ) = { ( I k , y k ) } k = 1 K . R_{\pi}(I)=\{(I_{k},y_{k})\}_{k=1}^{K}.
41: Under the fixed protocol, we treat cross-view stability as an operational proxy for geometric support and cross-view disagreement as a risk signal. These exogenous signals are then used for accept–abstain control.

43: 3.3. Canonicalization and Structural Screening
44: To make cross-view evidence comparable under the fixed protocol, we first map each returned string to a canonical form
45: y ~ k = Norm ⁡ ( y k ) ∈ 𝒴 , \tilde{y}_{k}=\mathrm{Norm}(y_{k})\in\mathcal{Y},
46: where Norm ⁡ ( ⋅ ) \mathrm{Norm}(\cdot) is a protocol-fixed normalization rule that removes only presentation variance, such as whitespace normalization and, when specified by the task protocol, case canonicalization, without changing the underlying transcription content.
47: We then apply a structural screening rule
48: v k = 𝕀 [ y ~ k ∈ 𝒱 ] ∈ { 0 , 1 } , v_{k}=\mathbb{I}[\tilde{y}_{k}\in\mathcal{V}]\in\{0,1\},
49: where 𝒱 ⊆ 𝒴 \mathcal{V}\subseteq\mathcal{Y} is a protocol-fixed set of lightweight admissibility constraints. These constraints are label-agnostic and serve only to reject degenerate continuations, not to recognize text or estimate confidence.
50: The main admissibility constraint in 𝒱 \mathcal{V} is a conservative geometric length bound. For each view I k I_{k} , we compute an upper bound L geom ​ ( I k ) L_{\mathrm{geom}}(I_{k}) from foreground geometry after scale normalization and dominant-axis span estimation. A decoded string is marked invalid if
51: | y ~ k | > L geom ​ ( I k ) . |\tilde{y}_{k}|>L_{\mathrm{geom}}(I_{k}).
52: This bound is not intended to estimate the exact ground-truth length; it only suppresses implausibly overlong continuations.
53: The resulting processed evidence is
54: R ~ π ​ ( I ) = { ( y ~ k , v k ) } k = 1 K . \widetilde{R}_{\pi}(I)=\{(\tilde{y}_{k},v_{k})\}_{k=1}^{K}.
55: Let
56: Ω ⁡ ( I ) = { k : v k = 1 } , n ⁡ ( I ) = | Ω ⁡ ( I ) | . \Omega(I)=\{k:v_{k}=1\},\qquad n(I)=|\Omega(I)|.
57: All downstream evidence statistics are computed only over Ω ⁡ ( I ) \Omega(I) . This induces a minimum-evidence gate with threshold K min K_{\min} .
58: 3.4. Decision Functional: Consensus, Stability, and Operating-Point Control
59: For samples with n ⁡ ( I ) ≥ K min n(I)\geq K_{\min} , let s ∗ ​ ( I ) s^{*}(I) denote the unique mode of the valid canonicalized outputs { y ~ k : k ∈ Ω ⁡ ( I ) } \{\tilde{y}_{k}:k\in\Omega(I)\} when it exists. If the mode is not unique, the system abstains. Otherwise, the candidate transcription is
60: y ^ π ​ ( I ) = s ∗ ​ ( I ) , \hat{y}_{\pi}(I)=s^{*}(I),
61: with vote fraction
62: q ( I ) = 1 n ⁡ ( I ) ∑ k ∈ Ω ⁡ ( I ) 𝕀 [ y ~ k = s ∗ ( I ) ] ∈ [ 0 , 1 ] . q(I)=\frac{1}{n(I)}\sum_{k\in\Omega(I)}\mathbb{I}\!\left[\tilde{y}_{k}=s^{*}(I)\right]\in[0,1].
63: To measure residual disagreement around the candidate, we use the bounded normalized edit distance
64: d ⁡ ( a , b ) = min ⁡ ( 1 , ED ⁡ ( a , b ) max ⁡ ( 1 , max ⁡ ( | a | , | b | ) ) ) ∈ [ 0 , 1 ] , d(a,b)=\min\!\left(1,\frac{\mathrm{ED}(a,b)}{\max(1,\max(|a|,|b|))}\right)\in[0,1],
65: where ED ⁡ ( ⋅ , ⋅ ) \mathrm{ED}(\cdot,\cdot) is Levenshtein edit distance, and define the candidate-centered dispersion
66: Δ ⁡ ( I ) = 1 n ⁡ ( I ) ​ ∑ k ∈ Ω ⁡ ( I ) d ⁡ ( y ~ k , s ∗ ​ ( I ) ) . \Delta(I)=\frac{1}{n(I)}\sum_{k\in\Omega(I)}d\!\left(\tilde{y}_{k},s^{*}(I)\right).
67: The resulting evidence summary is
68: e π ​ ( I ) = ( n ⁡ ( I ) , q ⁡ ( I ) , Δ ⁡ ( I ) ) . e_{\pi}(I)=\big(n(I),\,q(I),\,\Delta(I)\big).
69: The controller uses a consensus threshold τ ⁡ ( m ) \tau(m) and a fixed dispersion threshold κ \kappa . In the main operating-point family, the strictness index m m affects only the minimum required vote fraction, with τ ⁡ ( m ) \tau(m) nondecreasing in m m , while κ \kappa is held fixed. Larger m m therefore induces a stricter acceptance region through a stronger consensus requirement under the common stability gate Δ ⁡ ( I ) ≤ κ \Delta(I)\leq\kappa .
70: The instantiated controller is
71: f π , m ​ ( I ) = { s ∗ ​ ( I ) , if ​ n ​ ( I ) ≥ K min , s ∗ ​ ( I ) ​ exists uniquely , q ⁡ ( I ) ≥ τ ⁡ ( m ) , Δ ⁡ ( I ) ≤ κ , ⊥ , otherwise. f_{\pi,m}(I)=\begin{cases}s^{*}(I),&\text{if }n(I)\geq K_{\min},\\ &\phantom{\text{if }}s^{*}(I)\text{ exists uniquely},\\ &\phantom{\text{if }}q(I)\geq\tau(m),\\ &\phantom{\text{if }}\Delta(I)\leq\kappa,\\[2.0pt] \bot,&\text{otherwise.}\end{cases}
72: 3.5. Coverage, Risk, and Operating Points
73: Selective OCR is evaluated jointly by coverage and conditional risk on exposed outputs. For the controlled system f π , m ​ ( I ) ∈ 𝒴 ∪ { ⊥ } f_{\pi,m}(I)\in\mathcal{Y}\cup\{\bot\} , coverage is
74: Cov ( π , m ) = Pr [ f π , m ( I ) ≠ ⊥ ] . \mathrm{Cov}(\pi,m)=\Pr\!\left[f_{\pi,m}(I)\neq\bot\right].
75: If the protocol uses randomized view selection, the probability is taken jointly over the data distribution and the induced protocol randomness.
76: All controlled-system risk metrics are computed on the covered subset. We report mean CER and upper-tail CER (P99) on covered outputs, and define the conditional catastrophic exposure rate as
77: Meltdown @ δ ( π , m ) = Pr [ CER ( f π , m ( I ) , y gt ) ≥ δ | f π , m ( I ) ≠ ⊥ ] , \mathrm{Meltdown}@\delta(\pi,m)=\Pr\!\left[\mathrm{CER}\!\left(f_{\pi,m}(I),y^{\mathrm{gt}}\right)\geq\delta\ \middle|\ f_{\pi,m}(I)\neq\bot\right],
78: with δ = 2 \delta=2 in our main setting. Since CER is normalized by ground-truth length, severe over-generation may yield CER > 1 \mathrm{CER}>1 .
79: We report results on a small set of predefined operating points m m under a common protocol π \pi . In the main instantiation used in this paper, these operating points correspond to increasing consensus thresholds τ ⁡ ( m ) \tau(m) while the dispersion threshold κ \kappa is fixed. These settings are fixed before evaluation and shared across models and benchmarks.
80: For comparison, we report baseline risk on the full test set and controlled-system risk on the covered subset together with coverage. As an additional reference point, we include an approximately coverage-matched external selective baseline in Sec. 4.3.
81: 4. Experiments
82: 4.1. Experimental Setup
83: Backbones and datasets. We evaluate the controller on three frozen vision-language backbones used as black-box generators: LLaVA-Phi3 (3.8B) ( Zhu et al., 2024 ) , Gemma3 (4B) ( Team et al., 2025 ) , and GLM-OCR. Experiments use the official test sets of IIIT5K ( Mishra et al., 2012 ) and ICDAR 2013 ( Karatzas et al., 2013 ) .
84: Protocol instantiation. Unless otherwise noted, the common protocol uses K = 5 K=5 geometrically related views, consisting of one anchor view and four additional views sampled from a fixed admissible transform distribution over translation, crop jitter, and scale variation. Returned strings are canonicalized by Norm ⁡ ( ⋅ ) \mathrm{Norm}(\cdot) and filtered by the admissibility screen 𝒱 \mathcal{V} , with K min = 3 K_{\min}=3 .
85: Operating points. We use predefined strictness levels m ∈ { 1 , 3 , 5 } m\in\{1,3,5\} . In the main instantiation, these correspond to increasing consensus thresholds
86: τ ⁡ ( 1 ) = 0.1 , τ ⁡ ( 3 ) = 0.5 , τ ⁡ ( 5 ) = 0.9 , \tau(1)=0.1,\qquad\tau(3)=0.5,\qquad\tau(5)=0.9,
87: while the dispersion threshold is fixed at κ = 0.4 \kappa=0.4 . All settings are fixed before evaluation and shared across models and benchmarks. Unless otherwise stated, the main results use m = 3 m=3 .
88: Metrics and reporting protocol. Following Sec. 3.5, we report coverage together with covered-subset risk, including mean CER, upper-tail CER (P99), and Meltdown ​ @ ​ 2 \mathrm{Meltdown}@2 . Since the baseline never abstains, its risk is reported on the full test set, whereas controlled-system risk is reported on covered outputs. Whenever the controlled system applies output canonicalization, the same canonicalization is also applied to the baseline. Sec. 4.3 further includes an approximately coverage-matched external baseline.

94: 4.3. Approximately Coverage-Matched External Baseline Comparison
95: We next test whether the gains of GRC can be explained by standard confidence-based abstention alone. To this end, we compare against an external confidence-threshold selective baseline (Conf.-Thr.) adapted from the vanilla selective-prediction component of Srinivasan et al. (2024) . We retain only the threshold-based abstention rule, so that the comparison isolates a standard internal-confidence selective baseline under the OCR setting.
96: For fairness, this baseline uses the same frozen backbone, prompt template, deterministic decoding, and output canonicalization as the always-accept OCR baseline. It operates on a single view and accepts a transcription only when the model’s internal confidence exceeds a calibrated threshold. Confidence is instantiated by the mean token log-probability of the generated transcription, and the threshold is calibrated on a held-out split to target the coverage of our default operating point ( m = 3 m=3 ) for each backbone–dataset setting. Realized test-set coverage is therefore approximately, rather than exactly, matched.
97: Table 2 reports the comparison. At similar coverage, the confidence-threshold baseline reduces some ordinary errors, but remains much weaker at suppressing catastrophic exposure. GRC achieves lower CER mean and lower Meltdown ​ @ ​ 2 \mathrm{Meltdown}@2 in all six settings, with the largest gains on the more failure-prone LLaVA-Phi3. This suggests that single-view internal confidence does not capture the instability revealed by multi-view external evidence.

99: 4.4. Operating-Point Control
100: A key property of the controller is that the strictness index m m does not modify the backbone or protocol; it selects one predefined operating point under a fixed selective contract. In our main instantiation, increasing m m raises the required consensus threshold τ ⁡ ( m ) \tau(m) while the dispersion gate remains fixed, making acceptance more conservative and trading coverage for lower exposed risk.
101: Figure 4 visualizes this behavior across all three backbones on both IIIT5K and ICDAR13. In each case, increasing m m moves the system along a consistent risk–coverage frontier toward lower coverage and lower covered-output mean CER. This behavior is consistent with interpreting m m as a practical deployment knob, since the operator does not modify the backbone or protocol, but instead selects an operating point from a fixed and auditable family.

Taken together, these results show that the controller is not a loose collection of heuristics, but a complementary combination of admissibility screening and cross-view consensus control.

112: 5. Discussion and Limitations
113: GRC is designed for deployment control rather than backbone improvement. Under a fixed protocol, it reduces unstable user-facing exposure, but it does not eliminate all accepted errors. The main residual failure mode is stable-but-wrong consensus, where multiple admissible views support the same incorrect word and the system still accepts it. This marks a core boundary of the current design. Cross-view agreement provides evidence of stability, but not proof of correctness. As a result, GRC is most effective at filtering unstable and catastrophic exposure, and less effective at detecting errors that remain consistent across views.
114: Our study is also limited to a word-level scene-text setting, where lightweight structural screening and string-level consensus already provide useful control signals. Extending this framework to broader OCR settings will require stronger verification than word-level agreement alone. A natural next step is region-level verification, in which candidate transcriptions are tied more directly to localized visual evidence, together with stronger geometric admissibility tests and more precise cross-view validation. We therefore view GRC as a practical first control layer for frozen VLM OCR rather than a complete solution to reliable generative OCR.
115: 6. Conclusion
116: This paper reframes reliable generative OCR with frozen VLMs as a deployment-control problem rather than an average-accuracy problem. We present a Geometric Risk Controller that places a frozen backbone inside a fixed-protocol selective contract, where multi-view probing provides external evidence, structural screening removes degenerate outputs, and cross-view consensus governs accept-versus-abstain decisions. The result is a small set of predefined operating points that makes the coverage–risk trade-off explicit and auditable.
