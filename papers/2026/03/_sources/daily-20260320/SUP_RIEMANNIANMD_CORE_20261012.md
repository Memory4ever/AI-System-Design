```text
Q+X = ((1−a²)/(1+a²), 2a/(1+a²))ᵀ
Q−X = ((1−a²)/(1+a²),−2a/(1+a²))ᵀ
f(Q+X) = η/(1+η²/4) > f(X)=0
f(Q−X) =−η/(1+η²/4) < f(X)=0
```
