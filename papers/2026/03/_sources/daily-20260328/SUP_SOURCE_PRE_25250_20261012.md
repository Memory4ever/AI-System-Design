## 两PRE

开放分类的负侧还可能随测试环境改变，而不只由固定 ID 类别推出。与 ID 文字相距较远的词，不一定能代表当前未知图像；一个受限分支保存近期高分与低分图像特征的两份有界队列，用它们对候选负词的激活差排序，再混入当前 batch 的信息生成拒识分数。冻结 encoder 只固定表示，队列、负标签集合与读出阈值仍在变化；高置信筛选得到的是派生正负样本，不是真实类别标签，需保存更新次序与各自版本。

[必要方法与直接对照](https://arxiv.org/html/2603.25250v1)支持在所测 CLIP/OOD 人口中用当前激活替代纯 ID 距离，却不保证伪标签污染能自行修复。早期错放过多时适配会弱于静态基线；词库缺少相关词或 text encoder 不理解它们时，新增状态也无法补出可靠支持。标签编码、相似度、排序、队列与动态阈值都付费，批量吞吐还可低于静态方案，训练免费不等部署免费。分布、词域或队列资格失配时，应回静态负标签、可信标注/专用 detector 与重新校准，而不让两个 score 簇或更高 AUROC签发未知样本的安全权限。
