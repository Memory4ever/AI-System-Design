预先可知整段相机轨迹时，锚点也可以先由一个全局生成器提出，再让另一生成器按局部窗口自回归插值，而不使用同一层级并行树。稀疏关键帧空间跨度大，逐帧独立编码可避免把它们当相邻视频帧做时间压缩；每个局部段读取其前后锚点与已生成历史，look-ahead 条件仍是提案，不是真实未来。坏锚点会污染后续窗口，整条轨迹准备也限制在线条件变化下的使用，不能把这条路径作为所有 rolling memory 的升级。
