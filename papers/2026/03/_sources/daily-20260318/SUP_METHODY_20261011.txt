L194: ## Appendix B Concealment Detector Training
L195: 
L196: As explained in Section cite8†3 , we fine-tune a Llama3-1B model with a binary classification head to serve as our concealment detector. Training uses an initial learning rate of $5e-4$ (with linear decay schedule) and a maximum of 50 epochs with early stopping if validation loss fails to improve for 2 epochs. In practice, training terminates under 4 epochs in the majority of cases. Unlike the concealers, the detector is fully fine-tuned (i.e., no LoRA).

L833: ### B.5 Sequence Length Variance Control: Theory and Proof
L834: 
L835: ###### Theorem 4 (Sequence length reduces attention-output variance).
L836: 
L837: Assume the attention output is the uniform average $x=\frac{1}{T}\sum_{i=1}^{T}h_{i}$, where $\{h_{i}\}_{i=1}^{T}$ are scalar random variables (e.g., one fixed coordinate of the value vectors) that are zero-mean and mutually independent, with $\mathrm{Var}(h_{i})=\sigma^{2}$ for all $i$. Then $\mathrm{Var}(x)=\frac{\sigma^{2}}{T}$.
L838: ###### Proof.
L839: 
L840: Let $x=\sum_{i=1}^{T}a_{i}h_{i}$ with $a_{i}\geq 0$ and $\sum_{i=1}^{T}a_{i}=1$. Assume $\{h_{i}\}_{i=1}^{T}$ are independent and $\mathbb{E}[h_{i}]=0$ for all $i$, with $\mathrm{Var}(h_{i})=\sigma^{2}$. Then $\mathbb{E}[x]=0$ and
L841:  | $\displaystyle\mathrm{Var}(x)$  | $\displaystyle=\mathbb{E}\big[x^{2}\big]=\mathbb{E}\left[\left(\sum_{i=1}^{T}a_{i}h_{i}\right)^{2}\right]$  |  | (75)
L842:  |  | $\displaystyle=\sum_{i=1}^{T}a_{i}^{2}\mathbb{E}[h_{i}^{2}]+2\sum_{1\leq i<j\leq T}a_{i}a_{j}\mathbb{E}[h_{i}h_{j}].$  |
L843: 
L844: By independence and $\mathbb{E}[h_{i}]=0$, for $i\neq j$ we have
L845: 
L846:  | $$\mathbb{E}[h_{i}h_{j}]=\mathbb{E}[h_{i}]\mathbb{E}[h_{j}]=0,$$  |  | (76)
L847: so all cross terms vanish. Also $\mathbb{E}[h_{i}^{2}]=\mathrm{Var}(h_{i})=\sigma^{2}$. Hence,
L848: 
L849:  | $$\mathrm{Var}(x)=\sum_{i=1}^{T}a_{i}^{2}\sigma^{2}=\sigma^{2}\sum_{i=1}^{T}a_{i}^{2}.$$  |  | (77)
L850: 
L851: If $a_{i}=1/T$, then $\sum_{i=1}^{T}a_{i}^{2}=1/T$, giving $\mathrm{Var}(x)=\sigma^{2}/T$. ∎
L852: ### B.6 Grouped Query Attention Variance Analysis: Theory and Proof
L853: 
L854: We formally characterize how attention variants differ in output variance through their averaging mechanisms.
L855: ###### Theorem 5 (Output variance scaling for Attention / GQA / MQA ($G=H$)).
L856: 
L857: Assume (i) attention weights are uniform over the attended keys, (ii) the value rows $\{V_{j}\}_{j=1}^{n}$ are zero-mean, mutually independent, and satisfy $\mathrm{Var}(V_{j})=\sigma_{V}^{2}$ (all $j$), and (iii) variance is measured per output coordinate. Then:
L858: 
L859:  | $$\mathrm{Var}\bigl(\mathrm{Attn}\bigr)=\frac{\sigma_{V}^{2}}{n}.$$  |  | (78)
L860: For grouped query attention (GQA) with $G$ groups of equal size $n_{g}=n/G$, where each query attends only within its group, we have
L861: 
L862:  | $$\mathrm{Var}\bigl(\mathrm{Attn}_{\mathrm{GQA}}\bigr)=\frac{1}{G}\cdot\mathrm{Var}\bigl(\mathrm{Attn}\bigr).$$  |  | (79)
L863: 
L864: For multi-query attention (MQA), under the same uniform-weight assumption, each head output has
L865: 
L866:  | $$\mathrm{Var}\bigl(\mathrm{Attn}_{\mathrm{MQA}}\bigr)=\frac{\sigma_{V}^{2}}{Gn}=\frac{1}{G}\mathrm{Var}\bigl(\mathrm{Attn}\bigr).$$  |  | (80)
L867: Theorem cite137†5 shows that variance reduction comes from averaging: under uniform attention, the output averages over $n$ values, so $\mathrm{Var}(\mathrm{Attn})=\sigma_{V}^{2}/n$. GQA and MQA averages over only $n_{g}=n/G$ values and thus reduces variance by a factor $G$.
L868: ###### Proof.
L869: 
L870: Variance of the Attention. The scaled dot-product attention mechanism is defined as:
L871: 
L872:  | $$\mathrm{Attn}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^{\top}}{\sqrt{d_{k}}}\right)V.$$  |  | (81)
L873: The softmax function outputs a probability distribution over the keys. Let the softmax output be $A=\mathrm{softmax}\left(\frac{QK^{\top}}{\sqrt{d_{k}}}\right)$, where $A$ is a matrix with each row summing to 1. The final attention output is obtained by multiplying the softmax output $A$ with the value matrix $V$:
L874: 
L875:  | $$\mathrm{Attn}(Q,K,V)=AV.$$  |  | (82)
L876: To simplify the analysis, we make the following additional assumptions: The softmax output $A$ is approximately uniform, meaning each element of $A$ is roughly $1/n$, where $n$ is the number of keys/values. Given this assumption, the variance of the attention is:
L877: 
L878:  | $$\mathrm{Var}(\mathrm{Attn}(Q,K,V))\sim\mathrm{Var}(AV)=\frac{1}{n}\sum_{i=1}^{n}\mathrm{Var}(V_{i})d_{\mathrm{head}}=\frac{1}{n}\cdot n\cdot\sigma_{V}^{2}d=\sigma_{V}^{2}d=\sigma_{W}^{2}d.$$  |  | (83)
L879: where $W$ is the universal weight matrix defined as before.
L880: 
L881: Variance under Grouped Query Attention. Suppose the $n$ queries are partitioned into $G$ disjoint groups of equal size $n_{g}=n/G$, and each query attends only to its own group. Then the softmax output $A$ is uniform for all $V_{i}$, and roughly uniform of weight $1/n_{g}$. Writing $V_{i}$ for the $i$-th row of $V$, we have
L882:  | $$\mathrm{Attn}(Q,K,V)=AVd=\begin{pmatrix}\tfrac{1}{n_{g}}(\sum_{i\in\mathcal{G}_{1}}A_{i})V_{1}\\
L883: \tfrac{1}{n_{g}}(\sum_{i\in\mathcal{G}_{2}}A_{i})V_{2}\\
L884: \vdots\\
L885: \tfrac{1}{n_{g}}(\sum_{i\in\mathcal{G}_{G}}A_{i})V_{G}\end{pmatrix}d,$$  |  | (84)
L886: 
L887: where $\{\mathcal{G}_{1},\dots,\mathcal{G}_{G}\}$ are the index sets of each group. Under the same variance assumption $\mathrm{Var}(V_{i})=\sigma_{V}^{2}$ and independence across rows, each group’s output has variance
L888:  | $$\mathrm{Var}\Bigl(\tfrac{1}{G}\Bigl(\tfrac{1}{n_{g}}\sum_{i\in\mathcal{G}_{g}}A_{i}\Bigr)V_{g}\Bigr)=\tfrac{1}{G^{2}n_{g}^{2}}\sum_{i\in\mathcal{G}_{g}}\mathrm{Var}(V_{g})=\frac{n_{g}\sigma_{V}^{2}}{G^{2}n_{g}^{2}}=\tfrac{\sigma_{V}^{2}}{G^{2}n_{g}}.$$  |  | (85)
L889: 
L890: Since there are $G$ independent group outputs, the overall variance (per row) remains
L891: 
L892:  | $$\mathrm{Var}\bigl(\mathrm{Attn}(Q,K,V)\bigr)=\frac{\sigma_{V}^{2}d}{G^{2}n_{g}}=\frac{\sigma_{V}^{2}d}{Gn}.$$  |  | (86)
L893: In particular, compared to the fully uniform case ($G=1$), grouped query attention reduces the output variance by a factor of $G$.
L894: 
L895: Variance under Multi-Query Attention. In Multi-Query Attention (MQA), we use $n$ distinct query projections but share a single pair of keys and values across all heads. Let
L896: 
L897:  | $$Q^{(n)}\in\mathbb{R}^{n\times d_{k}}\quad,\quad K\in\mathbb{R}^{n\times d_{k}}\quad,\quad V\in\mathbb{R}^{n\times d_{v}}$$  |  | (87)
L898: where $Q^{(n)}$ is the $n$-th query projection and $(K,V)$ are shared. The output of head $g$ is
L899: 
L900:  | $$\mathrm{Attn}^{(n)}(Q^{(n)},K,V)=\mathrm{softmax}\Bigl(\tfrac{Q^{(g)}K^{\top}}{\sqrt{d_{k}}}\Bigr)V.$$  |  | (88)
L901: 
L902: Assume each row $V_{i}$ of $V$ has variance $\mathrm{Var}(V_{i})=\sigma_{V}^{2}$ and that the softmax weights are approximately uniform, i.e. each weight is about $1/n$. Then for any query $i$ and head $g$,
L903:  | $$\mathrm{Attn}^{(g)}_{i}=\tfrac{1}{n}\sum_{j=1}^{n}V_{j},\qquad\mathrm{Var}\bigl(\mathrm{Attn}_{i}^{(g)}\bigr)=\frac{1}{n^{2}}\sum_{j=1}^{n_{g}}\mathrm{Var}(V_{j})d=\frac{\sigma_{V}^{2}d}{Gn}.$$  |  | (89)

citeturn33039view2 [wordlim: 200] Crawled: today; Content type: text/html; Source: open({"ref_id":"https://arxiv.org/html/2603.15611v1","lineno":1080}); Total lines: 1106
L1033: ##### Code Generation (Step 1).
L1034: 
L1035: The Code LLM generates $M$ candidate solutions $\{C_{1},\ldots,C_{M}\}$ for each question.
L1036: 
L1037: ##### Test Generation (Step 2-1).
L1038: 
L1039: For each candidate $C_{m}$, the Test LLM performs white-box generation: it inspects the candidate code and produces $N$ test suites $\{T_{m,1},\ldots,T_{m,N}\}$, each containing multiple assertion statements.
L1040: ##### Mistake Book Retrieval (Step 2-2, 2-3).
L1041: 
L1042: The system queries the Mistake Book for historical failures $T^{hist}$ associated with the current question, retrieving tests with the highest failure frequency to form a stable evaluation baseline.
L1043: 
L1044: ##### Test Validation (Step 3).
L1045: 
L1046: Each generated test suite is executed against the ground-truth code $C_{GT}$ to compute validity scores. Tests with incorrect predictions are corrected using oracle outputs and retained to enrich coverage.
L1047: ##### Code Evaluation (Step 4-1).
L1048: 
L1049: Candidate solutions are evaluated against the combined test set (newly generated tests plus historical failures). Pass rates determine the adversarial scores for both models.
L1050: 
L1051: ##### Mistake Book Update (Step 4-2).
L1052: 
L1053: The Mistake Book is dynamically updated: newly failed tests are added with frequency 1, while historical tests that now pass have their frequency decremented or are removed.
L1054: ##### Reward Computation (Step 5).
L1055: 
L1056: The Code LLM receives rewards based on pass rates. The Test LLM receives composite rewards balancing validity and adversarial difficulty: $R_{T}=\alpha\cdot\text{Valid}+(1-\alpha)\cdot\text{Adv}$. To balance training compute, only the test suite group with highest reward variance (TopVar) is selected for the Test LLM update.

L1058: ## Appendix E Evaluation Metrics Definition
L1059: ### E.1 Avg
L1060: 
L1061: Avg represents the macro-average of the code generation performance across all evaluated benchmarks. It is calculated as the arithmetic mean of the avg@32 scores on HumanEval^{+}, MBPP^{+}, and BigCodeBench, providing a single scalar to reflect the model’s overall coding capability.
L1062: ### E.2 Mul
L1063: 
L1064: Mul is designed to evaluate the yield of high-quality tests by combining validity and adversarial difficulty. As described in UnLeakedTestBench (cite119†Huang et al., 2025 ), the calculation of mutation score ($mut@k$) is inherently conditional on the generated tests first being valid (i.e., compiling and passing the original code).
L1065: 
L1066: This dependency creates a trade-off between $pass@k$ and $mut@k$:
L1067: 
L1068:   * •
L1069: A model might achieve a high $pass@k$ by generating trivial, low-complexity tests that lack fault-detection capability (resulting in a low $mut@k$).
L1070: 
L1071:   * •
L1072: 
L1073: Conversely, a model might achieve a high $mut@k$ by generating highly complex tests, even if only a small fraction of them are valid (resulting in a low $pass@k$). This can occur if the metric evaluation considers the “best" tests from a sparse set of valid candidates.
L1074: 
L1075: To address this, we define Mul as:
L1076: 
L1077:  | $$Mul=pass@k\times mut@k$$  |  | (9)
L1078: By multiplying these two metrics, Mul normalizes the mutation score against the total sampling budget. It reflects the true proportion of generated tests that are both valid and adversarial, ensuring that a high score requires the model to simultaneously maintain high generation quality and strong fault-detection capability.
L1079: ## Appendix F Limitations and Future Work
L1080: 
L1081: ##### Dependence on Ground Truth Code.
L1082: 
L1083: Code-A1 requires ground truth solutions to validate generated tests during training. This limits applicability to domains where reference implementations are unavailable. Future work could explore using consensus among multiple code samples or execution-based validation to relax this requirement.
L1084: ##### Test Format Constraints.
L1085: 
L1086: The current framework requires tests in assertion format for reliable extraction and execution. This excludes more complex testing scenarios such as stateful interactions, I/O-based testing, or property-based testing. Extending Code-A1 to support diverse test formats would broaden its applicability.
L1087: ##### Generalization to Other Domains.
L1088: 
L1089: We evaluate Code-A1 exclusively on Python function-level code generation. Whether the adversarial co-evolution dynamics transfer to other programming languages, longer code contexts, or non-code reasoning tasks (e.g., mathematical theorem proving with verifiers) remains an open question for future investigation.
