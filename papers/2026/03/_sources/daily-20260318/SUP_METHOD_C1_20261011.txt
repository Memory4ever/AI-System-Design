L4@P0: ABSTRACT
L5@P0: Residual connections [12] with PreNorm [60] are standard in modern LLMs, yet they accumulate
L6@P0: all layer outputs with fixed unit weights. This uniform aggregation causes uncontrolled hidden-state
L7@P0: growth with depth, progressively diluting each layer’s contribution [27]. We propose Attention
L8@P0: Residuals (AttnRes), which replaces this fixed accumulation with softmax attention over preceding
L9@P0: layer outputs, allowing each layer to selectively aggregate earlier representations with learned, inputdependent weights. To address the memory and communication overhead of attending over all
L10@P0: preceding layer outputs for large-scale model training, we introduce Block AttnRes, which partitions
L11@P0: layers into blocks and attends over block-level representations, reducing the memory footprint while
L12@P0: preserving most of the gains of full AttnRes. Combined with cache-based pipeline communication
L13@P0: and a two-phase computation strategy, Block AttnRes becomes a practical drop-in replacement for
L14@P0: standard residual connections with minimal overhead.
L15@P0: Scaling law experiments confirm that the improvement is consistent across model sizes, and ablations
L16@P0: validate the benefit of content-dependent depth-wise selection. We further integrate AttnRes into
L17@P0: the Kimi Linear architecture [69] (48B total / 3B activated parameters) and pre-train on 1.4T tokens,
L18@P0: where AttnRes mitigates PreNorm dilution, yielding more uniform output magnitudes and gradient
L19@P0: distribution across depth, and improves downstream performance across all evaluated tasks.

L85@P1: 1 Introduction
L86@P1: Standard residual connections [12] are the de facto building block of modern LLMs [35, 51, 9]. The update hl =
L87@P1: hl−1 + fl−1(hl−1) is widely understood as a gradient highway that lets gradients bypass transformations via identity
L88@P1: mappings, enabling stable training at depth. Yet residuals also play a second role that has received less attention.
L89@P1: Unrolling the recurrence shows that every layer receives the same uniformly-weighted sum of all prior layer outputs;
L90@P1: residuals define how information aggregates across depth. Unlike sequence mixing and expert routing, which now
L91@P1: employ learnable input-dependent weighting [53, 20, 9], this depth-wise aggregation remains governed by fixed unit
L92@P1: weights, with no mechanism to selectively emphasize or suppress individual layer contributions.
L93@P1: In practice, PreNorm [60] has become the dominant paradigm, yet its unweighted accumulation causes hidden-state
L94@P1: magnitudes to grow as O(L) with depth, progressively diluting each layer’s relative contribution [27]. Early-layer
L95@P1: information is buried and cannot be selectively retrieved; empirically, a significant fraction of layers can be pruned with
L96@P1: minimal loss [11]. Recent efforts such as scaled residual paths [54] and multi-stream recurrences [72] remain bound to
L97@P1: the additive recurrence, while methods that do introduce cross-layer access [36, 56] are difficult to scale. The situation
L98@P1: parallels the challenges that recurrent neural networks (RNNs) faced over the sequence dimension before attention
L99@P1: mechanism provided an alternative.
L100@P1: We observe a formal duality between depth-wise accumulation and the sequential recurrence in RNNs. Building
L101@P1: on this duality, we propose Attention Residuals (AttnRes), which replaces the fixed accumulation hl =
L102@P1: P
L103@P1: i
L104@P1: vi
L105@P1: with hl =
L106@P1: P
L107@P1: i αi→l
L108@P1: · vi, where αi→l are softmax attention weights computed from a single learned pseudo-query
L109@P1: wl ∈ R
L110@P1: d per layer. This lightweight mechanism enables selective, content-aware retrieval across depth with only one
L111@P1: d-dimensional vector per layer. Indeed, standard residual connections and prior recurrence-based variants can all be
L112@P1: shown to perform depth-wise linear attention; AttnRes generalizes them to depth-wise softmax attention, completing
L113@P1: for depth the same linear-to-softmax transition that proved transformative over sequences (§6.2, §6.1).
L114@P1: In standard training, Full AttnRes adds negligible overhead, since the layer outputs it requires are already retained for
L115@P1: backpropagation. At scale, however, activation recomputation and pipeline parallelism are routinely employed, and these
L116@P1: activations must now be explicitly preserved and communicated across pipeline stages. We introduce Block AttnRes to
L117@P1: maintain efficiency in this regime: layers are partitioned into N blocks, each reduced to a single representation via
L118@P1: standard residuals, with cross-block attention applied only over the N block-level summaries. This brings both memory
L119@P1: and communication down to O(N d), and together with infrastructure optimizations (§4), Block AttnRes serves as a
L120@P1: drop-in replacement for standard residual connections with marginal training cost and negligible inference latency
L121@P1: overhead.
L122@P1: Scaling law experiments confirm that AttnRes consistently outperforms the baseline across compute budgets, with
L123@P1: Block AttnRes matching the loss of a baseline trained with 1.25× more compute. We further integrate AttnRes into
L124@P1: the Kimi Linear architecture [69] (48B total / 3B activated parameters) and pre-train on 1.4T tokens. Analysis of
L125@P1: the resulting training dynamics reveals that AttnRes mitigates PreNorm dilution, with output magnitudes remaining
L126@P1: bounded across depth and gradient norms distributing more uniformly across layers. On downstream benchmarks, our
L127@P1: final model improves over the baseline across all evaluated tasks.
L128@P1: Contributions
L129@P1: • Attention Residuals. We propose AttnRes, which replaces fixed residual accumulation with learned softmax
L130@P1: attention over depth, and its scalable variant Block AttnRes that reduces memory and communication from O(Ld) to
L131@P1: O(N d). Through a unified structured-matrix analysis, we show that standard residuals and prior recurrence-based
L132@P1: variants correspond to depth-wise linear attention, while AttnRes performs depth-wise softmax attention.
L133@P1: • Infrastructure for scale. We develop system optimizations that make Block AttnRes practical and efficient at scale,
L134@P1: including cross-stage caching that eliminates redundant transfers under pipeline parallelism and a two-phase inference
L135@P1: strategy that amortizes cross-block attention via online softmax [31]. The resulting training overhead is marginal,
L136@P1: and the inference latency overhead is less than 2% on typical inference workloads.
L137@P1: • Comprehensive evaluation and analysis. We validate AttnRes through scaling law experiments, component
L138@P1: ablations, and downstream benchmarks on a 48B-parameter model pre-trained on 1.4T tokens, demonstrating
L139@P1: consistent improvements over standard residual connections. Training dynamics analysis further reveals that AttnRes
L140@P1: mitigates PreNorm dilution, yielding bounded hidden-state magnitudes and more uniform gradient distribution across
L141@P1: depth.

L182@P2: Limitations. Whether fixed or gated, both approaches share a fundamental constraint: each layer can only access
L183@P2: its immediate input hl−1, a single compressed state that conflates all earlier layer outputs, rather than the individual
L184@P2: outputs themselves. This entails several limitations: (1) no selective access: different layer types (e.g., attention vs.
L185@P2: MLP) receive the same aggregated state, despite potentially benefiting from different weightings; (2) irreversible loss:
L186@P2: information lost through aggregation cannot be selectively recovered in deeper layers; and (3) output growth: later
L187@P2: layers learn increasingly larger outputs to gain influence over the accumulated residual, which can destabilize training.
L188@P2: These limitations motivate a mechanism that lets each layer selectively aggregate information from all preceding layers.

L254@P3: will make the full O(Ld) communication practical, fully realizing the potential of Full AttnRes.
L255@P3: 3.2 Block Attention Residuals
L256@P3: We propose Block Attention Residuals, which partitions the L layers into N blocks: within each block, the layer outputs
L257@P3: are reduced to a single representation via summation, and across blocks, we apply full attention over only N block-level
L258@P3: representations and the token embedding. This reduces both memory and communication overhead from O(Ld) to
L259@P3: O(N d).

L382@P5: 4.1 Training
L383@P5: For small-scale training, AttnRes adds a tiny computation overhead and no extra memory usage, as the activations
L384@P5: need to be saved for backpropagation regardless. Under large-scale distributed training, pipeline parallelism poses the
L385@P5: primary infrastructure challenge for AttnRes. Full AttnRes requires all L layer outputs to be transmitted across stages;
L386@P5: Block AttnRes reduces this to N block representations, and the optimizations below further minimize the remaining
L387@P5: overhead.
L388@P5: Pipeline communication. With standard residual connections, pipeline parallelism [18] transfers a fixed-size hidden
L389@P5: state between adjacent stages, independent of pipeline depth. Block AttnRes requires all accumulated block representations at each stage for inter-block attention, and naïvely transmitting the full history at every transition incurs redundant
L390@P5: communication.
