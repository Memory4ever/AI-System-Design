## Summary

Kimi CLI supports a rich hook system via `[[hooks]]` with events like `PreToolUse`, which is great for blocking dangerous actions. However, there is currently no way for hooks to auto-approve safe, routine operations — every gated tool call still requires manual user confirmation.

## Request

Please add a PermissionRequest (or equivalent) hook event that fires when the CLI is about to prompt the user for tool approval. Hooks attached to this event should be able to return a programmatic approval decision, similar to how Claude Code handles it.
