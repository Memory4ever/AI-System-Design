## 4. 证据与知识整合

Gamma-World 的旧 closure 是 false negative。其长期增量不是“多一个视频 benchmark”，而是把主体 identity 与跨主体通信从固定 slot + dense all-to-all attention 中拆开：显式 agent axis 使用 parameter-free simplex rotary phase，使主体可区分且 permutation-equivalent；Sparse Hub Attention 用少量 hub tokens 承担共享通信状态，流式 causal student 分别维护 per-agent 与 hub KV history。Method=`§3`，Experiments=`§4`，Discussion=`§5`；主量化证据来自作者多人虚拟环境中的两主体训练和两/四主体测试，覆盖 video fidelity、action controllability 与 inter-agent consistency；论文另有双臂机器人定性协作示例，但没有量化证明真实机器人控制稳健性或 safety contract。两类证据都不证明开放世界物理/社会因果或生产 SLO。该机制已由 `MULTIMODAL-WORLD-MODELS` 的 Ch25 正文与 paired binding 承载。
