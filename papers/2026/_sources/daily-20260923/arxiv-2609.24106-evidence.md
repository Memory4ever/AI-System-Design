# `2609.24106v1` — 网页问句频率不等于用户需求

- 身份与日期：[arXiv 版本页](https://arxiv.org/abs/2609.24106)、[精确 v1 全文](https://arxiv.org/html/2609.24106v1)，访问 2026-09-23；官方 09-22 New 公告落入本窗，v1 的 09-21 投稿标记不单独证明首发。
- 问题与旧方案：大规模网页问句便于获取且覆盖词形/主题，在无真实日志时是合理语言材料；但网页刊登次数由模板、SEO、抓取和重复发布共同决定，不是人类发问次数。
- 机制与状态：作者把问题文本连同 host/page provenance 分类，比较问句形式、出现频率与来源分布。数据 owner 应区分 occurrence count、source/publisher count 与真实交互 demand；若要给训练或评估加需求权重，需另有用户行为样本、隐私授权和覆盖校准。形式分类器只能提出 provenance hypothesis，不能为单条问句认证真人身份。
- 证据边界：110 个 FineWeb snapshots、2013–2025 的 13.4B question occurrences；最频繁的前千问句中大部分是模板内容，论文还报告 Genuine share 的不同趋势估计，但这些属于其 host 标注、采样和爬取组成，不代表整个人类提问分布。AUC 0.725 在目标分类条件下、相对 commerce FAQ 仅 0.554，说明来源识别会失效；没有独立真实用户需求基准可把网页计数校准成需求。
- Books Decision：`TRAIN-DATA` Ch27 已讲网页重复改变经验风险，但未将“问句分布”的发布频率与用户需求解耦，已在该逻辑后增补。V2 评分 2 + 2 + 2 = 6/9；写后独立复核通过。
