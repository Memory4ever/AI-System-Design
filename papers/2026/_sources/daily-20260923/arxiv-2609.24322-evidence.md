- 为什么旧方案合理：分类部署常用准确率和权重重建误差验收 PTQ；索引中的向量压缩也可单独验证。但 RAG 的 encoder 权重量化改变 query/document score，排序正确性不是分类准确率或向量重建误差的逻辑推论。本文研究的是 **encoder weight-only PTQ**，不是把已存 embedding 压缩成 PQ code。
- 机制：§3 将全精度 score `z` 与量化扰动 `δ` 分开。若每项 score 误差不超过 `ε` 且全精度 top-1 与 runner-up 的 gap `g₂ ≥ 2ε`，top-1 对该误差预算稳定；`g₂ < 2ε` 只表示可能翻转，不表示必然错误。实际部署无逐 query 全精度 score，作者先在无标签校准集同时运行 FP/PTQ，估计差分扰动 `S` 的 conformal 分位数，再以 PTQ top-1/top-2 gap 检查是否接受该 query。保证 `P(接受且 top-1 改变) ≤ α` 依赖校准与测试可交换/同分布，非逐请求绝对保证；检索 query 大多 gap 小，接受率很低，因而它更像风险诊断，而非普遍可用的在线捷径。
- 实验合同：§4 对 53 个 ViT/Qwen3-Embedding fine-tuned checkpoint、其他文本 embedders、CLIP 与 cross-encoder，在图像/文本分类、图像/text-to-image/text retrieval、reranking 上比较 W4/W3 weight-only PTQ、per-channel 或 group-128 scale。文本检索用 NFCorpus、SciFact、SCIDOCS、FiQA；默认 mixed-precision 配额 3.5 bits/weight，按 128 calibration queries 衡量逐层 gap sensitivity。§5 表 1 与附录 A.3 表 17 同时给 FP/PTQ top-1 identity 变化、nDCG 与 judged relevant top-1 流失，不能把 identity flip 全当质量下降；作者实验中多数被替换的 relevant top-1 的确变成不相关，仍只限这些数据集和标注。
- 修复与代价：§6 对检索采用逐层 gap-sensitivity precision allocation，而不是按 weight reconstruction error 分配 bit；对分类采用低 gap query 走 FP 的 fallback。前者需保存 calibration corpus/queries、FP 参考与逐层试量化结果，付出混合精度执行与校准成本；后者若用在小 gap 检索会把大多数请求送回 FP、失去吞吐优势。Appendix A.8/A.9 比较其他 allocation criteria、预算和校准 seeds。作者结果不证明任意 encoder、ANN 索引、动态 corpus、硬件、batch/concurrency 或 SLO 下的收益。
