# `2609.22359v1` — 可靠度信号必须进入偏好目标

- 身份与日期：[arXiv 版本页](https://arxiv.org/abs/2609.22359)、[精确 v1 全文](https://arxiv.org/html/2609.22359v1)，访问 2026-09-23；官方 09-22 New 公告归本窗。HTML 的 07-26 投稿标记不是可证首次公开时刻；更早作者发布待核。
- 问题与旧方案：只训练抵抗社会压力可抑制迎合，但遇到可信纠错也可能拒绝；只训练“有理由就更新”又可能接纳不可靠来源。旧的单轴偏好目标在来源可信度稳定、无需区分两类反驳时简单，但不能识别三态决策。
- 机制与状态：将来源声称的可靠度 `r` 与模型先验强度 `p` 放进 keep/flip 偏好标签覆盖，LoRA-DPO 加 chosen NLL 学到随 `p` 调整的阈值；Qwen2.5-7B 三 seed、另一个 Llama 8B 家族、IPO 对照说明不是特定 DPO loss 或同题配对的唯一效应，SFT 模仿相同报告未复现。训练 owner 决定覆盖和标签，独立证据 owner 才可验证来源实际 track record。
- 评价与失败：自报 `r` 与另行审计冲突时模型跟随自报数值，甚至忽略审计；不能把本文说成来源真实性验证或普遍抗投毒。显式数值/合成 threshold 任务、少数模型与偏好优化器，尚未证明自然文本可靠性、开放检索或生产 RAG。抵抗与更新的 trade-off 是该任务内的经验前沿，不是形式不可能定理。
- Books Decision：`TRAIN-RLHF` Ch31 原有偏好数据质量与群体标签，这里补来源可靠度和先验强度进入监督合同的必要性，保留外部证据核验。V2 评分 2 + 2 + 2 = 6/9；独立写后复核通过。
