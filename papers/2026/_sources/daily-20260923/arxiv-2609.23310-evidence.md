# `2609.23310v1` — 通信增益不能只看谱或平均值

- 身份与日期：[arXiv 版本页](https://arxiv.org/abs/2609.23310)及[精确 v1 全文](https://arxiv.org/html/2609.23310v1)，访问 2026-09-23；官方 09-22 New 公告落入本窗。HTML 内 09-20 投稿标记不替代首次公开时刻。
- 问题与旧方案：通信轮数、网络谱半径或平均个体准确率便于汇总，在同质任务或仅需总体优化时有用；但它们可能隐藏消息方向相对任务读出的差异、受影响社区损失和整体投票下降。
- 机制与状态：作者在固定 evidence/network/readout 的线性系统构造等特征谱、等奇异值谱但收益正负相反的通信算子；task-projected finite-time response 保留状态经通信传到目标读出坐标的方向。系统 owner 决定通信边与轮数，评价 owner 同时测 individual/community/global readout；参与者仍各有 private evidence。跨社区权重的选择可约束测得的子群退化，但控制器不因此拥有信息真实性或安全授权。
- 评价边界：小规模训练非线性代理、合成任务与一组手写数字切片；社区保护的 17.78% 严格违规率是数字任务的依赖网格块，不是独立抽样的生产风险估计。直接校准与响应近似表现接近，guarded 规则在多数块回退同社区通信；零观察违规不构成保护证明。只有少数 update templates、三训练种子和重复使用的图像 split，不证明开放式 LLM Agent 外推或线性响应优于直接测量。
- Books Decision：`AGENT-MULTI-AGENT` Ch82 已有同源信息不生增益与 coordination tax；本文增加“方向对齐任务读出、分群损失”的评价合同，在信息上界之后接续，未把新论文名称作为架构命令。V2 评分 2 + 2 + 2 = 6/9；写后独立复核通过。
