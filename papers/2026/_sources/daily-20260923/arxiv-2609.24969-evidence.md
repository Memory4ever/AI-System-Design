- 准入与评分：Ch66 已有 CEM proposal、importance accounting 和 unbiased audit floor，但尚未清楚区分固定输入下**原模型输出轨迹的风险率**与改变输入分布后的风险率，也未在语言模型的 proposal 中明确“事件定义、搜索 surrogate、估计目标”三种所有权。Design Delta 2、System Reach 2、Durability 2，合计 6；标准 Source Review 加独立 Books 判断，owner `PLATFORM-EVALUATION-SYSTEM`。
- 问题与旧方案：§1、§3。原模型 `p` 对固定 prompt 的随机续写有目标事件 `Φ(y)`，估计量是 `μ=E_p[Φ]`。均匀 Monte Carlo 不改变目标且简单，但深尾事件样本预算过高；CEM 或其他倾斜采样可以增加命中，却必须回权，不能把 proposal 的事件频率作为原风险率。
- 机制与状态：§4–5、Appendix A/I。作者以原模型权重扰动构造语言模型 proposal `q_δ=p_{θ+δ}`，沿每个 token 计算似然比，合成 `p(y)/q_δ(y)` 回权。二值 `Φ` 拥有最终事件判定权；可微 surrogate 只为寻找 proposal 提供梯度，不能替换 `Φ`。自适应 regularization 根据采样与 ESS 迹象约束过度集中；它降低某些已见模式的方差，不能证明未发现的失败模式已有 support。训练 proposal 的模型与原模型是两个不同 artifact，后者始终是 estimand owner。
- Evaluation contract：§6–7、Appendix G/L。321 个 model×length×event 组合：246 token presence、65 profanity classifier、5 conjunction、5 ordered sequence；模型是约 120M GPT-2 Small 与约 2.6B Gemma-2，短生成长度和固定 prompt。作者以可核的 reference probabilities 和误差目标比较 naive MC/CEM/其他方法。最高 `>800×` 是 GPT-2 Small Token Presence 的特定深尾、长度及 compute-weighted 几何均值，不是所有事件或生产 Agent 效率。正文没有独立部署硬件、并发或 SLO 合同，不可外推。
- 证明与未证明：Importance sampling 在 proposal 覆盖目标事件 support 且权重可计算时保持目标期望；理论可能性不等于有限预算下能发现全部稀有模式。§8 明确真实复杂 agent failure 没有可核的 ground truth；此文没有真实工具调用、不可逆操作或 release upper-bound 实验。ESS 高也可能只是未触达漏掉的模式。风险门槛仍需原模型/分层 audit floor、事件定义复审和独立 release evidence；它不能替代 Ch66 既有的 anytime-valid SCARCE 上界路线。
