L229: ## Model Introduction
L230: 
L231: Hy3 preview is a 295B-parameter Mixture-of-Experts (MoE) model with 21B active parameters and 3.8B MTP layer parameters, developed by the Tencent Hy Team. Hy3 preview is the first model trained on our rebuilt infrastructure, and the strongest we've shipped so far. It improves significantly on complex reasoning, instruction following, context learning, coding, and agent tasks.
L232: Property  | Value
L233: --- | ---
L234: Architecture  | Mixture-of-Experts (MoE)
L235: Total Parameters  | 295B
L236: Activated Parameters  | 21B
L237: MTP Layer Parameters  | 3.8B
L238: Number of Layers (excluding MTP layer)  | 80
L239: Number of MTP Layers  | 1
L240: Attention Heads  | 64 (GQA, 8 KV heads, head dim 128)
L241: Hidden Size  | 4096
L242: Intermediate Size  | 13312
L243: Context Length  | 256K
L244: Vocabulary Size  | 120832
L245: Number of Experts  | 192 experts, top-8 activated
L246: Supported Precisions  | BF16
L247: ## Highlights
L248: 
L249:   * STEM & Reasoning — Complex reasoning underpins everything else. Hy3 preview performs well on challenging STEM benchmarks like FrontierScience-Olympiad and IMOAnswerBench, and achieved excellent results in the Tsinghua Qiuzhen College Math PhD qualifying exam (Spring '26) and the China High School Biology Olympiad (CHSBO 2025), demonstrating generalizable reasoning capacity.
L250:   * Context Learning & Instruction Following — Real-world tasks require the ability to parse messy, lengthy contexts and follow complex rules. We built CL-bench and CL-bench-Life from our own business scenarios to innovatively measure context learning ability. Hy3 preview exhibits solid gains in both context learning and instruction following capabilities.
L251:   * Code & Agent — Coding and agents saw the biggest gains. With a rebuilt RL infrastructure and larger-scale training tasks, we posted competitive scores across mainstream coding agent benchmarks (SWE-bench Verified, Terminal-Bench 2.0) and search agent benchmarks (BrowseComp, WideSearch).

L278: ### Instruct Model Performance
L279: 
L280: #### STEM & Reasoning
L281: 
L282: Complex reasoning underpins everything else. Hy3 preview performs well on challenging STEM benchmarks like FrontierScience-Olympiad and IMOAnswerBench. It also achieved excellent results in the Tsinghua Qiuzhen College Math PhD qualifying exam (Spring '26) and the China High School Biology Olympiad (CHSBO 2025), demonstrating a high degree of generalizable reasoning capacity.
L283: #### Context Learning & Instruction Following
L284: 
L285: Real-world tasks require the ability to parse messy, lengthy contexts and follow complex rules. We built CL-bench and CL-bench-Life from our own business scenarios to innovatively measure context learning ability. Hy3 preview exhibits solid gains in both context learning and instruction following capabilities.
L286: #### Code & Agent
L287: 
L288: Coding and agents saw the biggest gains. With a rebuilt RL infrastructure and larger-scale training tasks, we posted competitive scores across mainstream coding agent benchmarks (SWE-bench Verified, Terminal-Bench 2.0) and search agent benchmarks (BrowseComp, WideSearch).
L289: Coding is about whether a model can execute in a development environment. Search is about whether it can find and combine information from the open web. Both matter for complex agent scenarios like OpenClaw. Hy3 preview scores well on ClawEval and WildClawBench — a sign that its agent capabilities are becoming practical.
L290: Beyond public benchmarks, we built internal evaluation sets to test the model in real development scenarios. On Hy-Backend (backend-focused tasks), Hy-Vibe Bench (real-user dev workflows), and Hy-SWE Max, Hy3 preview scores competitively against other open-source models.

L301: Deploy Hy3 preview with cite97†vLLM or cite98†SGLang first, then call the OpenAI-compatible API:
L302: 
L303:     from openai import OpenAI
L304: 
L305:     client = OpenAI(base_url="http://localhost:8000/v1", api_key="EMPTY")
L306: 
L307:     response = client.chat.completions.create(
L308:         model="hy3-preview",
L309:         messages=[
L310:             {"role": "user", "content": "Hello! Can you briefly introduce yourself?"},
L311:         ],
L312:         temperature=0.9,
L313:         top_p=1.0,
L314:         # reasoning_effort: "no_think" (default, direct response), "low", "high" (deep chain-of-thought)
L315:         extra_body={"chat_template_kwargs": {"reasoning_effort": "no_think"}},
L316:     )
L317:     print(response.choices[0].message.content)
L318: > Recommended parameters: `temperature=0.9`, `top_p=1.0`.
L319: >
L320: > Reasoning mode: Set `reasoning_effort` to `"high"` for complex tasks (math, coding, reasoning) or `"no_think"` for direct responses.

L323: ## Deployment
L324: 
L325: Hy3-preview has 295B parameters in total. To serve it on 8 GPUs, we recommend using H20-3e or other GPUs with larger memory capacity.
L326: ### vLLM
L327: 
L328: Build vLLM from source:
L329: 
L330:     uv venv --python 3.12 --seed --managed-python
L331:     source .venv/bin/activate
L332:     git clone https://github.com/vllm-project/vllm.git
L333:     cd vllm
L334:     uv pip install --editable . --torch-backend=auto
L335: Start the vLLM server with MTP enabled:
L336: 
L337:     vllm serve tencent/Hy3-preview \
L338:       --tensor-parallel-size 8 \
L339:       --speculative-config.method mtp \
L340:       --speculative-config.num_speculative_tokens 1 \
L341:       --tool-call-parser hy_v3 \
L342:       --reasoning-parser hy_v3 \
L343:       --enable-auto-tool-choice \
L344:       --served-model-name hy3-preview
L345: ### SGLang
L346: 
L347: Build SGLang from source:
L348: 
L349:     git clone https://github.com/sgl-project/sglang
L350:     cd sglang
L351:     pip3 install pip --upgrade
L352:     pip3 install "transformers>=5.6.0"
L353:     pip3 install -e "python"
L354: Launch SGLang server with MTP enabled:
L355: 
L356:     python3 -m sglang.launch_server \
L357:       --model tencent/Hy3-preview \
L358:       --tp 8 \
L359:       --tool-call-parser hunyuan \
L360:       --reasoning-parser hunyuan \
L361:       --speculative-num-steps 1 \
L362:       --speculative-eagle-topk 1 \
L363:       --speculative-num-draft-tokens 2 \
L364:       --speculative-algorithm EAGLE \
L365:       --served-model-name hy3-preview
