| --- | --- | --- |
| [Sema `2604.20940v1`](https://arxiv.org/abs/2604.20940v1) | 原文实际提出“人看的信号保真”与 Agent 需要的语义事件之间的传输目标差异，并把客户端音频 token / 屏幕 accessibility-tree 或 OCR、视觉 token 与服务端重建分开。它直接影响多模态 Agent 上行带宽、状态放置与延迟取舍，不是仅因 `cs.MM` 标签入选。 | 只有仿真 WAN、既定任务正确率和具体 codec 配对；不能外推任意 VLM 可直接理解离散 code、实网抖动/SLO 或全负载成本。Ch23/62 已有 representation/transport 职责，保留受限 `仅报告`，不把作者数字写成通用平台结论。 |
| [MAGIC-TTS `2604.21164v1`](https://arxiv.org/html/2604.21164v1) | 题摘的潜在增量不是 TTS 得分，而是把 token-local 发声时长与停顿作为显式数值控制，与缺失控制分开。exact-v1 §3 式(1)/(6) 的可用性 mask、零值残差和 flow acoustic generator 使它成为多模态生成控制接口的条件分支，虽只在语音任务内。 | 旧的 duration predictor 与 flow TTS 本来合理；本次作者数据/对齐器、局部场景及控制指标不能证明跨语音模型可迁移或值得把 Ch24 改为特定 TTS 配方。保留标准 `仅报告`；不是因为局部任务就机械排除。 |
| [AgentEcho `2604.21255v1`](https://arxiv.org/abs/2604.21255v1) | 原文提出把 tool graph 中完成任务所必需的边与可自由选择的行动模式分开，尝试区分能力改善和行为同质化；这可能改变 Agent 评价中的比较对象，不只是“另一个榜单”。 | 18 模型的行为相似、受控蒸馏及 RPS/AGS 只给受测协议下的诊断；相似度不识别具体模型的训练来源，也不能把共同行动都解释为同源。Ch66/82 的任务有效性与行为观测已足以承载一般判断，保留受限 `仅报告`。 |
| [Symbolic Grounding `2604.21346v1`](https://arxiv.org/abs/2604.21346v1) | 使用 Bongard-LOGO 的生成程序给 LLM 特权符号输入，是“像素表征瓶颈还是规则推理瓶颈”的输入干预/上界诊断。原始题摘的潜在增量是评价因果问题及 oracle 身份，而不是抽象图像指标提升。 | 程序输入不是可部署像素→符号前端；模型池、输入长度及部分 grounding 条件不全匹配，因此不能把差额全归于视觉 encoder。Ch23/66 已要求输入身份、oracle 与推理分账；保留标准 `仅报告`，不把受限诊断写成所有 VLM 的结构结论。 |
