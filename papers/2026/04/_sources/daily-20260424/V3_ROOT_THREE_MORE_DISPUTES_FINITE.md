## `2604.20874v1` Root Theorem：有限窗口不推出唯一持久架构

[官方 exact-v1 §5–9、§12](https://arxiv.org/html/2604.20874v1)以有限窗口和作者设定的非零退化为前提，提出持续压缩、改写、丢弃是无界持续理解的唯一架构。有限窗口确实要求**一次输入**受限；append-only 的**完整原文都留在输入中**也会越界。但从这些条件无法排除外部不变日志/知识库配合按任务检索、选择性引用与独立校验等架构：它们可保持活跃窗口有界而不重写原始持久状态。论文把“理解连续性”的操作性验收、可比较的替代系统及跨模型退化率均留有缺口；60+ session 的作者系统观察只支持该实现可维持一定内存足迹，不能证明唯一性。保留作者对长任务记忆质量门禁的工程提醒，不采用“Root Theorem”作为普遍必要定理。Ch76/77 既有信息选择、来源/派生记忆责任无需因此改写。原 `2+1+2=5`、中心普遍性争议/暂缓合理；若有严格定义的任务保持指标和非同构替代对照，再定点重开。

## `2604.21251v1` CAP：固定标签与跨 query InfoNCE 不能直接证明条件 MI 目标

[官方 exact-v1 §3.2、Appendix B.1–B.2](https://arxiv.org/html/2604.21251v1)把目标写为 `I(a_f; a_k | q_k)`/`I(a_r; a_k | q_k)`，但每个 `q_k` 在实验标签池中配一个固定 `a_k`。**就该经验分布**而言，条件在具体 `q_k` 后标签无随机性，前述条件 MI 为零；这不否定真实任务若同一 query 有随机合法答案时条件 MI 可非零。论文实际 InfoNCE 分母使用一批**不同 queries**的答案作负例，可作为跨 query 判别 surrogate，却不能仅凭式(3)–(4)签发所声称的固定 query 条件 MI 下界。Appendix B.2 又转为 frozen encoder 的距离 proxy，须与信息论目标分账。prompt 选择与遗忘/保留的受限实验可独立看待，不据此采用“已证明最优信息瓶颈”机制。Ch31/34 既有遗忘及评价边界不变。原 `2+1+2=5`、中心推导争议/暂缓合理；重开需明确每个 query 的条件采样分布、匹配的条件负例及 surrogate 适用边界。

## `2604.21391v1` ResVLA：起点密度独立不迫使条件流速度独立

[官方 exact-v1 §3.3 Eq7 与 Appendix A.3](https://arxiv.org/html/2604.21391v1)从 `p0(x|c)=p0(x)`、起点 score 不含 `c`，直接推出 `t→0` 的条件 vector field 不含 `c`，进而推出条件梯度必消失。反例：令 `x0~N(0,1)` 与 `c∈{-1,+1}` 独立，终点 `x1=c`，直线条件流 `x_t=(1-t)x0+tc` 的边界速度 `u0(x,c)=c-x`，仍依赖 `c`。概率路径的时间导数/运输目标不能由单个时刻的 density score 唯一决定；论文未给出把二者等同所需的额外约束。因此不能采用“独立噪声必导致监督梯度消失，语义 anchor 因而必要”的普遍定理。DCT 低频 anchor + residual flow 仍是可检验的受限设计分支，LIBERO/真实机器人局部结果也不因该逻辑反例自动归零。Ch26 保留既有分层行动与反馈边界，不为此强保证改写。原 `2+2+2=6`、深入必要审阅/中心理论争议暂缓合理；重开需修订定理假设或给出能隔离 anchor 贡献的机制证据。
