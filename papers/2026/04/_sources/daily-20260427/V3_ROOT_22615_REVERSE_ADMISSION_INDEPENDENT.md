# 04/27 GazeVLA 负侧反向准入：独立裁决

复核者：root（非 04/27 报告作者）；2026-09-28。本裁决只覆盖具名家族的贡献准入及必要证据，不代表整日来源、日期或 Books Gate。

**结论：恢复为条件候选，暂按 2+2+2=6/9 标准审阅。** [arXiv:2604.22615v1](https://arxiv.org/html/2604.22615v1) 的完整题摘、§3.1–3.3、§4.4 与表 2 支持这个有限判断。旧“机器人局部模型改进”关闭理由漏掉了新的监督接口：先在人类第一视角数据以有效 gaze mask 学前动作目标，再在没有机器人 gaze 标注的后训练中预测意图 token，让连续 action expert 读取其 KV 后提动作。它给 Ch26 的人类示教→机器人 action 桥接一个明确的可选**中间状态与条件消费**，比仅直接模仿人手轨迹或混合数据多出可核验的设计选择。`ROADMAP` owner 为 `MULTIMODAL-EMBODIED-VLA`，相邻 `MULTIMODAL-REPRESENTATION` 只需短 handoff。

不能采用作者“gaze 等于人类真实因果意图”的强叙事。gaze 是经过过滤的二维视觉 proxy；对任务相关区域的定位不证明反事实目标或物理安全。表 2 同训练集关掉 autoregressive intention step 的 `ours w/o CoT` 为 ID 16/20、OOD-position 5/10、OOD-object 6/10、OOD-scene 5/10，完整版为 19/20、6/10、8/10、6/10；这个有限 ablation 支持特定设置下额外意图步与结果相关，样本数小、没有独立跨环境复现，也不能把提升全归因于 gaze 监督。另有 human-data 与训练阶段消融，需和 inference-step 对照分开。主张若用于 Books，只能描述**有条件的跨本体监督分支**，并保留传感器/标定/标注成本、错误意图累积、额外推理延迟及低层 controller 独立执行权；要先完成报告作者的具体 owner/相邻段比较和写后复核。
