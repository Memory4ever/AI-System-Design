## 逐项核验

- **10480 Dataset Lineage：5 分标准，仅报告，窄处置 PASS。** [v1](https://arxiv.org/html/2604.10480v1) §3–5、Limitations。队列/文档抽取、alias/时间筛选与人工低置信检查支持文档 lineage；430 nodes/971 edges 不等全部隐含祖先已经内容证明。必须同时保留 §4.2 的有效内容侧证据：作者对所选样本做 exact instruction-triplet matching，不能把整个研究写成“完全没有内容核验”。该局部冗余比较也不验证所有边或污染传播比例。§5.1 root/out-degree 筛选、MinHash 后 570K 指令的 Vendi/centroid 比较跨不同规模数据，并非训练质量对照；未报道依赖无法恢复是原文明确限制。因此不采用污染比例作真实完整 ancestry，保留有限图发现/采样支路合理，而不是否定其全部内容证据。
- **10493 SWE-Shepherd：前分母具体关闭、不评分 PASS。** [v1](https://arxiv.org/html/2604.10493v1) §3–5 实际 heuristic step reward→折扣累计→qLoRA/MSE PRM→动作选择。100 SWE-bench Verified、GPT-5-mini/max30；baseline 57%/$0.029/15.2 steps 对 PRM 51%/$0.053/12.2，resolved/unresolved reward 0.4894/0.4818，不支持宣传的成功改善。已有过程 proxy 与动作选优原则没有因这组未分离机制的结果获得重要新边界；关闭不是因为负面、小模型或局部结果，反例仍保留，不改成“PRM有效”。
- **10500 Routing-Depth Visual Replay：5 分标准仅报告 PASS。** [v1](https://arxiv.org/html/2604.10500v1) §3.2–3.4、§4.1–4.4/Table1/3/5。crop/self-distillation、salience selected block 重复、显式→latent curriculum 的复合分支确实存在，不用既有组件为由拒绝。梯度 norm 的关联未排除其他优化原因；Eq5 visited 与防重选文字不能自行修复。§3.4 仅称关闭 visual replay，不能推出 routing 也零额外成本；Table1 较 IVT-LR 的部分时间反而变慢。8 H100 训练/8 H20 评价、eager attention、不同模型 λ 及其文字方向矛盾、α/投影反向切片均限域；不采用普遍诊断或零成本保证。
- **10506 Progressive VLM Training 与10517 EgoTSR：各5分标准仅报告、分别家族 PASS。** 分别读 [10506 v1](https://arxiv.org/html/2604.10506v1) §3–5/Table1/2 和 [10517 v1](https://arxiv.org/html/2604.10517v1) §3–4/Table1。官方正文 author lists 实际有交集但集合不同，ID/标题/正文不同；共同 AgiBot、CoT→Tag 与相同短任务结果是关联 recipe，不能因题名相似强去重。10517另有 LongTag/长任务与 subtask planner；10506 batch8×acc2，10517 batch4×acc2/H800，均 bf16/AdamW2e−7/warm1000。forward/reverse 与短长任务切片有效，但追加数据、训练和任务支持未隔离 CoT 唯一因果，更不证明答案只能来自透明因果通道。保留非零 reverse gap、局部场景判断，不当真实机器人闭环或普遍无偏。
- **10508 Self-Repair：5分标准仅报告 PASS。** [v1](https://arxiv.org/html/2604.10508v1) §III–V/TableVII、Discussion/Limitations。最多四轮反馈/首次成功即停的 cumulative solved，不是每轮单答 accuracy；提取/15秒 Python subprocess 共同影响测量。7 API模型、HumanEval164/MBPP257 是有限支持。TableVII 只有4模型，greedy repair 与 T=.8五独立样本同时改变反馈和温度、tokens未匹配；8B resample79.9%高于repair76.8%。保留模型依赖选择与成本，不能概括为repair普遍优于sampling；provider reasoning-trace 提取失败不证明推理能力更差。无需复现所有代码来关闭该强外推。
- **10511 Causal Policy Reasoning：5分标准已读，中央强机制主张窄争议暂缓 PASS。** [v1](https://arxiv.org/html/2604.10511v1) §3–7/Table3/4 及直接必要 Appendix B。实际40 cases×4 API models×5 prompts×3 repetitions=2400，不是2400独立政策案例；case random-effect ICC .537。作者主观 intuitiveness 分类又用 naive response 验证，YES/NO 与 directional 支持不均；CoT×counterintuitive OR .053 是相对收益 interaction，不是CoT全面降低准确性，Table3该切片75.0%仍高于naive70.8%。citation p=.53不证明没有记忆。保留这些真实协议/结果，仅隔离“causal parrots/CoT机制因果”解释，不否认所有benchmark证据。Appendix B 原文明确完整 prompt 须联系作者，重开需要完整prompt、标签定义及针对替代解释的控制或作者收窄；不要求等待私有附件或重跑所有case才能安全终态，不入Books。
- **10516 SGKR：6分标准仅报告 PASS。** [v1](https://arxiv.org/html/2604.10516v1) §2–3/Algorithm1、§4/Table1/2。AST function-call graph加knowledge/semantic I/O，query BFS连接输入→输出是具体结构检索分支，不是给embedding换名。同名合并会暴露跨trace新路径；同名不证明实现、前提/类型相同，path存在不证明真实可执行或事实truth。DABstep378/FinQA360/ConvFinQA300限定，baseline top5/top2按平均node数，不等严格匹配tokens；gold-symbol转换/LLM生成后执行验证不提升外部事实权限。保留动态结构路径及消融，未因这组结果改变已有限制的执行/grounding设计，不冒称全配方已有覆盖。
