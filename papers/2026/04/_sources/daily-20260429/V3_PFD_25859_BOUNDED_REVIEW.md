现有 Ch26 已将 future feature / point-motion teacher 定义为**训练期表示监督**，部署移除 auxiliary decoder，另有 future latent 通路干预和 action outcome 的评价合同。本文机制差别不是又加一个 feature teacher：同一 WAM backbone、同一噪声和参数，student 的 action query 只看当前帧，privileged teacher 的 action query 看真实未来帧；训练目标是两个 action-velocity 预测的 stop-gradient 差 `r=sg(v_teacher−v_base)`，小 adapter 从当前条件的 `v_base` 预测此差，输出 `v_base+g(v_base,t)`。teacher 仅在训练时多做一遍 attention forward，部署不生成或消费未来视频，只在每个 action-denoising step 跑 adapter。**未来信息是对当前动作去噪方向的可蒸馏 correction**，不是持久世界状态、真实将来可见性或动作执行权。这是 Ch26 已有「future 用作 representation regularizer」之外的具体受限设计/检验分支，若非作者 source→owner 核通过，可考虑在 Training-only Foresight 段作最窄对照；当前不写共享书稿。

评价必须分母分账。LIBERO reproduced Fast-WAM 四 suite mean `96.95`→PFD `98.10`，其中 Object `99.4→99.2` 反退；作者发布版 Fast-WAM 原表为 `97.60`，不能与作者复训基线混作同条件。RoboTwin clean/randomized `91.88/91.78→93.11/92.69`，受限于所用数据/仿真场景。LIBERO matched-trainable-layer direct finetune `96.70`、shuffled-future `96.62` 低于 PFD，支持当前帧—未来帧对应和 action-side correction 的作用；但 pure finetune 没有额外 teacher forward，不能称完整训练 compute matched。减视频侧可训练深度、加 adapter 宽度的对照 `97.36`，固定深度 `K=6` 的默认宽度 `97.40`，原文也说未隔离固定深度时单独 width 效应；不能从这些表唯一证明容量分配原因。Adapter-only `96.60` 低于复训基线，说明「小 adapter 零成本即可恢复」不是无条件成立。单 H100、10 denoise steps、50 trial 的端到端 `190→192ms` 仅约 1% 推理开销；**训练有额外 privileged forward**，不采标题的总成本为零。比较中其他 VLA 包含 embodied pretraining，不作 matched architecture/数据因果推断。没有真实物理安全、OOD embodiment 或 causal world model 证明。
