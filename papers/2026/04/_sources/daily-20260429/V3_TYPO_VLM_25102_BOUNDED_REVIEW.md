# 2604.25102v1：图片文字攻击的可读性与拒绝分账

- Source Family：[`arXiv:2604.25102v1`](https://arxiv.org/html/2604.25102v1)，正式题名 *One Perturbation, Two Failure Modes: Probing VLM Safety via Embedding-Guided Typographic Perturbations*。日内 arXiv 官方公告窄批链为候选日期依据；页首 `28 Apr 2026` 不单独作为北京首公开时刻，尚待日级身份 Gate。
- 贡献准入：视觉文字攻击的低 ASR 可能只是文字未被读到，也可能是读到后安全拒绝；如果不把 perceptual readability、refusal、actual unsafe completion 分开，发布评测会把感知失败错算成安全防护。此为 Ch72 的具体评价分母问题，而非“视觉攻击又提高若干百分点”。作者侧保留受限候选，拟 `Design Delta 2 + System Reach 1 + Durability 2 = 5/9`、标准审阅。
- 必要方法：§2 对 1,000 条 SALAD-Bench 文本以 12 种字号／10 种变换造图，比较 JinaCLIP/Qwen embedding distance 与四 VLM 的 GPT-4o judge ASR；相关 `r=-.71` 至 `-.93` 为**渲染条件聚合层**，不是每个 prompt 的因果安全概率。§3 Eq2 在四个 surrogate embedding 上优化图像—原文相似度，CWA-SSA 是既有方法的目标改写；不是新授权控制或可用来验证输入无害的 detector。
- 关键反证：§4.1 的 50 个样本特意要求原始 text attack 对 GPT-4o、Claude 成功而 degraded image 两者失败，再按 20px 易恢复性排序，因此 Table 3 的这两模型所有 degraded baseline=0 是**选择条件**，不能外推真实分布的 baseline、整体 ASR 或攻击泛化率。§4.2 将结果自述分为 explicit refusal、readability failure、other：GPT-4o 6px 的可读性失败 35→10、拒绝 10→28，却仅 1 成功；Claude heavy-blur 的 empty response 39→14 和 ASR +28pp；Mistral triple-degradation 86→74% 反向。单一扰动同时可改变两机制，回复类别与 GPT-4o judge 又不是独立视觉识别真值，**不能**从相关或该后验分类证明“安全对齐被单独击穿”。§6 限一套 SALAD、黑字白底、约 2.5h/样本，未对 detector 防线测试。
