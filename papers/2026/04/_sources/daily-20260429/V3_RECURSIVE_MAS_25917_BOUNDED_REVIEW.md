具体新分支不是「多 Agent 多聊几轮」。每个冻结的模型用内层两层残差 `RecursiveLink` 将其输出 hidden state 返回输入 embedding 域，产生若干无文本 latent steps；跨异构模型用含 `W3` 尺度映射的外层 link，把上一 Agent latent 序列交给下一 Agent，最后 Agent 在最后一轮才解码文本。训练先以目标答案 embedding 的 cosine 对齐预热内层 link，再展开整个模型环，最终答案 CE 的梯度沿多轮计算图更新各外层 link；模型主体参数不因此共同微调。Ch82 已有 typed text vs latent/KV medium、版本化 sender/receiver transform、receiver 与 effect owner 分账，**尚未明确跨 Agent latent 环需以最终目标反传共同学习 link、训练递归深度与部署轮数构成同一身份**。若保留长期增量，唯一拟 owner 为 Ch82 的 latent communication 段；Ch30/31 是训练技术邻接，不应另建一份 Agent 方案。

支持与反证按协议分开。Table 2 在同一作者框架、相同 recursion round `r=1/2/3` 比 `Recursive-TextMAS`，报告推理运行时间比例 `1.2×/1.9×/2.4×`、文本 token 减 `34.6%/65.5%/75.6%`，对应的准确率相对差异需按具体 benchmark/Light/Scaled 读，不能把摘要 `8.3%` 写成每任务收益。Table 3 的另类基线采用相同数据和模型设定但不是同一媒介单变量实验；Table 4 残差双层 link 在 Math500/GPQA-D/LiveCodeBench 三项优于三种 link 变体，证明所测架构选择的受限价值，不能从而唯一归因跨轮梯度。Table 5 的 `$4.27`、15.29GB、13.12M 参数是作者估算/所测训练设置，不是全量部署成本；跨 Agent latent payload 的隐藏状态字节、版本兼容、审计和工具副作用没有被「输出 token 减少」覆盖。AIME 每个 30 题，论文用 Pass@10；九 benchmark、四协作布局是不同样本/架构，不能称九个独立生产 Agent 工作流，更不能由最终准确率证明中间消息忠实或权限安全。

中央理论保证要精确隔离。Theorem 4.1/Appendix A.3 实际证明形式是**单个内层** link Jacobian 的谱范数下界 `||J||₂≥Ω(1−√(log(1/δ)/d_h))`，Appendix A.2 还设 `W3=I`、Kaiming 初始化、权重算子范数条件。`||J||₂` 是最大奇异值：即使 `J=diag(1,α)`、`0<α<1`，它仍为 1，但沿第二方向的反向梯度经过 `r` 轮变成 `α^r`。故单步**最大**方向的下界不证明任意 credit 方向、全环 Jacobian 乘积、训练后参数或异构 `W3` 的梯度「近常数」。这个反例只隔离印刷的普遍多轮稳定推断，**不**否定受限实验收益，也不声称论文代码实际梯度消失。Appendix A.1 的 `m|V|d_h` vs `md_h²` 还把文本基线完整 vocab projection 纳入复杂度；真实相对延迟要继续由给定 `N,m,t,d_h,|V|`、硬件和生成/传输协议测量，不能把复杂度式当通用速度保证。

作者侧拟 `Design Delta 2 + System Reach 2 + Durability 2 = 6/9`，Standard；**因多轮稳定这个中央理论叙述有明确反例，执行必要范围的深入纠错／Disputed 仅限该保证**。实际 Ch82 是否值得吸收上述「训练—部署 recursion 身份」尚待非作者 source→owner 判别；若通过，正文只需把 frozen backbones、trainable link、全环最终 CE、depth/version/compatibility、latent 不可读和 typed-text 回退接到现有通信责任链，绝不采用 theorem 为通用稳定保证或把 token 数当 bytes/latency。若 Ch82 现有段已具体承载这条端到端训练责任，则保受限 Report Only/Existing，不能因新名词自动整合。未写共享 Books，未作独立复核或日级 Gate。
