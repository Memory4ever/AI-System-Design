Training Reasoning Models on the Tsallis Loss Continuum*，v1 提交 04/28T17:52:38Z；提交字段本身不是首公开证明。本日 arXiv 官方相邻公告窄批链支持其 ID 落 04/29 08:00 北京批，仍需同家族更早公开的最终日期抽核。只读 §2–7、直接限制与当前 Ch33 相邻命题，未遍历其它附件或版本。

**旧判断→具体增量→设计选择：** [Ch33 GRPO](../../../../../books/part-04-training-system/33-grpo.md)已有全对/全错组零梯度、按 mixed-outcome prompt 补样、group size／selector 和 verifier 噪声合同；这些改变的是**采样准入或组内比较**。本文把同一训练例的成功边际概率 `Pθ=pθ(y*|x*)` 放入 Tsallis `Jq`，梯度方向同例内不变，但以 `Pθ^{-q}` 在**不同训练例之间**重权；这与增加 `G`、全错组丢弃、全局学习率或简单 outcome reward 稠密化不是同一旋钮。`q=0` 是期望成功率 pole，`q=1` 是 latent rationale 的边际似然 pole，不等于普通已标 CoT 的 teacher-forced SFT 的所有情形。若低 `Pθ` 的任务先验让 GRPO 更新几乎无信号，应用侧需要在“继续补采/提供 warm-up 标注”之外评估逐例权重与轨迹后验过滤是否可承担额外偏差和噪声；这是可核验的 Ch33 唯一 owner 提案，Ch31 的偏好奖励权威并非本机制 owner。

**定点原文机制：** §4 Proposition4.1/§5 Eq6 的连续梯度流为 `p_dot=p^(2-q)||s||²`。§5 Theorem5.1 的 `Ω(1/p0)` 只给 `q=0` 在 score norm 上界、单例、连续梯度流下的逃逸时间**下界**；`q=1` 的 `Θ(log(1/p0))` 要额外有沿途 score norm 正下界，临界点所有 q 均可停滞。不能说生产 Adam/有限 minibatch 的任何 RLVR 都至少该墙钟时间，更不能说所有 q 都有无条件严格速度排序。§6 GARL 用同一 `M` 条 prior rationale 的 `w_m=p(y*|x,z_m)` 估 `P` 并放大 RLOO 梯度；PAFT 按 `w_m` 后验近似重采样，再在选中 rationale 上作加权 teacher forcing。GARL 的低方差会混入不连贯 rationale 梯度；PAFT 仅近似后验、低 `P` 时无有效样本。有限 `M` 的 ratio estimator 偏差 `O(q/(M P^(q+1)))` 是固定正 `P`、大 `M` 渐近；§6.1.2 自承长输出 `w_m≥ε` 假设极弱，不能把式子当 cold start 的统一数值保证。训练/评测分别 exact-match／substring，不能混写为同一验收。

**评价及反证：** §7 用单个 Qwen3-0.6B、FinQA/HotPotQA/MuSiQue 三子集、单 seed，所有方法 `M=32` rollout，评估 16 sample、以 validation maj@16 挑 test checkpoint。等 rollout 数不等总 token、反传、wall-clock 成本匹配，不能采 §6 的 drop-in compute 字面零开销。冷启动无任务指令的 GARL 与有指令 warm-start GRPO 还同时改变格式/目标分布；作者 §7.2 明说不能据此断言 prompt 不必要。Warm-start Table3：FinQA GARL `q=.25` 38.7 对 GRPO26.9；HotPotQA PAFT `q=.75` 47.9 对33.5；MuSiQue PAFT22.4 对15.8。GARL 的 HotPotQA/MuSiQue 表项是 **peak-before-collapse**，不等最终稳定成绩，§7.4 对其零崩溃机制仍无受控消融。`q=1` 的 fast escape 也带噪标注记忆/估计偏差，不能写成最优固定值。§9 明示严格答案相等监督、单规模三数据集、连续流分析，general reward 与大模型稳定性未证。
