# 2604.25119v1：不生成输出的 LoRA 预分发审计

- 官方精确版：[Evaluation without Generation: Non-Generative Assessment of Harmful Model Specialization](https://arxiv.org/html/2604.25119v1)，§2–5、§7 的必要段。家族在本日 arXiv 窄批次内，精确首公开仍以日级公告联合链复核，`28 Apr 2026` 仅为原页日期文字。
- 准入命题：已有 output red-team 在允许生成且能人工复核时仍合理；当目标内容不应生成，上传的开放权重 LoRA 又要在分发**前**审查时，行为采样不能作唯一 admission。本文 §2.2 明确定义的是“该 LoRA 是否直接用目标类别数据 fine-tune”，并非抽象的全部危险能力；§3 用固定 Gaussian latent 经扩散网络若干去噪步读取 hidden states，按探针／层／时间汇聚为 functional response，再用有标签 LoRA 训练判别器。这是 no-output 的受限证据接口，不是只看静态 delta 范数。作者侧保留候选，拟 `Design Delta 2 + System Reach 2 + Durability 2 = 6/9` 标准；因真实 Books 评价缺口可触发受影响命题深入，不靠安全题名自动 7+。
- 受控证据：§4.1 在 SD1.5/SDXL/FLUX 三架构、各类约 1,000 个作者训练 LoRA 上比较 random-projected raw weights 与 Gaussian probing；五折与 leave-dataset-out 分开。§4.1.2 的同类／跨类 dataset-pair 区分提示 raw weight 可学 dataset identity，不能仅凭随机交叉验证高分宣称内容信号。§4.2 的公开平台 SDXL 1,118 LoRA 样本，原权重分类在逐层 unit-Frobenius rescale 后 AUROC `.920→.832`、Gaussian `.924→.943`，仅支持对这一**特定重缩放**的稳健性，不是 adaptive 对手通用鲁棒。
- 核心边界：§5 的高危类样本分架构只有 18/34/74，FLUX 仅用 4 个 Gaussian probes，五折 100% recall 与低 FPR 只属于这批有权限取得的 LoRA；§5.2 也自限为当前数据条件的 separability，非部署近乎完美发现率。标签来自直接训练类别，不能证明生成内容、组合 adapter、merge、下游提示下的实际能力。§7 明说政策边界需人定、可能误伤，并仍缺其它权重操纵与更大 base model 的验证。Gaussian probing 不生成图片，但仍运行扩散网络、需已知 base、层选择和多个前向；不称零推理或无成本。
