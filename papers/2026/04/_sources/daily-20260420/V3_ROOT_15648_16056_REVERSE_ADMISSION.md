# 04/20 两项旧准入的非作者反向复核

本记录只裁决 `2604.15648v1` 与 `2604.16056v1` 的贡献准入，不替代来源、日期、其余候选或整日 Gate。旧的必要 Source Review 仍保留；裁决不表示论文无学术价值或其局部结果为零。

## 2604.15648v1 — HyperGVL

[官方 exact-v1](https://arxiv.org/html/2604.15648v1) §2.3–2.4、§3.4–3.5、§4、Appendix D 将 2,400 个 meta problems 分别表达为 35 种文本×视觉组合，产生 84,000 对问答；这些不是 84,000 个独立问题。不同表示导致模型读图表现差异，WiseHyGR 用同一任务族中实测最佳组合为标签训练 router，并报告有限域内及超图节点分类的收益。这支持“在这些超图任务里，输入编码与选择器会影响受测模型”，但不能推成任意多模态对象或通用 router 的新合同。尤其裸顶点邻接可能丢超边成员身份，而论文的 clique expansion 带超边 ID、二部图带超边节点，不能把所有 pairwise 表示宣称为信息丢失。相对 `MULTIMODAL-REPRESENTATION` 与评价章节已有的表示身份/格式敏感度，论文主要新增超图专用任务、编码与局部选择配方；没有独立于该领域的长期表示或 evaluator 权限变化。**同意具名前分母关闭**，不是因为“图任务”或“局部实验”自动排除；此前标准 Only 的必要审阅保留为发现具体误判的证据。

## 2604.16056v1 — AST

[官方 exact-v1](https://arxiv.org/html/2604.16056v1) §3.1–3.4、§4.2：先将源音频反演到 flow latent，再由词级 LCS/ASR 对齐处理源与目标时长不等；未改词取源 latent/semantic condition，编辑词取目标 condition/噪声，最后加 mel-space 弱引导缓和拼接边界。这是可执行的语音编辑 recipe，不是“只改 prompt”。但反演近似、ASR 对齐与生成 ODE 没有给未编辑 waveform 逐样本恒等的证明；论文自身的 WER/DNSMOS 与其他指标也有 trade-off，完整时延与线上 SLO 未披露。`MULTIMODAL-GENERATIVE-PARADIGMS` 现有条件、时间片、provisional state、生成后验证的主线并未因该任务获得新的 owner 或可推广提交界限。**同意具名前分母关闭**，理由是受限音频编辑组合尚未改变项目长期设计判断，而非认为语音不在范围内。

两项均是有限 source→owner 反向准入，不给未检查的剩余前分母关闭项签字；04/20 总分母仍以正式日报当前作者工作态为准，直至独立日级复核。
