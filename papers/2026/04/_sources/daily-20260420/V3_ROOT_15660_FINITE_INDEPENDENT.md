结论：作者撤销原“DP 模型 post-processing 足以保护全部合成记录”的前分母关闭是正确的。印刷算法从原始私有 `D` 独立抽取 `X`，逐列置换后将 `X̃` 连同 DP 模型预测标签发布。置换保每列原始多重集合。对于替换邻接的单行 `x=0` 与 `x=1`，发布含 0 的事件分别为概率 1 与 0；任意有限 ε、δ<1 都不满足该发布对象的 DP 不等式。DP-SGD 只约束模型输出通道，不能将其保证通过后处理定理转给另行读取原始 `X` 的通道。§3.3 关于整个合成数据满足同一 `(ε,δ)` 的论证因此与印刷 Algorithm 2 不相容。
