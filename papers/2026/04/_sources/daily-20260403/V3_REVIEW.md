- **`2604.01621v1` DWDP**：[官方 v1 PDF §2–5、附录 A](https://arxiv.org/pdf/2604.01621v1)首页标 2026-04-03，arXiv 身份页记录 v1 于 04-02 05:00 UTC 提交；按常规公告时钟推断进入北京时间 04-03 08:00 批次，最终 owner 仍以公告记录为准。**版本注意**：同一 v1 的 HTML 渲染首页误显 `August 24, 2026`，故以当时 v1 PDF 而非 HTML 页眉核实验内容。传统 attention data parallel + expert parallel 的每层 all-to-all 会把请求长度、KV 命中与专家热度的不均放大为 rank 等待；DWDP 在每 rank 复制 attention 权重，把每层 MoE 专家权重分片放到 peer GPU，下一层权重经 copy-engine `cudaMemcpyAsync` 拉取、双缓冲隐藏在本层 MoE 与下一层 attention 之后。这是用重量移动换掉**集体跨 rank 同步**，不是无通信、无同步：本 rank 执行 MoE 前仍等所需权重完成，且 copy/compute 争用 HBM、L2、功耗及 peer 出口。作者在 GB200 NVL72、DeepSeek-R1 的 MoE NVFP4 / KV FP8、TensorRT-LLM commit `3a89495`、disaggregated context server 中，将 8K 输入/1K 输出与 20～100 TPS/user 条件下同等 TPS/user 的 output TPS/GPU 报告为比 DEP 高 8.8%；这只是该模型/硬件/量化/工作负载的作者实验，不证明 Decode、跨节点、其他拓扑、多租户或生产 tail SLO 的收益。附录 A 中与 copy 重叠的 attention kernel 反而约慢 1.19×，展示 hidden communication 并非免费。旧 EP 在 peer 带宽不足、MoE 权重搬运无法藏入足够 compute window、故障隔离优先时仍成立。Books 决定：主任务已独立核原文并将「分片 peer 权重、局部完成门槛取代全局同步」作为 `INFER-DYNAMO` Ch52 的独立设计分支纳入，`INFER-GPU-MEMORY` 只负责权重驻留/内存层级交接；该项整合不等于 04-03 整日 Gate。
