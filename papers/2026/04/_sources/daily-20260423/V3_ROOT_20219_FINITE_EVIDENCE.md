# 2604.20219v1：深度逐层逼近的有界审阅

**范围：** 2026-04-23 工作候选，未签首公开日期或整日 Gate。原始来源为 [arXiv exact-v1 HTML](https://arxiv.org/html/2604.20219v1) 与 [版本页](https://arxiv.org/abs/2604.20219v1)；本次读摘要、§1.1–1.2、Theorem 2.1、Corollary 2.2–2.3、Remark 与结论。版本页未见撤回标记；v1 的「22 Apr」是投稿/论文日期，不直接充当北京时间首次公开时刻。

**问题与旧方案。** UAT 及 depth separation 通常保证最终输出可逼近或说明某些函数的深浅表达效率，却不保证一个网络的每个中间前缀已经是可用近似。对只使用最终输出的普通网络，这并非缺陷；若想按误差容忍度逐级添加深度，就需要保留旧前缀并给各级 readout 一个独立的误差边界。

**机制与证明范围。** 作者构造宽度 `2dN+d+2`、预先指定任意有限深度的混合激活网络；两个 sine 通道负责细尺度数值实现，其余 ReLU 通道负责几何定位。每一级是「前缀计算＋仿射输出头」的 `Φ_l`，不是原始 hidden state；新级以残差 `Γ_l` 追加。Theorem 2.1 对 `f∈L^p([0,1]^d)`、`1≤p<∞` 给出存在性上界 `||f−Φ_l||_p ≤ (2d+1)ω_{f,p}(N^{-l})`；有 Hölder 条件时才变为相应几何收敛上界。这个界逐级更紧，不等于任意训练轨迹的实际误差逐级单调下降；作者也明确混合激活不继承其先前纯 ReLU 构造的单调性保证。

**评价合同与代价。** 这是构造性数学证明，不是预训练 Transformer、训练算法或推理 SLO 的实验。参数数量按实数仿射系数计；Remark 明确没有控制系数幅度、位精度与数值稳定性。旧的普通 ReLU/Residual 网络仍适于常规联合训练和最终输出任务；新构造换来有条件的逐层可读出界，但要承担混合激活、额外读出头和潜在精度成本。不能把 `Φ_l` 的界写成标准 Transformer 每层 hidden representation 的 certified accuracy，也不能推出梯度优化、泛化或部署成本收益。

**贡献与 Books。** 工作评分暂为 Design Delta 2 / System Reach 1 / Durability 2 = **5**，标准审阅：它给深度的逐级表示解释一个具体条件，却只触及特构近似网络的单组件表达问题。[Ch4](../../../../../books/part-01-worldview/04-why-models-learn.md) 已区分 UAT 存在性、depth separation 表达效率、优化与泛化；[Ch5](../../../../../books/part-01-worldview/05-what-neural-networks-learn.md) 已把 hidden 表示与可读出行为分开。论文的逐层定量界值得在日报保留为受限替代构造，但不改变当前大模型设计结论，也不足以把混合激活定理插入 Ch4 的通用主线。拟处置为 **仅报告**，待非作者对 exact-v1、owner 与评分作独立复核；首次公开批次尚待日级归属核。
