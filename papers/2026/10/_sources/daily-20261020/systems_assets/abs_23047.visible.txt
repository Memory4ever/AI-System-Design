Title: DIFFLET: A Fast Inference Engine for Diffusion Transformer Models on AWS Trainium
Authors:  Bin Ma ,  Min Yu ,  Vijay Kodamalla ,  Jialin Liu ,  Dong Li
View a PDF of the paper titled DIFFLET: A Fast Inference Engine for Diffusion Transformer Models on AWS Trainium, by Bin Ma and 4 other authors
View PDF
HTML (experimental)
Abstract: On AWS Trainium2, every component of a diffusion model runs as a program compiled ahead of time for fixed shapes, while pipelines differ across models, prompt lengths across requests, and caching decisions across denoising steps. We present Difflet, a serving engine in which five model pipelines share one compilation backend, joint attention is split across cores by attention head, and a host controller decides at each denoising step whether to run the denoiser or reuse its earlier output. A small probe program computes the caching signal on the device and returns one number per step, and a resident model process keeps every program loaded across requests. Across five image and video model families, fused attention accelerates denoiser steps by 1.2-4.3x over the same framework using PyTorch/XLA attention, and at 32.8k visual tokens it is the only attention that compiles. On four of the five models, resident serving is 1.5-3.4x faster than standalone runs that reload weights from a warm file cache for each generation.
