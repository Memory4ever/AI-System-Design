1 MoA in Five Primitives
MoA builds every array computation from a small, fixed set of primitive operators. Five recur con-
stantly throughout this paper series:
•ψ(psi) — indexing: picks out an element or sub-array by its index tuple.
•ι(iota) — index generation: produces the index set of an array from its shape.
•ρ(rho) — shape: the sequence of an array’s dimension sizes. The object that carries every cost
prediction in this paper,ρ machine(d), is theshape of a machine, in direct analogy to the shape of
an array.
•rav (ravel) — flattening: linearizes a multi-dimensional array into one dimension, in a specified
order. This is the operator that reassembles independently-computed device outputs with no
arithmetic combination, only concatenation — the mechanism behind every no-communication
ensemble in this series.
•γ(gamma) — a generalized indexing/reshaping operator used in tiling and blocking derivations.
In Brief
A computation’sDNF(Denotational Normal Form) says what the answer must be, with no
mention of tiles, threads, or memory hierarchy. ItsONF(Operational Normal Form) is where
device-specific decisions get made — which tile size, how many threads, which precision. MoA’s
guarantee is that any admissible ONF realizing a given DNF produces the same answer, prov-
ably, not just empirically. This paper adds athirdvendor’s ONF (AMD MI100, OpenMP
target-offload) to a DNF this series has already realized twice (NVIDIA A100 via Triton; a
15-core CPU via OpenMP) — same DNF, same guarantee, a new device-specific ONF.
Dimension liftingis the step that turns a single-device ONF into an ensemble: the query/batch
dimension of an attention computation is split acrossdreal machines, each with its own real, measured
shapeρ machine(d), weighted byw i ∝1/t i — faster devices get proportionally more rows — and the
outputs are reassembled by rav (no communication) or by a real collective such asMPI Gatherv
(communication-bearing, the subject of this paper).
