What's New  [#what-s-new] ​
A record of new features and key fixes across Kimi Code products — focused on the changes most worth knowing about.
LatestKimi Code Desktop
v1.1.0 October 14, 2026  [#v1-1-0-october-14-2026] ​
Linux support  [#linux-support] ​
Desktop is now available for x86_64 Linux, with AppImage, deb, and RPM packages. →  [/code/docs/en/kimi-code-desktop/getting-started.html#install-and-launch] Install and launchRemote Control  [#remote-control] ​
Enable it under Settings → Remote Control, then use a link or QR code to control the local Agent from a phone, tablet, or another computer. Tasks and local tools still run on the computer running Desktop. →  [/code/docs/en/kimi-code-desktop/remote-control.html] Remote ControlFile Tree panel  [#file-tree-panel] ​
The new File Tree in the right sidebar browses, searches, and refreshes workspace files, with click-to-preview. Toggle it with Cmd + Shift + E on macOS or Ctrl + Shift + E on Windows and Linux. →  [/code/docs/en/kimi-code-desktop/interface-and-sessions.html#right-panel] Right panel
Also in this release: experimental progress updates can be enabled under Settings → Lab for newly created sessions; the new kimi app command opens a new Desktop session in the current or a specified directory. →  [/code/docs/en/kimi-code-desktop/settings-and-extensions.html#lab] Lab ·  [/code/docs/en/kimi-code-desktop/getting-started.html#open-a-workspace-from-the-terminal] Open a workspace from the terminal
Kimi Code CLI
v2.2.0 October 14, 2026  [#v2-2-0-october-14-2026] ​
Open a new Desktop chat from the terminal  [#open-a-new-desktop-chat-from-the-terminal] ​
The new kimi app [path] command opens Kimi Code Desktop with a new draft in the current or specified directory, making it easy to move from the CLI into the graphical interface. →  [/code/docs/en/kimi-code-cli/reference/kimi-command.html#kimi-app] kimi appExperimental progress updates  [#experimental-progress-updates] ​
NotifyUser lets the Agent post short progress updates mid-turn. It is off by default and can be enabled in the TUI /experiments panel or in the Web / Desktop settings Lab, applying only to sessions created afterward. →  [/code/docs/en/kimi-code-cli/reference/tools.html#collaboration-tools] Collaboration toolsInterruptible background waits  [#interruptible-background-waits] ​
WaitFor is capped at 90 seconds. While it waits, pressing Enter or Ctrl-S steers your message into the current turn and ends the wait early, while background tasks keep running. →  [/code/docs/en/kimi-code-cli/guides/interaction.html#during-streaming-output] During streaming output
Also in this release: fullscreen mode keeps a one-line summary of each user message and lets you jump back to it; user skill cards are now highlighted prompts that can be sent with Ctrl-S.
Kimi Code CLI
v2.1.0 September 23, 2026  [#v2-1-0-september-23-2026] ​
Fullscreen mode (experimental)  [#fullscreen-mode-experimental] ​
A new experimental fullscreen interface: the transcript scrolls independently, text can be selected with the mouse, fold blocks expand or collapse on click, and a clickable "Jump to bottom" indicator sits at the bottom. Enable it under /settings → TUI mode, or set tui_mode = "fullscreen" in ~/.kimi-code/tui.toml, then restart Kimi Code. →  [/code/docs/en/kimi-code-cli/configuration/config-files.html#tuitoml] tui.tomlFaster startup, lower memory  [#faster-startup-lower-memory] ​
Shorter CLI startup time and reduced memory usage — first paint arrives noticeably sooner in large projects.File watching is now off by default  [#file-watching-is-now-off-by-default] ​
Filesystem watching for config and workspace files no longer runs by default; to hot-reload AGENTS.md, skills, or MCP config, set [watch] enabled = true or KIMI_CODE_WATCH=1. →  [/code/docs/en/kimi-code-cli/configuration/config-files.html#watch] watch
Also in this release: hardened workspace trust boundaries — file tools can no longer reach outside the working directory through symbolic links, and project-local config only takes effect after the workspace is trusted; new auto_session_title config to turn off automatic session title generation by clients. →  [/code/docs/en/kimi-code-cli/configuration/config-files.html#top-level-fields] Config files
Kimi Code Desktop
Kimi Code Desktop is here September 17, 2026  [#kimi-code-desktop-is-here-september-17-2026] ​
The Kimi Code desktop client is officially available: it carries the Agent core of Kimi Code CLI into a graphical interface, where you open a project, talk to the Agent, and ship changes in one window. Available now for macOS (Apple Silicon / Intel) and Windows. →  [/code/docs/en/kimi-code-desktop/getting-started.html] Quick StartEvery step stays visible  [#every-step-stays-visible] ​
Tool calls, thinking, and the files changed in each turn are all presented in the interface; sensitive operations raise approval prompts, and three permission modes (Always Ask / Ask When Needed / Never Ask) keep you in control. →  [/code/docs/en/kimi-code-desktop/task-execution-and-review.html#approvals-and-permissions] Handle approvalsA complete workflow from conversation to delivery  [#a-complete-workflow-from-conversation-to-delivery] ​
Goal mode keeps long-running objectives moving and can be paused, resumed, or cancelled; plan mode proposes an approach before touching files, and the plan can be reviewed and refined; long tasks can move to the background, where you can check progress or stop them at any time. →  [/code/docs/en/kimi-code-desktop/task-execution-and-review.html#task-modes] Choose a task modeBuilt-in browser and visual annotation  [#built-in-browser-and-visual-annotation] ​
The browser lives in the right panel, with tabs that stay with the session and page context shared with the Agent; screenshot annotation, text selection comments, @ file mentions, and element picking on web pages tell the Agent exactly what to change. →  [/code/docs/en/kimi-code-desktop/task-execution-and-review.html#built-in-terminal] Verify in the terminal
Download:  [https://code.kimi.com/kimi-code/desktop/download/KimiCode-mac-arm64.dmg] macOS · Apple Silicon ·  [https://code.kimi.com/kimi-code/desktop/download/KimiCode-mac-x64.dmg] macOS · Intel ·  [https://code.kimi.com/kimi-code/desktop/download/KimiCode-win-x64.exe] Windows
Kimi Code CLI
v2.0.0 September 17, 2026  [#v2-0-0-september-17-2026] ​
New /desktop command  [#new-desktop-command] ​
The new /desktop slash command (alias /install-desktop) and the kimi install-desktop subcommand open the desktop app page in your browser, so you can download and install the desktop client without leaving the terminal. →  [/code/docs/en/kimi-code-cli/reference/kimi-command.html#kimi-install-desktop] kimi install-desktopMermaid diagrams in the terminal  [#mermaid-diagrams-in-the-terminal] ​
Mermaid code blocks now render as diagrams in the terminal; turn this off under /settings → Mermaid diagrams, or set mermaid = "off" in the [markdown] section of tui.toml.
Also in this release: the built-in browser plugin is renamed to Kimi Browser Extension; when accumulated media in a session exceeds 20 MB, the oldest images and videos are omitted from requests with a warning →  [/code/docs/en/kimi-code-cli/guides/interaction.html#paste-images-and-videos] Paste images and videos. Since v2.0.1, a provider's API key can be read from a named environment variable via api_key_env instead of being written into the config file →  [/code/docs/en/kimi-code-cli/configuration/config-files.html#providers] Config files.
Kimi Code CLI
v0.43.0 September 14, 2026  [#v0-43-0-september-14-2026] ​
AI session titles in Web, on by default  [#ai-session-titles-in-web-on-by-default] ​
A title is generated automatically after the first turn, and you can regenerate it from the rename box — no more naming sessions by hand.Delete sessions from the session selector  [#delete-sessions-from-the-session-selector] ​
Select a session in the session selector, press Ctrl-X, then y to confirm — cleaning up old sessions is much easier.Fairer time budgets in Goal Mode  [#fairer-time-budgets-in-goal-mode] ​
Time budgets no longer count the time while a session is closed, and the 24-hour cap is gone, so long-running goals no longer burn budget while you are away. →  [/code/docs/en/kimi-code-cli/guides/interaction.html#goal-mode] Goal mode
Also in this release: kimi upgrade (alias kimi update) gains a -y, --yes flag to skip the confirmation prompt; the new KIMI_CODE_PERMISSION_MODE_REMINDER environment variable (set to 0) stops injecting auto-permission-mode reminders into the model context. v0.43.1 fixes pressing Ctrl-C while a subagent is running quitting the entire CLI — it now only interrupts the running subagent.

The web settings now include a Plugins panel for browsing the plugin marketplace and installing, enabling, disabling, or removing plugins. →  [/code/docs/en/kimi-code-cli/customization/plugins.html] Plugins
Also in this release: Tower mode (experimental) no longer starts on its own — turn it on explicitly with /tower on or /tower <base-branch>; the new kimi session list command lists sessions from the command line. v0.40.1 fixes the kimi-cli migration prompt reappearing after the migration had completed or been dismissed.
