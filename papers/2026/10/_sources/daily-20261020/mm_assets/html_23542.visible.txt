Abstract
A memory test for a video world model should say whether the scene
was set, whether the asked change was carried out, and whether the
last frame shows the result. Current tests fold these into one
number, so a low score is easy to read as forgetting.
When the change is not carried out, the hidden state transition
cannot appear, so the test is not really a test of memory.
We introduce MIST, an evaluation that separates the change from the
memory it should leave behind.
The model first sets the scene while the change stays hidden, and
only later is asked to show it, with leakage before that point kept
under control. This separation locates the bottleneck: the model sets
the scene but does not carry out the instructed change.
The same gap appears in general memory evaluations.
On that basis we propose M3-Agent (Make the Missing Move), which recursively revises the details of the input
instruction so that the model successfully carries out the
requested instruction. Relative to the baseline, it more than
triples the MIST reveal score. On the
benchmarks, WRBench’s score TT rises by 26.1% and MBench-T’s score
UU by 52.7%. The method meets the problem from the execution side:
it shows what the frozen model can do once the move is stated, and it
sets a stricter baseline.

1 Introduction
Memory tests for video world models ask about a scene the camera no
longer shows: who sat down, what went into the box, whether the
candy broke
(Brooks et al., 2024; Bruce and others, 2024; Valevski et al., 2024).
Object relations have to survive when the camera looks away, and
actions have to update them
(Shin et al., 2026; Ma et al., 2026; Chen et al., 2026a).
Current tests fold these checks into one number: a person and a
chair, an object left in a room, or a cube still in a cup
(Lu et al., 2026; Zhang et al., 2026a). A low number is easy to read
as forgetting, yet it cannot say whether the scene was set, whether
the asked change was carried out, or whether the last frame shows
the result (Fig. 1).

When the change is not carried out, the hidden transition cannot
appear, so the test is not really a test of memory.
Figure 2 shows the usual clip. The child never sits
before the camera leaves. The camera comes back to candy that was
never broken. A box stays shut. The task names the target, but the
last frame never shows it. The score drops before memory is tested.
Until that change happens, asking the model to remember targets the
wrong stage. Tools that rewrite a video for quality, physics, or
preference do not ask whether the asked change was shown
(Lee et al., 2024; Xue et al., 2024; Liu et al., 2025a).
What is needed first is an evaluation that separates the change
from its result.
We introduce MIST to separate the two. The model first
sets the scene while the change stays hidden, and only later is
asked to show it, with leakage before that point kept under
control. On Wan TI2V-5B, three 5-second shots and 43 cases, the
scene is usually set and the hidden change does not leak, yet 41 of
43 baseline clips never show it. Asking only to open leaves most
lids down, and naming the answer helps less than revising the
failed move (§4).
Looking at the last frame and revising the instruction makes the
change appear, though the shown state can still be wrong. The
bottleneck is therefore execution: the scene is set, but the
instructed change is not carried out.
The same gap appears in general memory evaluations. Failed clips on
WRBench skip the departure or the return, and failed clips on
MBench-T return to an object that is still intact
(§7). On that basis we propose M3-Agent
(Make the Missing Move). It recursively revises the
details of the input instruction so that the same model carries out
the requested instruction. No memory module is added or trained. Relative to the baseline,
MIST reveal rises from 0.147 to 0.492. On the benchmarks,
WRBench’s score TT rises by 26.1% (0.452→\to0.570, n=40n{=}40) and
MBench-T’s score UU by 52.7% (0.292→\to0.446, n=30n{=}30; 23 of 30
keep the baseline).
These results say where the score is lost. They do not show that
the model stored the target state. A judged last frame is not
stored memory (§8). They do show that the model
can already carry out many missing changes once the instruction
names them. The method meets the problem from the execution side:
it shows what the frozen model can already do once the move is
stated.
This paper makes three contributions (Fig. 1).
(1) MIST, an evaluation that scores whether the scene is
set, whether the hidden change leaks, and whether it is finally
shown, so a missing change is not reported as forgetting
(§3–4).
(2) Evidence that failed official clips also miss the asked
change: a skipped return on WRBench, an intact object on MBench-T
(§7).
(3) M3-Agent, which recursively revises the input
instruction on the same model. It more than triples MIST reveal and
raises TT by 26.1% and UU by 52.7% (§5,
§7).

2 Related Work
A low memory score can come from failed persistence, a wrong
state update, or a missing operation that never makes the state
observable. The three lines of work below each report one total.
Video generators as world models.
Large video generators are treated as simulators or interactive
environments (Brooks et al., 2024; Bruce and others, 2024; Alonso et al., 2024; Valevski et al., 2024; Huang et al., 2025a).
Long-horizon systems add packing, retrieval, or persistent state to
reduce drift (Henschel et al., 2024; Zhang et al., 2025; Yu et al., 2025; Hong et al., 2025; Wu et al., 2026; Chen et al., 2026c). Neither line shows that a hidden state was kept
and updated.
Hidden state and stage-resolved evaluation.
A hidden state cannot be scored if the requested update never
happens. StEvo-Bench, MemoBench, and the Video Shell Game study
updates under occlusion or unseen
swaps (Shin et al., 2026; Ma et al., 2026; Chen et al., 2026a).
WRBench and MBench add a camera leave and a later
check (Lu et al., 2026; Zhang et al., 2026a). Temporal and physical
suites likewise separate whether a transition occurs from whether
its endpoint is correct (Feng et al., 2024; Bansal et al., 2024; Li et al., 2025). MIST applies that principle to delayed
reveal; it does not replace Official WRBench, Official MBench, or
the Video Shell Game.
Judges and test-time refinement.
Structured VLM judges help on appearance, but remain weakest on
temporal and motion errors (Tong et al., 2024; Yang et al., 2025b).
VideoRepair, PhyT2V, Video-T1, and VQQA already diagnose or rewrite
videos for quality, physics, or preference
(Lee et al., 2024; Xue et al., 2024; Liu et al., 2025a; Song et al., 2026),
but none asks whether the asked change was shown. M3-Agent instead
revises the instruction so the model carries that change out. We
claim no numbered comparison with the tools above. The broader map
is in Appendix B.
3 MIST: separating scene setup from delayed state reveal
The cases in Fig. 2 show a missing final state, but
not why it is missing. A closed lid and a change that was never
carried out can produce the same total. MIST separates the two
(Fig. 3a). The model first sets the scene while
the change stays hidden, and only later is asked to show it.

What the evaluation does.
A delayed query asks who sits where, what is inside, or how many
objects remain. In text, this is a question about a target state
sT⋆s_{T}^{\star}. For a video generator, the clip must also produce that
state on screen. MIST names sT⋆s_{T}^{\star}, hides it behind an opaque
gap, and only then asks the generator to show it. Each case is three
5-second shots: the first establishes the scene, the second passes
through the opaque gap, and the third requests the reveal. All
reveal comparisons reuse the same locked first two shots. The
baseline prompt and the gap never contain the answer; the ablations
that do name it are marked as such.
The paired reveal analysis freezes the first two shots and regenerates
only the last shot from the same pre-reveal context.
Answer-only and diagnosis-guided arms may place the target in the
reveal prompt; Table 3 marks that access.
A prompt-channel audit confirms the target in the M3 and same-sentence
templates and confirms its removal from the generic open-and-hold arm,
so that arm is answer-free.
The same-sentence resample is an equal-compute control, not a
target-free control.
R0–R2 cover presence and count, binding, and history-update
operations (Table 1).

(1)
Eq. (1) says that a total collapses when any factor is
missing, and the total alone cannot tell a missing action from an
incorrect state. We therefore report the factors separately rather
than their product (Fig. 3a): setup checks the first
shot, leak the gap, and reveal and inside the last shot.
Never-open is the thresholded action class, not the mean reveal: a
low mean is not a never-open count (Figure 6).
A valid setup followed by a closed lid places the failure on the
reveal path, not on forgetting.
WRBench and MBench-T test the same gates in one continuous clip.
Each publishes a unique score, TT and UU, that gives no
credit when a step of this path is missing:
a→leave​until unjudgeable→return→hold⁡(xT),a\;\to\;\mathrm{leave}\;\text{until unjudgeable}\;\to\;\mathrm{return}\;\to\;\mathrm{hold}(x_{T}),
(2)
where aa is the requested event, such as a sit or a break. The
score thus requires the executed move, not only a final match
(§7).
4 Pre-experiments: the target is named, but the reveal is missing
We apply the MIST measures before designing an agent or evaluating
an official suite. Two questions come first. At which gate does the
baseline fail, and can naming the target fix it?
Does the scene fail before memory is tested?
Setup is high (Table 2): in most first shots the
objects and the container are in place. In 38 of 43 cases setup is
at least 0.8 while the baseline reveal stays below 0.3. What is missing is the later move that shows the asked-for
state.
Where does the baseline fail?
Mean reveal stays low. When each clip receives one label, 41 of 43
baseline clips never open; one opens to an empty or blocked view,
and one is correct. In the closed cases the final state cannot
be evaluated at all, because the required action never exposes it.
On those 41 clips, a hand comes in and does not open in 38, nobody
comes in in 3, and the wrong object is opened in none. The shot
length is not why the lid stays down (Figure 6),
but the three-shot stitch shapes how the failure looks: on a packed
15s MiniMax-H3 take the same judge finds 3 of 43 never-open and 24
of 43 opened onto the wrong state (Appendix C). The
failure moves from not opening to opening wrong; in both cases the
asked change is not carried out.
A low total here says nothing about whether the model forgot
sT⋆s_{T}^{\star}: persistence has not been tested yet.
Did the hidden gap leak the answer?
No target is visible in the middle chunk.
Paired gap leak is 0/430/43 for both the baseline and the later rewrite.
A broader 51-row baseline export also contains no leak, but that export
is not the paired denominator. Setup is not a leak. The reveal failure
does not follow an early exposure of the answer; it occurs at the
action gate in Eq. (1).

What changes after a targeted rewrite?
We inspect the last shot, diagnose its failed move, and rewrite only
that shot. With one kept clip per case, rather than best-of-five,
reveal rises and inside match rises with it
(Table 2). Setup remains flat.
Per case, reveal rises in 35 of 43, stays the same in 6, and falls
in 2; the mean paired change is 0.34 (95% CI 0.24 to 0.45).
The failure class also changes. Of the baseline never-opens, rewrite
leaves many closed, opens some onto a wrong state, and makes some
correct (Fig. 4a). The table’s open-but-wrong clips
include newly opened wrong states plus the initially correct case
R2-10, which the rewrite can break. The rewrite exposes more
states, but it does not guarantee that the exposed state is correct.
Accounting detail is in Figure 6.
All three operation families move the same way, and setup stays
flat in each: reveal goes from 0.132 to 0.549 on presence and count,
from 0.147 to 0.464 on binding, and from 0.163 to 0.454 on a history
update (Fig. 4c; Figure 6). Closed lids
that remain are not piled in one family. Openings onto the wrong state
are failed updates, not noise in one family
(Figure 6). The rewrite has to spell out both the
move and the last-frame evidence, not only a verb.
Finding 1. A hidden state cannot be judged until the model makes it
visible; a visible opening can still expose the wrong state.
Is naming the target enough?
The kept-clip diagnosis above locates the failure at the reveal gate;
it does not yet explain what kind of instruction opens that gate. If
the missing piece were only the answer, inserting sT⋆s_{T}^{\star} should
suffice. If it were only a verb, “open and hold” should suffice. We allocate the
same five tries in five ways (Table 3,
Fig. 4): the answer sentence is present or absent, and
the failed move is either rewritten or left unchanged. A fifth arm
rewrites the move from the same last frame but forbids every target
noun, color, and count (audited; 0/43 leaks).
The ordering in Table 3 separates these explanations.
The bare “open and hold” instruction performs worst. Supplying the
answer helps, but resampling the same sentence does not match a
diagnosis-guided rewrite. Looking at the clip and changing
the failed move gives the strongest best-of-five reveal and inside
scores (0.763 against 0.684 for answer-only). With the target
withheld the same rewrite reaches 0.174 and leaves 28 of 43 lids
closed: on this probe the rewrite opens the lid only when the prompt
also says what is inside. Each arm keeps, per case, the try whose
last frame the judge scores highest, so no cell here is the one-clip
mean of Table 2. Later tries are not better on
average, so the best-of-five cell is a running best
(Fig. 4d).
Where the same cases have an unchanged-prompt control, extra draws of

two tries add little.

Asking only to open fails, naming the target helps, and revising the
failed move helps most, but only with the target named. The next
section turns look, diagnose, and change into a test-time workflow.
5 M3-Agent: revise the instruction for the missing change
The pre-experiments show that the workflow must revise the failed
instruction, not append the target or repeat the same prompt.
M3-Agent (Make the Missing Move) does that at test
time (Fig. 3b): it reads the last frame, revises the
details of the instruction for that change, and generates again with
the same model. It does not add or train a memory module.
The workflow has three steps. First, a short task record lists the
actor or object, its required binding, the operation, and the
evidence that must appear in xTx_{T}; these fields come from the task
card. Second, a VLM inspects the generated last frame against that
record and assigns a visible failure mode, such as no action, wrong
binding, missing departure, return to an intact object, or an
occluded view. Third, the workflow rewrites the failed operation
rather than the answer, and the frozen generator produces another
candidate. This third step is the one that works in
Table 3.
The rewrite preserves the actor, object, target state, and temporal
order; only the failed operation and its final-frame evidence clause
may change. Diagnosis reads the rendered xTx_{T} once, never the
generator’s hidden states.
A worked case.
Figure 3b traces the workflow on that case. The
task record asks for the orange marble in the tin, the purple disk
outside, and a visible marble at the end. The raw take opens the tin
onto another object, which the record labels a wrong binding rather
than a missing action. The revised instruction keeps the tin, the
disk, and the order of events, and names the object that must go in;
the next take opens onto the orange marble. The raw take stays in the
candidate set, so a revision that makes things worse is not kept.
Given KK candidates, M3-Agent keeps the clip that best carries out
the instruction,
x^=arg⁡maxk≤K​score​(x(k),sT⋆),\hat{x}\;=\;\underset{k\leq K}{\arg\max}\;\mathrm{score}\!\left(x^{(k)},s_{T}^{\star}\right),
(3)
and the original candidate remains in the set. The score here is the
same check that reports the result: the MIST judge on MIST, and the
official gates on WRBench and MBench-T. A reader that sees only the
last frame, without that score, does not reliably beat the baseline
(§8). A single revision is not always better:
R2-10, for example, turns a correct case into an incorrect
one, so the original clip stays eligible. Searching several
instructions at test time is a known strategy
(Snell et al., 2024; Oshima et al., 2025; He et al., 2025; Khalaf et al., 2025; Landesberg, 2026).
Every reported best-of-KK and official keep-best cell is chosen after
generation with the reporting scorer; that is an oracle coverage
estimate, not a deployable critic
(Appendix A).
On MIST.
The agent works with frozen TI2V-5B. It preserves the first two
5-second shots and rewrites only the final reveal shot, and the
reveal prompt may include sT⋆s_{T}^{\star} (Table 3). The
kept-clip analysis in Table 2 locks one outcome per
case; Table 3 instead generates K=5K{=}5 candidates per
arm and applies Eq. (3).
On WRBench and MBench-T.
The agent works on 10-second clips from frozen T2V-A14B and keeps
each suite’s official camera clause; on WRBench the caption stays
task-context none. Candidate instructions establish the
requested relation before departure and hold it after return. On
MBench-T the candidate set must include the original clip: forcing
another leave–return can preserve the camera motion while worsening
the returned state. Selection is made per sample over a small
instruction set.

7 Main results: the same diagnosis on official scores
Under the scorers fixed in §6, we ask whether
official memory protocols fail at the same execution gates isolated
by MIST. Inspecting failed clips on official WRBench and MBench-T
shows the same missing action. The analysis transfers a diagnosis,
not a number: Internal MIST, Official unique scores, and packed H3
pilots remain separate cells (Appendix C).
What do the official scores contain?
Both suites already require the path in
Eq. (2) (Lu et al., 2026; Zhang et al., 2026a).
We report which gates change and which clip is kept per item.
We do not treat a correlation between a total and one of its own
parts as a separate causal finding
(Appendix A).
What happens when we search that path?
The two official protocols fail at different points, and those
points map onto the two remaining MIST failure types. On WRBench, the
camera often does not complete the required departure and return:
a shut D​6D6 gate is the same class as a never-open, so
persistence is not yet measured. On MBench-T the camera returns,
but the object is often still intact (Fig. 2): the
path completed, yet the aftermath is the wrong world state, as in
the open-but-wrong MIST clips. The search therefore has two different
jobs. On WRBench it has to find a missing path. On MBench-T it has to
keep the original clip when a fixed rewrite harms the aftermath.

8 Discussion: what execution evidence can establish
MIST separates the scene, the change, and the last frame
(Eqs. (1)–(2)); M3-Agent revises the
instruction. Neither shows what the model stored.
Measurement.
A high reveal is not a memory claim. If the asked change never
occurs, persistence is untested, whether the clip stays closed or
opens onto the wrong state (Table 2;
§4).
Selection.
Keep-best is an oracle over a small candidate pool, scored by the
same check that reports the result. The rewrite may name the
target, and a target-withheld control fails
(Table 3). A last-frame reader that does not see the
score does not beat the baseline
(Table 12). Because a rewrite can damage a
correct case, the original clip stays eligible.
Scope.
The main study uses one generator family under Internal and Official
protocols; packed MiniMax-H3 cells stay Internal
(Fig. 3; Appendix C). The held-out judge
check is not human validation (Appendix D). Claim boundaries
are in Table 13.
What a positive result would need.
We cannot claim the backbone stored sT⋆s_{T}^{\star}. That claim would
need a target-blind selector that beats the baseline, held-out
cases, and human labels on the exposed state. Until then, an opened
lid shows that the state can be judged, not that it was remembered.
9 Conclusion
MIST splits one memory score into three questions: was the scene
set, was the asked change carried out, and does the last frame show
the result. On the Internal cases the scene and gap usually hold,
yet the baseline often never shows the change, so persistence is
not yet tested. Revising the failed instruction exposes more of the
target state than naming it alone, though the shown state can still
be wrong.
M3-Agent revises the instruction so the same frozen model carries
out the change. Relative to the baseline, reveal rises on Internal
MIST and the Official unique scores improve, with opposite keep-best
consequences on the two suites. These cells do not establish that
the backbone stored sT⋆s_{T}^{\star}. A memory evaluation should
publish the three checks apart, not one total.

Appendix B Extended literature map and positioning
This section records the wider 2024–2026 literature used to bound
the paper’s claims. Entries are grouped by the question they answer,
rather than presented as evidence for one aggregate notion of
“memory.”
What enables long and persistent rollouts?
Diffusion and latent-video foundations establish the rendering
lineage [Ho et al., 2020, Blattmann et al., 2023, Team Wan, 2025], while
physical-AI platforms broaden the world-model framing
[NVIDIA et al., 2025]. Recent systems address exposure bias,
out-of-sight dynamics, bounded memory, and revisit stability through
self-conditioned training or explicit state
[Huang et al., 2025b, Duan et al., 2026b, Team et al., 2026, Xu et al., 2026b]. Omnimodal enterable worlds, controlled action-memory
probes, and long-horizon audio–visual story generation extend the same
line [Zhang et al., 2026b, King et al., 2026, Duan et al., 2026a].
Agent-driven and embodied evaluations further test
whether action-conditioned worlds remain usable over long objectives
[Ding et al., 2026, Wang and Li, 2026, Yang et al., 2026, Liu et al., 2026]. EntityBench separately measures recurring entities
across multi-shot gaps [He et al., 2026b]. Long-horizon
generators and packing systems also appear in the main related work
[Wu et al., 2024b, Xiang et al., 2024, Zhu et al., 2024, Garcin et al., 2026, Wang et al., 2026]. These works motivate
long-horizon memory, but architectural success in one protocol does
not resolve MIST’s execution-versus-persistence ambiguity.
Which benchmark dimensions are adjacent to MIST?
WorldBench and IntPhys 2 isolate physical concepts and object
permanence, whereas EWMBench and VBench 2.0 separate scene, motion,
semantics, and intrinsic faithfulness
[Upadhyay et al., 2026, Bordes et al., 2025, Yue et al., 2025, Zheng et al., 2025]. Understanding suites separate
endpoint answers from continuous
tracking [Yu et al., 2026, Chen et al., 2026b, Han et al., 2026b].
LongVideoBench and MLVU test long-context understanding rather than
generator-side state
production [Wu et al., 2024a, Zhou et al., 2024].
ChronoMagic-Bench separates amount of change from temporal coherence,
and T2VPhysBench evaluates physical laws with manual judgments
[Yuan et al., 2024, Guo et al., 2025]. Adjacent temporal
and physical suites include TC-Bench, T2V-CompBench, OSC-Bench,
YoCausal, PhyGenBench, and VideoPhy2
[Sun et al., 2024, Han et al., 2026a, Xie et al., 2026, Meng et al., 2024, Bansal et al., 2025]. MIST instead fixes a
target state and asks whether the generated operation makes that
state judgeable after an opaque gap.
How has video generation been refined at test time?
Reward gradients and human-feedback rewards improve video generation
through learned objectives
[Prabhudesai et al., 2024, Liu et al., 2025b].
GenMAC and Prompt-A-Video use collaborative or preference-aligned
prompt revision [Huang et al., 2024, Ji et al., 2024].
ScalingNoise, VISTA, RAPO++, and ImagerySearch broaden search over
noise, prompts, candidates, or evaluators
[Yang et al., 2025a, Long et al., 2025, Gao et al., 2025, Wu et al., 2025]. LatSearch and noise-trajectory search move
selection inside diffusion inference, while GEARS diagnoses and
recycles candidates
[Zhao et al., 2026, Ramesh and Mardani, 2025, He et al., 2026a].
M3-Agent is not a generic test-time search. Its contribution is an
operation-constrained response to a delayed-reveal diagnosis, and its
score-aware selection remains an oracle coverage analysis.
What can automated video evaluators establish?
VBench and EvalCrafter established multidimensional evaluation beyond
single perceptual totals
[Huang et al., 2023, Liu et al., 2023b]. VideoScore,
AIGV-Assessor, LOVE, and UVE learn or organize fine-grained
human-facing quality or task judgments
[He et al., 2024, Wang et al., 2024, Wang et al., 2025, Liu et al., 2025c, Li et al., 2024]. VideoGen-Eval decomposes prompts
into checkable questions, while WorldJen and RAVEN-Eval study rubric
design, score compression, ordering, and confidence
[Yang et al., 2025b, Inbasekar et al., 2026, Jia et al., 2026].
CLIP-style alignment and vision-centric VLMs provide useful readers
[Radford et al., 2021, Liu et al., 2023a, Tong et al., 2024], but no one
reader is treated here as ground truth for latent state. This is why
MIST reports gate-specific judgments, a held-out reread, and explicit
disagreement with official scorers.
Embedding-centric vision learners and generators, and cycle-consistent
text-guided image editing, sit adjacent to the representation and
prompt-revision tools used above
[Xu et al., 2025, Xu et al., 2026a, Xu et al., 2023].

Appendix D Held-out last-frame judge
The main 122B judge is unchanged. Qwen3-VL-8B-Instruct rereads the
same locked last frames as Table 6 and answers YES or NO
to sT⋆s_{T}^{\star}. Official TT and UU are not replaced.
The main-text last-frame rate 0.0230.023 is a strict YES rate. Mean
inside in Table 2 is 0.0470.047.

almost every baseline frame is negative. Agreement on the action bit
of rewritten frames is much lower, and agreement with official WRBench
and MBench gates is lower still
(Table 20). An 8B YES is not an official D​5D5 or
D​6D6 decision, and it is not an MBench state score. Those rubrics ask
different questions.
