Abstract
Large Vision-Language Models (LVLMs) repeatedly process hundreds of visual tokens across decoder layers, incurring substantial computation and memory costs.
Existing inference-time visual token pruning methods often irreversibly remove low-ranked tokens, although the set of visual tokens receiving high query-conditioned attention can change across decoder depth.
Recoverable routing preserves skipped tokens for later reconsideration, but re-admits them with stale representations after bypassing intermediate transformations.
We further find that replacing stale re-admitted states with their current-depth oracle states from a full-token reference trajectory substantially improves grounding performance.
We therefore propose CatchUp, a training-free framework for depth-aware visual-token re-admission.
CatchUp repeatedly re-evaluates query-conditioned visual relevance, processes only selected visual tokens through each decoder interval, and preserves deferred tokens for later re-admission.
Upon re-admission, CatchUp approximates missed representation evolution using reference-to-current transition signals from semantically and spatially related visual tokens.
Across three referring-expression grounding datasets and six multimodal benchmarks, CatchUp achieves the highest average relative retention in both benchmark groups at 64-, 128-, and 192-token budgets.
At a 64-token budget with 88.9% fewer active visual tokens, CatchUp retains 92.17% of the full model’s performance on average across six multimodal benchmarks while reducing end-to-end latency by 8.0%.
Code is available at https://github.com/pej0918/CatchUp

Large Vision-Language Models (LVLMs) represent images as hundreds or thousands of visual tokens processed with text tokens throughout decoder layers.
Although these tokens provide fine-grained evidence, repeatedly processing them incurs substantial attention, feed-forward, and memory costs.
Visual-token reduction has therefore become a common strategy for improving inference efficiency, either by compressing representations before decoding or reducing visual tokens within the decoder [20, 3, 25, 17, 9].
Most decoder-side methods remove or compress visual tokens based on attention, query relevance, redundancy, or spatial structure [3, 25, 17, 9].
Despite differences in scoring criteria and reduction schedules, these methods restrict the set of visual tokens available to later decoder layers.
Once a visual token is removed or absorbed into a compressed representation, it cannot independently return even if it becomes relevant at a later decoder depth.
Recoverable routing relaxes this limitation by preserving unselected visual tokens through layer-wise bypass or stage-wise deferral [4, 19].
However, when a deferred token is re-admitted, it retains a hidden state from before the skipped decoder transformations, while tokens that remain active have been updated through the intermediate layers.
As a result, the re-admitted token can be misaligned with the current decoder depth.
Effective recoverable routing should therefore account for how both visual relevance and representations depend on decoder depth. We observe that the visual-token sets favored by query-conditioned attention change substantially across decoder depth, with tokens excluded at earlier layers receiving high relevance scores later.
We further find that replacing stale re-admitted states with their current-depth oracle states from a full-token reference trajectory substantially improves grounding performance.
Building on these observations, we propose CatchUp, a training-free framework that enables depth-aware visual-token re-admission for efficient LVLM inference.
At selected decoder layers, CatchUp re-evaluates query-conditioned relevance, preserves unselected visual tokens for later re-admission, and processes only the selected visual tokens until the next routing decision.
When a deferred token is selected again, CatchUp approximates the representation evolution it missed during deferral using reference-to-current transition signals from semantically and spatially related visual tokens.
In this way, CatchUp allows re-admitted visual tokens to “catch up” with the current decoder depth without requiring every visual token to traverse all intermediate layers.
Experiments across referring-expression grounding and general multimodal benchmarks consistently show that CatchUp achieves a better accuracy-efficiency trade-off than both irreversible pruning and uncorrected recoverable routing.
At matched routing budgets, CatchUp achieves the highest grounding performance among the evaluated efficient methods. Under matched prefill computation, CatchUp uses the fewest visual tokens and the smallest decoder KV-cache, while reducing end-to-end latency by 8.0% relative to dense inference.
Our main contributions are:
•
We identify two complementary limitations in efficient visual-token routing.
Irreversible reduction can discard tokens that receive high query-conditioned relevance scores at later decoder depths, while re-admitted tokens can carry stale representations after skipping intermediate decoder layers.
•
We introduce CatchUp, a training-free framework for depth-aware visual-token re-admission that preserves deferred visual tokens for later reconsideration and approximates the representation evolution missed during deferral using reference-to-current transition signals from semantically and spatially related visual tokens.
•
We show that CatchUp achieves the highest average retention in both benchmark groups, while using the smallest decoder KV-cache under matched prefill computation and reducing end-to-end latency by 8.0% relative to dense inference.
2 Related Work
2.1 Irreversible Visual Token Reduction
Visual-token reduction methods operate either before decoding or within the language decoder.
Pre-decoder methods select or merge redundant vision-encoder
outputs [20], while decoder-side methods use
attention or query relevance [3, 25],
adaptive budgets [21, 22, 18],
progressive reduction [17], diversity and
duplication [1, 16], or spatial and
grounding constraints [6, 5, 9].
Despite different selection criteria and reduction schedules, these methods share an irreversible token-handling pattern.
Once an original token is pruned or merged, it is no longer available as an individual token in subsequent decoder layers.
2.2 Recoverable Visual Token Routing
Recoverable routing replaces permanent removal with conditional computation.
Recent recoverable methods such as ALVTS [4] and ReRoute [19] preserve unselected visual tokens through layer-wise bypass or stage-wise deferral, allowing them to return to active computation at later decoder layers.
Both are related to token-wise conditional computation in Mixture-of-Depths [15], but specifically target visual tokens within pretrained LVLM decoders.
These methods allow previously excluded evidence to be reconsidered at later decoder layers, but do not update deferred tokens for the decoder transformations they skip.
As a result, a re-admitted token may carry a hidden state that is misaligned with the current decoder depth.
Structural comparison.
Table 1 compares representative decoder-side methods across repeated selection, original-token recoverability, and re-admission correction.
Irreversible methods make pruned or merged original tokens unavailable for subsequent computation, while ALVTS and ReRoute preserve original tokens for later re-admission without correcting for skipped decoder transformations.
CatchUp combines recoverable repeated routing with re-admission correction that approximates the representation evolution missed during deferral.
3 Motivating Observations
To understand the requirements for effective recoverable visual-token routing, we examine two empirical questions.
(i) Can visual tokens excluded by an early selection become highly ranked by the same query-conditioned relevance criterion at later decoder depths?
(ii) Does representation staleness affect re-admitted tokens at the current decoder depth?
3.1 Observation I: Query-Relevant Visual-Token Sets Change Across Decoder Depth

Voln⁡(ℓ)=1−|ℰnℓ∩ℰnℓ−1|K.\operatorname{Vol}_{n}(\ell)=1-\frac{\left|\mathcal{E}_{n}^{\ell}\cap\mathcal{E}_{n}^{\ell-1}\right|}{K}.
(1)

We therefore define the late-emerging evidence ratio (LER) relative to the reference layer ℓref=2\ell_{\mathrm{ref}}=2:
LERn⁡(ℓ)=|ℰnℓ∖ℰnℓref|K.\operatorname{LER}_{n}(\ell)=\frac{\left|\mathcal{E}_{n}^{\ell}\setminus\mathcal{E}_{n}^{\ell_{\mathrm{ref}}}\right|}{K}.
(2)
LER measures the fraction of the layer-ℓ\ell top-KK set that was absent from the layer-2 reference set.
Under an irreversible layer-2 top-KK selection, these tokens would be unavailable for later reconsideration.

As shown in Figure 2(a), the mean volatility is 28.85%, indicating that more than one quarter of the top-64 set changes between adjacent layers on average.
LER exceeds 50% by layer 7 and reaches 99.42% at layer 31 (Figure 2(b)).
These results do not imply that later-layer relevance estimates are inherently more accurate; rather, they show that the evidence identified by the same criterion changes substantially with decoder depth.
This motivates preserving excluded tokens for later reconsideration.
The remaining question is whether their stale representations remain suitable when they return.
3.2 Observation II: Re-Admitted Tokens Carry Stale Representations
A deferred token skips the self-attention and feed-forward transformations of intermediate decoder layers and therefore returns with an earlier-layer hidden state.
This can leave the re-admitted token misaligned with the current decoder depth, unlike continuously active tokens that undergo the intervening transformations.
We therefore examine two aspects of representation staleness: whether stale states remain informative for re-admission decisions, and whether they are suitable for downstream computation once re-admitted.

The qualitative example further shows that the stale condition localizes an incorrect region, whereas the current-depth oracle produces a prediction closer to the ground-truth target.
These results show that the representation carried by a re-admitted token affects downstream grounding even when token selection is held fixed.
Combined with Section 3.1, this analysis reveals two complementary requirements for recoverable routing: deferred visual evidence should remain available for later reconsideration, and its representation should account for the transformations skipped before re-admission.
Since obtaining the full-token current-depth state would negate the computational benefit of deferral, efficient routing requires an approximation of this missed representation evolution.
4 Method
Figure 4:
Overview of CatchUp.
At each routing layer, CatchUp re-evaluates the complete visual-token set, processes only selected visual tokens through the subsequent decoder interval, and preserves deferred tokens for later re-admission.

4.1 Overview
Motivated by the observations in Sections 3.1 and 3.2, we introduce CatchUp, a training-free framework that combines reversible visual-token routing with Local Transition Correction (LTC).
CatchUp repeatedly re-evaluates query-conditioned visual relevance over the complete visual-token set and processes only selected visual tokens between routing layers.
When a deferred token is selected again, LTC approximates the representation evolution missed during deferral using reference-to-current transition signals from related visual tokens.
Let 𝒱\mathcal{V} denote the visual-token index set and LL the total number of decoder layers, indexed by {0,…,L−1}\{0,\ldots,L-1\}.
CatchUp performs visual-token routing at a subset of these layers,
𝒮={ℓ1,ℓ2,…,ℓS}⊆{0,…,L−1},ℓ1<ℓ2<⋯<ℓS,\mathcal{S}=\{\ell_{1},\ell_{2},\ldots,\ell_{S}\}\subseteq\{0,\ldots,L-1\},\quad\ell_{1}<\ell_{2}<\cdots<\ell_{S},
where S=|𝒮|S=|\mathcal{S}| is the number of routing layers, ℓs\ell_{s} denotes the ss-th routing layer, and 𝒱s⊆𝒱\mathcal{V}_{s}\subseteq\mathcal{V} denotes the visual tokens selected at ℓs\ell_{s}.
We denote by hi​[ℓ]h_{i}[\ell] the representation of token ii available at decoder depth ℓ\ell.
Routing at ℓs\ell_{s} is performed at the layer input, before executing decoder layer ℓs\ell_{s}, and only the selected visual tokens subsequently participate in its attention and feed-forward computation.
All visual tokens remain active through the decoder layers preceding the first routing layer ℓ1\ell_{1}.
At each routing layer ℓs\ell_{s}, CatchUp first selects 𝒱s\mathcal{V}_{s} from the complete visual-token set at the layer input, allowing previously deferred tokens to return to active computation.
LTC is then applied only to newly re-admitted tokens before the selected tokens execute decoder layer ℓs\ell_{s}. Thus, it does not affect the routing decision at the same layer.
Figure 4 summarizes the overall procedure.
4.2 Reversible Visual Evidence Routing
Query-conditioned visual-token selection.
At routing layer ℓs\ell_{s}, CatchUp re-evaluates the complete visual-token candidate set using the current-layer text query and each visual token’s latest available representation.
For an active token, this representation is available at the input to the
current routing layer, whereas a deferred token retains its latest cached
hidden state.
Deferred tokens are not propagated through the skipped decoder layers for routing; instead, their cached states are projected using the key projection of the current routing layer and scored against the current-layer text query.
Let 𝐀~s(m)\widetilde{\mathbf{A}}_{s}^{(m)} denote the resulting post-softmax routing attention of head mm, and let t⋆t_{\star} denote the last text-token position.
The relevance score of visual token i∈𝒱i\in\mathcal{V} is
ris=1Nh​∑m=1Nh𝐀~s(m)​[t⋆,i],r_{i}^{s}=\frac{1}{N_{h}}\sum_{m=1}^{N_{h}}\widetilde{\mathbf{A}}_{s}^{(m)}[t_{\star},i],
(3)
where NhN_{h} denotes the number of attention heads.
Given the visual-token budget KsK_{s} at routing layer ℓs\ell_{s}, we select
𝒱s=TopKi∈𝒱⁡(ris;Ks).\mathcal{V}_{s}=\operatorname{TopK}_{i\in\mathcal{V}}\left(r_{i}^{s};K_{s}\right).
(4)
Because selection is performed over the complete original visual-token set 𝒱\mathcal{V}, a token excluded at one routing layer remains eligible for reconsideration at later routing layers.
Although deferred tokens are scored using stale cached states, Section 3.2 shows that these states retain useful
query-relevance information for re-admission.
Reversible token execution.
After selection at routing layer ℓs\ell_{s}, all text tokens and the visual tokens in 𝒱s\mathcal{V}_{s} are processed through the subsequent decoder interval.
For s<Ss<S, this interval consists of decoder layers ℓs,…,ℓs+1−1\ell_{s},\ldots,\ell_{s+1}-1, with the next routing decision performed at the input to layer ℓs+1\ell_{s+1}.
After the final routing layer ℓS\ell_{S}, the selected tokens are processed through layers ℓS,…,L−1\ell_{S},\ldots,L-1.
Visual tokens outside 𝒱s\mathcal{V}_{s} are deferred.
Their cached hidden states are carried forward unchanged, while the tokens are excluded from decoder computation until the next routing decision.
For each deferred token, CatchUp tracks the decoder depth associated with
its latest cached representation. To support LTC, CatchUp retains the
current visual-state snapshot together with only those historical snapshots still referenced by deferred tokens, and releases historical snapshots once they are no longer needed.
Further implementation details are provided in the supplementary material.
Before the first routing decision, all visual tokens are active, and we define 𝒱0=𝒱\mathcal{V}_{0}=\mathcal{V}.
The set of tokens newly re-admitted at routing layer ℓs\ell_{s} is
ℛs=𝒱s∖𝒱s−1.\mathcal{R}_{s}=\mathcal{V}_{s}\setminus\mathcal{V}_{s-1}.
(5)
Tokens in ℛs\mathcal{R}_{s} reintroduce visual evidence that did not participate in computation while they were deferred.
However, their cached representations have not undergone the same decoder transformations as tokens that remained active.
CatchUp therefore applies LTC to the newly re-admitted tokens in ℛs\mathcal{R}_{s} before they resume active computation.
4.3 Local Transition Correction
LTC aims to approximate the representation evolution missed by a re-admitted token without explicitly processing that token through the decoder layers it skipped.
Consider a token p∈ℛsp\in\mathcal{R}_{s} with stale cached state hp​[ℓp]h_{p}[\ell_{p}], where ℓp<ℓs\ell_{p}<\ell_{s} denotes the reference depth associated with its latest cached representation.
The current-depth oracle in Section 3.2 would instead provide the same token’s state from a full-token reference trajectory at decoder depth ℓs\ell_{s}.
Because obtaining this oracle state would require full-token computation
through the skipped decoder layers, LTC approximates the missing
representation transition from ℓp\ell_{p} to ℓs\ell_{s} using reference-to-current transition signals from related visual tokens.
Intuitively, LTC identifies visual tokens related to the re-admitted token at its reference depth and uses their reference-to-current displacements to estimate the token’s missed representation evolution.
For notational simplicity, we suppress the routing-step index ss for
token-specific quantities defined at the current routing layer ℓs\ell_{s}.
Transition-anchor candidates.
At routing layer ℓs\ell_{s}, we define the candidate anchor set as
ℱs=𝒱s∩𝒱s−1.\mathcal{F}_{s}=\mathcal{V}_{s}\cap\mathcal{V}_{s-1}.
(6)
Since ℱs∩ℛs=∅\mathcal{F}_{s}\cap\mathcal{R}_{s}=\varnothing, a newly re-admitted token is never used as an anchor at the same routing layer. A re-admitted token can, however, become eligible as an anchor at a subsequent routing layer if it remains selected.
A token q∈ℱsq\in\mathcal{F}_{s} is selected at both the previous and current routing layers and has therefore been updated through the immediately preceding decoder interval.
Its state hq​[ℓs]h_{q}[\ell_{s}] represents the token at the current routing layer.
Let h¯q​[ℓ]\bar{h}_{q}[\ell] denote the retained reference state of token qq from the visual-state snapshot at layer ℓ\ell.
For a re-admitted token pp whose latest cached representation is associated with reference depth ℓp\ell_{p}, the pair (h¯q​[ℓp],hq​[ℓs])(\bar{h}_{q}[\ell_{p}],h_{q}[\ell_{s}]) provides a reference-to-current transition signal that can be transferred to pp.
Semantic–spatial anchor selection.
Not all candidate anchors provide equally useful transition signals for a
re-admitted token.
Because a re-admitted token has no current-layer representation, we measure representation similarity using the retained visual-state snapshot at its reference depth ℓp\ell_{p}, which provides a common reference for the deferred token and candidate anchors.
For each candidate anchor q∈ℱsq\in\mathcal{F}_{s}, we compute
ap​q=cos⁡(hp​[ℓp],h¯q​[ℓp])−λ​dsp​(p,q),a_{pq}=\cos\left(h_{p}[\ell_{p}],\bar{h}_{q}[\ell_{p}]\right)-\lambda d_{\mathrm{sp}}(p,q),
(7)
where cos⁡(⋅,⋅)\operatorname{cos}(\cdot,\cdot) denotes cosine similarity, dsp​(p,q)d_{\mathrm{sp}}(p,q) denotes the Euclidean distance between their patch-grid coordinates after normalizing each spatial axis to [0,1][0,1], and λ\lambda controls the contribution of spatial distance to anchor
selection. If ℱs=∅\mathcal{F}_{s}=\varnothing, LTC is skipped and the cached representation hp​[ℓp]h_{p}[\ell_{p}] is used unchanged.
Otherwise, we retain up to the MM highest-scoring anchors,
𝒩p=TopMq∈ℱs⁡(ap​q),\mathcal{N}_{p}=\operatorname{TopM}_{q\in\mathcal{F}_{s}}\left(a_{pq}\right),
(8)
and compute their normalized anchor weights as
wp​q=exp⁡(ap​q/τ)∑q′∈𝒩pexp⁡(ap​q′/τ),q∈𝒩p,w_{pq}=\frac{\exp\left(a_{pq}/\tau\right)}{\sum_{q^{\prime}\in\mathcal{N}_{p}}\exp\left(a_{pq^{\prime}}/\tau\right)},\qquad q\in\mathcal{N}_{p},
(9)
where τ\tau is a temperature parameter.
Local transition transfer.
For each selected anchor q∈𝒩pq\in\mathcal{N}_{p}, its reference-to-current representation displacement is
δp​q=hq​[ℓs]−h¯q​[ℓp].\delta_{pq}=h_{q}[\ell_{s}]-\bar{h}_{q}[\ell_{p}].
(10)
LTC estimates the missing transition of re-admitted token pp by aggregating these local displacements:
Δ​hp=∑q∈𝒩pwp​q​δp​q.\Delta h_{p}=\sum_{q\in\mathcal{N}_{p}}w_{pq}\delta_{pq}.
(11)
Rather than replacing the re-admitted token with an anchor representation, LTC transfers only the estimated representation change and adds it to the token’s own stale representation:
h^p=hp​[ℓp]+γ​Δ​hp,\widehat{h}_{p}=h_{p}[\ell_{p}]+\gamma\Delta h_{p},
(12)
where γ\gamma controls the correction strength.
This residual formulation retains the token’s own stale representation as the base state while approximating the evolution missed during deferral.
The corrected state h^p\widehat{h}_{p} then serves as the representation of token pp when it resumes active computation.
Unlike the current-depth oracle in Section 3.2, LTC does not require access to full-token current-depth states during inference.
Instead, it estimates this evolution using retained reference states and local transition signals available during efficient inference.
CatchUp therefore preserves the computational benefit of reversible token routing while reducing the representation mismatch caused by skipped decoder transformations.

5 Experiments
5.1 Experimental Setup
Baselines.
We compare CatchUp with FastV [3], SparseVLM [25], PyramidDrop [17], Nüwa [9], and the recoverable routing method ReRoute [19], all under a common LLaVA-1.5-7B backbone [12]. We additionally report the dense 576-token model as Full and compare efficient methods under matched routing budgets whenever applicable.
Evaluation Benchmarks.

For all grounding benchmarks, we report Acc@0.5, using val/TestA/TestB for RefCOCO and RefCOCO+ and val/test for RefCOCOg.
When a single RefCOCO score is reported, it denotes the average over val, TestA, and TestB.
We further evaluate general multimodal capability on POPE [11],

and MMBench [13], using the standard evaluation metric for each benchmark.
Experimental Settings.

We also evaluate CatchUp on Qwen2.5-VL-7B-Instruct [2], and further results and analyses are in the supplementary material.

6 Conclusion
We introduced CatchUp, a training-free framework combining reversible visual-token routing with Local Transition Correction (LTC) to preserve deferred evidence and approximate missed representation evolution.
CatchUp achieves the best performance among the evaluated efficient methods across all eight grounding splits at 64-, 128-, and 192-token budgets.
Across six multimodal benchmarks, it retains 92.17% of the full model’s performance at a 64-token routing budget.
These results highlight that effective recoverable routing requires both preserving deferred evidence and correcting stale representations upon re-admission.

Appendix A Implementation Details
This section provides additional implementation details of CatchUp that are omitted from the main paper for brevity.
All operations are performed during inference without updating any
pretrained model parameters.
A.1 Reversible Routing and Persistent Token States
CatchUp maintains one persistent logical entry for each original visual token throughout inference.
Each entry stores the token’s original index, patch-grid position,
latest hidden representation, and the decoder depth associated with that representation.
Routing therefore changes whether a visual token participates in decoder computation without permanently discarding its identity, spatial correspondence, or latest available representation.
At routing layer ℓs\ell_{s}, CatchUp reconstructs the complete candidate set of original visual tokens and computes the query-conditioned relevance scores defined in the main paper.
The selected set is
𝒱s=TopKi∈𝒱⁡(ris;Ks),\mathcal{V}_{s}=\operatorname{TopK}_{i\in\mathcal{V}}(r_{i}^{s};K_{s}),
(13)
where 𝒱\mathcal{V} denotes the complete set of original visual tokens. For active visual tokens, routing scores are computed from their current hidden representations. For deferred tokens, CatchUp recomputes their routing keys from the cached hidden representations using the key projection of the current routing layer rather than reusing stale keys. Routing is performed at the input to decoder layer ℓs\ell_{s}, before that layer is executed.
Tokens outside 𝒱s\mathcal{V}_{s} are deferred rather than removed.
After selection and any required LTC, only the text tokens and visual tokens in 𝒱s\mathcal{V}_{s} are gathered into a compact sequence.
For s<Ss<S, this sequence is processed through decoder layers ℓs,…,ℓs+1−1\ell_{s},\ldots,\ell_{s+1}-1, after which routing is performed again at the input to layer ℓs+1\ell_{s+1}.
After the final routing decision, the selected tokens are processed through layers ℓS,…,L−1\ell_{S},\ldots,L-1.
Selected visual tokens preserve their original relative order when forming this compact sequence.
After the interval, their updated hidden states are scattered back to
their corresponding persistent token entries, and their associated
reference depths are updated accordingly.
Deferred tokens bypass the decoder interval.
Their cached hidden representations and associated reference depths
remain unchanged.
At the next routing layer, these persistent entries are again included in the complete candidate set, allowing previously deferred tokens to be re-scored and potentially selected again.
Before the first routing decision, all visual tokens are active, and
we define 𝒱0=𝒱\mathcal{V}_{0}=\mathcal{V}.
The set of newly re-admitted tokens at routing layer ℓs\ell_{s} is
ℛs=𝒱s∖𝒱s−1.\mathcal{R}_{s}=\mathcal{V}_{s}\setminus\mathcal{V}_{s-1}.
(14)
Accordingly, ℛ1=∅\mathcal{R}_{1}=\varnothing, since no visual token has
been deferred before the first routing decision.
A.2 Need-Based Reference-State Management
For each visual token ii, CatchUp tracks the reference depth ℓi\ell_{i}
associated with its latest cached representation.
When a token remains deferred across multiple routing intervals, both its cached representation and ℓi\ell_{i} remain unchanged.
Therefore, when token pp is re-admitted at routing layer ℓs\ell_{s}, its cached state corresponds to an earlier decoder depth,
ℓp<ℓs.\ell_{p}<\ell_{s}.
(15)
LTC requires reference anchor representations at the reference depth ℓp\ell_{p} of the re-admitted token.
To provide these states without retaining the full decoder history,
CatchUp uses need-based retention of decoder-layer reference snapshots.
Each reference snapshot stores visual representations indexed by their
original visual-token positions.
Following the notation in the main paper, h¯q​[ℓ]\bar{h}_{q}[\ell] denotes the
stored reference representation of token qq at decoder depth ℓ\ell.
Reference snapshots reflect the visual states associated with their
corresponding decoder depths. At a routing layer, newly re-admitted tokens are stored after LTC has been applied, so their corrected states become the corresponding reference states.
A historical snapshot is retained only while it is required by at least one currently deferred visual token.
Specifically, if the latest cached representation of any deferred token
is associated with reference depth ℓ\ell, the corresponding snapshot
remains live.
Once no deferred token refers to that layer, the corresponding snapshot is released.
The current visual-state snapshot is retained as a potential reference for visual tokens that become deferred at the current routing decision.
It is released once no deferred token requires that layer as its reference.
Consequently, snapshot retention is determined dynamically by the
reference layers of currently deferred tokens rather than by a fixed history window.
This policy avoids storing visual states for every decoder layer and also avoids retaining obsolete reference snapshots after they are no longer needed.
The retained reference states are used only by LTC and do not introduce additional visual tokens into the decoder computation or KV cache.
As a defensive fallback, if a required reference snapshot is unavailable, LTC is skipped for the affected token and its cached representation is used without modification.
A.3 LTC Eligibility and Transition Anchors
LTC is applied only to newly re-admitted visual tokens
p∈ℛsp\in\mathcal{R}_{s}.
For such a token, we define the re-admission gap as
gp=ℓs−ℓp,g_{p}=\ell_{s}-\ell_{p},
(16)
where ℓp\ell_{p} denotes the last active decoder depth that produced its latest cached representation.
The transition-anchor candidate set is
ℱs=𝒱s∩𝒱s−1.\mathcal{F}_{s}=\mathcal{V}_{s}\cap\mathcal{V}_{s-1}.
(17)
Since ℱs∩ℛs=∅\mathcal{F}_{s}\cap\mathcal{R}_{s}=\varnothing, a newly re-admitted token is not eligible to serve as an anchor at the same routing layer. A token re-admitted at an earlier routing layer can, however, become an anchor at a subsequent routing layer if it remains selected.
Accordingly, a token in ℱs\mathcal{F}_{s} is selected at both consecutive routing layers and has been updated through the immediately preceding decoder interval.
When fewer than MM candidate anchors are available, all available candidates are used.
If the required reference snapshot is unavailable, LTC is not applied and the cached representation of pp remains unchanged.
A.4 Semantic–Spatial Anchor Selection
For LLaVA-1.5, the 576 visual tokens correspond to a
24×2424\times 24 patch grid.
Let (yi,xi)(y_{i},x_{i}) denote the grid coordinate of visual token ii, where
yi,xi∈{0,…,23}.y_{i},x_{i}\in\{0,\ldots,23\}.
(18)
We normalize the two spatial axes independently to [0,1][0,1]:
𝐩i=(yi23,xi23).\mathbf{p}_{i}=\left(\frac{y_{i}}{23},\frac{x_{i}}{23}\right).
(19)
The spatial distance between re-admitted token pp and candidate anchor qq is the Euclidean distance between their normalized patch-grid coordinates:
dsp​(p,q)=‖𝐩p−𝐩q‖2.d_{\mathrm{sp}}(p,q)=\left\|\mathbf{p}_{p}-\mathbf{p}_{q}\right\|_{2}.
(20)
The maximum horizontal or vertical displacement is therefore 11, and the maximum diagonal distance is 2\sqrt{2}.
Semantic similarity is evaluated using the retained visual-state snapshot
associated with the reference depth of the re-admitted token.
Specifically, the cached representation hp​[ℓp]h_{p}[\ell_{p}] is compared with the stored candidate representation h¯q​[ℓp]\bar{h}_{q}[\ell_{p}].
This provides a common reference for comparing the deferred token and candidate anchors without directly comparing a stale state with a current-depth state.
Candidate anchors are ranked according to the semantic–spatial score defined in the main paper,
ap​q=cos⁡(hp​[ℓp],h¯q​[ℓp])−λ​dsp​(p,q),a_{pq}=\cos\left(h_{p}[\ell_{p}],\bar{h}_{q}[\ell_{p}]\right)-\lambda d_{\mathrm{sp}}(p,q),
(21)
and at most MM highest-ranked candidates are retained.
Their scores are converted into normalized aggregation weights using the temperature τ\tau defined in the main paper.
A.5 Transition Computation and State Update
For each selected anchor q∈𝒩pq\in\mathcal{N}_{p}, CatchUp computes its
reference-to-current representation transition,
δp​q=hq​[ℓs]−h¯q​[ℓp].\delta_{pq}=h_{q}[\ell_{s}]-\bar{h}_{q}[\ell_{p}].
(22)
The transition estimated for re-admitted token pp is then
Δ​hp=∑q∈𝒩pwp​q​(hq​[ℓs]−h¯q​[ℓp]),\Delta h_{p}=\sum_{q\in\mathcal{N}_{p}}w_{pq}\left(h_{q}[\ell_{s}]-\bar{h}_{q}[\ell_{p}]\right),
(23)
where wp​qw_{pq} denotes the normalized semantic–spatial anchor weight.
LTC applies this estimated transition to the token’s own cached
representation:
h^p=hp​[ℓp]+γ​Δ​hp.\widehat{h}_{p}=h_{p}[\ell_{p}]+\gamma\Delta h_{p}.
(24)
This implementation transfers the local change in representation rather than directly mixing absolute current-depth anchor states.
The token’s own cached representation therefore remains the base state, while the anchor transitions approximate the representation evolution missed during deferral.
The corrected state h^p\widehat{h}_{p} directly replaces the stale cached representation and is used when token pp resumes active computation through the subsequent decoder interval.

C.1 Additional Details for Motivating Observations
We provide additional protocol and metric details for the motivating
observations in the main paper.
Observation I protocol.
The evidence-dynamics analysis uses 500 RefCOCO samples with
LLaVA-1.5-7B under full-token inference with all 576 visual tokens.
At each decoder layer, query-conditioned relevance is measured using the
post-softmax attention from the last text token to each visual token,
averaged over attention heads.
We use K=64K=64 and decoder layer 2, corresponding to the first routing layer in our routing configuration, as the reference depth.
Relevance volatility and the late-emerging evidence ratio (LER) are
computed as defined in the main paper.
For reference, two independently sampled top-64 subsets from 576 visual
tokens have an expected LER of 1−64/576=88.89%1-64/576=88.89\%.
Stale–oracle routing agreement.
For the routing diagnostic in Observation II, stale and current-depth oracle routing use the same current-layer text query and the same key projection of the current routing layer.
They differ only in the visual representation used to construct each key.
Let ℓis\ell_{i}^{s} denote the reference depth associated with visual token
ii’s latest available representation before routing at ℓs\ell_{s}.
The two routing scores are
ri,stales=Attn⁡(qℓs,Kℓs​(hi​[ℓis])),r_{i,\mathrm{stale}}^{s}=\operatorname{Attn}\left(q^{\ell_{s}},K_{\ell_{s}}(h_{i}[\ell_{i}^{s}])\right),
(26)
and
ri,oracles=Attn⁡(qℓs,Kℓs​(hi,full​[ℓs])).r_{i,\mathrm{oracle}}^{s}=\operatorname{Attn}\left(q^{\ell_{s}},K_{\ell_{s}}(h_{i,\mathrm{full}}[\ell_{s}])\right).
(27)
Here, hi​[ℓis]h_{i}[\ell_{i}^{s}] is the token’s latest available representation, while hi,full​[ℓs]h_{i,\mathrm{full}}[\ell_{s}] is the representation of the same token at the current decoder depth from a separate full-token reference trajectory.
The oracle scores are used only for diagnostic comparison and never alter the actual stale-state routing trajectory.
For sample nn, let 𝒱stale,ns\mathcal{V}_{\mathrm{stale},n}^{s} and 𝒱oracle,ns\mathcal{V}_{\mathrm{oracle},n}^{s} denote the resulting top-KsK_{s} selections at routing stage ss.
Overall Top-KK Overlap is micro-averaged across all evaluated
sample–routing-stage events:
Overlap​@​K=∑n,s|𝒱stale,ns∩𝒱oracle,ns|∑n,sKs.\operatorname{Overlap@K}=\frac{\sum_{n,s}\left|\mathcal{V}_{\mathrm{stale},n}^{s}\cap\mathcal{V}_{\mathrm{oracle},n}^{s}\right|}{\sum_{n,s}K_{s}}.
(28)
Let
𝒟ns=𝒱∖𝒱stale,ns−1\mathcal{D}_{n}^{s}=\mathcal{V}\setminus\mathcal{V}_{\mathrm{stale},n}^{s-1}
(29)
denote the tokens deferred by the actual stale-routing trajectory
immediately before routing stage ss.
The stale and oracle re-admission sets are
ℛstale,ns=𝒱stale,ns∩𝒟ns,ℛoracle,ns=𝒱oracle,ns∩𝒟ns.\mathcal{R}_{\mathrm{stale},n}^{s}=\mathcal{V}_{\mathrm{stale},n}^{s}\cap\mathcal{D}_{n}^{s},\qquad\mathcal{R}_{\mathrm{oracle},n}^{s}=\mathcal{V}_{\mathrm{oracle},n}^{s}\cap\mathcal{D}_{n}^{s}.
(30)

The first routing stage is excluded from both agreement metrics because no visual token has yet been deferred.
For the random reference, we uniformly sample the same number of visual

Mean and standard deviation are reported over five random seeds.
Oracle-state intervention.
To isolate the effect of representation staleness after re-admission, we
replay a fixed routing trajectory and hold the selected and deferred token sets and the visual-token budget unchanged at every routing layer.
Only newly re-admitted token states are modified.
For each j∈ℛsj\in\mathcal{R}_{s}, the stale condition retains its cached state, whereas the current-depth oracle condition replaces it with
hj,full​[ℓs]h_{j,\mathrm{full}}[\ell_{s}] from a separate full-token reference
trajectory at the same decoder depth.
All other token states are left unchanged at each intervention point.
The full-token reference trajectory is used only for this diagnostic
analysis and is not required by CatchUp inference.
C.2 Ablation Variant Definitions
We provide additional details for the component and anchor-selection
ablations reported in the main paper.
Unless stated otherwise, all variants use the same routing layers,
visual-token budget, and hyperparameters as CatchUp, and differ only in
the component being ablated.
Component-ablation variants.
Monotonic Compact Routing uses compact visual-token execution but
does not permit re-admission: once a visual token is excluded, it remains
unavailable at subsequent routing layers.
CatchUp w/o LTC enables reversible routing over the complete
visual-token set, but applies no correction when a deferred token is
re-admitted. The token therefore resumes computation directly from its
cached stale representation.
Absolute-State Mixing uses the same reversible routing and semantic–spatial anchor construction as CatchUp, but replaces transition transfer with direct mixing of current-depth anchor states.
For a re-admitted token pp, we first aggregate the current representations of its selected anchors,
hpanchor=∑q∈𝒩pwp​q​hq​[ℓs],h_{p}^{\mathrm{anchor}}=\sum_{q\in\mathcal{N}_{p}}w_{pq}h_{q}[\ell_{s}],
(32)
and update the re-admitted representation as
h^p=(1−β)​hp​[ℓp]+β​hpanchor,\widehat{h}_{p}=(1-\beta)h_{p}[\ell_{p}]+\beta h_{p}^{\mathrm{anchor}},
(33)
where β=0.2\beta=0.2.
Thus, Absolute-State Mixing directly incorporates the anchors’ current representations, whereas LTC transfers only their reference-to-current representation changes, as described in Section A.5.
This comparison isolates whether the useful correction signal lies in the absolute anchor states or in the representation transitions they undergo.
Anchor-selection variants.
The anchor-selection ablation keeps the LTC transition-residual update fixed
and changes only how anchors are selected from the valid candidate set
ℱs\mathcal{F}_{s} defined in Section A.3.
Random uniformly samples up to MM valid candidate anchors and assigns them uniform aggregation weights.
Spatial ranks candidate anchors using only normalized patch-grid
proximity,
ap​qsp=−dsp​(p,q).a_{pq}^{\mathrm{sp}}=-d_{\mathrm{sp}}(p,q).
(34)
Semantic ranks candidate anchors using only representation similarity
at the re-admitted token’s reference depth,
ap​qsem=cos⁡(hp​[ℓp],h¯q​[ℓp]).a_{pq}^{\mathrm{sem}}=\cos\left(h_{p}[\ell_{p}],\bar{h}_{q}[\ell_{p}]\right).
(35)
Semantic + Spatial, used by CatchUp, combines the two cues,
ap​qsem+sp=cos⁡(hp​[ℓp],h¯q​[ℓp])−λ​dsp​(p,q).a_{pq}^{\mathrm{sem+sp}}=\cos\left(h_{p}[\ell_{p}],\bar{h}_{q}[\ell_{p}]\right)-\lambda d_{\mathrm{sp}}(p,q).
(36)
For the score-based variants, the top-MM candidates are retained and
their aggregation weights are obtained using the same softmax weighting
procedure as in the main method.
C.3 Representation Alignment of Re-Admitted Tokens
We first examine whether LTC moves a stale re-admitted representation toward the representation that the same token would have obtained had it been processed continuously to the current decoder depth.
For analysis only, we obtain this oracle representation from a separate
full-token reference trajectory.
This full-token reference trajectory is never used during CatchUp inference.
For a re-admission event of token pp at routing layer ℓs\ell_{s}, let hp,full​[ℓs]h_{p,\mathrm{full}}[\ell_{s}] denote the same token’s representation at the corresponding decoder depth in the full-token reference trajectory.
Given a re-admitted representation h^p​[ℓs]\hat{h}_{p}[\ell_{s}], we measure
directional alignment using cosine similarity,
CosSim=cos⁡(h^p​[ℓs],hp,full​[ℓs]),\operatorname{CosSim}=\cos\left(\hat{h}_{p}[\ell_{s}],h_{p,\mathrm{full}}[\ell_{s}]\right),
(37)
and overall representation discrepancy using normalized ℓ2\ell_{2} distance,
NormL2=‖h^p​[ℓs]−hp,full​[ℓs]‖2‖hp,full​[ℓs]‖2+ϵ,\operatorname{NormL2}=\frac{\left\|\hat{h}_{p}[\ell_{s}]-h_{p,\mathrm{full}}[\ell_{s}]\right\|_{2}}{\left\|h_{p,\mathrm{full}}[\ell_{s}]\right\|_{2}+\epsilon},
(38)
where ϵ\epsilon is a small constant for numerical stability.
Higher cosine similarity and lower normalized ℓ2\ell_{2} distance indicate
better alignment with the current-depth oracle state.
We compare three variants:
Stale, which re-admits the cached representation without
correction;
Absolute-State Mixing, which directly mixes current-depth anchor
states into the re-admitted representation;
and LTC, which transfers the local representation transition
defined in the main paper.

C.6 Additional Backbone
We further evaluate CatchUp on Qwen2.5-VL-7B-Instruct [2] to examine whether its effectiveness transfers beyond the LLaVA-1.5 backbone.
We use the same routing layers {2,7,15,23}\{2,7,15,23\} and LTC hyperparameters as in the main LLaVA-1.5 experiments.
We compare against representative efficient methods across average visual-token budgets of 64, 128, and 192.
As shown in Table 11, CatchUp achieves the best RefCOCO accuracy at all three visual-token budgets and the best or tied-best result in seven of the nine budget–benchmark comparisons.

These results show that the effectiveness of CatchUp transfers consistently to a different LVLM backbone.
