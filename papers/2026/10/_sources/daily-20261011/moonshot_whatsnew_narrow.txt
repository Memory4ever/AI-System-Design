What's New

A record of new features and key fixes across Kimi Code products — focused on the changes most worth knowing about.
Latest
Kimi Code Desktop
v1.1.0
October 14, 2026
​
Linux support
​
Desktop is now available for x86_64 Linux, with AppImage, deb, and RPM packages. →
Install and launch
Remote Control
​
Enable it under Settings → Remote Control, then use a link or QR code to control the local Agent from a phone, tablet, or another computer. Tasks and local tools still run on the computer running Desktop. →
Remote Control
File Tree panel
​
The new File Tree in the right sidebar browses, searches, and refreshes workspace files, with click-to-preview. Toggle it with
Cmd + Shift + E
on macOS or
Ctrl + Shift + E
on Windows and Linux. →
Right panel
Also in this release: experimental progress updates can be enabled under Settings → Lab for newly created sessions; the new
kimi app
command opens a new Desktop session in the current or a specified directory. →

October 14, 2026

Open a new Desktop chat from the terminal
​
The new
kimi app [path]
command opens Kimi Code Desktop with a new draft in the current or specified directory, making it easy to move from the CLI into the graphical interface. →
kimi app
Experimental progress updates
​
NotifyUser lets the Agent post short progress updates mid-turn. It is off by default and can be enabled in the TUI
/experiments
panel or in the Web / Desktop settings Lab, applying only to sessions created afterward. →
Collaboration tools
Interruptible background waits
​
WaitFor
is capped at 90 seconds. While it waits, pressing
Enter
or
Ctrl-S
steers your message into the current turn and ends the wait early, while background tasks keep running. →
During streaming output
Also in this release: fullscreen mode keeps a one-line summary of each user message and lets you jump back to it; user skill cards are now highlighted prompts that can be sent with
Ctrl-S
.
