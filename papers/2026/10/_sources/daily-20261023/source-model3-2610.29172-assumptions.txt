A.1 Assumptions: Equivalent-kernel model of regularized flow matching, and regularity conditions
The regularized objective in ( A.1 ) penalizes variation of c ↦ v t ​ ( c , x ) c\mapsto v_{t}(c,x) . For each fixed ( t , x ) (t,x) , this is a supervised regression problem in c c whose population design distribution is the conditional law of C | X t = x C\mid X_{t}=x , i.e., proportional to p t ⋆ ​ ( x ∣ c ′ ) ​ P C ​ ( d ​ c ′ ) p^{\star}_{t}(x\mid c^{\prime})P_{C}(dc^{\prime}) . Classical equivalent-kernel calculations for regularized least squares show that the fitted value at c c is a local average of the regression target ( Silverman, 1984 ) , which gives Eq. 5.3 . We now simplify this equivalent-kernel representation into the form used in our analysis.

Motivating Assumption 5.1 . The factorization ( 5.4 ) is an equivalent-kernel approximation of the kind used for smoothing splines and other roughness-penalized estimators ( Silverman, 1984 ; Wahba, 1990 ; Green and Silverman, 1994 ) . The exact kernel K λ , t , x K_{\lambda,t,x} depends on ( t , x ) (t,x) only through the design density ρ t , x ​ ( c ) := p t ⋆ ​ ( x ∣ c ) ​ p C ​ ( c ) \rho_{t,x}(c):=p^{\star}_{t}(x\mid c)p_{C}(c) , so replacing it by a common kernel is justified when ρ t , x \rho_{t,x} is locally stable over the smoothing length scale of the penalty.
Equivalently, using the normal-equation resolvent R ρ := ( M ρ + λ ​ L c ∗ ​ L c ) − 1 R_{\rho}:=(M_{\rho}+\lambda L_{c}^{\ast}L_{c})^{-1} , the second-resolvent identity
R ρ t , x − R ρ ¯ = − R ρ t , x ​ ( M ρ t , x − M ρ ¯ ) ​ R ρ ¯ \displaystyle R_{\rho_{t,x}}-R_{\bar{\rho}}=-R_{\rho_{t,x}}\big(M_{\rho_{t,x}}-M_{\bar{\rho}}\big)R_{\bar{\rho}}
(A.6)
shows that the exact kernels are stable whenever the perturbation M ρ t , x − M ρ ¯ M_{\rho_{t,x}}-M_{\bar{\rho}} is small in the operator norm induced by the regularized problem. This is the standard Fredholm/resolvent picture behind Tikhonov-regularized least squares and kernel ridge regression ( Cucker and Smale, 2002 ; Caponnetto and De Vito, 2007 ; Kress, 2014 ; Engl et al., 1996 ) . For the Gaussian-like paths we consider, the approximation is expected to be best for small t t , large path variance, or locally slowly varying conditional mean μ ⋆ \mu^{\star} . It is weakest near t = 1 t=1 in low-noise regions, where p t ⋆ ​ ( x ∣ c ) p^{\star}_{t}(x\mid c) sharply localizes around level sets of the conditional mean.
Also, in Section A.4 we numerically test how well Eq. A.4 approximates the velocity field learned by a neural network, on a synthetic task. This is equivalent to verifying how well Eq. 5.3 and Eq. 5.4 together approximate a neural CFM’s learned velocity field.
Remark A.1 .
The learned vector field representation Eq. A.4 obtained from Lemma A.1 is stronger than saying that v ^ t ​ ( c , x ) \hat{v}_{t}(c,x) is an ordinary pointwise smoother of v t ⋆ ​ ( c , x ) v^{\star}_{t}(c,x) : ordinary smoothing in c c at fixed ( t , x ) (t,x) would replace the conditional mean by a smoothed mean and would not create the same excess endpoint variance. The density-weighted form in ( A.5 ) is structurally different: it locally blends the conditional probability paths themselves, weighting by how likely each c ′ c^{\prime} is to have produced the observed x x under the true model. This blending is what produces the variance inflation.

A.2 Formal Main Results
We are now ready to state our formal main results, deferring proofs to Section A.3 . First, we show that under our assumptions, smoothing over the flows directly translates to smoothing over the conditionals . This is the key bridge between regularization of the vector field and variance inflation in the generated distribution.
