Abstract
Vision-language-action (VLA) navigation models translate visual observations and instructions into actions.
Navigation success assesses whether an agent reaches the goal.
However, reaching the goal successfully does not establish whether the model genuinely follows the instructions or relies on visual cues or navigation history.
We introduce NavBind to diagnose instruction-action binding: whether changing the instruction influences the probabilistic distribution of the actions, with the navigation context fixed.
We construct 3,252 route-fork contexts by recombining route-aligned instruction segments from R2R-CE and RxR-CE.
Each context pairs full instructions that share the description of the route already traveled but specify different branches.
Both are evaluated under the same agent state and navigation history.
We compare generated local action sequences, the likelihoods of fixed reference action sequences under both instructions, and changes in visual attention and attribution.
Across the evaluated models, higher reported navigation success does not imply that the model more faithfully follows the instructions.
 1 Introduction
 Figure 1: Does the action follow the instruction? 
 NavBind pairs one fixed navigation history H with two full instructions
 P+S_{A} and P+S_{B} . The shared prefix P describes the completed route,
and the remaining suffixes S_{A} and S_{B} specify different executable branches.
This example contrasts turning left with going up the stairs.
We jointly examine generated action-sequence changes, fixed-target action
likelihood, visual attention, and attribution for each instruction’s
corresponding reference actions.
In vision-and-language navigation in continuous environments (VLN-CE) ( Krantz et al., 2020 ) , vision-language-action (VLA) models ( Zhang et al., 2024 ) map visual observations and instructions to actions.
Success rate measures whether an agent reaches the goal but does not establish whether it follows the instruction.
Route-fidelity metrics ( Jain et al., 2019 ) assess the similarity between the generated trajectory and the ground-truth trajectory, providing an indirect measure of instruction following.
However, these metrics still cannot establish whether the model genuinely follows the instructions , as it may instead rely on visual cues or navigation history alone.
Language interventions, i.e., changing the language instruction and observing how the local actions or navigation performance change, provide a more direct test of language dependence.
NavTrust ( Jiang et al., 2026 ) and Contrast Sets ( Anwar et al., 2025 ) rephrase instructions and assess changes in navigation performance.
However, these tests keep the intended navigation behaviour unchanged.
R2RIE-CE ( Taioli et al., 2024 ) modifies instructions by injecting direction, object, and room errors.
However, it neither ensures that the modified instructions describe feasible routes nor provides reference actions corresponding to them.
Without matching reference trajectories for the modified instructions, a behavioural change alone does not show that the model followed them.
We therefore ask not merely whether the model’s behaviour changes, but whether changing the instruction to describe another feasible route makes the model more likely to choose the corresponding actions .
We keep the agent’s state, navigation history, and completed instruction prefix fixed.
In Figure  1 , both turning left and continuing up the stairs are feasible, and the remaining instruction specifies which branch to take.
We use instruction-action binding to describe the requirement that the model assigns higher probability to the actions required by the instruction.
We introduce NavBind , a controlled diagnostic built through cross-route
recombination of route-instruction examples drawn from R2R-CE and RxR-CE.
Using fine-grained route-language alignments, we retain one example’s
completed instruction prefix and combine it with either its original suffix
or a compatible suffix from another route.
The resulting full-instruction pairs specify different executable
branches under the same replayed history and agent state, yielding
3,252 contexts with reference action sequences for both branches.
Within each fixed context, we first ask: does changing the instruction
change the action sequence the model generates?
We then ask: does the model assign higher probability to the actions
for a branch when instructed to take that branch rather than the other?
We test this by comparing the likelihood of each reference action
sequence under the two instructions.
This comparison can reveal changes in action preference even when the
generated sequence stays the same.
Finally, we examine the visual response: do attention heatmaps and
gradient-based attribution heatmaps highlight different image regions
under the two instructions?
We evaluate four navigation VLAs on NavBind : Uni-NaVid
 ( Zhang et al., 2025 ) , StreamVLN ( Wei et al., 2025 ) , JanusVLN
 ( Zeng et al., 2026 ) , and FutureNav ( Zhang et al., 2026a ) .
We find that higher reported navigation success does not imply that the model more faithfully follows the instructions.
(Table  1 ).
It also shows that models respond more strongly when the instructions
contrast opposite turns than when they contrast forward movement with a turn.
Our contributions are:
 • 
We construct NavBind by recombining instruction segments
across routes into full instructions for two feasible branches.
Each pair preserves the agent state, history, and
completed instruction prefix, and provides reference action
sequences for both branches.
 • 
We diagnose instruction-action binding using generated
sequences to measure output changes, fixed-target likelihoods
to assess preferences for the instructed actions, and attention
and gradient-based attribution heatmaps to track spatial changes.
 • 
We show that higher reported navigation success does not imply that the model more faithfully follows the instructions. This supports evaluating how
language affects local decisions alongside navigation success.
 2 Related Work
 2.1 Language Diagnostics in VLN
Instruction fidelity beyond success.
Goal completion can obscure whether an agent followed the described route.
Stay on the Path introduced CLS and longer R4R routes
 ( Jain et al., 2019 ) , while LAW extended language-aligned supervision
and evaluation to VLN-CE ( Raychaudhuri et al., 2021 ) .
Modality ablations further showed that R2R agents could rely strongly on graph
structure ( Hu et al., 2019 ) . These works motivate
language-specific evaluation through task metrics, supervision, and modality
ablations.
Language interventions in VLN.
Early diagnostics mask object, direction, and numerical cues
 ( Zhu et al., 2022 ) and swap directional tokens
 ( Hahn et al., 2023 ) .
Skill-focused evaluations append atomic instructions to truncated RxR
episodes ( Yang et al., 2023 ) and construct human-refined atomic
instructions, including same-start left/right pairs
 ( Wang et al., 2024 ) .
These studies evaluate agents on discrete navigation graphs and
their action tests cannot be directly applied to navigation VLAs
that execute low-level actions.
In VLN-CE, NavTrust evaluates whether agents maintain navigation performance
under instruction corruption and stylistic variation
 ( Jiang et al., 2026 ) .
Contrast Sets tests instruction rephrasing with unchanged navigation
goals on a physical robot
 ( Anwar et al., 2025 ) .
However, these tests keep the intended navigation behaviour unchanged.
R2RIE-CE injects direction, object, and room errors into
instructions to study error detection and localization
 ( Taioli et al., 2024 ) .
The modified instructions are not paired with matching reference
trajectories.
However, it neither ensures that the modified instructions describe feasible routes nor provides reference actions corresponding to them.
Without matching reference trajectories for the modified instructions, a behavioural change alone does not show that the model followed them.
CAST pairs generated alternative instructions with short action
branches for counterfactual training ( Glossop et al., 2026 ) , but the intended action behaviour only include a short horizon rather than a long horizon.
 NavBind constructs full-instruction pairs for long-horizon navigation
by recombining original route-aligned instruction spans across source
routes.
The pairs specify different executable branches under the same
agent state, navigation history, and completed instruction prefix.
Scoring both reference action sequences under both instructions tests
whether the model’s local action preferences shift toward the
instructed branch.
 2.2 Language-Action Coupling in VLAs
Recent work examines whether language and other multimodal signals influence
VLA action generation. VLA-Trace connects representation similarity,
attention-path knockouts, and rollout-level behavioural probes
 ( Shi et al., 2026 ) , while Häon et al. (2025) identify semantic
activation directions and intervene on them to steer actions.
 Zhang et al. (2026b) diagnose linguistic blindness in manipulation VLAs using
contradictory instructions and recalibrate attention at inference time, while
 Zhan et al. (2026) study robustness to linguistic perturbations and
strengthen language guidance through residual steering. These studies
establish that language and internal pathways can affect VLA actions, but their
evaluations center on manipulation and often combine diagnosis with model
modification. NavBind tests instruction-action binding in frozen navigation
VLAs: two valid route instructions share the same history but specify different
executable branches. We align behaviour with fixed-target likelihood and
visual attribution.
 3 Problem Setting
 3.1 VLN-CE
In vision-and-language navigation in continuous environments (VLN-CE), an
agent follows a natural-language instruction I through a continuous 3D
environment ( Krantz et al., 2020 ) .
At time t , it receives an egocentric observation o_{t} and acts from the
navigation history
 H_{t}=(o_{0},a_{0},\ldots,a_{t-1},o_{t}). 
 (1) 
A navigation policy assigns a conditional distribution
 \pi_{\theta}(a_{t}\mid I,H_{t}) over its next one or few actions. A full episode ends when the
agent emits Stop or reaches the maximum steps, and success means stopping near the destination.
We study the widely used four-action interface
 \mathcal{A}=\{\textsc{Forward},\textsc{Left},\textsc{Right},\textsc{Stop}\}, 
 (2) 
adopted by low-level VLN-CE agents Krantz et al. (2020) and recent navigation VLAs
 ( Zhang et al., 2025 ; Wei et al., 2025 ; Zeng et al., 2026 ; Zuo et al., 2026 ; Yang et al., 2026 ; Zhang et al., 2026a ) .
 Forward advances the agent by a fixed distance, while
 Left and Right rotate it by a fixed angular increment.
This finite action vocabulary provides a common behavioural interface and, for
models that expose action logits, permits exact likelihood evaluation of a
fixed action sequence.
 3.2 Local Route-Fork Diagnosis
Within each source pair, a local diagnostic context consists of a valid
history H_{h} ending at a nonterminal route fork v and its completed
instruction prefix P_{h} , where h\in\{A,B\} identifies the source route
(Figure  2 (a)). Each remaining suffix S_{s} , with
 s\in\{A,B\} , specifies one outgoing branch. The full input instruction is
 I_{h,s}=P_{h}+S_{s} , and an evaluation condition consists of H_{h} and I_{h,s} .
From the state reached by H_{h} , the reference action sequence for either
executable branch g\in\{A,B\} is
 G_{h,g}=(a^{h,g}_{1},\ldots,a^{h,g}_{K_{h,g}}),\quad K_{h,g}\leq K. 
 (3) 
The diagnostic horizon K limits its length, and Stop ends the
sequence.
For each context (H_{h},P_{h}) , NavBind compares I_{h,A} and I_{h,B} ,
as in a horizontal comparison in Figure  2 (b).
Both conditions start from exactly the same pose, current observation, and
observation-action history.
Instruction-action binding requires the model to assign higher probability
to the actions required by the suffix. Section  4 
describes how route geometry and fine-grained language annotations yield
these matched conditions.

 4.1 Route-Aligned Source Pairs
We construct source pairs from English R2R-CE and RxR-CE routes and instructions
 ( Anderson et al., 2018 ; Ku et al., 2020 ; Krantz et al., 2020 ) .
For R2R and English RxR, we use released fine-grained annotations from
FGR2R ( Hong et al., 2020 ) and Landmark-RxR ( He et al., 2021 ) ,
respectively. These annotations divide full instructions into shorter
text segments, called sub-instructions , and align each segment
with the part of the trajectory it describes.
We first identify route pairs with the structure shown in
Figure  2 (a): two routes in the same scene share a directed
segment from u to the fork v , then take different outgoing edges at v .
The routes may differ before u . Both branches beyond v must be executable
and nonterminal. We require a sufficiently long shared segment u\!\to\!v 
to align the two routes’ positions and orientations
at v . Sharing v alone leaves arrival
orientation unconstrained, which can change the interpretation of
instructions such as “turn left.”
For each source route h in a candidate pair, we use the sub-instruction
annotations to place the language boundary at v . An edge-exact boundary
requires the preceding subpath to end at v and the next subpath to start at v with its
first edge entering branch h . We recover the corresponding
original-text offsets by monotonic matching with case, spacing, and punctuation
normalized. Cutting at the start of that next sub-instruction yields
 I_{h,h}=P_{h}+S_{h} : the prefix P_{h} covers the full route up to v , including
any portion before u , and the suffix S_{h} retains the remaining instruction.
Both spans preserve their original wording.
Selection uses route annotations alone. Repeated physical forks are deduplicated.
For each retained pair, expert replay of route h from its source start to v 
yields a history H_{h} paired with its completed prefix P_{h} . From each state at v ,
we construct both local branch targets G_{h,A} and G_{h,B} .
The resulting history-prefix pairs form the fixed
row contexts in Figure  2 (b).
 4.2 Matched Interventions
Figure  2 (b) crosses each context (H_{h},P_{h}) with both
suffixes. Each cell gives the instruction I_{h,s} , evaluated with the
history H_{h} in its row.
Suffix intervention.
Within each row, the diagonal instruction I_{h,h} retains the source text,
and the off-diagonal instruction substitutes the other route’s suffix.
Evaluating I_{h,A} and I_{h,B} from the same replay history and fork state
implements the primary fixed-context
comparison defined in Section  3.2 .
Matched prefix intervention.
Across rows, the supplementary comparison between (H_{A},I_{A,s}) and
 (H_{B},I_{B,s}) holds the suffix fixed while jointly changing the history
and its source prefix.
It compares the model’s response to the same branch beyond v across
the two source-matched contexts.
Each source pair initially yields two candidate contexts and four conditions,
linked by a source-pair identifier. We retain contexts whose two reference
sequences differ within four actions at every evaluated native action scale.
The resulting NavBind set contains 3,252 contexts from 1,648 source pairs,
shared by all models.
 5 Diagnosing Instruction-Action Binding

Given the matched conditions constructed in Section  4 , we
analyze instruction-action binding from three complementary perspectives. We
first measure whether an intervention changes the generated local action
sequence. We then measure how it changes the likelihood and
action distribution of a fixed reference target. Finally, we examine
how visual attention and attribution change across conditions. Likelihood
comparisons keep the target fixed, while gradient-based attribution follows
each instruction’s corresponding GT. Figure  3 illustrates
these comparisons on one navigation context.
 5.1 Generated Action Sequences
For each context (H_{h},P_{h}) , we generate local action sequences under
 I_{h,A} and I_{h,B} using native inference without teacher forcing.
We report the percentage of contexts whose sequences match exactly in action
symbols, order, and length within horizon K as Same sequence
(Same seq.).
 5.2 Fixed-Target Action Likelihood
Discrete generation can remain unchanged even when model’s
action distribution changes. We therefore measure
changes in the likelihood of fixed reference action sequences.
Figure  3 (a) illustrates the scoring procedure for context
 (H_{B},P_{B}) , corresponding to the second row of Figure  2 (b).
The targets G_{B,A} and G_{B,B} are each scored under both instructions,
 I_{B,A} and I_{B,B} , giving four likelihood scores.
In general, L_{h,s,g} denotes the mean negative log-likelihood (NLL) of
target G_{h,g} under instruction I_{h,s} and history H_{h} . Its indices
specify the history h , input suffix s , and target branch g , respectively.
For chunk policies, we compute the mean NLL over the target’s action tokens
 z_{1},\ldots,z_{N} :
 L_{h,s,g}=-\frac{1}{N}\sum_{k=1}^{N}\log p_{\theta}\!\left(z_{k}\mid I_{h,s},H_{h},z_{<k}\right). 
 (4) 
Here p_{\theta} is the model’s full-vocabulary token probability. We use
natural logarithms throughout. At position
 k , the model receives the same preceding target tokens z_{<k} under both suffixes
(teacher forcing). Only action tokens contribute to the average.
Lower L_{h,s,g} means higher target likelihood, and perplexity is
 \mathrm{PPL}_{h,s,g}=\exp(L_{h,s,g}) .
Single-step policies instead score each target action at the state reached
by executing its preceding GT actions. We sum the native action-token log
probabilities across decisions and divide by the total valid token count.
Both suffixes use the same GT observation sequence, with independent model
memory. This supplies a closed-loop counterpart to the chunk score. The primary suffix effects keep H_{h} , P_{h} , and G_{h,g} fixed:
 \displaystyle d_{h,A} 
 \displaystyle=L_{h,B,A}-L_{h,A,A}, 
 (5) 
 \displaystyle d_{h,B} 
 \displaystyle=L_{h,A,B}-L_{h,B,B}. 
 (6) 
The mean is
 \bar{d}_{h}=\tfrac{1}{2}(d_{h,A}+d_{h,B}) . We report its average across
evaluated samples as \bar{d} .
To interpret \bar{d} in Table  1 , positive values mean
that matching suffixes make their reference actions more likely,
negative values mean less likely, and zero means no net advantage.
We convert this log-probability difference to a relative percentage change
using (\exp(\bar{d})-1)\times 100\% . Thus, \bar{d}=0.0127 gives
 (\exp(0.0127)-1)\times 100\%\approx 1.28\% for reference-action token
probabilities, averaged geometrically across tokens, targets, and contexts.
We report Both+ as the percentage of contexts where both d_{h,A}>0 and
 d_{h,B}>0 , so each reference is more likely under its matching suffix.
As a complementary metric, we report symmetric KL divergence. Let
 q^{(j)}_{h,s,g} denote the action distribution, renormalized over the four
legal actions, at reference step
 j of G_{h,g} , scored with I_{h,s} and H_{h} using the protocol above.
With the same preceding target actions, we compute
 D_{\mathrm{SKL}}(q^{(j)}_{h,A,g},q^{(j)}_{h,B,g}) , then average over steps, targets,
and contexts. KL is zero for unchanged action probabilities and increases
with their redistribution, irrespective of target alignment.
 5.3 Visual Attention and GT-Conditioned Attribution
We next compare visual attention and the visual sensitivity of each
instruction’s corresponding reference action sequence. Let A denote decoder
attention from action-query positions to visual tokens. Raw attention is
measured under each fixed reference sequence G_{h,g} , so both suffixes
receive the same preceding target tokens at every prediction position.
For gradient-based attribution, the explained action follows the instruction:
 I_{h,s} is paired with its corresponding GT sequence G_{h,s} . Its score is
 Q_{h,s}=-L_{h,s,s}. 
 (7) 
We extract gradient magnitude |\nabla_{A}Q_{h,s}| and the elementwise
product magnitude \left|A\odot\nabla_{A}Q_{h,s}\right| . For chunk policies, maps aggregate the
teacher-forced action-query positions under fixed observations.
Let M^{e}_{h,s,g} denote a map computed under instruction I_{h,s} and
reference sequence G_{h,g} . Raw attention compares the same reference
under both suffixes:
 \operatorname{IoU}^{\mathrm{attn}}_{h,g}=\operatorname{IoU}\!\left(\mathcal{B}(M^{\mathrm{attn}}_{h,A,g}),\mathcal{B}(M^{\mathrm{attn}}_{h,B,g})\right), 
 (8) 
and averages the two references within each context. Gradient and
attention \times gradient compare the corresponding GTs:
 \operatorname{IoU}^{e}_{h}=\operatorname{IoU}\!\left(\mathcal{B}(M^{e}_{h,A,A}),\mathcal{B}(M^{e}_{h,B,B})\right). 
 (9) 
This comparison jointly changes the instruction and the explained action.
Here \mathcal{B} selects a fixed top-response fraction on the scoring grid.
Heatmaps are interpolated to RGB
resolution for display, while IoU uses the original scoring-grid masks.
For single-step policies, fixed-reference attention is compared at aligned
GT states and averaged over steps. Corresponding-GT gradients are compared
only at the shared fork observation, using each instruction’s first GT
action. Later GT trajectories can have different views.
IoU equals one for identical selected regions and zero for disjoint regions.
Lower IoU indicates greater spatial change under the respective comparison.
Section  7 relates these changes to fixed-target likelihoods
and changes in the action sequences.

 6.1 Data and Models
We evaluate Uni-NaVid ( Zhang et al., 2025 ) , StreamVLN
 ( Wei et al., 2025 ) , JanusVLN ( Zeng et al., 2026 ) , and FutureNav
 ( Zhang et al., 2026a ) on the same 3,252 NavBind contexts constructed in
Section  4 , using released checkpoints.
 6.2 Evaluation Protocol
We use a four-action horizon ( K=4 ) and each model’s native action
increments. Uni-NaVid and StreamVLN generate action chunks under fixed
observations, while JanusVLN and FutureNav execute each predicted action
before the next decision. We retain native decoding: Uni-NaVid uses sampling
and StreamVLN uses greedy decoding.
 7 Results
 7.1 Main Results
In Table  1 , Uni-NaVid has the highest reported
RxR-CE val-unseen SR. However, StreamVLN has the highest \bar{d} and
KL values.
Uni-NaVid’s Both+ is 29.15%, only 4.15 percentage points above a 25%
reference. This reference assumes that the two likelihood gains are
independent and each has a 50% chance of being positive.
StreamVLN and FutureNav have nearly identical reported SR (54.4%
and 54.5%), yet StreamVLN has higher \bar{d} (0.8360 versus 0.4411),
Both+ (80.38% versus 70.60%), and KL (0.8233 versus 0.6208).
Thus, higher navigation success does not necessarily mean that changing
the instruction has a larger effect on action probabilities.
JanusVLN and FutureNav change their action sequences more often than
StreamVLN (lower Same seq.), but show smaller likelihood gains for the
instructed action sequences (lower \bar{d} ). Their attention and attribution
heatmaps also highlight more similar visual regions across instructions
(higher IoU).
One possible explanation is that these models rely on similar visual
cues without clearly distinguishing the instructed branch, leaving them
less confident about which action to take.
Small probability shifts could then be enough to change the selected action.
 7.2 Consistency Across Diagnostics
Table  2 shows that StreamVLN’s Unchanged group
has lower \bar{d} than its Changed group.
In this group, changing the instruction produces a smaller increase
in the likelihood of the required actions.
The Unchanged group also has higher Attn., Grad., and Attn. \times Grad.
IoU, so the heatmaps highlight more similar regions under the two
instructions.
Thus, the likelihood and visual results agree with the generated-action
results: unchanged action sequences come with smaller changes toward
the required actions and smaller changes in the highlighted visual regions.

 8 Conclusion
 NavBind diagnoses instruction-action binding through route-fork
interventions under fixed navigation contexts, combining generated behavior,
fixed-target likelihoods, and visual attention and attribution. Across 3,252
shared contexts, higher reported navigation success does not always mean
more frequent action changes or larger shifts in action probabilities.
These findings support evaluating how language affects local decisions
alongside episode-level navigation success.
Limitations
Recombining source instructions may introduce ambiguity
or unnatural transitions at the segment boundaries. The four-action window
captures local instruction responses, while later responses and error recovery
remain outside the evaluation horizon. Model-native action increments also
give this window different physical extents across models. Visual IoU
quantifies spatial changes in attention and attribution, without establishing
whether the selected regions are relevant to the instructed branch or causally
determine the action.
