Appendix A Theoretical Model of Variance Inflation
This section provides the formal setup and proof of Theorem 1 from Section 5 . The argument proceeds in three steps.
•
First, an equivalent-kernel approximation ( Section A.1 ) reduces the regularized flow-matching solution to a density-weighted local average of the true velocity field.
•
Second, this representation implies that the endpoint distribution generated by the regularized flow is a local mixture of true conditionals ( Proposition A.2 ).
•
Third, taking moments of this mixture gives an explicit decomposition of the learned covariance into true conditional covariance and unresolved variation of the conditional mean. A short operator argument then shows that, on average, this unresolved variation dominates the squared smoothing bias, yielding Theorem 1 .
Setup.
We restate the regularized flow-matching problem from Section 5 : we study the population-level optimum
v λ ∈ arg ⁡ min v ∈ 𝒱 ​ { 𝔼 ⁡ [ ‖ v T ​ ( C , X T ) − X ˙ T ‖ 2 ] + λ ​ 𝔼 ​ [ ‖ ( L c ​ v T ) ​ ( C , X T ) ‖ 2 ] } , \displaystyle v_{\lambda}\in\arg\min_{v\in\mathcal{V}}\left\{\mathbb{E}\!\left[\|v_{T}(C,X_{T})-\dot{X}_{T}\|^{2}\right]+\lambda\,\mathbb{E}\!\left[\|(L_{c}v_{T})(C,X_{T})\|^{2}\right]\right\},
(A.1)
as a proxy for the inductive bias of a learned conditional flow. Here 𝒱 \mathcal{V} is the chosen vector-field class, λ ≥ 0 \lambda\geq 0 controls the strength of regularization, and L c L_{c} is a linear operator acting only on the conditioning variable: for each fixed ( t , x ) (t,x) , L c L_{c} acts on the function c ↦ v t ​ ( c , x ) c\mapsto v_{t}(c,x) while treating t t and x x as fixed. Examples include derivative penalties such as L c = ∇ c L_{c}=\nabla_{c} , higher-order smoothness penalties, and RKHS-type penalties. This captures the regime of interest: the learned vector field may depend flexibly on the flow state x x and time t t , but its dependence on the conditioning variable c c is smoothed.
Justification for studying this setup:
Prior work has established that neural networks exhibit a spectral or smoothness bias during training, preferentially fitting smoother and lower-frequency components before finer-scale structure ( Daniely, 2017 ; Jacot et al., 2018 ; Rahaman et al., 2019 ; Xu et al., 2020 ; Lee et al., 2019 ) . Equation ( 5.1 ) captures this behavior in an idealized population-level model. Closely related, Pfrommer et al. (2025) study a special case with L c = ∇ c 2 L_{c}=\nabla_{c}^{2} as a model of smoothness bias in conditional diffusion models. More broadly, underfitting of learned velocity and score fields has been studied extensively in the diffusion and flow-matching literature. Prior work has linked smoothness and selective underfitting of these fields to generalization, interpolation, and hallucination in generative models ( Yoon et al., 2023 ; Scarvelis et al., 2023 ; Aithal et al., 2024 ; Song et al., 2025 ) . Finally, in Appendix A.4 we numerically evaluate how well the factorized equivalent-kernel representation in Equations ( 5.3 ) and ( 5.4 ) approximates trained neural CFMs on synthetic one-dimensional regression tasks.
For brevity, throughout this appendix we write v ^ := v λ \hat{v}:=v_{\lambda} for the regularized population solution.

A.1 Assumptions: Equivalent-kernel model of regularized flow matching, and regularity conditions
The regularized objective in ( A.1 ) penalizes variation of c ↦ v t ​ ( c , x ) c\mapsto v_{t}(c,x) . For each fixed ( t , x ) (t,x) , this is a supervised regression problem in c c whose population design distribution is the conditional law of C | X t = x C\mid X_{t}=x , i.e., proportional to p t ⋆ ​ ( x ∣ c ′ ) ​ P C ​ ( d ​ c ′ ) p^{\star}_{t}(x\mid c^{\prime})P_{C}(dc^{\prime}) . Motivating Assumption 5.1 . The factorization ( 5.4 ) is an equivalent-kernel approximation of the kind used for smoothing splines and other roughness-penalized estimators ( Silverman, 1984 ; Wahba, 1990 ; Green and Silverman, 1994 ) . The exact kernel K λ , t , x K_{\lambda,t,x} depends on ( t , x ) (t,x) only through the design density ρ t , x ​ ( c ) := p t ⋆ ​ ( x ∣ c ) ​ p C ​ ( c ) \rho_{t,x}(c):=p^{\star}_{t}(x\mid c)p_{C}(c) , so replacing it by a common kernel is justified when ρ t , x \rho_{t,x} is locally stable over the smoothing length scale of the penalty.
Equivalently, using the normal-equation resolvent R ρ := ( M ρ + λ ​ L c ∗ ​ L c ) − 1 R_{\rho}:=(M_{\rho}+\lambda L_{c}^{\ast}L_{c})^{-1} , the second-resolvent identity
R ρ t , x − R ρ ¯ = − R ρ t , x ​ ( M ρ t , x − M ρ ¯ ) ​ R ρ ¯ \displaystyle R_{\rho_{t,x}}-R_{\bar{\rho}}=-R_{\rho_{t,x}}\big(M_{\rho_{t,x}}-M_{\bar{\rho}}\big)R_{\bar{\rho}}
(A.6)
shows that the exact kernels are stable whenever the perturbation M ρ t , x − M ρ ¯ M_{\rho_{t,x}}-M_{\bar{\rho}} is small in the operator norm induced by the regularized problem. This is the standard Fredholm/resolvent picture behind Tikhonov-regularized least squares and kernel ridge regression ( Cucker and Smale, 2002 ; Caponnetto and De Vito, 2007 ; Kress, 2014 ; Engl et al., 1996 ) . For the Gaussian-like paths we consider, the approximation is expected to be best for small t t , large path variance, or locally slowly varying conditional mean μ ⋆ \mu^{\star} . It is weakest near t = 1 t=1 in low-noise regions, where p t ⋆ ​ ( x ∣ c ) p^{\star}_{t}(x\mid c) sharply localizes around level sets of the conditional mean.
Also, in Section A.4 we numerically test how well Eq. A.4 approximates the velocity field learned by a neural network, on a synthetic task. This is equivalent to verifying how well Eq. 5.3 and Eq. 5.4 together approximate a neural CFM’s learned velocity field.
Remark A.1 .
The learned vector field representation Eq. A.4 obtained from Lemma A.1 is stronger than saying that v ^ t ​ ( c , x ) \hat{v}_{t}(c,x) is an ordinary pointwise smoother of v t ⋆ ​ ( c , x ) v^{\star}_{t}(c,x) : ordinary smoothing in c c at fixed ( t , x ) (t,x) would replace the conditional mean by a smoothed mean and would not create the same excess endpoint variance. The density-weighted form in ( A.5 ) is structurally different: it locally blends the conditional probability paths themselves, weighting by how likely each c ′ c^{\prime} is to have produced the observed x x under the true model. This blending is what produces the variance inflation.

A.2 Formal Main Results
We are now ready to state our formal main results, deferring proofs to Section A.3 . First, we show that under our assumptions, smoothing over the flows directly translates to smoothing over the conditionals . This is the key bridge between regularization of the vector field and variance inflation in the generated distribution.
