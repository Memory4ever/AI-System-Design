Appendix A Proof of the Visual-Utilization Failure Bounds
Here we formalizes the probe-dominance assumption used in Section 3.2 and proves Theorem 1 . Recall that ϕ X = 1 \phi_{X}=1 indicates that the representations of X X contain sufficient signal to support the ground-truth answer. Conditional on an error, this latent state corresponds to a visual-utilization failure, whereas ϕ X = 0 \phi_{X}=0 corresponds to a visual-representation failure. The fixed binary probe M M is the composite probe defined in Section 3.3 ; we apply the same probe to X X , X + X_{+} , and X − X_{-} with respect to the ground-truth answer Y X Y_{X} . The positive transformation X + X_{+} strengthens the relevant visual signal, while the negative transformation X − X_{-} weakens it, without changing the ground-truth answer.
Assumption 1 (Probe dominance) .
Conditioned on an error, probe detection of Y X Y_{X} on X + X_{+} is a conservative proxy for probe detection when the original representations contain the required signal. Similarly, probe non-detection of Y X Y_{X} on X − X_{-} is a conservative proxy for probe non-detection when that signal is absent. Formally,
ℙ ⁡ ( M ⁡ ( X , Y X ) = 1 ∣ ℋ , ϕ X = 1 ) \displaystyle\mathbb{P}\bigl(M(X,Y_{X})=1\mid\mathcal{H},\phi_{X}=1\bigr)
≥ ℙ ⁡ ( M ⁡ ( X + , Y X ) = 1 ∣ ℋ ) , \displaystyle\geq\mathbb{P}\bigl(M(X_{+},Y_{X})=1\mid\mathcal{H}\bigr),
ℙ ⁡ ( M ⁡ ( X , Y X ) = 0 ∣ ℋ , ϕ X = 0 ) \displaystyle\mathbb{P}\bigl(M(X,Y_{X})=0\mid\mathcal{H},\phi_{X}=0\bigr)
≥ ℙ ⁡ ( M ⁡ ( X − , Y X ) = 0 ∣ ℋ ) . \displaystyle\geq\mathbb{P}\bigl(M(X_{-},Y_{X})=0\mid\mathcal{H}\bigr).
The intuition behind this assumption is that the latent state ϕ X \phi_{X} directly describes the property that the probe is designed to detect, whereas X + X_{+} and X − X_{-} modify this property only indirectly and may do so imperfectly. If the original representations truly contain the required evidence ( ϕ X = 1 \phi_{X}=1 ), the probe should be at least as likely to detect it as it is after the positive transformation. Conversely, if the representations truly lack the required evidence ( ϕ X = 0 \phi_{X}=0 ), the probe should be at least as likely to return non-detection as it is after the negative transformation. Thus, the transformed inputs provide conservative proxies for the latent states.
Proof of Theorem 1 .
All probabilities below are conditioned on the error event ℋ \mathcal{H} . By definition,
μ ϕ = ℙ ⁡ ( ϕ X = 1 ∣ ℋ ) , 1 − μ ϕ = ℙ ⁡ ( ϕ X = 0 ∣ ℋ ) . \mu_{\phi}=\mathbb{P}(\phi_{X}=1\mid\mathcal{H}),\qquad 1-\mu_{\phi}=\mathbb{P}(\phi_{X}=0\mid\mathcal{H}).
First consider the probability that the probe does not detect the required evidence. By the law of total probability,
ℙ ⁡ ( M ⁡ ( X , Y X ) = 0 ∣ ℋ ) = \displaystyle\mathbb{P}\bigl(M(X,Y_{X})=0\mid\mathcal{H}\bigr)={}
ℙ ⁡ ( M ⁡ ( X , Y X ) = 0 ∣ ℋ , ϕ X = 1 ) ​ μ ϕ \displaystyle\mathbb{P}\bigl(M(X,Y_{X})=0\mid\mathcal{H},\phi_{X}=1\bigr)\mu_{\phi}
+ ℙ ⁡ ( M ⁡ ( X , Y X ) = 0 ∣ ℋ , ϕ X = 0 ) ​ ( 1 − μ ϕ ) . \displaystyle+\mathbb{P}\bigl(M(X,Y_{X})=0\mid\mathcal{H},\phi_{X}=0\bigr)(1-\mu_{\phi}).
The first term is nonnegative, and Assumption 1 lower-bounds the second conditional non-detection rate by the non-detection rate on X − X_{-} . Therefore,
ℙ ⁡ ( M ⁡ ( X , Y X ) = 0 ∣ ℋ ) ≥ ℙ ⁡ ( M ⁡ ( X − , Y X ) = 0 ∣ ℋ ) ​ ( 1 − μ ϕ ) . \mathbb{P}\bigl(M(X,Y_{X})=0\mid\mathcal{H}\bigr)\geq\mathbb{P}\bigl(M(X_{-},Y_{X})=0\mid\mathcal{H}\bigr)(1-\mu_{\phi}).
When ℙ ⁡ ( M ⁡ ( X − , Y X ) = 0 ∣ ℋ ) > 0 \mathbb{P}(M(X_{-},Y_{X})=0\mid\mathcal{H})>0 , rearranging gives the lower bound
μ ϕ ≥ 1 − ℙ ⁡ ( M ⁡ ( X , Y X ) = 0 ∣ ℋ ) ℙ ⁡ ( M ⁡ ( X − , Y X ) = 0 ∣ ℋ ) . \mu_{\phi}\geq 1-\frac{\mathbb{P}(M(X,Y_{X})=0\mid\mathcal{H})}{\mathbb{P}(M(X_{-},Y_{X})=0\mid\mathcal{H})}.
For the upper bound, apply the same decomposition to probe detection:
ℙ ⁡ ( M ⁡ ( X , Y X ) = 1 ∣ ℋ ) = \displaystyle\mathbb{P}\bigl(M(X,Y_{X})=1\mid\mathcal{H}\bigr)={}
ℙ ⁡ ( M ⁡ ( X , Y X ) = 1 ∣ ℋ , ϕ X = 1 ) ​ μ ϕ \displaystyle\mathbb{P}\bigl(M(X,Y_{X})=1\mid\mathcal{H},\phi_{X}=1\bigr)\mu_{\phi}
+ ℙ ⁡ ( M ⁡ ( X , Y X ) = 1 ∣ ℋ , ϕ X = 0 ) ​ ( 1 − μ ϕ ) . \displaystyle+\mathbb{P}\bigl(M(X,Y_{X})=1\mid\mathcal{H},\phi_{X}=0\bigr)(1-\mu_{\phi}).
The second term is nonnegative, and Assumption 1 lower-bounds the first conditional detection rate by the detection rate on X + X_{+} . Hence,
ℙ ⁡ ( M ⁡ ( X , Y X ) = 1 ∣ ℋ ) ≥ ℙ ⁡ ( M ⁡ ( X + , Y X ) = 1 ∣ ℋ ) ​ μ ϕ . \mathbb{P}\bigl(M(X,Y_{X})=1\mid\mathcal{H}\bigr)\geq\mathbb{P}\bigl(M(X_{+},Y_{X})=1\mid\mathcal{H}\bigr)\mu_{\phi}.
When ℙ ⁡ ( M ⁡ ( X + , Y X ) = 1 ∣ ℋ ) > 0 \mathbb{P}(M(X_{+},Y_{X})=1\mid\mathcal{H})>0 , rearranging yields
μ ϕ ≤ ℙ ⁡ ( M ⁡ ( X , Y X ) = 1 ∣ ℋ ) ℙ ⁡ ( M ⁡ ( X + , Y X ) = 1 ∣ ℋ ) . \mu_{\phi}\leq\frac{\mathbb{P}(M(X,Y_{X})=1\mid\mathcal{H})}{\mathbb{P}(M(X_{+},Y_{X})=1\mid\mathcal{H})}.
Combining the two inequalities proves Theorem 1 .
