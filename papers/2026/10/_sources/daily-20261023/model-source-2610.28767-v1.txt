  Abstract 
    
 Current evaluation of LLMs on benchmarks typically aggregates performance over individual examples into a single scalar score.
This approach is overly coarse and ignores the diverse scope of skills covered by benchmark datasets.
To address this limitation and better exploit benchmark data, we propose  SkillEval , a new evaluation framework that performs cross-model, skill-level analysis.
The framework integrates advances from two areas:
(1) it leverages the meta-cognitive capabilities of LLMs to automatically discover interpretable skills from questions, and
(2) it applies cognitive diagnosis models (CDMs) from psychometrics to estimate per-skill abilities of LLMs.
We conduct experiments on 3,811 LLMs evaluated on 9,523 items across five benchmarks spanning diverse domains (MATH, BBH, GPQA, MuSR, IFEval).
Compared to the traditional average-based evaluation paradigm,  SkillEval  produces reliable, more calibrated and informative yet concise model profiles that more accurately predict model behavior on unseen items.
We also demonstrate the utility of  SkillEval  in two downstream tasks:
(1) LLM routing, which dynamically assigns each query to a capable but efficient model, reducing inference cost by over 60% while achieving improved performance, and
(2) Computerized Adaptive Testing (CAT), where an unseen model can be efficiently evaluated using a trained CDM.
Furthermore, we show that these skill profiles provide useful insights, for example, how benchmarks share skills and how instruction-tuned models differ from their base models.

  1  Introduction 

 
 Benchmarks for large language models (LLMs) have rapidly proliferated in recent years. While this creates new opportunities, it also raises a key challenge: how to effectively leverage a large collection of benchmarks for comprehensive LLM evaluation?
Current evaluation practices remain quite raw.
The common approach is to evaluate a model on all items in a benchmark and then report the average score.
This naive statistical way collapses performance across items into a single number, which obscures fine-grained capability differences  ( Cui et al., 2026a ) .
For example, two LLMs with similar overall accuracy on a math benchmark (0.63 vs. 0.65) may exhibit very different profiles across sub-skills such as algebra and geometry.
This leads to a natural question:  Given a set of test items, how can we go beyond a scalar score to a more informative, human-understandable capability estimate?  
 
 
 To answer this, we develop a new evaluation framework that aims to assess the  latent abilities  underlying observed item scores, and represents them as fine-grained skill profiles of LLMs.
This problem has long been studied in psychometrics and the education community using various latent variable models.
A representative family of approaches is Item Response Theory  ( Lord and Novick, 1968 , IRT;) , which jointly models test-taker traits (e.g., ability) and item traits (e.g., difficulty and discrimination).
IRT models are also increasingly used in machine learning, but typically for data-centric tasks such as dataset analysis or distillation  ( Kipnis et al., 2025 ;  Maia Polo et al., 2024 ;  Zouhar et al., 2025 ;  Rodriguez et al., 2021 ;  Cui et al., 2026b ) , and less often for LLM evaluation as it still produces a scalar overall ability score that suffers from capability collapse.
Some recent work explores multidimensional-IRT  ( Reckase, 2006 )  and its neural variants that learn ability vectors  ( Chen et al., 2025 ;  Cui and Sachan, 2025 ;  Song et al., 2025 ;  Gor et al., 2024 ) .
However, these multidimensional models are known to suffer from poor interpretability and non-identifiability, making them less suitable for reliable evaluation. 
 
 
 In this study, we propose  SkillEval , a new evaluation framework that identifies latent skills and estimates LLM abilities at the skill level.
The framework consists of a skill discovery module, which extracts shared skills from problems, and a neural cognitive diagnosis model  ( Wang et al., 2020 , CDM;) , which estimates per-skill abilities based on model performance on skill-associated items.
We evaluate  SkillEval  on a large-scale dataset of 36M model–item response records, covering 3,811 models and 9,523 items across five benchmarks from various domains, including MATH  ( Hendrycks et al., 2021 ) , BBH  ( Suzgun et al., 2023 ) , GPQA  ( Rein et al., 2024 ) , MuSR  ( Sprague et al., 2024 ) , and IFEval  ( Zhou et al., 2023 ) .
We conduct extensive experiments and demonstrate the superiority of  SkillEval  from various aspects: 
 
  •  
 
 Compared to MIRT-style methods,  SkillEval  extracts high-quality, human-understandable skills and produces stable ability estimates across runs, ensuring reproducible and robust evaluation. 
  
  •  
 
  SkillEval  accurately predicts model performance at both the item (with     AUC  =  81.73   {\rm AUC}=81.73   ) and benchmark (with Pearson     r  =  0.989   r=0.989   ) levels, outperforming strong baselines. In a downstream routing task where the goal is to assign queries to a cheap yet capable model,  SkillEval  matches the strongest LLM at     25  %   25\%    of the cost (    τ  =  0.80   \tau{=}0.80   ,     99.9  %   99.9\%    of strongest accuracy), and exceeds it by    3.7  3.7    points at     37  %   37\%    of the cost (    τ  =  0.95   \tau{=}0.95   ). It also profiles previously unseen LLMs efficiently without retraining the shared network:    20  20    adaptively chosen answers yield a mean benchmark-score error comparable to    100  100    randomly chosen answers. 
  
  •  
 
 In addition,  SkillEval  serves as a useful tool for analyzing dataset structure and model behavior, such as skill coverage across benchmarks, co-mastery patterns among skills, and skill-level differences between base and instruction-tuned models, offering useful insights into data curation and model training.

  2  Profiling LLMs’ Skills with Cognitive Diagnostic Models 

 
  2.1  Problem Statement 

 
 Given a set of models to be evaluated     {   ℳ  1   ,  …  ,   ℳ  M   }   \{\mathcal{M}_{1},...,\mathcal{M}_{M}\}    and a collection of test items     {   x  1   ,  …  ,   x  N   }   \{x_{1},...,x_{N}\}    from one or multiple benchmarks, we represent their performance using a matrix     𝒮  ∈   ℝ   M  ×  N     \mathcal{S}\in\mathbb{R}^{M\times N}   , where each entry     𝒮   i  ​  j    \mathcal{S}_{ij}    denotes the score of the    i  i   -th model on the    j  j   -th item.
We formulate LLM profiling as a function    ℱ  \mathcal{F}    that takes    𝒮  \mathcal{S}    as input and outputs some estimates for each model’s capabilities, i.e.,      ℱ  ⁡   (  𝒮  )    →   {   θ  1   ,  …  ,   θ  M   }    \mathcal{F}(\mathcal{S})\rightarrow\{\theta_{1},...,\theta_{M}\}   , where     θ  i   \theta_{i}    is a quantitative measurement of the capabilities of model    i  i   . 
 
 
 The common practice in evaluation is to model    ℱ  \mathcal{F}    as a simple average over individual items, i.e.,      θ  i   =    1  n   ​    ∑   j  =  1   n    S   i  ​  j       \theta_{i}=\frac{1}{n}\sum_{j=1}^{n}S_{ij}   .
While this provides a concise summary of model performance, it suffers from two key limitations. First, it compresses the model’s performance into a single scalar metric, failing to capture variations across fine-grained skills.
Second, the naive average can be affected by bias induced by the difficulty distribution of the test items, and may not faithfully reflect the model’s true ability. Indeed, this type of ability modeling assumes that all items in a given benchmark contribute equally to the estimation of a single ability dimension, which is typically an implausible assumption. 
 
 
 To address these limitations, we propose a new paradigm for profiling LLMs.
We assume that the items in the benchmark are associated with a set of underlying latent skills     𝒞  =   {   c  1   ,  …  ,   c  K   }    \mathcal{C}=\{c_{1},\ldots,c_{K}\}   .
Inspired by psychometric approaches for assessing latent traits, we use Cognitive Diagnosis Models (CDMs) to construct the profiling function       ℱ  CD   ​   (  𝒮  )    →  Θ  ∈   ℝ   M  ×  K     \mathcal{F}_{\rm CD}(\mathcal{S})\rightarrow\Theta\in\mathbb{R}^{M\times K}   , where the profile     θ  i   \theta_{i}    for each model is a    k  k   -dimensional vector representing its proficiency over the set of skills.
An overview of our method is shown in Figure   1  . 
 
 
 
  2.2  Q-Matrix Construction 

 
 We use a binary Q-matrix     𝒬  ∈    {   0  ,  1   }    N  ×  K     \mathcal{Q}\in\{0,1\}^{N\times K}    to denote the mapping between    N  N    items and    K  K    skills, where each entry      𝒬   i  ​  j    =  1   \mathcal{Q}_{ij}=1    indicates the    i  i   -th item is associated with the    j  j   -th skill and 0 otherwise.
Manually defining and annotating skills is challenging, costly, and difficult to scale.
Recent work shows that LLMs can automatically identify meaningful skills from problem content  ( Didolkar et al., 2024 ;  He et al., 2026 ) .
We adapt this approach to our setting, consisting of two main steps: skill labeling and skill clustering.

  2.4  Learning Item Parameters from Text

  3  Evaluation of Skill Profiles 

 
 Experiment Setup. 

 
 We train our text-conditioned NCDM on a subset of the RouterEval dataset  ( Huang et al., 2025 ) , including 3,811 LLMs evaluated on 9,523 items from five benchmarks: MATH, BBH, GPQA, MuSR, and IFEval.
For the number of skills, we set     K  =  100   K{=}100    as the main experimental configuration, as it achieves a better balance between interpretability and performance. We provide comparisons with other values of    K  K    in Appendix   F  . 
 
 
 
  3.1  Quality of Discovered Skills 

 
 Since our evaluation is centered around skills, it is crucial to assess the quality of these LLM-discovered skills.
We consider the following three criteria:
(1)  Semantic clarity , which measures whether a skill description is clear, unambiguous, and self-contained;
(2)  Level of abstraction , which captures the granularity of a skill, where a good skill should be neither overly broad nor overly specific to particular questions;
(3)  Diversity , which evaluates whether different skills are non-redundant and capture distinct aspects.
For the first two criteria, we adopt LLM-as-a-judge.
For the last one, we use intra-list diversity defined as averaged pair-wise dissimilarities, which is widely used in recommendation systems.

 Human validation of skill–question assignments. 

 
 Clear skill descriptions do not by themselves establish that the skills are relevant to their assigned questions. We therefore evaluate the skill–question assignments through human annotation. Three annotators, each holding an MSc in engineering, evaluated    780  780    skill–question pairs covering all    100  100    skills. We sampled up to    10  10    questions uniformly at random from each skill’s assigned items, retaining all items for smaller clusters. Annotators were shown revised descriptive skill names and question text, and judged whether answering each question required the named skill. Majority voting accepted    652  652    of    780  780    assignments (    83.6  %   83.6\%   ), with an acceptance rate of     81.7  %   81.7\%    when averaged equally across skills. Inter-annotator agreement was    0.715  0.715    in mean pairwise Cohen’s kappa and    0.714  0.714    in Krippendorff’s nominal alpha; both measures equal    1  1    for perfect agreement and    0  0    for agreement expected by chance. These judgments provide evidence for the semantic relevance of the sampled assignments. 
 
 
 
 
  3.2  Stability 

 
 For an evaluation method, the stability of its results is essential.
However, multidimensional latent ability models commonly suffer from non-identifiability: the    θ  \theta    vectors learned in repeated training runs are inconsistent, as they are affected by rotation, permutation, and random initialization.
This prevents such models from serving as a reliable and reproducible means of evaluation.
 SkillEval  instead ties each dimension of    θ  \theta    to a named skill through a fixed Q-matrix, which anchors the coordinate system across runs.

 Benchmark-level prediction. 

 
 Benchmark accuracy is the quantity most often used to compare LLMs, so we ask whether item-level predictions recover each LLM’s score on each benchmark.
In the OOD setting, we average an LLM’s predicted probabilities over a benchmark’s held-out items and compare the result with its observed accuracy on those items (Figure   2  ).
Although the two methods reach similar correlations on the pooled score (    r  =  0.989   r{=}0.989    vs.    0.993  0.993   ),  SkillEval  is more accurate within every benchmark, most clearly on MATH (   0.977  0.977    vs.    0.852  0.852   ) and IFEval (   0.966  0.966    vs.    0.718  0.718   ).
 SkillEval ’s predictions lie in a narrow band along the diagonal, whereas IRTNet’s spread widely: LLMs with nearly identical observed accuracy can receive very different predicted scores.
IRTNet also tends to overestimate accuracy, with most points above the diagonal on MATH, GPQA and MuSR, while  SkillEval  stays better calibrated.
This is because that IRTNet’s per-benchmark errors for the same LLM point in different directions and largely cancel when averaged into the pooled score.
In addition, the pooled score is also dominated by BBH, which contributes 61% of the held-out items and on which both methods already agree closely.
A good pooled correlation can therefore hide inaccurate per-benchmark estimates, and the per-benchmark comparison is the one that matters when LLMs are compared on a given benchmark.

 Item-side versus model-side accuracy. 

 
 Taken together, Table   3   and Figure   2   reveal a trade-off between predicting items and comparing models.
IRTNet lets every item draw on all    d  d    latent dimensions, so it can fit item-specific idiosyncrasies and attains higher pooled AUC on unseen items (+3.2 points).
 SkillEval  restricts each item to the dimensions of its assigned skills and summarises its difficulty along those skills with a single discrimination scalar, which limits how finely it can model individual items.
The same restriction forces all items that share a skill to constrain the same ability dimension, so each dimension of    Θ  {\Theta}    is estimated from many related items.
As a result,  SkillEval  estimates where each LLM stands within a domain more accurately: it ranks LLMs better on every benchmark (Figure   2  ) and yields ability profiles that are stable across retraining (Table   2  ).
The cost lies on the item side: difficulty and discrimination learned from text are less precise, and errors in the Q-matrix propagate directly into predictions.
For an evaluation framework, whose purpose is to compare models rather than to predict individual responses, we consider this trade-off favourable.

  4.2  Profiling Unseen LLMs 

 
 When a new LLM becomes available, we want to estimate its skill profile from a small set of its answers without retraining the entire diagnostic network. We train the text-conditioned NCDM using only training-item responses from    3,048  3{,}048    LLMs.
We then freeze the network, including the item difficulty and discrimination parameters, and estimate only the    K  K   -dimensional profile of each new LLM from its answers to    N  N    items drawn from the training-item pool. This is ability estimation with fixed item parameters, also called  scoring  in psychometrics  ( Segall, 1996 ) .
We evaluate this procedure on    200  200    held-out LLMs, using separate test items whose responses never enter profile estimation. 
 
 
 Starting point and related skills. 

 
 We fit a multivariate Gaussian to the raw (pre-sigmoid) profiles of the    3,048  3{,}048    training LLMs and use it as a prior. Starting from the prior mean, we update the new LLM’s profile with L-BFGS, using Equation   1   with a Gaussian prior regularizer.
Because the Gaussian captures correlations between skills, an answer also shifts skills that are correlated with the item’s assigned skills. As more answers are observed, the data term increasingly outweighs the fixed prior (Appendix   G  ).

 Measures. 

 
 We measure what the answers reveal about each LLM in two ways. For each benchmark, we average the predicted probabilities over its test items and compare this predicted accuracy with the observed accuracy on those items. The  benchmark-score error  is their absolute difference, averaged over the five benchmarks and the LLMs.  Profile agreement  compares the relative skill estimates from    N  N    answers with a reference profile estimated from all    7,618  7{,}618    pool answers without the prior. We compute Pearson correlation across LLMs for each skill, then average over skills. A  simple-count  baseline uses the same randomly selected items to estimate each benchmark score as the fraction answered correctly. If no items from a benchmark have been answered, it uses the prediction from the zero-answer profile.

  6  Conclusion 

 
  SkillEval  applies a Neural Cognitive Diagnostic Model to
   3,811  3{,}811    LLMs across    9,523  9{,}523    items and five benchmarks, producing
interpretable mastery profiles over     K  =  100   K{=}100    named skills. Unlike IRTNet’s latent dimensions, these profiles are stable across retraining: each skill’s estimates correlate at    0.96  0.96    on average between runs.
Skill-conditioned routing reaches      Acc  ​  @  ​  1   =   65.67  %    \mathrm{Acc@}1{=}65.67\%    (vs.     61.57  %   61.57\%    for the strongest single LLM,     62.05  %   62.05\%    for KNN,     63.08  %   63.08\%    for IRTNet over three runs and     61.10  %   61.10\%    for the IRT 2PL router) and matches the strongest LLM at     4  ×   4{\times}    lower inference cost.  SkillEval  also profiles previously unseen LLMs without retraining the shared network:    20  20    adaptively chosen answers give a mean benchmark-score error comparable to    100  100    randomly chosen answers. Skill profiles recover
benchmark-level scores at Pearson     r  =  0.989   r{=}0.989   . The framework surfaces
diagnostic findings invisible to aggregate scores: differences between base and instruction-tuned models that are statistically significant after Bonferroni correction on     14  /  100   14/100    skills, and overlapping skill coverage across benchmarks. An exploratory analysis in Appendix   L   examines asymmetric co-mastery: LLMs mastering one skill often also master another, while the reverse is less common. Testing how these patterns generalise across LLM populations is a direction for future work. Limitations are in Appendix   O  .

  Appendix A  Related Work 

 
 LLM Evaluation and Routing. 

 
 Standard LLM evaluation aggregates item-level correctness into a single
benchmark score  ( Gao et al., 2024 ;  Hendrycks et al., 2021 ;  Cobbe et al., 2021 ) , creating leaderboards whose rankings are influenced as
much by evaluation protocol (prompt format, shot count, decoding parameters)
as by true model capability  ( Biderman et al., 2024 ) . Platforms such as the
Open LLM Leaderboard and RouterBench   Hu et al. (2024)   release
per-item correctness matrices for thousands of LLMs, enabling but not
themselves performing fine-grained analysis. Routing systems match queries
to the cheapest capable model, typically using latent query-model embeddings
without explicit semantic skills. Closest in spirit to our work, CAIMIRA
  Gor et al. (2024)   applies IRT to factual QA, and   Didolkar et al. (2024)   use LLM-generated skill labels to probe
mathematical reasoning. We build on the latter by scaling skill extraction
to five benchmarks and fitting a full CDM over the extracted skills. 
 
 
 
 Cognitive Diagnostic Models. 

 
 Cognitive Diagnostic Models (CDMs) originate in educational psychometrics
and estimate latent skill mastery from observed item responses, extending
Item Response Theory (IRT) by modelling proficiency as a vector over
 named  skills rather than a scalar or a continuous embedding.
Classical CDMs such as DINA   de la Torre (2009)   assume conjunctive
skill requirements (an item is correct only if all required skills are
mastered) and binary mastery. The Neural CDM (NCDM)   Wang et al. (2020)  
relaxes these assumptions with neural interaction functions while
preserving mastery-to-score monotonicity via non-negative weight
constraints, and is generalised in NeuralCD   Wang et al. (2023)  ;
reference implementations are collected in the EduCDM library
  bigdata-ustc (2021)  . CDMs have been widely deployed for human
assessment over hundreds of skills and tens of thousands of examinees,
making them a natural fit for LLM evaluation where response matrices are
now orders of magnitude larger. 
 
 
 
 Psychometric Methods for LLMs. 

 
 Recent work applies psychometric models to LLMs at scale. IRT-Router
  Song et al. (2025)   uses multidimensional IRT with a query-cluster
relevance vector for routing. IRTNet   Chen et al. (2025)   jointly learns
   d  d   -dimensional LLM ability embeddings, query discrimination, and query
difficulty via a Mixture-of-Experts architecture, evaluated on    112  112    LLMs
and    10  10    benchmarks. Metabench  ( Kipnis et al., 2025 )  compresses six public
benchmarks to under     3  %   3\%    of their combined items using    2  2   -PL IRT and
Fisher-information filtering on       ∼   5,000   {\sim}\,5{,}000    LLMs, showing that a
single latent factor explains     79  %   79\%    of benchmark variance. TinyBenchmarks  ( Maia Polo et al., 2024 ) 
similarly uses IRT-based item selection to reduce evaluation cost. All of these approaches treat LLM ability as a
low-dimensional latent embedding without a named skill structure.
 SkillEval  commits to an  a priori  Q-matrix over     K  =  100   K{=}100   
semantically labeled skills derived from LLM metacognition and SBERT
clustering, enabling skill-level analyses of co-mastery patterns,
skill interaction within items, and base versus instruction-tuned differences that
are not expressible over a continuous latent embedding. We scale to
   3,811  3{,}811    LLMs (    34  ×   34{\times}    IRTNet, comparable to metabench’s
      ∼   5,000   {\sim}\,5{,}000   ) across five benchmarks.

  Appendix D  Q-Matrix Construction Details 

 
 Skill extraction prompt. 

 
 For each item we prompt GPT-4o-mini at temperature    0  0    with the benchmark, the subtask and the item text, and ask for two to four skills, each with a label, the cognitive process and the content domain, together with the single most important skill, which we call the primary skill. Labels on the list of generic labels in the prompt are removed after extraction. The system prompt and the user template are reproduced below; long lines are wrapped for display. We extract the full skill list rather than only the primary skill, yielding a mean of    2.9  2.9    skills per
item and    13,276  13{,}276    unique skill strings across    9,523  9{,}523    items. The primary
skill alone is too coarse: it covers only the headline category and produces
Q-matrix rows with mean row-sum    1.0  1.0   , which under-constrains the diagnostic
model. 
 
 
  System prompt.   
You are a psychometrician designing a Q-matrix for cognitive diagnostic
   assessment of AI systems. Your task: identify the specific cognitive
   skills each test item measures.

RULES:
1. Each skill must be a compound phrase (5-10 words):
   [specific_cognitive_process] + [specific_content_domain]
2. Extract 2-4 skills per item. At least one must be domain-specific.
3. FORBIDDEN generic labels (will be rejected):
   - "reading comprehension", "logical reasoning", "critical thinking"
   - "mathematical reasoning", "problem solving", "analytical thinking"
   - "scientific knowledge", "attention to detail", "numerical
      reasoning"

4. Specificity test: would fewer than 100 items in a 10,000-item test
   share this exact skill? If not, decompose further.
5. Use lowercase snake_case labels.

 Embedding and clustering. 

 
 The    13,276  13{,}276    unique skill strings are embedded with the
 all-mpnet-base-v2  sentence transformer into     ℝ  768   \mathbb{R}^{768}    and
    L  2   L_{2}   -normalised. We compare three clustering families: HDBSCAN after
UMAP reduction to    5  5   D,    K  K   -Means, and HAC with cosine distance and
average linkage. We select HAC because it yields the highest downstream
test AUC at every    K  K    we tried, despite a lower silhouette score
(   0.053  0.053    at     K  =  50   K{=}50    vs.    0.144  0.144    for    K  K   -Means and    0.160  0.160    for HDBSCAN
at     K  =  281   K{=}281   ). Intrinsic clustering quality is therefore not a reliable
proxy for diagnostic utility. 
 
 
 
 Coverage fix. 

 
 Our first pipeline iteration assigned each item to a single cluster via the
primary skill only, which left     43  %   43\%    of clusters with fewer than    10  10    items and    10  10    empty columns in    𝐐  \mathbf{Q}    at     K  =  100   K{=}100   . Switching to the multi-skill assignment described above removed all empty columns, reduced the fraction of under-populated clusters to     36  %   36\%    and raised the mean column-sum from    95  95    to    139  139    items per skill. 
 
 
 
 Reference-answer ablation. 

 
 Our default skill extraction does not use reference solutions. To test whether showing the extractor a reference solution changes the result, we ran two new extractions for the    2,470  2{,}470    MATH and GPQA items that have a reference solution, one from the question and one from the question plus the solution. Both use the same prompt, the same extraction model and the same question text, and they are separate from the extraction that produced the Q-matrix. The solution changes which skills are named: the token-level Jaccard overlap between the two label sets is    0.37  0.37   , against    0.73  0.73    between two independent question-only runs. A blind judge (GPT-4.1-mini) compared both label sets on    600  600    items, each in both presentation orders. We retain the    357  357    items with a consistent, non-tied preference in both orders; the remaining judgments do not enter the percentages below. Among the retained items the judge preferred the solution-aware labels in     49.6  %   49.6\%    and the question-only labels in     50.4  %   50.4\%   , so it showed no clear aggregate preference for either extraction condition. Within the retained subset the preference differs by benchmark: question-only labels are preferred on MATH (    59  %   59\%   ) and solution-aware labels on GPQA (    61  %   61\%   ). We keep question-only extraction, which also applies to item banks without reference solutions.

  Appendix G  Profiling Unseen LLMs: Details 

 
  Network.  The frozen network is trained with the recipe of the main model in Appendix   E   (seed    42  42   , batch size    1024  1024   ,    15  15    epochs), using only the training-item responses of the    3,048  3{,}048    training LLMs. 
 
 
  Estimation.  Each profile is represented by unconstrained raw parameters    𝐫  \mathbf{r}   , with     𝜽  =   sigmoid  ⁡   (  𝐫  )     \bm{\theta}=\mathrm{sigmoid}(\mathbf{r})   . The prior on    𝐫  \mathbf{r}    is a multivariate normal distribution. Its mean    𝝁  \bm{\mu}    is the mean raw profile of the    3,048  3{,}048    training LLMs; its covariance    𝚺  \bm{\Sigma}    is their empirical covariance shrunk by     10  %   10\%    towards its diagonal. Let    A  A    be the set of answered items,     y  j   y_{j}    indicate whether item    j  j    was answered correctly, and     p  j   p_{j}    be the predicted probability of correctness from Equation   1  . We estimate    𝐫  \mathbf{r}    by minimising 
 

  
  
     −   ∑   j  ∈  A     [   y  j   log   p  j   +   (  1  −   y  j   )   log   (  1  −   p  j   )   ]   +    1  2      (  𝐫  −  𝝁  )   ⊤    𝚺   −  1     (  𝐫  −  𝝁  )   .   -\sum_{j\in A}\big[y_{j}\log p_{j}+(1-y_{j})\log(1-p_{j})\big]\;+\;\tfrac{1}{2}(\mathbf{r}-\bm{\mu})^{\top}\bm{\Sigma}^{-1}(\mathbf{r}-\bm{\mu}).    
  
  (4)    
 
 The first term measures fit to the observed answers; the second penalises departures from profiles supported by the prior. We optimise with L-BFGS, starting from    𝝁  \bm{\mu}   . With no answers, the raw estimate is    𝝁  \bm{\mu}    and the skill profile is its sigmoid transform. In a check on the first    20  20    LLMs using all    7,618  7{,}618    pool answers, fits with and without the prior have a mean absolute difference of    0.005  0.005    in their test-item probabilities. During adaptive selection, each update starts from the previous raw estimate. At each evaluated budget, we refit from    𝝁  \bm{\mu}   , using the same procedure for random and adaptive selection. 
 
 
  Evaluation.  We use the first    200  200    of the    763  763    held-out LLMs. Random-selection metrics are averaged over three seeds; adaptive selection is deterministic for a given LLM and network. Both selection methods are evaluated at the same answer budgets up to    500  500   . Table   9   lists the values shown in Figure   4  . At each tested budget from    5  5    to    500  500    answers, paired     95  %   95\%    bootstrap intervals over LLMs favour adaptive selection on both measures: the adaptive-minus-random difference is below zero for benchmark-score error and above zero for profile agreement. 
 
 
  Reference profiles and robustness.  Profile agreement uses a reference estimated from all pool answers without the prior, avoiding a shared prior term in the reference and the estimates being evaluated. This reference is itself an estimated profile. We assign zero agreement to a skill whose estimates are constant across LLMs; this includes the zero-answer setting, where Pearson correlation is undefined. Using a reference estimated with the prior, or restricting the measure to the    50  50    skills with at least    20  20    pool items, changes the agreement values but preserves the ordering of the compared methods. 
 
 
  Per-LLM AUC.  Test-item AUC changes little in this setting, from    0.68  0.68    with no answers to    0.69  0.69    with all answers. The zero-answer prediction uses the same profile for every LLM, so reaching this AUC does not require estimating differences between their skills.   Appendix L  Empirical Co-Mastery Patterns 

 
 Mastery and link rule. 

 
 This exploratory analysis asks whether LLMs that master one skill also tend to master another, even when the reverse is less common. We find such asymmetric co-mastery patterns across most skills, with similar patterns visible in the observed responses. In Equation   1  , estimated mastery    θ  \theta    is interpreted relative to item difficulty, so its value alone does not specify expected accuracy on a skill’s items. For this analysis, we classify an LLM as mastering a skill when its predicted probability of a correct answer, averaged over the items assigned to that skill, exceeds    0.5  0.5   , that is, when the model expects it to answer more than half of those items correctly. 
 
 
 For two skills    A  A    and    B  B   , let     P  ⁡   (  A  ∣  B  )    P(A\mid B)    denote the share of LLMs mastering    A  A    among those mastering    B  B   . For example,    52  52    of the    55  55    LLMs mastering  combinatorics of dice rolls  also master  divisibility rules for factorials , so      P  ⁡   (  divisibility  ∣  dice  )    =   52  /  55   ≈  0.95   P(\text{divisibility}\mid\text{dice})=52/55\approx 0.95   . In the reverse direction, only    52  52    of the    167  167    LLMs mastering divisibility rules also master dice-roll combinatorics, so      P  ⁡   (  dice  ∣  divisibility  )    =   52  /  167   ≈  0.31   P(\text{dice}\mid\text{divisibility})=52/167\approx 0.31   . Almost every LLM that masters the dice-roll skill thus also masters the divisibility skill, whereas most LLMs that master the divisibility skill do not master the dice-roll skill. We represent this pattern by a link from divisibility rules to dice rolls. 
 
 
 We draw a link from    A  A    to    B  B    when two conditions hold. First, we require      P  ⁡   (  A  ∣  B  )    P(A\mid B)       −  {}-{}        P  ⁡   (  B  ∣  A  )    P(B\mid A)          >  0.3   {}>0.3   , capturing an asymmetry like the one above. Second, we require a strong association. The odds of an event are its probability divided by the probability that it does not occur, so a probability of    0.75  0.75    corresponds to odds of    3  3   . The odds ratio compares the odds of mastering    A  A    among LLMs that master    B  B    with those among LLMs that do not. A ratio of    1  1    indicates no association; a ratio above    1  1    means mastery of    A  A    is more likely among LLMs mastering    B  B   . We require an estimated odds ratio above    10  10   . Without this condition, unrelated skills could be linked simply because one is mastered more frequently than the other. 
 
 
 
 Odds ratio. 

 
 For two skills    A  A    and    B  B   , let     n   A  ​  B    n_{AB}    be the number of LLMs that master both,     n   A  ​   B  ¯     n_{A\bar{B}}    the number that master    A  A    but not    B  B   ,     n    A  ¯   ​  B    n_{\bar{A}B}    the number that master    B  B    but not    A  A   , and     n    A  ¯   ​   B  ¯     n_{\bar{A}\bar{B}}    the number that master neither. The Haldane correction adds    0.5  0.5    to each count, which keeps the odds ratio finite when a count is zero: 
 

  
  
       OR  ⁡   (  A  ,  B  )    =     (    n   A  ​  B    +  0.5   )   ​   (    n    A  ¯   ​   B  ¯     +  0.5   )      (    n   A  ​   B  ¯     +  0.5   )   ​   (    n    A  ¯   ​  B    +  0.5   )      .   \mathrm{OR}(A,B)\;=\;\frac{(n_{AB}+0.5)\,(n_{\bar{A}\bar{B}}+0.5)}{(n_{A\bar{B}}+0.5)\,(n_{\bar{A}B}+0.5)}.    
    
 
 
 
 
 Co-mastery graph. 

 
 Applying this rule to every pair of skills gives a  co-mastery graph  with skills as nodes. The graph orders two skills when following links in their direction leads from one to the other. To simplify the graph, we remove a direct link when the original graph also connects the same pair through one intermediate skill. This leaves    304  304    links connecting    86  86    of the    100  100    skills; some retained links may still be implied by longer paths. Of these    86  86    skills,    18  18    have no incoming link and    13  13    have no outgoing link. Every link points from a more commonly mastered skill to a less commonly mastered one, because     P  ⁡   (  A  ∣  B  )    P(A\mid B)    can exceed     P  ⁡   (  B  ∣  A  )    P(B\mid A)    only when more LLMs master    A  A    than    B  B   . Its direction therefore follows from the construction and does not show that    A  A    must be learned before    B  B   . Repeating the construction and link removal with a mastery cut-off of    0.4  0.4    instead of    0.5  0.5    gives    391  391    links connecting    89  89    skills, and with    0.6  0.6    it gives    209  209    links connecting    68  68    skills. Only    29  29    direct links appear at all three cut-offs, so individual links are sensitive to the cut-off. 
 
 
 
 Checks. 

 
 Two checks support these patterns. First, we construct a second graph using the same LLMs, items and skill assignments, but classify an LLM as mastering a skill if it answers more than half of that skill’s items correctly. This graph orders    1,325  1{,}325    pairs. The co-mastery graph orders    983  983    in the same direction and one in the opposite direction, leaving the rest unordered. Wherever both graphs order a pair, they agree in all but one case. Second, we independently shuffle each skill’s mastery labels across LLMs, preserving the share mastering each skill while disrupting the observed associations. Before link removal, the rule finds at most    51  51    links in any of    200  200    shuffles, compared with    1,031  1{,}031    in the original profiles. This supports associations beyond individual skill frequencies. Across the    304  304    retained links, the median of     P  ⁡   (  A  ∣  B  )    P(A\mid B)    is    0.87  0.87    and the median of     P  ⁡   (  B  ∣  A  )    P(B\mid A)    is    0.26  0.26   . A benchmark average does not expose these relationships between named skills. For dataset design, the graph can suggest skills to assess within groups of LLMs sharing a strength, as dice-roll combinatorics distinguishes among the    167  167    LLMs that master divisibility rules. 
 
 
 
 Cross-family overlap. 

 
 We also apply the link rule separately to each model family with at least    100  100    LLMs: Llama, Qwen, Mistral, Gemma and Phi. We compare the resulting link sets before removing any links. For two families, the Jaccard index is the number of links shared by both divided by the number found in at least one. Across the ten family pairs, it ranges from    0.09  0.09    to    0.31  0.31   . The detected links are therefore only partly shared across the sampled families; whether these patterns persist in other LLM populations remains to be tested.

  Appendix O  Limitations 

 
 Scope of the new-LLM experiments. 

 
 The new-LLM results use    200  200    of the    763  763    held-out LLMs and one trained network. We evaluate one adaptive selection rule at answer budgets up to    500  500   . The prior is estimated from profiles produced by that network, while observed scores for the smaller benchmarks are based on relatively few test items. The results describe the evaluated LLMs, network and item pool; they do not establish an advantage for adaptive selection in every setting. 
 
 
 
 Co-mastery vs. causal prerequisites. 

 
 The co-mastery graph in Appendix   L   is constructed from
statistical co-mastery (    OR  >  10   \mathrm{OR}>10   ), not causal dependency. The
observed structure likely reflects a mix of skill-difficulty ordering
and shared training-data signal rather than experimentally verifiable
cognitive prerequisites. Establishing causal prerequisite relations
would require intervention experiments (skill-specific fine-tuning)
beyond our scope; we therefore phrase all structural claims in terms
of co-mastery. 
 
 
 
 Q-matrix inter-annotator agreement. 

 
 The Q-matrix is constructed semi-automatically via LLM-proposed skill
phrases clustered by SBERT and HAC. Cluster choice is validated by
downstream NCDM AUC rather than by human adjudication. A human validation of a sample of skill–question assignments is reported in Section   3.1  . It tests whether an assigned skill is needed, not whether needed skills are missing. Items near cluster boundaries should be interpreted with
additional caution. We sweep the number of skill
clusters    K  K    and report sensitivity to    K  K   , but we do not separately
vary the clustering algorithm (HAC), the skill-extraction prompt, or
the sentence-embedding source (SBERT); we leave a joint pipeline-robustness
study to future work. 
 
 
 
 Evaluation scope. 

 
 Our item-wise OOD setting holds out all responses to the test items while retaining the same benchmarks and LLM population. We treat the Q-matrix as part of the test design: the skill taxonomy and Q-matrix are constructed before this split, using question text and benchmark/subtask metadata from the complete item bank, including test items. Skill extraction and clustering use item content rather than the evaluated LLMs’ responses. However, the clustering method and the number of clusters were chosen with reference to downstream performance (Appendices   D   and   F  ). Item difficulty and discrimination for test items are predicted from their text by projections trained on training items only. The evaluation is therefore transductive with respect to the skill representation, while test-item responses are excluded from parameter fitting: it measures prediction of held-out responses within a fixed, item-bank-derived taxonomy. Generalization remains limited. IRTNet outperforms  SkillEval  on held-out-item prediction (Table   3  ). When MuSR and IFEval are jointly excluded from response-based training, observed routing accuracy on MuSR is similar to that of the single-model baseline selected by training accuracy (   0.470  0.470    versus    0.467  0.467   ), whereas IFEval routing falls below the random-routing baseline (   0.410  0.410    versus    0.437  0.437   ; Appendix   J  ). These results limit the scope of our routing and profiling claims; reliable transfer to new benchmark domains or skill families remains to be established. 
 
 
 
 Benchmark coverage. 

 
 SkillEval covers five English-language benchmarks (MATH, BBH, GPQA, MuSR, IFEval). Notable gaps include multilingual reasoning, tool use,
long-context retrieval, safety/red-team benchmarks, and open-ended
generation. The Q-matrix pipeline is designed to extend to new
benchmarks without retraining existing skill clusters: adding a new
benchmark requires running the LLM skill extraction pipeline on its
items, assigning each extracted skill to its nearest existing cluster
(or expanding    K  K   ), and retraining NCDM.
