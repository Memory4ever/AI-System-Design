The exponent ν \nu describes capacity demand, while α j \alpha_{j} describes the

Selective access and the economics of reuse.
Selective access allows persistent memory and per-query input to scale
separately. If a query needs a bounded number of fixed-length records and
indexing reliably locates them, model input can stay bounded as the bank
grows. Tasks that synthesize more evidence may require more reading, and
index search and updates still incur costs. Cross-task reuse can shift work
from repeated reading and reasoning to earlier extraction or consolidation.
With costs expressed in consistent units, average cost over N N reuses is
C ¯ N = C build + C maint ​ ( N ) N + C ¯ query . \overline{C}_{N}=\frac{C_{\mathrm{build}}+C_{\mathrm{maint}}(N)}{N}+\overline{C}_{\mathrm{query}}.
(4.6)
At equal performance, lightweight writing and direct reading may cost less
when reuse is limited. More expensive preparation becomes worthwhile when
cumulative query savings exceed its additional cost. For fixed-quality
policies with no ongoing maintenance, the crossover reuse count is the
extra construction cost divided by the per-query saving.

Environmental change bounds how many times a memory can be reused before
it needs revision. Retention extends the period over which preparation costs
can be amortized, and transfer increases the number of tasks served by the
same experience. Adaptation incurs the maintenance cost required to keep
that experience useful. These continual-learning properties determine the
reuse horizon and update costs in the resource-optimal allocation of
Equation ( 4.4 ).
4.3.2 Parametric Memory Scaling Law
Parametric memory writes deployment experience into model parameters or
persistent neural states rather than into an external store. Representative
designs include trainable memory layers Berges et al. [2025] ,
plug-and-play memory modules Cao et al. [2025] , memory states
updated at test time Behrouz et al. [2025] , Kuratov et al. [2026] , side
memories isolated from the backbone Wang et al. [2024d] , Das et al. [2024] , Wang et al. [2024e] ,
and direct editing or fine-tuning of backbone
weights Meng et al. [2023] , Xu et al. [2026b] . These approaches confront the
same fundamental question as non-parametric memory regarding how performance
scales with experience and resources, and at what write and compute cost. They
differ in one essential respect. All writes share the same parameters, so new
writes alter how earlier content is read out. Accumulating experience therefore
adds usable content while simultaneously increasing the probability that
existing content is overwritten. We build this property into the scaling relation
and propose a parametric counterpart to Equation ( 4.2 ).
Resource dimensions of parametric memory.
We retain the notation of Section 4.3.1 ,
where E t E_{t} denotes cumulative experience, θ \theta denotes the foundation model,
and 𝒟 \mathcal{D} denotes the task distribution. Parametric memory involves three
resources. Memory capacity M M is the number of memory parameters, memory
slots, adapter rank, or persistent-state dimensions, playing the role of
B ¯ \bar{B} . The write budget U U represents the computation used to write
experience into parameters, such as gradient steps, update steps per write, and
write frequency. Readout compute is fixed by the architecture, as each forward
pass traverses the memory parameters or performs a fixed top- k k lookup
without consuming additional prompt context tokens;
consequently, the read budget R R is generally not an independent decision
variable. This marks the first major divergence from non-parametric memory.
The second difference concerns occupancy. External memory can directly report its
actual occupancy B t B_{t} , whereas parametric memory has no directly observable
counterpart. We therefore define the load ratio
ρ t = I ⁡ ( E t ) κ ​ M , \rho_{t}=\frac{I(E_{t})}{\kappa M},
(4.7)
where I ⁡ ( E t ) I(E_{t}) is the information in the experience that must be retained,
measured in bits, and κ \kappa is the information a single parameter can
store. Knowledge-capacity studies estimate κ ≈ 2 \kappa\approx 2 bits per
parameter and report that this ratio holds even under int8
quantization Allen-Zhu and Li [2025] . The dimensionless quantity
ρ t \rho_{t} measures how full the memory has become.

The first term mirrors Equation ( 4.2 ), approximating the

eviction while leaving surviving records intact, a cost mediated by the read
and maintenance terms. In parametric
memory, additional experience rewrites shared parameters directly, so performance
degradation as experience grows is an intrinsic property of the substrate
rather than only a retrieval or selection problem.
Equation ( 4.8 ) yields three testable predictions.
First, when experience and write budget are fixed and only capacity grows,
loss is initially dominated by interference and follows the power law only
after the load ratio enters the safe regime (Figure 11 (a)).

magnitude across substrates (Figure 11 (b)). Third, load curves
measured at several capacities should approximately collapse onto a single

Evidence for the capacity term.
Experiments that hold the foundation model fixed and enlarge only the memory
parameters support the shape of the capacity term. Memory Layers at Scale
enlarges the Memory+ value count from 1M to 64M in a 1.3B configuration
(Figure 12 (a)) Berges et al. [2025] .
NaturalQuestions accuracy rises from 13.68 to 20.78 and TriviaQA F1 from
42.89 to 62.14, well above a dense model of the same configuration without
memory layers (7.76 and 32.64). Between 16M and 64M, however,
NaturalQuestions improves by only 0.64 while TriviaQA still improves by 3.47,
indicating that the same capacity range places different tasks at different
points on the power law. The same work scales memory parameters to 128B on
foundation models of at most 8B, showing that memory capacity can far exceed
backbone size (though these Memory+ layers are trained jointly during pretraining,
so sequential deployment writes remain to be tested separately).

Capacity demand and balanced growth.
Analogous to Equation ( 4.5 ), maintaining a target
performance p 0 p_{0} requires the load ratio to stay below its critical value,
which implies

The exponent ν \nu has the same meaning as in
Equation ( 4.5 ), with ν ≈ 1 \nu\approx 1 when experience consists
of independent facts and ν < 1 \nu<1 when it shares rules or skills. Parametric
memory compresses shared regularities into the same parameters as it writes,
so consolidation happens implicitly during training.
Equation ( 4.9 ) leads to two differences from
non-parametric memory. First, when external capacity falls short, degradation
arises through retrieval competition or eviction while surviving records remain
intact; when parametric capacity falls short,
earlier content is directly overwritten in shared weights, which is harder to reverse. Second, ρ ⋆ \rho^{\star}
appears in the denominator, so improving the substrate or the write policy
can reduce the required capacity by orders of magnitude
(Figure 11 (c)), often more efficiently than adding parameters.

Writing more often is not always better. TMEM varies how much context
accumulates before a parametric write is triggered, where F1 peaks at a 4K-token
threshold on LoCoMo (25.72) and at 12K on LongMemEval-S (41.24), and declines
at both smaller and larger thresholds
(Figure 13 (b–c)) Ren et al. [2026] . A plausible interpretation is that writing too often

too rarely forces each update to compress too much context at once. The policy π \pi therefore
exhibits a task-dependent favorable range rather than shifting the critical ratio
monotonically.
