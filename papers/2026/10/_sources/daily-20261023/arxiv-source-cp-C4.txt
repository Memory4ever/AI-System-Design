C.4 Quantization and temperature implementation.
For each model, we instantiate the same pretrained checkpoint under each quantization mode
𝒬 ∈ { fp16 , int8 , nf4 } \mathcal{Q}\in\{\mathrm{fp16},\mathrm{int8},\mathrm{nf4}\} . The fp16 setting uses half-precision
inference, while the int8 and nf4 settings use post-training low-bit inference following standard
LLM quantization practice [ 7 , 8 ] . In all cases,
quantization changes only the numerical representation used at inference time: the model checkpoint,
training procedure, prompt template, candidate labels, calibration split, and evaluation split are held
fixed. No model weights are fine-tuned or otherwise updated between inference configurations.

C.5 Compute resources
All experiments were run on a local workstation equipped with an AMD Ryzen Threadripper PRO CPU and a single NVIDIA RTX A6000 GPU with 48GB of GPU memory. Model inference, including fp16, int8, and nf4 configurations, was executed on the GPU. CPU resources were used for data loading, preprocessing, conformal calibration, the logistic-regression router used by LATENT-ROBUST, and result aggregation. The experiments were run sequentially over the dataset–model–configuration grid.
