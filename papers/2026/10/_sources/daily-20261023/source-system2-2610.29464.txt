Abstract.
Dense retrieval has become a fundamental paradigm for modern information retrieval, supporting efficient semantic search across a wide range of applications.
Its effectiveness, however, relies critically on query embeddings that adequately capture users’ information needs, which can be difficult for short, ambiguous, or underspecified queries.
Feedback-based query reformulation approaches like pseudo-relevance feedback (PRF) alleviate this by incorporating additional evidence from retrieved or generated content.
However, existing embedding-space approaches commonly aggregate or interpolate feedback vectors, implicitly treating them as complete target representations.
Such pointwise fusion can unnecessarily suppress query corrections along directions not expressed by individual feedback items, even when these directions are supported by complementary evidence.
To address this limitation, we propose Directional Posterior Feedback Fusion (DIFF), a query reformulation framework that models feedback as directional evidence rather than target points.
DIFF represents feedback as confidence-weighted directional evidence in the tangent space of the original query and jointly infers a controlled query update through prior-regularized posterior fusion, without retraining the underlying dense retriever.
Experiments across multiple dense retrievers and different feedback sources show that DIFF achieves the best overall retrieval performance, demonstrating the effectiveness of explicitly modeling how feedback should constrain query updates.
Code is available at: https://anonymous.4open.science/r/DIFF/ .
Keywords: Query Reformulation, Dense Retrieval, Pseudo-relevance Feedback, Generative Relevance Feedback
1. Introduction
Dense retrieval has become a fundamental paradigm for modern information retrieval ( Xiong et al., 2020 ; Izacard et al., 2021 ; Karpukhin et al., 2020 ) .
It represents queries and documents as dense vectors and retrieves relevant documents according to their similarity in a shared semantic embedding space, thus bridging the gap between users’ information needs and vast document collections ( Sun and Surdeanu, 2026 ; Tu et al., 2026 ) .
However, its effectiveness depends critically on whether the query embedding adequately captures the user’s underlying information need ( Yu et al., 2021 ; Lin et al., 2021 ) .
User queries can be short, ambiguous, or underspecified, and only partially describe the relevant information ( Tu et al., 2026 ; Gao et al., 2023 ) .
Query reformulation therefore offers a natural way to bridge this gap by enriching the initial query representation with additional evidence.
A common strategy is to obtain such evidence from feedback.
Classical pseudo-relevance feedback (PRF) ( Abdul-Jaleel et al., 2004 ; Rocchio Jr, 1971 ) assumes that top-ranked documents from an initial retrieval contain useful information and uses them to refine the query representation.
More recently, large language models (LLMs) ( Yang et al., 2025 ; Liu et al., 2024 ; Achiam et al., 2023 ; Touvron et al., 2023 ) have further broadened the possible sources of feedback by generating hypothetical documents, pseudo-answers, query expansions, or other auxiliary content ( Gao et al., 2023 ; Wang et al., 2023 ; Mackie et al., 2023 ) .
Despite their different origins, these approaches share a common question: Given a set of feedback representations, how should they be used to modify the original query?
In this work, we separate this question from how the feedback is obtained and focus on converting feedback vectors into a controlled and robust query update.
Existing vector-based feedback methods commonly construct the reformulated query by averaging feedback embeddings, linearly interpolating them with the original query, or otherwise moving the query toward an aggregate feedback representation ( Li et al., 2025 ; Gao et al., 2023 ; Yu et al., 2021 ) .
Although intuitive, such pointwise fusion implicitly treats each feedback vector as evidence for a complete target representation (as shown in the left part of Figure 1 ; more detailed discussion in § 2.3 ).
This assumption can be unnecessarily restrictive.
A feedback item may support only one aspect of the information need rather than specify what the entire reformulated query should be.
Consequently, dimensions or directions not expressed by that feedback should not automatically be interpreted as evidence against changing the query along those directions.
To address this limitation, we shift from pointwise fitting to directional constraints.
Instead of asking the reformulated query to approach each feedback vector as a whole, we let each feedback constrain only the query movement along the direction it supports, as shown in the right part of Figure 1 .
Specifically, we operate in the tangent space of the unit sphere at the original query representation, where feedback can be expressed as local directional evidence and multiple pieces of evidence can be jointly incorporated through a constrained optimization objective.
This formulation allows complementary feedback to govern different directions of the query update, while a prior toward the original query keeps the reformulation conservative when feedback evidence is insufficient.
Figure 1 . A comparison between pointwise fitting and directional constraints.
Based on this formulation, we propose DI rectional Posterior F eedback F usion (DIFF), a query reformulation framework for dense retrieval.
DIFF first converts feedback vectors into directional evidence in the tangent space of the original query, and then estimates their contributions using lightweight local- and set-level confidence control.
The resulting directional observations are jointly fused through a prior-regularized posterior objective with an efficient closed-form solution, after which the inferred correction is mapped back to the unit sphere.
DIFF operates directly on fixed pretrained embeddings without updating the retriever or training an additional reformulation model, making it applicable to feedback from different sources.
Experiments across multiple retrieval benchmarks and dense retrievers show that DIFF achieves the best overall retrieval performance in diverse retrieval settings.
In conclusion, our contributions are threefold:
(1) We introduce a directional perspective on vector feedback for dense query reformulation.
Rather than treating feedback embeddings as complete target points, we formulate each feedback item as a local directional constraint, allowing complementary evidence to contribute along different directions of the query update.
(2) We propose DIFF, a posterior fusion framework that jointly incorporates directional evidence with local feedback quality and set-level confidence, while explicitly regularizing the update toward the original query.
(3) We develop a training-free and feedback-source-agnostic reformulation method that operates directly on pretrained embeddings and admits an efficient closed-form solution, enabling its application to both retrieval-based and generated feedback.

2.1. Dense Retrieval
Given a query x q x_{q} and a document x d x_{d} , a dense retriever E ⁡ ( ⋅ ) E(\cdot) encodes them into L2-normalizated D D -dimensional representations:
(1)

Documents are then ranked according to the similarity between their representations and the query representation. With L2-normalization, ‖ 𝐪 ‖ 2 = ‖ 𝐝 ‖ 2 = 1 \|\mathbf{q}\|_{2}=\|\mathbf{d}\|_{2}=1 , so retrieval can be performed via their inner product, s ⁡ ( 𝐪 , 𝐝 ) = 𝐪 ⊤ ​ 𝐝 s(\mathbf{q},\mathbf{d})=\mathbf{q}^{\top}\mathbf{d} , which equals cosine similarity.

This geometric view motivates us to model query reformulation locally around the original query rather than directly manipulating its vector magnitude.
2.2. Feedback-based Query Reformulation
Given an original query representation 𝐪 \mathbf{q} and K K feedback representations generated by the same retriever E ⁡ ( ⋅ ) E(\cdot)

A feedback-based query reformulator constructs a new normalized representation 𝐪 ′ \mathbf{q}^{\prime} , which is subsequently used with the same dense retriever to retrieve documents.
The feedback can originate from different sources.
For example, the classical pseudo-relevance feedback (PRF) uses documents returned by an initial retrieval, whereas generative approaches can construct auxiliary texts such as hypothetical documents or pseudo answers and encode them as feedback.
Our focus is orthogonal to how these feedback items are obtained: given 𝐪 \mathbf{q} and ℱ \mathcal{F} , we study how to utilize them to produce a controlled query update regardless of how feedback is obtained.
A common strategy is to combine the original query with individual or aggregated feedback representations through averaging or linear interpolation.
Abstractly, these approaches move the query toward one or more feedback vectors in the embedding space.
As discussed above, this pointwise view implicitly treats a feedback representation as specifying a complete target for the reformulated query.
We next formalize why this can be undesirable when different feedback items provide complementary evidence.

3. Methodology
3.1. Overview
Given a normalized query embedding 𝐪 ∈ ℝ D \mathbf{q}\in\mathbb{R}^{D} and K K normalized feedback embeddings ℱ = { 𝐟 i } i = 1 K \mathcal{F}=\{\mathbf{f}_{i}\}_{i=1}^{K} , our goal is to construct a reformulated query 𝐪 ′ \mathbf{q}^{\prime} that incorporates useful information from the feedback while avoiding excessive deviation from the original query.
As discussed above, we do not treat feedback embeddings as complete target representations.
Instead, we convert them into directional observations in the tangent space T 𝐪 T_{\mathbf{q}} and jointly infer a query correction 𝜹 \bm{\delta} (as shown in Figure 1 ).
Specifically, each feedback item is represented by a triplet ( 𝐮 i , ℓ i , τ i ) (\mathbf{u}_{i},\ell_{i},\tau_{i}) , where 𝐮 i ∈ T 𝐪 \mathbf{u}_{i}\in T_{\mathbf{q}} denotes the direction supported by the feedback, ℓ i \ell_{i} specifies the target projection along this direction, and τ i ≥ 0 \tau_{i}\geq 0 represents the confidence of this directional observation. Each feedback item therefore provides a noisy constraint 𝐮 i ⊤ ​ 𝜹 ≈ ℓ i \mathbf{u}_{i}^{\top}\bm{\delta}\approx\ell_{i} . We jointly fuse these observations by the objective:
(7)
𝜹 ∗ = arg ⁡ min 𝜹 ∈ T 𝐪 ​ λ 2 ​ ‖ 𝜹 ‖ 2 + 1 2 ​ ∑ i = 1 K τ i ​ ( 𝐮 i ⊤ ​ 𝜹 − ℓ i ) 2 , \bm{\delta}^{*}=\arg\min_{\bm{\delta}\in T_{\mathbf{q}}}\frac{\lambda}{2}\|\bm{\delta}\|^{2}+\frac{1}{2}\sum_{i=1}^{K}\tau_{i}\left(\mathbf{u}_{i}^{\top}\bm{\delta}-\ell_{i}\right)^{2},
where λ > 0 \lambda>0 controls the strength of the original-query prior.
The first term favors a conservative correction around the original query, whereas the second term fits the directional evidence according to its estimated reliability.
Theorem 2.1 in § 2.3 makes this precise: summing the above decomposition over all feedback items shows that pointwise fusion equals directional fusion plus the penalty 1 2 ​ 𝜹 ⊤ ​ P ​ 𝜹 \tfrac{1}{2}\bm{\delta}^{\top}P\bm{\delta} with P = ∑ i τ i ​ ( I − 𝐮 i ​ 𝐮 i ⊤ ) P=\sum_{i}\tau_{i}(I-\mathbf{u}_{i}\mathbf{u}_{i}^{\top}) , which penalizes every direction in proportion to the total confidence of the feedback items that do not support it and is therefore what suppresses complementary corrections.
Equivalently, it can be interpreted as maximum a posteriori (MAP) inference under a zero-centered Gaussian prior over the query correction and noisy directional observations.
Our proposed method, Directional Posterior Feedback Fusion (DIFF), instantiates this formulation in three steps: constructing directional evidence ( 𝐮 i , ℓ i ) (\mathbf{u}_{i},\ell_{i}) (§ 3.2 ), estimating its precision τ i \tau_{i} through local- and set-level confidence (§ 3.3 ), and efficiently solving Eq. ( 7 ) while mapping the inferred correction back to the unit sphere (§ 3.4 ). Appendix C summarizes the overall algorithm.

The latter specifies the proposed query correction, whereas s i s_{i} indicates how closely the feedback agrees with the original query and is subsequently used to estimate its reliability.
This separation allows a feedback item to introduce new semantic directions without equating novelty itself with reliability.
3.3. Hierarchical Feedback Confidence
The directional representation above determines what correction each feedback item proposes, but not how much influence it should have on the reformulated query.
Actually, feedback is inherently noisy and imperfect ( Tu et al., 2025 ; Tu et al., 2026 ) : some feedback items may be less aligned with the original information need, while even individually plausible items may collectively form an ambiguous or inconsistent correction signal.
We therefore consider feedback reliability from two complementary perspectives.
At the local item-level, we assess the relative quality of each feedback item with respect to the original query, so that stronger feedback contributes more to posterior inference.
At the set-level, we assess whether the feedback items collectively provide a sufficiently coherent and reliable signal to justify modifying the query.
The two levels respectively control the relative contribution of individual observations and the overall strength of the feedback set.
Accordingly, we factor the precision or confidence of the i i -th directional observation as
(10)
τ i = g ​ a i , \tau_{i}=g\,a_{i},
where a i a_{i} denotes its local quality and g g denotes the confidence of the entire feedback set.
3.3.1. Local Quality
At each feedback’s local level, we would like to identify which feedback items are more compatible with the original query.
However, directly applying a fixed threshold to the query-feedback similarity s i s_{i} can be brittle, since similarity distributions may vary substantially across queries and embedding models.
Instead, we evaluate each feedback item relative to the feedback set of the same query using robust MAD normalization z i = s i − m 1.4826 ​ M z_{i}=\frac{s_{i}-m}{1.4826\,M} , where m = median i ⁡ ( s i ) m=\operatorname{median}_{i}(s_{i}) and M = median i ⁡ | s i − m | M=\operatorname{median}_{i}|s_{i}-m| are the median and median absolute deviation (MAD) of query-feedback similarities, respectively.
The robust normalization also helps reduce sensitivity to outlying similarity values and avoids relying on a global similarity scale.
Then, the local quality is calculated as a i = σ ⁡ ( z i ) a_{i}=\sigma\left(z_{i}\right) , where σ ⁡ ( ⋅ ) \sigma(\cdot) is the sigmoid function.
Thus, local quality a i a_{i} captures a query-local notion of quality, feedback with relatively stronger query affinity receives greater influence, while relatively weak feedback is downweighted.
3.3.2. Set-level Confidence
Local quality alone is insufficient to determine whether the overall feedback set as a whole supports a meaningful query update.
In particular, a set may contain relatively strong individual items while their proposed corrections point in different directions.
Therefore, we characterize set-level confidence using two factors: whether the directional evidence forms a coherent common signal, and whether the feedback set has sufficient average local quality.
We compute the mean evidence and summarize its common signal and dispersion:
(11)

Overall, DIFF separates query reformulation into three complementary decisions: which directions are supported by feedback, how strongly each piece of evidence should be trusted, and how far the query should ultimately move.

The posterior objective then reconciles these observations with the original-query prior, and the final spherical update ensures that the resulting reformulation remains a controlled directional change in the normalized embedding space.
Together, these components provide a unified mechanism for converting potentially noisy feedback vectors into a reliable query reformulation.
4. Experimental Setup
4.1. Datasets and Evaluation Metrics
We evaluate on 14 publicly available subsets of BEIR ( Thakur et al., 2021 ) , a widely used retrieval benchmark that covers diverse retrieval tasks and domains.
They are: ArguAna, Climate-FEVER, DBPedia, FEVER, FiQA, HotpotQA, MSMARCO, NFCorpus, Natural Questions, Quora, SCIDOCS, SciFact, Touche2020, and TREC-COVID.
This collection provides a heterogeneous testbed spanning fact verification, question answering, argument retrieval, scientific retrieval, and other retrieval scenarios.
Following standard evaluation practice, we report NDCG@10 as the primary retrieval metric and Recall@100 as a complementary measure of retrieval coverage.
Results are reported for individual datasets as well as aggregated across datasets when comparing the overall behavior of different reformulation methods.

For each retriever, queries, documents, and feedback texts are all encoded using the same underlying embedding model.
All query and feedback representations are L2-normalized before reformulation, consistent with the unit-sphere formulation.
The reformulated query is used directly against the original document index, and no retriever parameters are updated during query reformulation.
We consider two complementary sources of feedback: pseudo-relevance feedback (PRF) obtained from first-pass retrieval and generative relevance feedback (GRF) produced by an LLM (i.e., Qwen3.8-27B 4 4

This allows us to separate the mechanism used to obtain feedback from the mechanism used to incorporate it into the query representation.
In PRF, for each query, we first perform dense retrieval using the original query representation and take the top- K K retrieved documents as the feedback.
Each feedback document is encoded by the same dense retriever and supplied to the reformulation methods.
For GRF, we consider three forms of generated feedback: HyDE, Q2D, and CoT ( Gao et al., 2023 ; Wang et al., 2023 ; Mackie et al., 2023 ) .
This provides a complementary evaluation of whether DIFF and other fusion methods can operate across different feedback sources without modifying or retraining the reformulation mechanism.
We vary the number of feedback items over K ∈ { 1 , 3 , 5 , 10 , 20 } K\in\{1,3,5,10,20\} to examine the behavior of each method as increasingly more feedback evidence—and potentially more noise—is introduced.
Specifically, we adopt a relatively moderate value of K = 5 K=5 in the main results (§ 5.1 ), and then examine the effects of different values of K K under various models and settings in the analysis (§ 5.3 ).

4.3. Baselines
We compare DIFF against the original dense retriever and a range of fusion-based training-free query reformulation methods.
To ensure a controlled comparison, all methods use the same pretrained encoder, initial document ranking, feedback set, and document index under each experimental configuration.
Specifically, these methods are:
•
Original . We use the original query embedding without feedback reformulation, providing the base retrieval performance of each dense retriever.
•
VPRF ( Li et al., 2023 ; Li et al., 2025 ) . VPRF directly combines the original query representation with feedback document embeddings through vector-level averaging or interpolation.
•
Concat-P . Pairwise concatenation: concatenate the query with each feedback separately, feed the result to the dense retriever, and then average the embeddings of all query-document pairs.
•
Concat-L . Lairwise concatenation: concatenate the query with all feedback documents to obtain a global context, then feed it to the retriever (similar to ANCE-PRF ( Yu et al., 2021 ) ).
•
OR-PRF ( Zhang, 2026 ) . It constructs query updates from feedback components orthogonal to the original query, providing a relevant comparison for assessing whether DIFF benefits from jointly modeling directional evidence rather than directly aggregating orthogonal residuals.
•
DIME ( Faggioli et al., 2024 ) . DIME selects the important individual embedding dimensions based on the product across each dimension of the query and feedback embeddings.
•
Eclipse ( D’Erasmo et al., 2025 ) . Based on DIME, Eclipse further incorporates a comparison between top positive feedback and bottom negative feedback when calculating dimension importance.
•
AnchorQE ( Sun and Surdeanu, 2026 ) . AnchorQE estimates feedback contributions using query- or anchor-based retrieval scores to interpolate query and feedback embeddings. Note that AnchorQE requires additional retrieval operations to obtain feedback-based retrieval scores, introducing extra retrieval signals beyond the given feedback.

5. Results and Analysis
5.1. Main Results
Table 1 presents the overall retrieval performance across all BEIR subsets under different dense retrievers and feedback sources.
Overall, DIFF delivers the strongest and most consistent performance.
This trend holds for both PRF and all three forms of GRF, as well as across different embedding models, suggesting that the proposed directional formulation is not tied to a particular retriever or feedback construction strategy.
These results also highlight the importance of how feedback is utilized.
Generating high-quality feedback with LLMs alone is insufficient, and how to incorporate such feedback is equally important.
Specifically, simple vector averaging or concatenation does not consistently improve retrieval performance and can even degrade it, particularly when the feedback contains noisy information (especially PRF).
Methods that more carefully control the contribution of feedback generally exhibit more robust behavior.
DIFF further improves upon these approaches by treating feedback as directional evidence instead of complete target representations and by adapting its influence according to both individual feedback quality and set-level confidence.
In Appendix E.2 , we further report the per-query changes in NDCG@10 ( Δ \Delta NDCG@10) relative to the original retrieval results, indicating that DIFF behaves conservatively under noisy feedback and allows more beneficial updates when the feedback is more reliable.
Its consistent behavior across PRF and GRF supports our motivation that a feedback item may provide useful evidence for a particular correction direction without constituting a complete replacement for the original query representation.
Among the competing methods, AnchorQE is the closest to DIFF in overall performance, but requires additional retrieval operations to estimate feedback contributions.
These operations provide additional retrieval signals beyond the given feedback, particularly in the GRF setting where feedback is generated independently of the document collection.
Moreover, these additional retrieval operations introduce substantial computational overhead, as further demonstrated in the efficiency analysis in Appendix E.4 .
In contrast, DIFF requires no additional retrieval operations and achieves stronger overall performance.
It suggests that effectively modeling feedback geometry and reliability can be more beneficial than incorporating additional retrieval signals for feedback weighting.
Taken together, these results demonstrate that DIFF provides a robust feedback-utilization mechanism across heterogeneous retrieval conditions.
Rather than relying on a specific feedback source or additional retrieval signals, it consistently extracts useful query corrections from the feedback already available.
This cross-retriever and cross-feedback-source behavior is particularly important for our goal of developing a general reformulation framework that can be applied on top of diverse dense retrieval systems.

5.2. Ablation Study
We conduct an ablation study to examine the contribution of the major components.
As shown in Table 2 , the complete DIFF consistently achieves the best performance, while removing or replacing individual components generally degrades performance.
It provides evidence for both key aspects of our design: representing feedback through directional constraints rather than point targets, and controlling its influence according to feedback reliability.
We first examine DIFF’s central modeling choice: replacing directional posterior fusion with point-target fusion, where we directly aggregate the correction vectors as 𝜹 = ∑ i τ i ​ ℓ i ​ 𝐮 i \bm{\delta}=\sum_{i}\tau_{i}\ell_{i}\mathbf{u}_{i} .
This variant leads to one of the largest performance drops under both feedback sources.
Point-target fusion directly pulls the query toward feedback vectors and therefore implicitly suppresses components not expressed by each target.
In contrast, DIFF imposes a more selective directional constraint, requiring the inferred correction to agree with each feedback item only along the direction it supports.
The remaining degrees of freedom can consequently accommodate complementary evidence from other feedback items.
The consistent advantage of DIFF over point-target fusion empirically supports this distinction between fitting feedback as a target and using feedback as directional evidence.
The remaining ablations demonstrate the importance of controlling feedback reliability at both the individual and set levels.
Assigning equal precision to all feedback ( τ i = 1 \tau_{i}=1 ) causes more evident degradation under PRF than under HyDE, consistent with PRF containing noisier and more heterogeneous pseudo-relevant documents, whereas LLM-generated feedback is generally more consistent and focused on the input query.
This suggests that confidence estimation becomes particularly valuable when feedback quality is uneven.
Moreover, despite this degradation, the confidence-free variant still substantially outperforms simple point-target fusion methods such as VPRF and Concat, further demonstrating the advantage of directional fitting over directly aggregating feedback representations.
Within the hierarchy, removing local quality prevents DIFF from distinguishing the relative reliability of individual feedback items, while replacing robust normalization with raw query-feedback similarity also reduces performance, supporting query-wise calibration of feedback quality.
Set-level confidence provides complementary control over whether the feedback collectively warrants a substantial update.
Removing either its geometric consistency or average local-quality component leads to degradation, and removing the set-level gate altogether is consistently inferior to the full model.
Overall, these results show that the hierarchical design allows DIFF to account for both which feedback items should be trusted and how strongly the feedback set as a whole should influence the query, complementing the directional formulation with robustness to noisy or inconsistent feedback.
5.3. Analysis
5.3.1. Effect of Feedback Size ( K K )
We investigate the sensitivity of different reformulation methods to the number of feedback items K ∈ { 1 , 3 , 5 , 10 , 20 } K\in\{1,3,5,10,20\} .
As shown in Figure 2 , DIFF remains consistently strong and stable across different feedback sizes and retrievers.
In contrast, several baselines are substantially more sensitive to K K .
This is particularly evident for VPRF under PRF, whose performance deteriorates rapidly as the feedback set grows.
The different behaviors can be attributed to the quality of the underlying feedback: lower-ranked pseudo-relevant documents become increasingly noisy as more retrieval results are included, such that adding feedback does not necessarily provide additional useful evidence.
Indeed, PRF-based reformulation frequently performs below the original retriever, and its performance generally decreases with larger K K , further illustrating the risk of blindly incorporating pseudo-relevant documents.
On the contrary, GRF exhibits a substantially different pattern: performance is generally higher and considerably more stable as K K increases, suggesting that the generated feedback provides more focused and reliable information than retrieved feedback.
These observations also highlight that DIFF’s directional formulation and hierarchical confidence mechanism allow additional feedback to be incorporated without forcing every feedback item to exert equal or unrestricted influence, making the method less susceptible to the increasing noise associated with larger feedback sets.
Note that AnchorQE also exhibits stable performance with the aid of additional retrieval operations.
Overall, the results show that DIFF is effective for a particular choice of K K , and it remains robust as the amount of feedback (together with noise) increases.

5.3.2. Case Study: Geometric Behavior of Query Reformulation
To provide an intuitive view of how different reformulation strategies modify the query representation, we visualize a representative case in Figure 3 .
We compare VPRF, DIFF without confidence control, and the full DIFF under both PRF and HyDE feedback.
Notably, VPRF and DIFF w/o Conf differ primarily in their fusion mechanisms (i.e., Eq ( 4 ) with τ i = 1 \tau_{i}=1 ), allowing us to visually contrast the behaviors of these two strategies.
In PRF, the feedback documents are relatively dispersed, indicating substantial variation in the feedback signal.
VPRF is pulled toward the feedback set as a whole, while DIFF produces a more controlled displacement from the original query.
Removing confidence leads to a noticeably larger update, suggesting that directional fitting alone can preserve the structure of complementary feedback, whereas hierarchical confidence further limits the influence of uncertain evidence.
In the HyDE case where generated feedback is more coherent, both DIFF variants move the query in a similar direction, but the full model still produces a more conservative update.
Overall, these cases illustrate how directional fusion produces selective query corrections, while confidence control adapts their magnitude to feedback reliability.
6. Related Work
6.1. Dense Retrieval
Dense retrieval represents queries and documents as continuous semantic vectors and performs retrieval according to their similarity in a shared embedding space ( Fang et al., 2024 ; Zhao et al., 2024 ) .
Early dual-encoder approaches such as DPR demonstrated the effectiveness of independently encoding queries and passages for efficient maximum-inner-product search ( Karpukhin et al., 2020 ; Zhan et al., 2020 ) , while subsequent work improved dense retrievers through better negative sampling ( Xiong et al., 2020 ; Zhan et al., 2021 ; Qu et al., 2021 ) and large-scale pretraining ( Wang et al., 2022 ; Izacard et al., 2021 ; Xiao et al., 2022 ; Gao and Callan, 2021 ; Muennighoff et al., 2025 ) .
More recent embedding models further improve generalization across heterogeneous retrieval tasks through large-scale weak supervision and instruction-aware representation learning ( Xiao et al., 2024 ; Zhang et al., 2025 ; BehnamGhader et al., 2024 ) .
Despite these advances, retrieval effectiveness still depends critically on the quality of the query representation: short or under-specified queries may not fully express the underlying information need.
Our work is complementary to improvements in retriever training: we keep the pretrained dense retriever fixed and study how its query representation can be effectively refined using external feedback.
6.2. Query Reformulation
Query reformulation aims to enrich or modify the original query using additional information and can broadly be viewed through two sources of feedback ( Li et al., 2026 ) .
Pseudo-relevance feedback (PRF) assumes that top-ranked documents from an initial retrieval contain relevant information and uses them to refine the query.
Classical approaches operate in the lexical space through term reweighting or expansion ( Abdul-Jaleel et al., 2004 ; Rocchio Jr, 1971 ) , while recent methods extend PRF to neural and dense retrieval by learning feedback-aware query encoders or directly manipulating query and feedback representations in the embedding space ( Yu et al., 2021 ; Li et al., 2025 ) .
In parallel, generative relevance feedback (GRF) leverages the parametric knowledge of LLMs to generate auxiliary information without relying exclusively on the initial retrieval results.
Representative approaches generate hypothetical documents, pseudo-documents or answers, query expansions, or other forms of relevant content that are subsequently incorporated into retrieval, such as HyDE ( Gao et al., 2023 ) , Query2Doc ( Wang et al., 2023 ) , CoT ( Mackie et al., 2023 ) , Lamer ( Shen et al., 2023 ) , and GPRF ( Tu et al., 2026 ) .
These two lines of work have substantially expanded how useful feedback can be obtained , from retrieved documents to LLM-generated knowledge.
However, once feedback is available, an equally important question is how to incorporate it to modify the query representation , especially for dense retrievers that operate in the semantic embedding space beyond the explicit vocabulary space.
Existing approaches often simply aggregate or interpolate feedback representations ( Li et al., 2025 ; Li et al., 2023 ) , implicitly treating them as target points for query movement.
In contrast, our DIFF models feedback vectors as confidence-weighted directional constraints rather than complete target representations.
It also serves as a general reformulation mechanism on top of different feedback sources without retraining the underlying dense retriever.
7. Conclusions
In this paper, we introduce Directional Posterior Feedback Fusion (DIFF), a framework for feedback-based query reformulation in dense retrieval.
Moving beyond conventional pointwise fusion, it models feedback as directional evidence in the tangent space of the original query, allowing each feedback item to constrain only the correction direction it supports while preserving complementary information from other feedback.
Experiments across diverse retrieval settings demonstrate the effectiveness and robustness of DIFF and validate the benefits of directional modeling and confidence-aware fusion.
Future work includes extending the directional formulation beyond local tangent-space modeling to capture more complex geometry in embedding spaces, and investigating richer mechanisms for estimating feedback reliability or jointly exploiting heterogeneous feedback sources.

Appendix C DIFF Algorithm
Algorithm 1 summarizes the overall DIFF workflow. Generally, it consists of 4 steps: calculating the directional evidence, calculating the hierarchical confidence, posterior inference (solving the optimization objective), and spherical update.
Appendix D Implementation Details
For dense retrieval, we use a batch size of 256 and perform inference in FP16 precision.
For all query reformulation methods, hyperparameters are selected via grid search to ensure a fair comparison.
Specifically for DIFF, we search the prior strength over λ ∈ { 0.5 , 1 , 2 } \lambda\in\{0.5,1,2\} and the maximum update angle over θ up ∈ { π / 12 , π / 6 , π / 4 } \theta_{\mathrm{up}}\in\{\pi/12,\pi/6,\pi/4\} .
The vector indexing is implemented using the Faiss-GPU framework ( Douze et al., 2025 ) .
All experiments are conducted on a single NVIDIA A800 GPU and averaged over 5 runs.

E.2. NDCG@10 Changes ( Δ \Delta NDCG@10)
Figure 4 reports the overall Δ \Delta NDCG@10 distribution, and Figure 5 demonstrates the Δ \Delta NDCG@10 for each subset.
Under PRF, VPRF degrades substantially more queries than it improves, reflecting the risk of directly incorporating noisy feedback.
In contrast, DIFF leaves most queries unchanged and keeps the numbers of improved and degraded queries nearly balanced, with its Δ \Delta NDCG@10 distribution tightly concentrated around zero.
Under HyDE, where the feedback quality is generally higher, DIFF produces more improvements than degradations while still preserving a large fraction of queries.
It suggests that DIFF behaves conservatively under noisy feedback, but allows more beneficial updates when the feedback is more reliable.
E.3. Hyperparameter Analysis ( λ \lambda and θ up \theta_{\mathrm{up}} )
We analyze the sensitivity of DIFF to the prior strength λ \lambda and the maximum update angle θ up \theta_{\mathrm{up}} , as shown in Table 4 .
The two feedback sources exhibit different preferences.
Under PRF, a relatively small update bound ( θ up = π / 12 \theta_{\mathrm{up}}=\pi/12 ) performs consistently well across different λ \lambda , indicating that conservative updates are preferable when PRF may contain substantial noise.
In contrast, HyDE benefits from allowing larger query movements, with competitive performance observed under θ up = π / 6 \theta_{\mathrm{up}}=\pi/6 and π / 4 \pi/4 , consistent with its generally higher-quality feedback.
Meanwhile, increasing λ \lambda tends to mitigate the effect of a larger update bound by imposing a stronger prior toward the original query.
Overall, the interaction between λ \lambda and θ up \theta_{\mathrm{up}} reflects their complementary roles in controlling reformulation: the former regularizes the inferred correction, while the latter explicitly bounds the final angular displacement.
E.4. Efficiency Analysis
We compare the efficiency of different methods by measuring their execution time on 10 queries.
As shown in Table 5 , DIFF achieves comparable efficiency to lightweight baselines such as VPRF, Concat-P, and DIME.
In contrast, AnchorQE takes approximately 3.67 times that of DIFF, due to its additional retrieval operations for estimating feedback contributions.
These results demonstrate that DIFF effectively incorporates directional evidence without introducing substantial computational overhead.
