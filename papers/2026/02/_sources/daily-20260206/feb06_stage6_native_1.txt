Qwen family that balances generation quality, inference efficiency, and cost. Qwen-Image-2.1 unifies text-to-image generation and image editing in a single model, with just <strong>7B parameters in its visual generation component</strong> and native support for generating and editing transparent images.</p><p>This update introduces four key improvements:</p><ul><li><strong>Compact and efficient</strong>: A lightweight architecture and inference optimizations balance image quality and computational cost.</li><li><strong>Native transparency, unified creation and editing</strong>: Generate regular or transparent images from prompts, edit transparent layers, and extract subjects from photos.</li><li><strong>Versatile editing</strong>: Use up to <strong>10 reference images</strong>, specify local edits, preserve people and products, and handle a wide range of tasks.</li><li><strong>Realistic textures and refined aesthetics</strong>: Improved typography, portrait lighting, and fine details make generated images more visually compelling.</li></ul><h2 id=compact-and-efficient>Compact and Efficient<a hidden class=anchor aria-hidden=true href=#compact-and-efficient>#</a></h2><p>Qwen-Image-2.1 uses a lightweight architecture. Its visual generation component contains <strong>32 Single-Stream DiT layers and 7B parameters</strong>. Despite its compact size, the model delivers strong image generation quality. The Qwen-Image-Bench comparison below shows its performance alongside other open-source and closed-source models.</p><figure><img src=https://qianwen-res.oss-accelerate.aliyuncs.com/Qwen-Image/image2.1/images/example-01.png alt=\"Qwen-Image-Bench evaluation comparison\" width=100%><figcaption><p>Qwen-Image-Bench evaluation comparison</p></figcaption></figure><p>Inference efficiency is another focus, particularly when editing with multiple input images. This optimization comes from a <strong>mixed-granularity attention architecture</strong>. Text, including the system prefix and editing instructions, uses a token-level causal mask, while image generation uses a chunk-level mask. <strong>KV cache reuse</strong> allows input images and editing instructions to serve as static context, computed and cached in the first step to improve inference efficiency and reduce memory usage.</p><figure><img src=https://qianwen-res.oss-accelerate.aliyuncs.com/Qwen-Image/image2.1/images/example-03.png alt=\"Qwen-Image-2.1 mixed-granularity attention architecture\" width=100%><figcaption><p>Qwen-Image-2.1 mixed-granularity attention architecture</p></figcaption></figure><h2 id=native-transparency-unified-creation-and-editing>Native Transparency, Unified Creation and Editing<a hidden class=anchor aria-hidden=true href=#native-transparency-unified-creation-and-editing>#</a></h2><p>Native transparency is a major addition in this release.
