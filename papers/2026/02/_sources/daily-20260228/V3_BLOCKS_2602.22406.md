[2] h1: Towards Autonomous Memory Agents

[3] h6: Abstract.

[4] p: Recent memory agents improve LLMs by extracting experiences and conversation history into an external storage. This enables low-overhead context assembly and online memory update without expensive LLM training. However, existing solutions remain passive and reactive ; memory growth is bounded by information that happens to be available, while memory agents seldom seek external inputs in uncertainties. We propose autonomous memory agents that actively acquire, validate, and curate knowledge at a minimum cost. U-Mem materializes this idea via (i) a cost-aware knowledge-extraction cascade that escalates from cheap self/teacher signals to tool-verified research and, only when needed, expert feedback, and (ii) semantic-aware Thompson sampling to balance exploration and exploitation over memories and mitigate cold-start bias. On both verifiable and non-verifiable benchmarks, U-Mem consistently beats prior memory baselines and can surpass RL-based optimization, improving HotpotQA (Qwen2.5-7B) by 14.6 points and AIME25 (Gemini-2.5-flash) by 7.33 points.

[6] h2: 1. Introduction

[7] p: Large language models (LLMs) nowadays empower AI agents to achieve higher and broader goals ( Liu et al., 2025 ; Wang et al., 2024a ; Fang et al., 2025 ) , but deployed systems from research and industry are often ineffective in remembering user interactions, preferences, or domain knowledge beyond the given context window ( Hendrycks et al., 2025 ; Gao et al., 2025 ; Zhang et al., 2025 ) . This knowledge discontinuity forces AI agents to repeatedly ask known facts, past mistakes, and recompute answers; this clearly results in increased costs and degraded user experience ( Yin et al., 2025 ) . A recent way to address this problem to improve AI agents with experiences is to update the model parameters via supervised fine-tuning (SFT) or reinforcement learning (RL) ( Qi et al., 2024 ; Qian et al., 2025 ; Li et al., 2025 ; Luo et al., 2025 ) . However, doing so in practice is often too expensive and operationally infeasible ( Li et al., 2024 ) ; besides, many foundation models are closed-source or difficult to update without regressions ( Comanici et al., 2025 ; He et al., 2025a ) . This motivates non-parametric solutions that can improve AI agents without touching the model weights ( Agrawal et al., 2025 ; Dong et al., 2024 ; Wang et al., 2024b ; Shinn et al., 2023 ) .

[8] p: This has driven the recent interest in memory agents ( Xu et al., 2025 ; Chhikara et al., 2025 ; Ouyang et al., 2025 ; Cao et al., 2025 ; Zhang et al., 2026 ) : instead of updating model weights, the agent extracts critical experiences from the conversation history, user preferences, task outcomes, domain knowledge, and reasoning patterns, and puts them into an external memory store ( Zhou and Han, 2025 ; Nan et al., 2025 ; Patel and Patel, 2025 ; Yang et al., 2025 ; Wei et al., 2025 ; Tang et al., 2025 ; Zhou et al., 2025 ) . Meanwhile, it retrieves and assembles relevant memories at query time to guide future decisions. This non-parametric, memory-based solution can be deployed on closed-source models with a low overhead and enables memory update when new experiences arrive ( Rasmussen et al., 2025 ; Li et al., 2026 ; Huang et al., 2025 ; Zhou et al., 2026 ; Kong et al., 2025 ; Wang and Chen, 2025 ) .

[9] p: Despite this progress, existing memory agents remain largely passive . Their memory growth and learning are typically bounded by whatever information happens to appear from user interaction. Some recent solutions ( Zhang et al., 2026 ; Ouyang et al., 2025 ; Cao et al., 2025 ) additionally learn policies for memory operations for what to store, what to forget, and what to retrieve; this can even be done using RL-style objectives to optimize these choices ( Yan et al., 2025 ; Ma et al., 2026 ; Wang et al., 2025a ) . Yet, the memory operations are still reactive, where the agent does not actively seek external inputs when it encounters uncertainty, detects a failure mode, or identifies an opportunity to expand its knowledge base. In practice, there is abundant external data that can be harvested with minimal user frictions, including but not limited to user follow-up questions and corrections, more powerful teacher LLMs, tool-verified data and procedures, deep-research pipelines, and structured self-reflection over successes and failures. It is notable that exploiting these signals does not require human efforts in a traditional sense; instead, it can be framed as actions by the agent’s own autonomy in actively collecting, validating and making use of the available information.

[10] p: We argue that memory agents should be autonomous in how they actively acquire, validate, and curate knowledge. As shown in Figure 1 , an autonomous memory agent goes beyond passive data logging and retrieval: it decides when additional information is needed, where to obtain it (e.g., from a teacher, tools, or research), and is aware of the cost that is going to incur. This clearly distinguishes from recent art in self-evolving agents that are mostly passive. An autonomous memory agent can still evolve over time without requiring constant human annotation; this enables personalization and domain adaptation in real applications. Nevertheless, autonomy does not preclude human supervision; rather, it treats human experts as a last resort, consulted only when cheaper knowledge sources fail to provide sufficient confidence.

[13] p: To realize this vision, we face new challenges. (1) Cost-awareness . We note that, external knowledge, such as teacher LLMs, tool usage, research, is associated with different costs; the agent must decide who to query and when escalation is worth it. These issues are amplified in distribution shifts and cold-starts, where there is little feedback history to decide if new memories can be crucial for emerging needs. (2) Generalization . Achieving high accuracy and generalization at the same time is non-trivial. The agent should provide a good level of accuracy across both verifiable tasks, i.e., with objective checks, and non-verifiable tasks , i.e., where correctness is ambiguous and feedback is model- or preference-related.

[14] p: In this paper, we take a preliminary step toward this direction and propose U-Mem , the first memory agent that aims for autonomous knowledge acquisition and utility-driven update under cost constraints. To address the technical challenges, U-Mem leverages a cost-aware knowledge extraction cascade that progressively harvests correct knowledge by escalating supervision only when necessary; the cascade starts from inexpensive self-reflection and more powerful teacher models, moves to tool-augmented verification and deep research when needed, and consults human experts as a last resort. To address the cold-start and adaptation issue, we develop semantic-aware Thompson sampling to leverage feedback from downstream queries to improve the memory retrieval and utilization over time. By combining semantic relevance with posterior sampling over memory utility, the agent can systematically exploit proven memories while still exploring new ones.

[15] p: To evaluate the effectiveness of autonomous memory agents, we conduct extensive experiments on diverse benchmarks with open-weight and proprietary models, spanning verifiable reasoning (e.g., AIME) and non-verifiable generation (e.g., AdvancedIF). Results demonstrate that U-Mem consistently outperforms state-of-the-art memory baselines and, remarkably, matches or exceeds expensive Reinforcement Learning (RL) baselines. For instance, U-Mem boosts the performance of Qwen2.5-7B on HotpotQA by over 14%, and further enhances strong proprietary models like Gemini-2.5-flash by 7.3% on AIME25. These findings validate the efficacy of autonomous memory acquisition and establish U-Mem as a robust, cost-effective method for evolving agents in dynamic deployment scenarios.

[16] p: Contributions. We summarize our main contributions as follows:

[17] p: Unlike memory agents that are often passive, we propose autonomous memory agents that proactively collect external knowledge and evidence to grow and refine long-term memory.

[18] p: We propose a cost-aware knowledge extraction cascade that turns both successes and failures into durable memory, adaptively escalating supervision (teacher, tools, deep research, human) to maximize correctness. We also develop semantic-aware Thompson sampling to balance exploration and exploitation and integrate semantic relevance with learned utility.

[19] p: We evaluate autonomous memory agents across both verifiable and non-verifiable tasks, demonstrating that autonomy can substantially extend the capability boundary of memory-based agent evolution under realistic budget constraints.

[20] h2: 2. Related Work

[21] p: Reinforcement learning for LLMs is a standard paradigm in model fine-tuning and post-training alignment. RL training techniques have evolved from Proximal Policy Optimization (PPO) ( Schulman et al., 2017 ) to more stable, direct techniques like DPO ( Rafailov et al., 2023 ) and the efficient, critic-free GRPO ( Guo et al., 2025 ) . Methodology-wise, the training approaches diverge by feedback types: verifiable domains (e.g., math) often utilize ground-truth outcome supervision (RLVR) ( Liu et al., 2024 ) , whereas non-verifiable tasks often rely on preference models or AI feedback ( Lee et al., 2023 ) . While being effective, these paradigms remain computationally expensive due to the iterative parameter updates.

[22] p: LLMs with a memory bank . Existing research on LLM long-term memory can be categorized into two streams: dialogue memory, and reasoning trajectory memory. The former focuses on constructing a memory bank and extracting user profiles, preferences, and factual context from multi-session dialogues to enhance personalization and consistency. For instance, A-Mem ( Xu et al., 2025 ) builds an agentic memory that stores long interactions as structured notes and continuously links and evolves them into an interconnected memory network for better long-term recall. Mem0 ( Chhikara et al., 2025 ) proposes a scalable memory pipeline that extracts, consolidates/updates, and retrieves salient information from multi-session dialogues to support efficient long-term context recall. While effective for open-ended chat, these methods primarily address what the user said, rather than how to solve complex problems.

[23] p: Self-evolving memory agents . More relevant to our work is the second stream, which aims to distill transferable knowledge from the agent’s reasoning trajectories. ReasoningBank ( Ouyang et al., 2025 ) leverages test-time scaling to sample multiple candidate paths, synthesizing memories by contrasting self-generated successful and failed trajectories. ReMe ( Cao et al., 2025 ) proposes a framework for agent evolution that integrates multi-faceted experience distillation, context-adaptive reuse, and utility-based refinement. A critical limitation of these approaches is their dependency on the LLM’s intrinsic capability; they presume the model can eventually generate a correct solution via repeated sampling. In essence, these systems remain self-contained and passive in knowledge harvesting; their knowledge growth is strictly limited to the model’s pretraining data distribution. They are not designed to autonomously seek external knowledge when intrinsic reasoning fails, thus having "hard failures" where the model consistently makes errors.

[24] p: Our ideas: autonomous memory agents . Unlike off-the-shelf post-training and memory solutions that are often passive and cost–agnostic , U-Mem represents a shift towards autonomous memory agents: (1) Our framework is active to autonomously decide when to transcend internal limitations to acquire high-fidelity external knowledge from tools or even experts, and dynamically learns which memories are valuable through semantic-aware exploration. (2) On the other hand, our solution is also cost-aware in both compute and data samples. Recent work such as MemRL ( Zhang et al., 2026 ) and Memento ( Zhou et al., 2025 ) leverages query feedback to optimize the memory retrieval, but they overlook cold-start with new memories and various task difficulties. U-Mem aims to address these issues.

[26] h3: 3.1. Problem Formulation

[27] p: We formalize the continuous improvement of an LLM agent as a streaming decision process. Consider a stream of tasks 𝒬 = { q 1 , q 2 , … , q T } \mathcal{Q}=\{q_{1},q_{2},\dots,q_{T}\} arriving sequentially. The agent is parameterized by a frozen LLM backbone θ \theta and a dynamic memory store ℳ t \mathcal{M}_{t} . At each time step t t , the system state is defined as S t = ⟨ θ , ℳ t ⟩ S_{t}=\langle\theta,\mathcal{M}_{t}\rangle . Unlike traditional Reinforcement Learning (RL) which updates θ \theta , our framework keeps θ \theta fixed and evolves ℳ t \mathcal{M}_{t} to maximize performance.

[28] p: The interaction workflow for a query q t q_{t} proceeds as follows:

[29] p: Retrieval: The agent retrieves a subset of relevant memories C t = ℛ ⁡ ( q t , ℳ t ) C_{t}=\mathcal{R}(q_{t},\mathcal{M}_{t}) based on the current memory state.

[30] p: Inference: Conditioned on the retrieved context, the frozen LLM generates a reasoning trajectory y t ∼ π θ ( ⋅ | q t , C t ) y_{t}\sim\pi_{\theta}(\cdot|q_{t},C_{t}) .

[31] p: Feedback: The environment provides a scalar feedback signal r t = Eval ​ ( y t , q t ) r_{t}=\text{Eval}(y_{t},q_{t}) . We consider a unified feedback formulation covering both verifiable tasks (where r t r_{t} is a ground-truth binary outcome) and non-verifiable tasks (where r t r_{t} is a preference score from an external judge).

[32] p: Memory Evolution: Based on the trajectory y t y_{t} and feedback r t r_{t} , the memory extraction module ℰ \mathcal{E} distills new insights to update the state: ℳ t + 1 ← Update ​ ( ℳ t , ℰ ⁡ ( q t , y t , r t ) ) \mathcal{M}_{t+1}\leftarrow\text{Update}(\mathcal{M}_{t},\mathcal{E}(q_{t},y_{t},r_{t})) .

[33] p: Objective. Our goal is to design an optimal retrieval policy ℛ \mathcal{R} and extraction mechanism ℰ \mathcal{E} that maximize the cumulative reward ∑ t = 1 T r t \sum_{t=1}^{T}r_{t} over the task stream. This formulation frames memory management as a dual problem to parameter optimization: maximizing long-term utility through experience accumulation rather than weight updates.

[34] p: Evaluation Protocol. To rigorously evaluate the "learning-by-using" capability, we adopt a Train-Test protocol. The agent first processes a Training Stream where it is allowed to evolve ℳ \mathcal{M} continuously. Performance is then reported on a held-out Test Set , where the memory state is frozen ( ℳ t ​ e ​ s ​ t = ℳ f ​ i ​ n ​ a ​ l \mathcal{M}_{test}=\mathcal{M}_{final} ).

[35] h3: 3.2. Overview of U-Mem

[36] p: As illustrated in Figure 2 , U-Mem enables continuous, training-free evolution via a unified Retrieve-Infer-Evolve cycle. The workflow commences with a task router (instantiated by the frozen LLM backbone) that directs incoming queries to verifiable or non-verifiable streams. In the Retrieval phase, we employ Semantic-Aware Thompson Sampling (SA-CTS) to select memories by balancing semantic similarity with learned utility distributions. Subsequently, the agent performs Inference using the enhanced prompt. Finally, during Memory Evolution , a Cost-Aware Cascade (for verifiable tasks) or pairwise comparison (for non-verifiable tasks) distills experiences into memories, while environmental feedback updates memory utility posteriors to refine future retrieval without parameter updates.

[37] h3: 3.3. Memory for Verifiable Tasks

[38] p: In verifiable domains (e.g., mathematical reasoning, code generation), we posit that the substantial expansion of an agent’s capability boundary stems from learning from failures rather than merely reinforcing successes. To this end, we introduce a Cost-Aware Memory Extraction Cascade to adaptively distill high-quality corrective insights from failure trajectories. For memory retrieval, we propose Semantic-Aware Thompson Sampling (SA-CTS), a utility-driven retrieval mechanism designed to filter noise and precisely surface the most helpful memories for current reasoning.

[39] p: Memory Extraction Cascade . Standard memory approaches often prioritize extracting insights from successful trajectories. However, we argue that the most capability-expanding signals lie in failures. Extracting memories from failures is non-trivial. Naive self-reflection on incorrect trajectories often leads to hallucinated attribution , as the agent lacks the knowledge to identify its own errors. Recent work like ReasoningBank ( Ouyang et al., 2025 ) attempts to mitigate this via parallel sampling (generating k k trajectories). However, this fails when the model is fundamentally weak on a task, resulting in k k incorrect trajectories and no valid reference for learning.

[40] p: To guarantee high-quality extraction, we introduce a Cost-Aware Cascade . The core principle is that effective reflection requires a correct reference trajectory ( τ r ​ e ​ f \tau_{ref} ) for contrastive analysis. Upon generating a failure trajectory τ f ​ a ​ i ​ l \tau_{fail} , we escalate the request for τ r ​ e ​ f \tau_{ref} through a hierarchy of increasing cost and reliability:

[41] p: Level 1: Teacher LLM. We first query a stronger model. If successful, its output serves as τ r ​ e ​ f \tau_{ref} .

[42] p: Level 2: Tool-Augmented Teacher. If the teacher model fails, we equip it with external tools (e.g., a code interpreter), which have been proven to significantly improve the correctness of LLMs.

[43] p: Level 3: Human Expert (Simulated). As a last resort, we request a solution from a high-authority source, ideally a human expert. While expensive, this ensures the distillation of high-value, capability-expanding knowledge. In our experimental evaluation, to ensure scalability and reproducibility, we employ Gemini-3-pro-preview as a proxy for human experts.

[44] p: Once τ r ​ e ​ f \tau_{ref} is obtained, the agent performs Contrastive Reflection by analyzing the divergence between τ f ​ a ​ i ​ l \tau_{fail} and τ r ​ e ​ f \tau_{ref} . The distilled insights are formalized into a structured memory schema m = ⟨ Title , Description , Content ⟩ m=\langle\textit{Title},\textit{Description},\textit{Content}\rangle to support precise retrieval . We categorize these memories into two types:

[45] p: Global Procedural Memory: A high-level recipe summarizing the correct workflow derived from τ r ​ e ​ f \tau_{ref} (e.g., "For geometry proofs involving centroids, first apply the median property, then establish the segment ratios…").

[46] p: Local Corrective Memory: Specific error-correction rules derived from the divergence point (e.g., "When calculating variance, do not square the sum directly; instead, calculate the mean of squares…").

[47] p: If the agent succeeds initially, we bypass the cascade and directly extract Global Procedural Memory to reinforce the successful behavior. We maintain separate stores for global and local memories, employing a flat storage structure.

[48] p: Semantic-Aware Thompson Sampling for Retrieval . Existing memory frameworks typically rely on dense vector retrieval based on semantic similarity. While effective for recall, this approach often retrieves "relevant noise"—memories that are semantically related to the query but offer no substantial aid to the reasoning process. Recent works like MemRL ( Zhang et al., 2026 ) attempt to mitigate this by learning a scalar utility value for each memory based on environmental feedback (e.g., task success).

[49] p: However, we identify two critical limitations in current utility-based retrieval paradigms such as MemRL:

[50] p: Cold-Start Inequity (The Exploration Bias): In streaming settings, newly created memories have not yet received feedback and thus lack reliable utility estimates (often undefined or conservatively initialized). Under deterministic greedy ranking, such memories are rarely retrieved, which prevents them from being evaluated and updated. This creates a self-reinforcing loop where older memories—having accumulated historical feedback—dominate retrieval, even when some new memories could be highly valuable.

[51] p: Reward Bias via Task Difficulty: MemRL relies on absolute rewards as feedback. This introduces significant noise: a simple task may yield a positive reward even with irrelevant memories (false positive utility), while a complex task may result in failure despite retrieving useful memories (false negative utility). This confounds intrinsic task difficulty with memory efficacy.

[52] p: To address these challenges, we propose Semantic-Aware Thompson Sampling (SA-CTS) . Instead of maintaining a scalar point estimate, we model the utility of each memory m i m_{i} as a Gaussian distribution 𝒩 ⁡ ( μ i , σ i 2 ) \mathcal{N}(\mu_{i},\sigma_{i}^{2}) , representing the estimated utility and the epistemic uncertainty , respectively. This probabilistic formulation fundamentally resolves the exploration dilemma: even if a new memory’s mean utility μ \mu is not yet dominant, a large variance σ 2 \sigma^{2} allows it to be sampled at a high value. This grants it a chance to enter the top- k k context, receive feedback, and update its posterior—forming a closed-loop evolution mechanism absent in greedy approaches.

[53] p: Semantic-Aware Initialization. To construct the initial prior for a new memory m n ​ e ​ w m_{new} , we transfer statistics from its n n -nearest neighbors 𝒩 n ​ ( m n ​ e ​ w ) \mathcal{N}_{n}(m_{new}) in the embedding space. The distribution is initialized as:

[55] p: Crucially, the hyperparameter ϵ e ​ x ​ p ​ l ​ o ​ r ​ e \epsilon_{explore} acts as a "hard exploration switch," guaranteeing a non-zero variance for all new memories to ensure meaningful exposure regardless of neighbor consensus.

[56] p: Probabilistic Retrieval. During inference, given a query q t q_{t} , we employ Thompson Sampling to balance exploration and exploitation. For each candidate memory m i m_{i} , we sample a utility estimate u ~ i \tilde{u}_{i} from its posterior:

[58] p: The final retrieval score fuses semantic relevance with the sampled utility:

[59] table: (3) Score ​ ( m i ) = ( 1 − λ ) ⋅ sim ​ ( q t , m i ) + λ ⋅ u ~ i \text{Score}(m_{i})=(1-\lambda)\cdot\text{sim}(q_{t},m_{i})+\lambda\cdot\tilde{u}_{i}

[60] p: where λ ∈ [ 0 , 1 ] \lambda\in[0,1] balances the semantic prior and the learned utility. Unlike deterministic greedy selection, the stochasticity of u ~ i \tilde{u}_{i} allows high-variance (new or uncertain) memories to occasionally override low-variance established ones, dynamically optimizing the retrieval set.

[61] p: Advantage-based Bayesian Update. To decouple memory efficacy from task difficulty ( Reward Bias ), we employ an Advantage-based feedback mechanism. We define the signal as the performance differential between memory-augmented inference ( y m ​ e ​ m y_{mem} ) and base inference ( y b ​ a ​ s ​ e y_{base} ):

[63] p: For verifiable tasks, we instantiate 𝒮 ⁡ ( y ) \mathcal{S}(y) as a binary correctness reward against ground truth, i.e., 𝒮 ⁡ ( y ) = 𝕀 ⁡ [ y ​ is correct ] ∈ { 0 , 1 } \mathcal{S}(y)=\mathbb{I}[y\text{ is correct}]\in\{0,1\} . [66] p: Streaming Memory Evolution and Maintenance . In a continuous task stream, an append-only memory store inevitably suffers from unbounded growth and knowledge redundancy, diluting the retrieval density of high-value insights. To maintain a compact and evolving knowledge base, we implement an online Memory Consolidation mechanism. Immediately following the extraction phase (Sec. 3.3 ), the agent performs a semantic audit by comparing the newly generated memory m n ​ e ​ w m_{new} against the retrieved context set 𝒞 r ​ e ​ t ​ r ​ i ​ e ​ v ​ e ​ d \mathcal{C}_{retrieved} used in the current task. Acting as a curator, the LLM executes one of three discrete operations to refine the store:

[67] p: Append (Novelty): If m n ​ e ​ w m_{new} contains orthogonal insights not present in 𝒞 r ​ e ​ t ​ r ​ i ​ e ​ v ​ e ​ d \mathcal{C}_{retrieved} , it is appended to the store, expanding the agent’s knowledge boundary.

[68] p: Merge (Refinement): If m n ​ e ​ w m_{new} is semantically similar to an existing memory m o ​ l ​ d m_{old} but offers superior clarity or generality, we replace m o ​ l ​ d m_{old} with a merged version, consolidating fragmented knowledge into a stronger representation.

[69] p: Prune (Maintenance) : If m n ​ e ​ w m_{new} is a duplicate of an existing memory m o ​ l ​ d m_{old} (or if m o ​ l ​ d m_{old} is fully encompassed by a newly merged entry), the redundant m o ​ l ​ d m_{old} is removed. This keeps the retrieval space compact and ensures high information density.

[70] h3: 3.4. Memory for Non-Verifiable Tasks

[71] p: In non-verifiable domains (e.g., creative writing, open-ended chat, or summarization), a definitive ground truth is absent, rendering the concept of binary “success” or “failure” inapplicable. However, we posit that the core principle of memory acquisition remains the same: learning from contrast . Even without a binary signal, the agent can distill actionable insights by analyzing the divergence between a higher-quality response and a lower-quality one. To this end, we replace the Cost-Aware Cascade used in verifiable tasks with a Pairwise Contrastive Extraction strategy.

[72] p: Pairwise Contrastive Extraction . For a given task q t q_{t} , the agent generates two candidate reasoning trajectories. An external evaluator (e.g., an LLM-as-a-judge or human annotator) evaluates the pair to determine a winner, y win y_{\text{win}} , and a loser, y lose y_{\text{lose}} .

[73] p: The agent then acts as an extractor to analyze this pair and distill the preference into a structured template:

[74] table: (6) ℳ pref = ⟨ Trigger , Dimension , Comparison ⟩ \mathcal{M}_{\text{pref}}=\langle\text{\emph{Trigger}},\text{\emph{Dimension}},\text{\emph{Comparison}}\rangle

[75] p: Trigger: The specific context or constraint where this preference applies (e.g., “When asked to write a concise marketing email…” ).

[76] p: Dimension: The evaluation axis driving the decision (e.g., “Tone” , “Clarity” , or “Safety” ).

[77] p: Comparison: An explicit, actionable directive derived from the contrast (e.g., “Prefer direct bullet points ( y win y_{\text{win}} ) over dense narrative paragraphs ( y lose y_{\text{lose}} )” ).

[78] p: Relative signals are not only more robust to calibration noise but can also be used to induce a consistent preference signal in practice. Finally, we directly reuse the SA-CTS retrieval and streaming consolidation mechanisms detailed in Sec. 3.3, where we define the advantage feedback as r a ​ d ​ v = 𝕀 [ y m ​ e ​ m ≻ y b ​ a ​ s ​ e ] r_{adv}=\mathbb{I}[y_{mem}\succ y_{base}] , where ≻ \succ denotes the LLM judge’s pairwise preference.

[114] p: To visualize how U-Mem transcends the "internally bounded" limitations of passive memory agents, we present a qualitative analysis on a representative "hard failure" problem from AIME 2025. The task asks to find the number of subsets of 16 chairs chosen by 8 people such that "no person sits next to two other people," with the final answer modulo 1000.

[115] p: The No Memory baseline fails consistently ( 0 / 5 0/5 success rate) due to a stubborn inductive bias: the model conflates the specific "no-three-in-a-row" constraint with the ubiquitous "no-two-adjacent" problem. Existing memory agents struggle to correct this deep-seated reasoning error. ReasoningBank and ReMe , relying on self-sampling, fail to generate a single correct trajectory to serve as a reference, resulting in zero effective memory extraction. MemRL , while attempting to extract insights from the failure, suffers from attribution error: it extracts trivial procedural details—such as "calculating the number of gaps between people"—which are factually correct but insufficient to resolve the methodological flaw. In contrast, U-Mem triggers the cost-aware cascade to consult a Level-1 Teacher LLM. By contrasting the model’s failed trajectory with the successful external trajectory, U-Mem distills a high-order Corrective Strategy: (1) Explicitly define "Forbidden Patterns" to distinguish "no-three-in-a-row" from standard adjacency; and (2) When variable constraints involve upper bounds (e.g., a gap holding at most 2 people), immediately pivot from combinatorial formulas to Generating Functions. When re-evaluating the task, U-Mem retrieves this precise methodological correction, successfully overriding its intrinsic bias to derive the correct answer ( 907 907 ).
