L167: # CLASE: A Hybrid Method for Chinese Legalese Stylistic Evaluation
L168: 
L169: CLASE (Chinese LegAlese Stylistic Evaluation) is a hybrid evaluation framework designed to assess the stylistic fidelity of legal text generation. It combines objective linguistic feature analysis with experience-guided LLM evaluation to providing a transparent, reference-free, and interpretable assessment.
L170: ## Features
L171:   * Hybrid Scoring: Combines objective linguistic features (z-score normalized) with subjective LLM-as-a-judge assessments.
L172:   * Contrastive Learning: Automatically learns stylistic criteria from authentic vs. restored document pairs without manual annotation.
L173:   * Interpretable Feedback: Provides detailed, natural language feedback on stylistic deficiencies (e.g., lexical choice, sentence structure).
L174:   * Reference-Free: Evaluates generated text quality without requiring a gold-standard reference during inference.
L175: ## Project Structure
L176: 
L177:   * `exp_train_parallel.py`: Script for Training-Free Contrastive Learning. Extracts positive and negative stylistic examples from document pairs.
L178:   * `objective_scoring.py`: Computes the Objective Score using logistic regression on linguistic features.
L179:   * `subjective_scoring.py`: Computes the Subjective Score using an LLM judge with retrieval-augmented examples.
L180:   * `linguistic_features/`: Contains modules for extracting shallow, syntactic, and discourse-level features.
L181: ## Data
L182: 
L183: The dataset consists of Chinese legal documents structured for stylistic evaluation and restoration tasks.
L184: 
L185:   * `data/train/`: Training data (4,000 samples).
L186:     * `gist_4k.jsonl`: Contains the original case gists (summaries).
L187:       * Fields: `index`, `reserved`, `gist`
L188:     * `restored_4k.jsonl`: Contains the restored judgments corresponding to the gists.
L189:       * Fields: `index`, `reserved`, `gist`, `restored`
L190:     * `reason_4k.json`: Contains detailed legal reasoning and provisions.
L191:       * Fields: `index`, `header`, `reason`, `provisions`
L192:   * `data/test/`: Test data (200 samples).
L193:     * `restored_4001-4200.jsonl`: Test set with gold standard and generated texts.
L194:       * Fields: `index`, `gold` (original judgment), `generated` (model output)
L195: ## Installation
L196: 
L197:   1. Clone the repository:
L198: 
L199:     git clone https://github.com/rexera/CLASE.git
L200:     cd CLASE
L201: 
L202:   2. Install dependencies:
L203: 
L204:     pip install -r requirements.txt
L205:   3. Environment Setup: Create a `.env` file in the root directory with your API keys:
L206: 
L207:     # OpenAI / LLM API Configuration
L208:     OPENAI_API_KEY=your_api_key_here
L209:     BASE_URL=https://api.openai.com/v1  # or your custom endpoint
L210:     MODEL=gpt-4o-mini
L211: 
L212:     # Specific configs for scoring (optional overrides)
L213:     GENERATION_API_KEY=your_generation_key
L214:     GENERATION_BASE_URL=...
L215:     EMBEDDING_API_KEY=your_embedding_key
L216:     EMBEDDING_BASE_URL=...
L217: ## Usage
L218: 
L219: ### 1. Construct Experience Pool (Contrastive Learning)
L220: 
L221: Extract stylistic examples from your training pairs (authentic vs. restored documents).
L222: 
L223:     python exp_train_parallel.py
L224: 
L225: Input: `data/train/reason_4k.json`, `data/train/restored_4k.jsonl`
L226: Output: `clase_exp/model_output/examples.jsonl`
L227: ### 2. Objective Scoring
L228: 
L229: Train the logistic regression model on the experience pool and score new texts.
L230: 
L231:     python objective_scoring.py
L232: 
L233: Outputs: Trained model weights and scores in `output/objective_scores/`.
L234: 
L235: ### 3. Subjective Scoring
L236: 
L237: Run the LLM-as-a-judge evaluation with retrieval-augmented examples.
L238: 
L239:     python subjective_scoring.py
L240: 
L241: Outputs: Detailed scoring and feedback in `output/subjective_scores/`.
