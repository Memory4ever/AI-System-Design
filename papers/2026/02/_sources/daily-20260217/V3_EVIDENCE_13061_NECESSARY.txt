B18: 2 Diverging Flows
B19: 2.1 Problem Formulation
B20: We define the task of Extrapolation-Aware Probabilistic Regression as learning a mapping f θ : 𝒳 → 𝒫 ⁡ ( 𝒴 ) × ℝ f_{\theta}:\mathcal{X}\to\mathcal{P}(\mathcal{Y})\times\mathbb{R} that outputs both a predictive distribution and an extrapolation indicator. Formally, for an input x x :
B21: f θ ​ ( x ) = ( p θ ​ ( y | x ) , S θ ​ ( x ) ) f_{\theta}(x)=\left(p_{\theta}(y|x),\ S_{\theta}(x)\right) (1)
B22: where p θ ( ⋅ | x ) p_{\theta}(\cdot|x) approximates the conditional data density p d ​ a ​ t ​ a ​ ( y | x ) p_{data}(y|x) , and S θ ​ ( x ) S_{\theta}(x) serves as an extrapolation score.
B23: To ensure safety, this tuple must satisfy two critical properties: (i) Fidelity , where for in-distribution inputs ( x ∈ ℳ I ​ D x\in\mathcal{M}_{ID} ), p θ p_{\theta} minimizes the divergence from the true conditional distribution; and (ii) Trust , where the score acts as a discriminator for manifold membership, effectively separating valid from invalid inputs such that S θ ​ ( x ~ ) > S θ ​ ( x ) S_{\theta}(\tilde{x})>S_{\theta}(x) for any x ~ ∉ ℳ I ​ D \tilde{x}\notin\mathcal{M}_{ID} and x ∈ ℳ I ​ D x\in\mathcal{M}_{ID} .
B24: 2.2 Flow Matching
B25: We realize the predictive component of our formulation using the OT-FM framework ( Lipman et al., 2022 ) . For consistency with FM literature, we denote the target state as x ∈ 𝒳 x\in\mathcal{X} and the conditioning input as c ∈ 𝒞 c\in\mathcal{C} . While we frame our analysis in terms of probabilistic regression, this formulation is mathematically general and naturally extends to conditional generation tasks .
B26: The generative process in conditional generation is governed by the flow ODE:
B27: d ​ ψ t ​ ( x ) d ​ t = v t θ ​ ( ψ t ​ ( x ) , c ) , \frac{d\psi_{t}(x)}{dt}=v_{t}^{\theta}(\psi_{t}(x),c), (2)
B28: where t ∈ [ 0 , 1 ] t\in[0,1] , and v t θ v_{t}^{\theta} is a neural vector field that pushes a noise prior p 0 p_{0} to the target density p 1 ( ⋅ | c ) p_{1}(\cdot|c) . This probabilistic formulation naturally handles aleatoric uncertainty arising from inherent data noise. By sampling N N trajectories { ψ 1 ( i ) ( c ) } i = 1 N ∼ p θ ( ⋅ | c ) \{\psi_{1}^{(i)}(c)\}_{i=1}^{N}\sim p_{\theta}(\cdot|c) generated by solving Eq. 2 , we approximate the conditional expectation to obtain a robust prediction:
B29: x ^ = 𝔼 p θ ​ [ x | c ] ≈ 1 N ​ ∑ i = 1 N ψ 1 ​ ( x 0 ( i ) , c ) . \hat{x}=\mathbb{E}_{p_{\theta}}[x|c]\approx\frac{1}{N}\sum_{i=1}^{N}\psi_{1}(x_{0}^{(i)};c). (3)
B30: While this Monte Carlo integration effectively filters stochastic noise, it fails to guarantee model trustworthiness. For an off-manifold condition c ~ \tilde{c} disjoint from the training support, the FM continues to generate a coherent, low-variance predictive distribution, yielding a plausible but extrapolated prediction x ^ \hat{x} , rendering the standard estimator insufficient for safety-critical applications.
B31: 2.3 The Extrapolation Risk
B32: Let 𝒳 = ℝ d \mathcal{X}=\mathbb{R}^{d} denote the data space and 𝒞 = ℝ k \mathcal{C}=\mathbb{R}^{k} the conditioning space. We assume valid conditions lie on a lower-dimensional manifold ℳ I ​ D ⊂ 𝒞 \mathcal{M}_{ID}\subset\mathcal{C} with support defined by the data distribution p 1 ​ ( c ) p_{1}(c) . The complement 𝒞 O ​ O ​ D = ℝ k ∖ ℳ I ​ D \mathcal{C}_{OOD}=\mathbb{R}^{k}\setminus\mathcal{M}_{ID} represents the off-manifold regime.
B33: Optimal Transport theory establishes that the most efficient probability path follows the Euclidean geodesic u t O ​ T ​ ( x | x 1 ) = x 1 − x 0 u_{t}^{OT}(x|x_{1})=x_{1}-x_{0} , minimizing the kinetic energy of the transport ( Benamou & Brenier, 2000 ) . We define the Transport Energy Excess , ℰ ⁡ ( v θ , c ) \mathcal{E}(v^{\theta};c) , as the deviation of the learned vector field from this optimal geodesic:
B34: ℰ ⁡ ( v θ , c ) = 𝔼 t , x t ​ [ ‖ v t θ ​ ( x t , c ) − u t O ​ T ​ ( x t | x 1 ) ‖ 2 ] . \mathcal{E}(v^{\theta};c)=\mathbb{E}_{t,x_{t}}\left[||v_{t}^{\theta}(x_{t},c)-u_{t}^{OT}(x_{t}|x_{1})||^{2}\right]. (4)
B35: We highlight that minimizing ℰ ⁡ ( v θ , c ) \mathcal{E}(v^{\theta};c) is equivalent to the OT-FM objective, L FM L_{\text{FM}} ( Lipman et al., 2022 ) . Thus, standard training explicitly optimizes for efficiency, unintentionally enforcing the silent failure mode on invalid inputs.
B36: Ideally, a safe predictor would exhibit a geometric phase transition : minimizing ℰ ⁡ ( v θ , c ) → 0 \mathcal{E}(v^{\theta};c)\to 0 for c ∈ ℳ I ​ D c\in\mathcal{M}_{ID} (high fidelity) while maximizing ℰ ⁡ ( v θ , c ~ ) ≫ 0 \mathcal{E}(v^{\theta};\tilde{c})\gg 0 for c ~ ∈ 𝒞 O ​ O ​ D \tilde{c}\in\mathcal{C}_{OOD} (detectable divergence).
B37: However, for the ODE solution ψ t \psi_{t} to be unique and well-defined, the vector field u t u_{t} must be locally Lipschitz continuous with respect to c c ( Coddington & Levinson, 1955 ; Lipman et al., 2024 ) . That is, there exists a constant K K such that for any x ∈ 𝒳 x\in\mathcal{X} and c , c ′ ∈ 𝒞 c,c^{\prime}\in\mathcal{C} :
B38: ‖ u t ​ ( x , c ) − u t ​ ( x , c ′ ) ‖ 2 ≤ K ​ ‖ c − c ′ ‖ 2 . ||u_{t}(x,c)-u_{t}(x,c^{\prime})||_{2}\leq K||c-c^{\prime}||_{2}. (5)
B39: Combined with the spectral bias of deep neural networks ( Rahaman et al., 2019 ) , which preferentially learns low-frequency functions, the trained model inherently minimizes this Lipschitz constant K K . This regularity creates a fundamental extrapolation hazard . For any off-manifold query c ~ \tilde{c} residing in an ϵ \epsilon -neighborhood of a valid condition c ∈ ℳ I ​ D c\in\mathcal{M}_{ID} , the change in transport energy is bounded by the Lipschitz property:
B40: | ℰ ⁡ ( v θ , c ~ ) − ℰ ⁡ ( v θ , c ) | ≤ L ⋅ ‖ c ~ − c ‖ 2 ≈ 0 |\mathcal{E}(v^{\theta};\tilde{c})-\mathcal{E}(v^{\theta};c)|\leq L\cdot||\tilde{c}-c||_{2}\approx 0 (6)
B41: where L L is a constant dependent on K K . Since ℰ ⁡ ( v θ , c ) ≈ 0 \mathcal{E}(v^{\theta};c)\approx 0 for valid data (by training), the inequality forces ℰ ⁡ ( v θ , c ~ ) ≈ 0 \mathcal{E}(v^{\theta};\tilde{c})\approx 0 . Eq. 6 constrains pointwise velocities but not the full trajectories defining ℰ ⁡ ( v θ , c ~ ) \mathcal{E}(v^{\theta};\tilde{c}) , yet it describes the silent extrapolation behavior observed in FM models. Consequently, the model predicts efficient paths even for invalid inputs. This silent failure creates trajectories that resemble valid ones, making standard detection ineffective. We attribute this to the smoothness of the vector field: without explicit penalties, the model defaults to the simplest path for any input, regardless of its validity.
B42: 2.4 Contrasting Vector Fields
B43: To enforce the geometric property described in Sec. 2.3 , we adapt contrastive learning principles ( Hadsell et al., 2006 ; Chen et al., 2020 ) . Traditionally, contrastive learning organizes data in an embedding space by pulling semantically similar inputs (positives) together while pushing dissimilar ones (negatives) apart. We extend this logic to the space of vector fields, treating the optimal geodesic u t O ​ T u_{t}^{OT} as a geometric anchor . By pulling valid vector fields toward this anchor and pushing off-manifold ones away, we induce a controlled violation of the smoothness bias. This locally maximizes the Lipschitz constant at the manifold boundary, transforming the smooth extrapolation into a sharp gradient that signals invalidity.
B44: Let ( x 1 , c ) (x_{1},c) be a valid data-condition pair from the training set. We define the predicted velocity field under the valid condition, u ^ t , c = v t θ ​ ( x t , c ) \hat{u}_{t,c}=v^{\theta}_{t}(x_{t},c) , as the positive sample, and the velocity field under the off-manifold condition, u ^ t , c ~ = v t θ ​ ( x t , c ~ ) \hat{u}_{t,\tilde{c}}=v^{\theta}_{t}(x_{t},\tilde{c}) , as the negative sample.
B45: We introduce two margin-based penalty terms inspired by triplet loss objectives ( Balntas et al., 2016 ) . These terms constrain the geometric relationship between the target vector field u t u_{t} and the model’s predictions.
B46: First, the repulsion loss ( L repel L_{\text{repel}} ) encourages separation in Euclidean magnitude, ensuring that the error for the off-manifold condition is significantly higher than for the on-manifold condition. Second, the curvature loss ( L curve L_{\text{curve}} ) promotes directional divergence, penalizing off-manifold flows that align with the optimal transport path. We define these formally as:
B47: L repel \displaystyle L_{\text{repel}} = max ⁡ { d 1 ​ ( u t , u ^ c ) − d 1 ​ ( u t , u ^ c ~ ) + m r , 0 } \displaystyle=\max\{d_{1}(u_{t},\hat{u}_{c})-d_{1}(u_{t},\hat{u}_{\tilde{c}})+m_{r},0\} (7)
B48: L curve \displaystyle L_{\text{curve}} = max ⁡ { d 2 ​ ( u t , u ^ c ) − d 2 ​ ( u t , u ^ c ~ ) + m c , 0 } \displaystyle=\max\{d_{2}(u_{t},\hat{u}_{c})-d_{2}(u_{t},\hat{u}_{\tilde{c}})+m_{c},0\} (8)
B49: where d 1 ​ ( a , b ) = ‖ a − b ‖ 2 d_{1}(a,b)=\|a-b\|_{2} is the Euclidean distance, and d 2 ​ ( a , b ) = 1 − a ⋅ b ‖ a ‖ ​ ‖ b ‖ d_{2}(a,b)=1-\frac{a\cdot b}{\|a\|\|b\|} is the cosines distance. The hyperparameters m r m_{r} and m c m_{c} represent the desired margin of separation for magnitude and angle, respectively.
B50: The final training objective, Diverging Flows (DiFlo), combines the FM loss with these contrastive regularizers:
B51: L DiFlo = ‖ u t O ​ T − v t θ ​ ( x t , c ) ‖ 2 + λ ​ L repel + β ​ L curve L_{\text{DiFlo}}=\|u_{t}^{OT}-v^{\theta}_{t}(x_{t},c)\|^{2}+\lambda L_{\text{repel}}+\beta L_{\text{curve}} (9)
B52: where λ \lambda and β \beta , the weights of each contrastive component.
B53: This objective equips the model with an implicit ability to capture the manifold of valid conditions. The repulsion term forces the kinetic energy of off-manifold flows to deviate from the optimal transport cost, while the curvature term steers the vector field orthogonally to the geodesic path. As a result, solving the ODE (Eq. 2 ) yields flows that diverge substantially depending on the conditioning input, as illustrated in Figure 1 .
B54: 2.5 Negative Sample Creation
B55: The effectiveness of the contrastive objective is dependent on the quality of the negative samples. Random noise is often too easy to distinguish, failing to shape the decision boundary tightly around the ℳ I ​ D \mathcal{M}_{ID} . To induce a sharp geometric transition, we require hard negatives, inputs that occupy the ϵ \epsilon -neighborhood of the valid support but violate the underlying properties.
B56: We employ an adversarial outlier mining strategy. We define the optimal negative sample c ~ ∗ \tilde{c}^{*} as the local perturbation that maximizes the model’s transport energy, effectively identifying the direction of highest geometric sensitivity:
B57: c ~ ∗ = argmax c ~ : ‖ c ~ − c ‖ ≤ ϵ | | v t θ ( x t , c ~ ) − u t O ​ T | | 2 . \tilde{c}^{*}=\underset{\tilde{c}:||\tilde{c}-c||\leq\epsilon}{\text{argmax}}||v_{t}^{\theta}(x_{t},\tilde{c})-u_{t}^{OT}||^{2}. (10)
B58: In practice, we use Projected Gradient Descent (PGD) ( Madry et al., 2017 ) . PGD performs an iterative ascent along the gradient of L F ​ M L_{FM} , projecting perturbations back onto the ϵ \epsilon -ball ℬ ϵ ​ ( c ) \mathcal{B}_{\epsilon}(c) at each step:
B59: c ~ k + 1 = Π ℬ ϵ ​ ( c ) ​ ( c ~ k + η ⋅ sgn ​ ( ∇ c ~ ℒ F ​ M ​ ( c ~ k ) ) ) . \tilde{c}_{k+1}=\Pi_{\mathcal{B}_{\epsilon}(c)}\left(\tilde{c}_{k}+\eta\cdot\text{sgn}\left(\nabla_{\tilde{c}}\mathcal{L}_{FM}(\tilde{c}_{k})\right)\right). (11)
B60: We employ PGD to target local directions where the model attempts to generalize via smoothness, rather than enumerating infinite off-manifold inputs. Because the model relies on Lipschitz continuity to extend valid transport dynamics to off-manifold regions, structurally breaking this smoothness at the immediate boundary forces the model to implicitly learn the valid support. B61: 2.6 Detection of Off-Manifold Inputs
B62: We propose a detection metric grounded in the geometry of OT-FM. As established in the previous section, the target probability path for valid data is the straight line connecting the source p 0 p_{0} and the target p 1 p_{1} ( Lipman et al., 2022 ) .
B63: At inference time, given a starting noise sample x 0 x_{0} and a condition c c , the model generates a trajectory { x ^ t } t = 0 1 \{\hat{x}_{t}\}_{t=0}^{1} ending at the predicted sample x ^ 1 \hat{x}_{1} . Hence, we can evaluate the efficiency of the path taken to reach the prediction. We define the ideal optimal transport trajectory x opt x^{\text{opt}} as the direct linear interpolation between the start and the generated end, x t opt = ( 1 − t ) ​ x 0 + t ​ x ^ 1 x_{t}^{\text{opt}}=(1-t)x_{0}+t\hat{x}_{1} , where t ∈ [ 0 , 1 ] t\in[0,1] .
B64: A well-trained FM model conditioned on on-manifold data approximates this linear path, resulting in a generated trajectory where x ^ t ≈ x t opt \hat{x}_{t}\approx x_{t}^{\text{opt}} . Conversely, our contrastive objective (Eq. 9 ) prompts the vector field to diverge significantly from this linearity when the condition is off-manifold.
B65: To quantify this behavior, we introduce the Divergence from Optimal Trajectory (DOT) score. We define the DOT score as the integral of the L 1 L_{1} distance between the generated trajectory x ^ t \hat{x}_{t} and the ideal linear interpolant x t opt x^{\text{opt}}_{t} over the generation interval:
B66: S D ​ O ​ T ( x ^ 0 : 1 ) = ∫ 0 1 ∥ x ^ t − x t opt ∥ 1 d t . S_{DOT}(\hat{x}_{0:1})=\int_{0}^{1}\|\hat{x}_{t}-x^{\text{opt}}_{t}\|_{1}\,dt. (12)
B67: This metric effectively measures the area between the actual flow path and the chord connecting x 0 x_{0} and x ^ 1 \hat{x}_{1} . In practice, we solve the flow ODE using a numerical solver with N N discrete time steps { t 0 , … , t N } \{t_{0},\dots,t_{N}\} . The discrete approximation of the S D ​ O ​ T S_{DOT} score, averaged over spatial dimensions D D , is given by:
B68: S ^ D ​ O ​ T = ∑ i = 0 N ( 1 D ​ ∑ d = 1 D | x ^ t i ( d ) − x t i opt ( d ) | ) \hat{S}_{DOT}=\sum_{i=0}^{N}\left(\frac{1}{D}\sum_{d=1}^{D}|\hat{x}_{t_{i}}^{(d)}-x^{\text{opt}^{(d)}}_{t_{i}}|\right) (13)
B69: where x ^ t i ( d ) \hat{x}_{t_{i}}^{(d)} is the value of the d d -th dimension of the generated trajectory at time step t i t_{i} , and x t i opt ( d ) x^{\text{opt}^{(d)}}_{t_{i}} is the corresponding value on the ideal linear path. This metric captures the turbulence induced by our contrastive training. While on-manifold flows remain nearly straight (yielding S ^ D ​ O ​ T ≈ 0 \hat{S}_{DOT}\approx 0 ), extrapolation flows exhibit significant curvature and deviation from the geodesic (Figure 1 ), resulting in positive, large S ^ D ​ O ​ T \hat{S}_{DOT} values. For the algorithmic formulation of the inference refer to Appendix A.2 .
B70: 2.7 Split Conformal Prediction
B71: To ensure safety-critical reliability, we employ split conformal prediction ( Gammerman et al., 1998 ; Angelopoulos et al., 2024 ) to construct a statistically valid decision boundary. Given a user-specified error rate α ∈ ( 0 , 1 ) \alpha\in(0,1) , our goal is to identify a validity interval [ q l ​ o , q h ​ i ] [q_{lo},q_{hi}] such that the probability of a valid on-manifold input falling outside this range is bounded by α \alpha .
B72: We reserve a calibration dataset of M M exchangeable on-manifold conditions. We first compute the S ^ D ​ O ​ T \hat{S}_{DOT} for these samples and sort them in ascending order, denoting the sorted scores as 𝒮 c ​ a ​ l = { s ( 1 ) , s ( 2 ) , … , s ( M ) } \mathcal{S}_{cal}=\{s_{(1)},s_{(2)},\dots,s_{(M)}\} . We implement a two-sided conformal interval approach to determine the decision boundaries. Specifically, we distribute the error budget α \alpha equally between the lower and upper tails of the distribution. We calculate the indices for the lower and upper bounds as k l ​ o = ⌊ ( M + 1 ) ​ α 2 ⌋ k_{lo}=\lfloor(M+1)\frac{\alpha}{2}\rfloor and k h ​ i = ⌈ ( M + 1 ) ​ ( 1 − α 2 ) ⌉ k_{hi}=\lceil(M+1)(1-\frac{\alpha}{2})\rceil . The decision thresholds are then defined by the scores at these ranks: q l ​ o = s ( k l ​ o ) q_{lo}=s_{(k_{lo})} and q h ​ i = s ( k h ​ i ) q_{hi}=s_{(k_{hi})} .
B73: At inference time, a query condition c t ​ e ​ s ​ t c_{test} is accepted as in-distribution if and only if its score lies within the calibrated interval: q l ​ o ≤ S ^ D ​ O ​ T ​ ( x ⁡ ( c t ​ e ​ s ​ t ) ) ≤ q h ​ i q_{lo}\leq\hat{S}_{DOT}(x(c_{test}))\leq q_{hi}
B74: If the score falls outside this range, the input is flagged as invalid. Based on the exchangeability of the calibration and test data, this procedure provides a rigorous guarantee on the marginal coverage. The probability that a valid on-manifold input is correctly accepted satisfies, ℙ ⁡ ( q l ​ o ≤ S ^ D ​ O ​ T ​ ( x t ​ e ​ s ​ t ) ≤ q h ​ i ) ≥ 1 − α \mathbb{P}(q_{lo}\leq\hat{S}_{DOT}(x_{test})\leq q_{hi})\geq 1-\alpha . This ensures that the False Positive Rate (FPR), the rate at which valid inputs are incorrectly rejected, is controlled at level α \alpha .

B76: We evaluate Diverging Flows (DiFlo) across three distinct regimes that showcase the geometric behavior and deployment viability: (i) geometric verification on synthetic manifolds, (ii) weather temperature forecasting, and (iii) cross-domain style transfer. B113: 3.3 Cross-Domain Style Transfer
B114: Finally, we investigate the model’s ability to handle structurally disjoint conditioning manifolds by mapping grayscale MNIST digits ( c c ) ( LeCun & Cortes, 1998 ) to RGB Street House View Numbers (SVHN) ( x x ) ( Netzer et al., 2011 ) . We introduce Fashion-MNIST (FMNIST) ( Xiao et al., 2017 ) and Kuzushiji-MNIST (KMNIST) ( Clanuwat et al., 2018 ) to probe whether Diverging Flows implicitly captures the semantic support of valid conditions. FMNIST represents a clear structural shift (clothing vs. digits), whereas KMNIST poses a harder semantic shift , sharing significant low-level statistics (e.g., stroke density) with MNIST.

B123: 3.4 Efficacy of Negative Sampling Strategies
B124: To isolate the contribution of our adversarial negative mining, we compare Diverging Flows trained with PGD against three alternative negative sampling strategies: (i) Heuristics : Domain-specific augmentations (random resized crops, rotations, and Gaussian blur) intended to create near-manifold perturbations; (ii) Masking : Random and checkerboard masking strategies that remove spatial information; and (iii) Outlier Exposure : Using the Omniglot ( Lake et al., 2015 ) dataset as a source of explicit, fixed negative samples.

B132: The results in Table 4 highlight a limitation of static negative sampling: it requires prior knowledge of the manifold boundary. Heuristic Transforms perform exceptionally well on the digit tasks (outperforming PGD slightly on FMNIST/KMNIST) because shifts like rotation and cropping directly align with the known invariances of character recognition. However, the same strategy fails completely on the Weather task. In a physical system, a rotated pressure field is not an off-manifold sample, it is often a impossible or represents a completely different valid state, making simple augmentations insufficient for defining the boundary of thermodynamic validity, without the required domain knowledge. Similarly, Outlier Exposure and Masking struggle to generalize. Outlier exposure effectively overfits to the specific negative dataset (Omniglot) and fails to detect shifts in semantic structure (KMNIST) that do not resemble the training negatives.
B133: In contrast, PGD proves to be the only modality-agnostic solution. By dynamically optimizing for the hardest negative in the local neighborhood of the input, PGD automatically discovers the relevant boundary constraints. While it may be slightly outperformed by hand-crafted heuristics in simple domains, it achieves consistent, high-performance detection across domains without requiring manual, domain-specific engineering.
B134: 4 Conclusion and Limitations
B135: Diverging Flows allows a single Flow Matching model to simultaneously perform high-fidelity prediction and intrinsic extrapolation detection. Our core contribution is the formulation of a geometric phase transition: by actively enforcing trajectory divergence for off-manifold inputs, we transform the vector field from a generator into a self-monitoring mechanism. This shifts extrapolation detection from a post-hoc statistical estimation problem to a geometric constraint, ensuring that safety is an inherent property of the dynamics rather than an external add-on. Crucially, this design of Diverging Flows introduces zero inference overhead, establishing it as a robust solution for real-time critical applications.
B136: A limitation of our approach is the training overhead required to create hard negatives via iterative adversarial updates. Additionally, our current formulation relies on Euclidean Optimal Transport; but the contrastive principles developed here can easily be extended to Riemannian manifolds, which would make it effective to support geometric deep learning tasks ( Chen & Lipman, 2024 ) . Finally, we plan to deploy Diverging Flows in real-world robotic tasks, where detecting extrapolations is essential to avert potentially harmful outcomes.

B311: B.4 Comparison with DiffPath
B312: For completeness, we provide a reference comparison against DiffPath ( Heng et al., 2024 ) , an approach of using diffusion model’s reverse generation path for OOD detection. Unlike our framework, which actively shapes the vector field during training, DiffPath operates as a post-hoc, static detector on a frozen model.
B313: DiffPath usually utilizes a pre-trained model, which is not required to be trained on the in-distribution data. However, due to the lack of pre-trained models for our datasets, we trained a standard Diffusion Model from scratch on the exact in-distribution datasets used in our experiments. DiffPath utilizes this model to perform the reverse generation process on a set of ID calibration samples. It extracts various statistics from these generated trajectories and fits a statistical density estimator (GMM or KDE) to these features. At inference time, the validity of a query input is determined by the likelihood of its trajectory statistics under this fitted distribution.

B324: Remark on Flow vs. Diffusion Dynamics.
B325: It is important to note that DiffPath was originally designed for Diffusion Models, which solve a stochastic differential equation (SDE) or its probability flow ODE equivalent. In that regime, the learned vector fields often exhibit complex, non-linear trajectories where OOD inputs might induce detectable behavior, such as jittering. However, deploying such passive detectors on Flow Matching models is fundamentally challenging. As discussed in Section 2.3 , standard Flow Matching explicitly minimizes transport energy, forcing trajectories to be straight-line geodesics. Due to this strong smoothness bias, unregularized FM models collapse OOD trajectories into efficient, straight paths indistinguishable from valid data. Consequently, passive monitoring of path statistics is often insufficient for Flow Models, necessitating the active geometric regularization introduced in Diverging Flows to explicitly enforce divergence.
