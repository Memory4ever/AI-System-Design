B32: Curriculum RL.
B33: Standard RL treats all samples from p ⁡ ( x ) p(x) equally. Curriculum methods effectively optimize a sequence of objectives ℒ t ​ ( θ ) \mathcal{L}_{t}(\theta) , where the data distribution is re-weighted. The goal is to start with a “simple” distribution where gradient variance is low, and gradually anneal towards the target distribution p ⁡ ( x ) p(x) . In our setting, we define this re-weighting explicitly through an inclusion probability based on model confidence. Prior works have validated that intrinsic model probabilities can serve as reliable proxies for correctness ( Kadavath et al., 2022 ; Huang et al., 2024 ; Ren et al., 2023 ) . We formalize this signal as follows:
B34: Definition 2.1 (Model Confidence) .
B35: Quantifying confidence in LLMs is achieved by aggregating token-level probabilities. To obtain a stable signal c ⁡ ( x ) ∈ [ 0 , 1 ] c(x)\in[0,1] that depends only on the prompt, we first define the normalized uncertainty u ⁡ ( x ) u(x) as the expectation over trajectories sampled from the behavior policy π θ old \pi_{\theta_{\mathrm{old}}} :
B36: u ( x ) := 𝔼 y ∼ π θ old ( ⋅ | x ) [ 1 T ∑ t = 1 T H ( π θ old ( ⋅ | s t ) ) log ⁡ | 𝒱 | ] , u(x):=\mathbb{E}_{y\sim\pi_{\theta_{\mathrm{old}}}(\cdot|x)}\left[\frac{1}{T}\sum_{t=1}^{T}\frac{H(\pi_{\theta_{\mathrm{old}}}(\cdot|s_{t}))}{\log|\mathcal{V}|}\right], (4)
B37: where H H is the Shannon entropy and | 𝒱 | |\mathcal{V}| is the vocabulary size. The model confidence is defined as the complement:
B38: c ⁡ ( x ) := 1 − u ⁡ ( x ) ∈ [ 0 , 1 ] . c(x):=1-u(x)\in[0,1]. (5)
B39: High confidence implies the model has a “decisive” belief about the reasoning path. While sequence likelihood is not always a reliable predictor of correctness due to hallucinations ( Ren et al., 2023 ) , we leverage it here as an effective proxy for Curriculum Difficulty to stabilize training, rather than as a ground-truth verification signal.
B40: 3 Verifier-Independent Curriculum Reinforcement Learning
B41: We propose Verifier-Independent Curriculum Reinforcement Learning (VI-CuRL) , a novel framework for solving the high-variance challenge independent from verifiers.
B42: 3.1 The VI-CuRL Objective
B43: To formally operationalize our curriculum, we define a sequence of curriculum phases indexed by t = 1 , … , T t=1,\dots,T . Each phase is associated with a confidence threshold τ t \tau_{t} that determines which samples are included in the training process.
B44: Curriculum Mask and Retention Rate.
B45: We define the curriculum mask w t ​ ( x ) w_{t}(x) based on the frozen confidence scores. The selection is deterministic given the prompt and the threshold τ t \tau_{t} :
B46: w t ( x ) = 𝟏 [ c ( x ) ≥ τ t ] . w_{t}(x)=\mathbf{1}[c(x)\geq\tau_{t}]. (6)
B47: The target retention rate β t \beta_{t} corresponds to the population probability:
B48: β t = 𝔼 x ∼ p ⁡ ( x ) ​ [ w t ​ ( x ) ] ∈ ( 0 , 1 ] . \beta_{t}=\mathbb{E}_{x\sim p(x)}[w_{t}(x)]\in(0,1]. (7)
B49: In the implementation (Algorithm 1 ), we estimate β t \beta_{t} using the empirical batch retention β ^ t = 1 B ​ ∑ j = 1 B w t ​ ( x j ) \hat{\beta}_{t}=\frac{1}{B}\sum_{j=1}^{B}w_{t}(x_{j}) .
B50: The Weighted Surrogate Objective.
B51: For each phase t t , we optimize a re-weighted version of the standard surrogate ℒ ⁡ ( θ ) \mathcal{L}(\theta) that restricts learning to the selected subspace. To maintain the scale of the original objective, we introduce the importance sampling weight 1 / β t 1/\beta_{t} :
B52: ℒ t ( θ ) := 𝔼 x ∼ p ⁡ ( x ) 𝔼 y 1 : G ∼ π θ old ( ⋅ | x ) [ w t ​ ( x ) β t ℓ ( θ ; x , y 1 : G ) ] . \mathcal{L}_{t}(\theta):=\mathbb{E}_{x\sim p(x)}\mathbb{E}_{y_{1:G}\sim\pi_{\theta_{\mathrm{old}}}(\cdot|x)}\Big[\frac{w_{t}(x)}{\beta_{t}}\;\ell(\theta;x,y_{1:G})\Big]. (8)
B53: This weighted objective trades bias for variance. By focusing on the “easy” high-confidence region, it reduces the effective variance of the gradient estimator, albeit by optimizing a biased data distribution.
B54: The Curriculum Gradient Estimator.
B55: To optimize ℒ t ​ ( θ ) \mathcal{L}_{t}(\theta) , we use the standard auto-differentiation subgradient of the clipped PPO surrogate. Critically, the advantages A i A_{i} , masks w t ​ ( x ) w_{t}(x) , and weights β t \beta_{t} are treated as constants (“stop-gradients”) during the inner loop updates:
B56: g ^ t := w t ​ ( x ) β t ∇ θ ℓ ( θ ; x , y 1 : G ) . \hat{g}_{t}:=\frac{w_{t}(x)}{\beta_{t}}\;\nabla_{\theta}\ell(\theta;x,y_{1:G}). (9)
B57: 3.2 Curriculum Schedule and Algorithm
B58: We now detail the practical implementation of the VI-CuRL framework. The optimization process is divided into T T steps. At each step t t , we seek to effectively filter the training batch to retain only the samples where the model exhibits high confidence.
B59: Dynamic Quantile Thresholding.
B60: Defining a fixed schedule for the confidence threshold τ t \tau_{t} is challenging because the model’s confidence distribution shifts as training progresses. A static threshold might result in either empty batches (if too high) or ineffective filtering (if too low). To address this, we define the curriculum schedule via a target retention rate β t ∈ ( 0 , 1 ] \beta_{t}\in(0,1] . We strictly enforce β t \beta_{t} by dynamically setting τ t \tau_{t} to the ( 1 − β t ) (1-\beta_{t}) -th quantile of the batch confidence scores. Specifically, for a batch of prompts ℬ = { x 1 , … , x B } \mathcal{B}=\{x_{1},\dots,x_{B}\} , we calculate confidence scores c j = c ⁡ ( x j ) c_{j}=c(x_{j}) . Let c ( 1 ) ≤ ⋯ ≤ c ( B ) c_{(1)}\leq\dots\leq c_{(B)} be the sorted scores. The threshold is set using the sample quantile:
B61: τ t = c ( ⌊ ( 1 − β t ) ​ B ⌋ ) . \tau_{t}=c_{(\lfloor(1-\beta_{t})B\rfloor)}. (10)
B62: This ensures the empirical retention β ^ t \hat{\beta}_{t} matches the target schedule.

B67: 4 Theoretical Analysis of the Bias-Variance Trade-off
B68: In this section, we formalize the properties of VI-CuRL. Our analysis first addresses the “bias” component of the trade-off. We then dissect the “variance” component to reveal the source of the training stability.
B69: 4.1 Consistency of the Objective
B70: A foundational property of our framework is that the normalized gradient estimator g ^ t ​ ( x , y , θ ) \hat{g}_{t}(x,y;\theta) is, by construction, an unbiased estimator of the gradient of the surrogate objective ℒ t ​ ( θ ) \mathcal{L}_{t}(\theta) . That is, 𝔼 ⁡ [ g ^ t ​ ( x , y , θ ) ] = ∇ θ ℒ t ​ ( θ ) \mathbb{E}[\hat{g}_{t}(x,y;\theta)]=\nabla_{\theta}\mathcal{L}_{t}(\theta) . This ensures our algorithm correctly optimizes the objective for the current curriculum phase. The critical theoretical question, however, is whether maximizing these time-dependent surrogate objectives consistently leads to maximizing the base surrogate. Our first theorem confirms that it does:
B71: Theorem 4.1 (Consistency of the Objective) .
B72: Assuming the per-prompt surrogate loss is bounded, | ℓ ( θ ; x , y 1 : G ) | ≤ L max |\ell(\theta;x,y_{1:G})|\leq L_{\max} , the absolute difference between the true surrogate objective ℒ ⁡ ( θ ) \mathcal{L}(\theta) and the weighted objective ℒ t ​ ( θ ) \mathcal{L}_{t}(\theta) is bounded by ( 1 − β t ) (1-\beta_{t}) :
B73: | ℒ ⁡ ( θ ) − ℒ t ​ ( θ ) | ≤ 2 ​ L max ​ ( 1 − β t ) . |\mathcal{L}(\theta)-\mathcal{L}_{t}(\theta)|\leq 2L_{\max}(1-\beta_{t}). (11)
B74: The proof can be found in Appendix C.1 . The bounded-surrogate assumption | ℓ ( θ ; x , y 1 : G ) | ≤ L max |\ell(\theta;x,y_{1:G})|\leq L_{\max} is mild in practice with bounded rewards, group-normalized advantage, ratio clipping, and per-token KL penalty. ( Ouyang et al., 2022 ; Shao et al., 2024 ) . Meanwhile, as the curriculum is annealed ( τ t → 0 \tau_{t}\to 0 ), the retention rate β t → 1 \beta_{t}\to 1 , and the bound converges to zero, ensuring that ℒ t ​ ( θ ) → ℒ ​ ( θ ) \mathcal{L}_{t}(\theta)\to\mathcal{L}(\theta) . This theorem guarantees that the approximation error diminishes over time.
B75: 4.2 A Deeper Investigation of Variance
B76: Having established that our objective is asymptotically correct, we now analyze how the curriculum tames the variance that destabilizes standard RL. To this end, here we decompose the variance into its constituent parts.
B77: Definition 4.2 (Vector Variance) .
B78: For a random vector 𝐙 ∈ ℝ d \mathbf{Z}\in\mathbb{R}^{d} , we define its variance as the trace of its covariance matrix:
B79: Var ⁡ ( 𝐙 ) := 𝔼 ⁡ [ ‖ 𝐙 − 𝔼 ⁡ [ 𝐙 ] ‖ 2 ] . \Var(\mathbf{Z}):=\mathbb{E}[\|\mathbf{Z}-\mathbb{E}[\mathbf{Z}]\|^{2}].

B81: Let g ( x , y 1 : G ; θ ) := ∇ θ ℓ ( θ ; x , y 1 : G ) g(x,y_{1:G};\theta):=\nabla_{\theta}\ell(\theta;x,y_{1:G}) be the gradient of the surrogate loss, and let g ¯ ( x ; θ ) ( x ; θ ) = 𝔼 y 1 : G | π θ old [ g ] \bar{g}(x;\theta)(x;\theta)=\mathbb{E}_{y_{1:G}|\pi_{\theta_{\mathrm{old}}}}[g] be the expected gradient for a fixed prompt x x . B82: Var ⁡ ( g ^ t ​ ( x , y , θ ) ) = σ g , t 2 β t ⏟ Action Variance + V prob , t β t ⏟ Problem Variance + 1 − β t β t ​ ‖ ∇ θ ℒ t ​ ( θ ) ‖ 2 ⏟ Masking Variance , \begin{split}\Var(\hat{g}_{t}(x,y;\theta))=\underbrace{\frac{\sigma_{g,t}^{2}}{\beta_{t}}}_{\begin{subarray}{c}\text{Action Variance}\end{subarray}}+\underbrace{\frac{V_{\mathrm{prob},t}}{\beta_{t}}}_{\begin{subarray}{c}\text{Problem Variance}\end{subarray}}+\underbrace{\frac{1-\beta_{t}}{\beta_{t}}\|\nabla_{\theta}\mathcal{L}_{t}(\theta)\|^{2}}_{\begin{subarray}{c}\text{Masking Variance}\end{subarray}},\end{split} (12)
B83: where σ g , t 2 := 𝔼 x | w t = 1 [ Var y 1 : G | π θ old ( g ) ] \sigma_{g,t}^{2}:=\mathbb{E}_{x|w_{t}=1}[\Var_{y_{1:G}|\pi_{\theta_{\mathrm{old}}}}(g)] is the average action variance within the selected set of problems, and V prob , t := Var x | w t = 1 ⁡ ( g ¯ ​ ( x , θ ) ) V_{\mathrm{prob},t}:=\Var_{x|w_{t}=1}(\bar{g}(x;\theta)) is the variance of mean gradients within that same set.
B84: The proof can be found in Appendix C.2 . This decomposition reveals the narrative of VI-CuRL. The curriculum’s power lies in making the numerators of the first two terms— σ g , t 2 \sigma_{g,t}^{2} (action consistency) and V prob , t V_{\mathrm{prob},t} (problem homogeneity) —dramatically smaller. By selecting high-confidence (low-entropy) and homogeneous “easy” problems, their gradients become more consistent and well-aligned, reducing these numerators. B89: The proof can be found in Appendix C.3 . This lemma shows that as the curriculum threshold τ t \tau_{t} increases, the numerator G conf ​ ( τ t ) 2 G_{\conf}(\tau_{t})^{2} decreases, counteracting the decrease in the denominator β t \beta_{t} . Under reasonable assumptions (e.g., if β t ∝ ( 1 − τ t ) \beta_{t}\propto(1-\tau_{t}) and G conf ​ ( τ t ) 2 ∝ ( 1 − τ t ) G_{\conf}(\tau_{t})^{2}\propto(1-\tau_{t}) ), this bound can remain stable instead of diverging.

B91: Theorem 4.5 (Curriculum-Sensitive Variance Bound) .
B92: Assume that for each phase t t there exist constants a 1 , a 2 ≥ 0 a_{1},a_{2}\geq 0 and α > 0 \alpha>0 such that the variance numerators from Theorem 4.3 decay faster than the retention rate

B94: Then the total variance is bounded by
B95: Var ⁡ ( g ^ t ) ≤ ( a 1 + a 2 ) ​ β t α + 1 − β t β t ​ ‖ ∇ θ ℒ t ​ ( θ ) ‖ 2 . \Var(\hat{g}_{t})\leq(a_{1}+a_{2})\,\beta_{t}^{\alpha}+\frac{1-\beta_{t}}{\beta_{t}}\,\bigl\|\nabla_{\theta}\mathcal{L}_{t}(\theta)\bigr\|^{2}. (15)
B96: The proof can be found in Appendix C.4 . In practice, assumption ( 14 ) is naturally satisfied because the curriculum selects for high-confidence samples where the policy’s entropy is low and the problem difficulty is homogeneous. Under this circumstance, the first two terms vanish as β t → 0 \beta_{t}\to 0 . The remaining term is the masking variance, which is also expected to be small in practice, as the gradient on the “easiest” problems, ‖ ∇ θ ℒ t ​ ( θ ) ‖ \|\nabla_{\theta}\mathcal{L}_{t}(\theta)\| , should be close to zero. The theorem thus confirms that VI-CuRL successfully trades a controllable bias for a dramatically reduced variance.

Table 1 and Table 2 summarized the performance. In the Oracle setting, VI-CuRL consistently matched or outperformed standard baselines across all model scales, particularly on harder benchmarks, demonstrating that curriculum learning accelerated convergence even when perfect rewards were available. The benefits were even more critical in the Verifier-Free setting, where standard methods succumbed to high variance and often suffered from model collapse. In contrast, VI-CuRL effectively stabilized training, recovering performance comparable to the Oracle topline. This confirmed that managing gradient variance via a high-confidence curriculum was essential for learning from noisy, intrinsic signals. Additional results for Pass@8 and analysis verifications of the curriculum effectively sorts problems by difficulty were detailed in Appendix B .
