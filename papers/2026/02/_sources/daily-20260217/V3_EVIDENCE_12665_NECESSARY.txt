B19: 3 Problem setting
B20: We study satisfiability of 2–CNF formulas and design parameterized instance families whose difficulty can be tuned through interpretable structural properties. Throughout, let 𝒱 = { x 1 , … , x n } \mathcal{V}=\{x_{1},\dots,x_{n}\} be a finite set of Boolean variables, and let ℒ = 𝒱 ∪ { ¬ x ∣ x ∈ 𝒱 } \mathcal{L}=\mathcal{V}\cup\{\neg x\mid x\in\mathcal{V}\} be its associated set of literals. Given a literal ℓ \ell , we write ℓ ¯ \overline{\ell} for its complementary literal. We use the usual definitions ℓ → ℓ ′ := ℓ ¯ ∨ ℓ ′ \ell\rightarrow\ell^{\prime}:=\overline{\ell}\vee\ell^{\prime} and ( ℓ ↔ ℓ ′ ) := ( ℓ → ℓ ′ ) ∧ ( ℓ ′ → ℓ ) ≡ ( ℓ ¯ ∨ ℓ ′ ) ∧ ( ℓ ′ ¯ ∨ ℓ ) (\ell\leftrightarrow\ell^{\prime}):=(\ell\rightarrow\ell^{\prime})\wedge(\ell^{\prime}\rightarrow\ell)\equiv(\overline{\ell}\lor\ell^{\prime})\wedge(\overline{\ell^{\prime}}\lor\ell) .
B21: A 2–CNF is a conjunction of clauses, each clause a disjunction of at most two literals. A literal in a 2–CNF formula is pure if it appears with only one polarity. We write n := | 𝒱 | n:=|\mathcal{V}| for the number of variables and m := | 𝒞 | m:=|\mathcal{C}| for the number of clauses.
B22: Implication graph for 2-SAT. To decide satisfiability of a 2 2 –CNF formula, we associate with it an implication graph on vertex set ℒ \mathcal{L} . Each clause ( ℓ 1 ∨ ℓ 2 ) (\ell_{1}\lor\ell_{2}) contributes the edges ℓ 1 ¯ → ℓ 2 \overline{\ell_{1}}\to\ell_{2} and ℓ 2 ¯ → ℓ 1 \overline{\ell_{2}}\to\ell_{1} . We use l ↝ l ′ l\leadsto l^{\prime} to denote that there is a path from l l to l ′ l^{\prime} in the implication graph. A 2–CNF formula is unsatisfiable (UNSAT) iff there exists a variable x x such that x x and ¬ x \neg x belong to the same Strongly Connected Component (SCC) of the implication graph (equivalently, x ↝ ¬ x x\leadsto\neg x and ¬ x ↝ x \neg x\leadsto x ).
B23: Difficulty controls. For each generator, we vary the instance structure and its presentation (clause order, variable renaming), which does not change satisfiability but can stress heuristic sensitivity. For UNSAT generators, we mainly vary (i) the structure of the implication-graph witness of unsatisfiability (the UNSAT core ) and (ii) the number of filler clauses, i.e., clauses that can be satisfied independently of the core and thus do not contribute to the contradiction. For SAT generators, we mainly vary (i) the number of critical variables (e.g., backbone variables), (ii) the total number of variables, and (iii) the number of pure literals (literals that occur with only one polarity and hence do not constrain satisfiability).
B24: 3.1 UNSAT Generator using Implication Cycles
B25: We pick distinct variables v 1 , … , v L v_{1},\dots,v_{L} and for each we pick a literal ℓ i ∈ { v i , ¬ v i } \ell_{i}\in\{v_{i},\neg v_{i}\} for i = 1 , … , L i=1,\dots,L . Then, we construct a directed cycle in the implication graph:
B26: Forward part: ℓ 1 → ℓ 2 → ⋯ → ℓ k → ℓ 1 ¯ , \displaystyle\qquad\ell_{1}\to\ell_{2}\to\cdots\to\ell_{k}\to\overline{\ell_{1}},
B27: Backward part: ℓ 1 ¯ → ℓ k + 1 → ⋯ → ℓ L → ℓ 1 . \displaystyle\qquad\overline{\ell_{1}}\to\ell_{k+1}\to\cdots\to\ell_{L}\to\ell_{1}.
B28: Encoding each implication ℓ → ℓ ′ \ell\rightarrow\ell^{\prime} as the single 2-clause ℓ ¯ ∨ ℓ ′ \overline{\ell}\lor{\ell^{\prime}} yields a core that forces both ℓ 1 → ℓ 1 ¯ \ell_{1}\to\overline{\ell_{1}} and ℓ 1 ¯ → ℓ 1 \overline{\ell_{1}}\to\ell_{1} , hence UNSAT. The construction above contains one clause per displayed implication. The forward part contributes k k clauses; the backward part contributes ( L − k + 1 ) (L-k+1) clauses, for a total of L + 1 L{+}1 clauses.
B29: Parameters controlling difficulty. Difficulty is controlled by four parameters: (i) the cycle split ( L , k ) (L,k) , where L L is the number of literals in the core cycle and k k is the position of the twist to ℓ 1 ¯ \overline{\ell_{1}} (equivalently, the imbalance k / L k/L , with extremes k = 1 k=1 and k = L k=L ); (ii) the number of filler clauses r r that are satisfiable independently of the core (controlling size/density); (iii) the presentation , i.e., whether core clauses are ordered along the implication chain or shuffled and interleaved with fillers; and (iv) the total number of variables n ≥ L n\geq L , with variables outside the core appearing only in fillers (controlling the ratio L / n L/n ). The key structural difficulty is the imbalance k / L k/L : when it is close to 0 0 or 1 1 (e.g., k = 1 k=1 or k = L k=L ), one direction of the contradiction cycle is long while the other is short, forcing long-range implication tracking before closing the cycle.

B33: 3.3 Backbone-based Method
B34: The goal is to construct a satisfiable 2 2 –CNF that is the conjunction of: (i) clauses that infer a planted backbone assignment, i.e., an assignment on a subset of variables that is forced in every satisfying assignment (these variables take the same truth value in all solutions), and (ii) a remainder consisting only of monotone 2-clauses (all literals have the same polarity). We choose a backbone B ⊆ 𝒱 B\subseteq\mathcal{V} with a planted assignment b : B → { 0 , 1 } b:B\to\{0,1\} , and let F = 𝒱 ∖ B F=\mathcal{V}\setminus B be the free part. We introduce a fresh auxiliary variable a x a_{x} for each x ∈ B x\in B . The formula is a conjunction of two parts:
B35: Φ ⋆ := Φ backbone ⏟ infers ​ b ​ using only 2-clauses ∧ Φ mono ⏟ monotone 2-clauses over ​ F . \Phi^{\star}:=\underbrace{\Phi_{\text{backbone}}}_{\text{infers }b\text{ using only 2-clauses}}\land\ \underbrace{\Phi_{\text{mono}}}_{\text{monotone 2-clauses over }F}.
B36: (A) Backbone inference. For every x ∈ B x\in B , we add the following clauses using a fresh auxiliary a x a_{x} :
B37: Case ​ b ​ ( x ) = : \displaystyle\text{Case }b(x)=1\!: ( x ∨ a x ) ∧ ( x ∨ ¬ a x ) , \displaystyle(x\lor a_{x})\land(x\lor\neg a_{x}),
B38: Case ​ b ​ ( x ) = : \displaystyle\text{Case }b(x)=0\!: ( ¬ x ∨ a x ) ∧ ( ¬ x ∨ ¬ a x ) . \displaystyle(\neg x\lor a_{x})\land(\neg x\lor\neg a_{x}).
B39: Each pair is logically equivalent to the unit clause it emulates (respectively x x or ¬ x \neg x ), but uses only binary clauses; thus it fixes x x to b ⁡ ( x ) b(x) in all satisfying assignments.
B40: (B) Monotone remainder. We choose an orientation π ∈ { + , − } \pi\in\{+,-\} and add only 2-clauses over variables in F F :
B41: Case π = − : \displaystyle\text{Case }\pi=-:\ add clauses ​ ( ¬ y ∨ ¬ z ) ​ for ​ y , z ∈ F , \displaystyle\text{add clauses }(\neg y\lor\neg z)\ \text{for }y,z\in F,
B42: Case π = + : \displaystyle\text{Case }\pi=+:\ add clauses ​ ( y ∨ z ) ​ for ​ y , z ∈ F . \displaystyle\text{add clauses }(y\lor z)\ \text{for }y,z\in F.
B43: No variable from B B appears in Φ mono \Phi_{\text{mono}} . If π = − \pi=- , setting all y ∈ F y\in F to 0 0 satisfies Φ mono \Phi_{\text{mono}} ; if π = + \pi=+ , setting all y ∈ F y\in F to 1 1 does. Together with the pinned backbone, Φ ⋆ \Phi^{\star} is satisfiable.
B44: Parameters controlling difficulty. Let | B | = β ​ n |B|=\beta n and m mono m_{\text{mono}} be the number of monotone clauses added over F F . The part Φ backbone \Phi_{\text{backbone}} has exactly 2 ​ | B | 2|B| clauses and | B | |B| auxiliaries. The total clause count is | 𝒞 | = 2 ​ | B | + m mono |\mathcal{C}|=2|B|+m_{\text{mono}} . Difficulty is tuned via the backbone fraction β \beta , the monotone density relative to possible pairs 2 ​ m mono | F | 2 \frac{2m_{\text{mono}}}{|F|^{2}} , and the orientation π \pi .
B45: 3.4 Monotone Split with Moving Cross-Polarity Bridge
B46: We construct a 2 2 –CNF such that (i) a positive-monotone part over variables P P (only clauses of the form ( p ∨ p ′ ) (p\lor p^{\prime}) with p , p ′ ∈ P p,p^{\prime}\in P ), (ii) a negative-monotone part over variables N N (only clauses of the form ( ¬ q ∨ ¬ q ′ ) (\neg q\lor\neg q^{\prime}) with q , q ′ ∈ N q,q^{\prime}\in N ), with P ∩ N = ∅ P\cap N=\varnothing , and (iii) a single bridge clause that couples both parts ( ¬ p ⋆ ∨ q ⋆ ) (\neg p^{\star}\lor q^{\star}) with p ⋆ ∈ P p^{\star}\in P and q ⋆ ∈ N q^{\star}\in N . The bridge is inserted at a chosen position in the clause list so we can probe when a solving method backtracks as it scans clauses.
B47: Parameters controlling difficulty. The number of clauses is | 𝒞 | = m + + m − + 1 |\mathcal{C}|=m_{+}+m_{-}+1 with m + m_{+} and m − m_{-} the number of positive and negative clauses, plus the bridge. Densities m + / | P | m_{+}/|P| and m − / | N | m_{-}/|N| and the proportion of each part control how strongly each monotone part biases decisions. Bridge position s s probes sensitivity to late coupling and potential revision during clause scanning; satisfiability is invariant under s s . In particular, we parametrize generation with the overall variable density | P | + | N | 2 ​ | 𝒞 | \frac{|P|+|N|}{2|\mathcal{C}|} , the relative size of the positive part m + / | 𝒞 | m_{+}/|\mathcal{C}| , and the position s ∈ [ 1 , | 𝒞 | − 1 ] s\in[1,|\mathcal{C}|-1] of the bridge among the clauses.
B48: 3.5 Symmetry/Redundancy Probe
B49: Given a base 2 2 –CNF Ψ \Psi over variables 𝒱 \mathcal{V} , we build a new instance Φ := Ψ ∧ ρ ⁡ ( Ψ ) \Phi:=\Psi\land\rho(\Psi) , where ρ \rho is a bijective renaming from 𝒱 \mathcal{V} to a fresh, disjoint set 𝒱 ′ \mathcal{V}^{\prime} (so 𝒱 ∩ 𝒱 ′ = ∅ \mathcal{V}\cap\mathcal{V}^{\prime}=\varnothing ). Thus Φ \Phi is the concatenation of two isomorphic, independent copies of Ψ \Psi . Comparing a model on Ψ \Psi versus on Φ \Phi reveals the method’s ability to avoid redoing symmetric/duplicated reasoning.
B50: Properties (independence and symmetry). Independence . 𝒱 \mathcal{V} and 𝒱 ′ \mathcal{V}^{\prime} are disjoint, so there is no logical interaction. Automorphism. Swapping 𝒱 ↔ 𝒱 ′ \mathcal{V}\leftrightarrow\mathcal{V}^{\prime} (i.e. applying ρ \rho or ρ − 1 \rho^{-1} ) leaves Φ \Phi invariant. Φ \Phi has a nontrivial symmetry. Satisfiability. Φ \Phi is SAT iff Ψ \Psi is SAT. If Ψ \Psi has M M models, then Φ \Phi has M 2 M^{2} models (Cartesian product across copies). If Ψ \Psi is UNSAT, so is Φ \Phi . Absent symmetry-awareness or abstraction that reuses proofs across variable renamings, a model may re-discover the same implications twice, once per copy.

B78: 4 Dataset construction
B79: Verbalizers. We convert each 2–CNF into text using two approaches as illustrated in Fig 10 . The template verbalizer deterministically renders each clause into a short natural-language statement, using a fixed mapping from variables to entity names within a theme. We use 6 different templates to reformulate the SAT problem into a more practical problem: a direct verbalization of how the clause reads (logic), letter passing between people (letter), assignment of people to a blue and a red team (team), affinities between invitees to constrain a social gathering (social), room lighting rules (room), door locking (door). Each template maps a clause to a fixed sentence pattern with named entities (e.g., ¬ a ∨ b \lnot a\lor b becomes “either a is on the Blue team or b is on the Red team”). The mapping is deterministic and invertible, so the logical content of each clause is preserved by construction.
B80: The LLM verbalizer uses an LLM to rewrite each clause as a short narrative paragraph. We present the LLM with the two literals as natural-language statements derived from a thematic entity mapping (e.g., “the butler is innocent”, “the detective is the murderer”) and ask it to produce a paragraph expressing their disjunction. We use three themes (spy, heist, detective) to guide stylistic context. To prevent information loss, each paragraph is checked by a two-step LLM validator: it (i) extracts the two referenced entities and (ii) infers whether each is stated positively or negatively. We compare the recovered clause to the original; mismatches trigger regeneration (up to three attempts), after which we fall back to a deterministic template. On the augmented dataset, 95.4% of clauses validate on the first attempt and only 3.3% use the fallback, indicating that the verbalizer is typically semantically faithful.
B81: Choice of generation parameters. To generate the dataset, we use difficulty the parameters described in Section 3 for each generator. To facilitate sampling, each parameter is designed to be in [ 0 , 1 ] [0,1] . In our experiments, for each parameter, we split its possible values into thirds and generate data using an easy to manipulate value close to the center of each interval of the parameter space ( 0.2 ∈ [ 0 ; 1 3 ] 0.2\in[0;\frac{1}{3}] , 0.5 ∈ [ 1 3 , 2 3 ] 0.5\in[\frac{1}{3},\frac{2}{3}] , 0.8 ∈ [ 2 3 , 1 ] 0.8\in[\frac{2}{3},1] ). When studying the impact of each parameter, we considered 4 additional values that correspond to the bounds of those intervals ( 0 , 1 3 , 2 3 , 1 0,\frac{1}{3},\frac{2}{3},1 ). For generators where more than one major difficulty parameter identified, we vary only one parameter at a time and set the others to 0.5 0.5 to minimize the number of settings to evaluate. When generating data, the number of generated clauses is the main generation parameter, but minor differences might appear depending on the specifics of each generator. For instance, some generators are unable to generate an odd number of core clauses. Hereafter, number of clauses is given with a ± 1 \pm 1 tolerance to best match the target difficulty.
B82: Pipeline. For a given generator parameter combination, we generate 10 formulas and produce, for each of them, either 6 verbalizations for the template verbalizer or 3 for the LLM verbalizer (only in the ablation study Section 5.5 ).

B105: 5.3 Sensitivity to clause order
B106: We compare in Figure 6 our four main models under two clause orders: (i) the generator construction order (see Section 3 ) and (ii) a random permutation. Clause order significantly affects performance for all generators (paired t t -tests, p < 0.003 p<0.003 ), with a weaker but still significant effect for ImplicationCycle ( p = 0.035 p=0.035 ). For EquivalenceCore, shuffling is beneficial. As discussed in Section 5.2 , when implication structure is poorly formalized, contiguous implication chains can act as misleading local patterns; shuffling breaks these groupings by separating related clauses, reducing early commitment to an incorrect structure.

B111: 5.5 Verbalization strategy
B112: As shown in Figure 8 , template-only verbalizations yield similar performance across templates, indicating little sensitivity to surface wording when the clause structure is explicit. In contrast, LLM verbalizer substantially degrades accuracy ( Figure 9 ): at comparable clause sizes, performance drops by about 25 points relative to Figure 8 . We attribute this mainly to increased contextual noise and weaker structural cues, which make clause extraction harder even though the underlying 2-CNF is information-preserving and can be recovered when models are explicitly prompted to do so ( Section 3.5 ). Across themes, detective narratives are hardest, followed by spy, then heist, consistent with the intended stylistic bias. Detective stories tend to be more indirect, which further obscures the logical form. For ImplicationCycle, theme effects are smaller: the shared-literal chain induces more coherent narratives, improving verbalization consistency and partially mitigating theme differences. Overall, templates make the 2-CNF structure easy to recognize, whereas LLM narratives often impede structure recovery and lead models to miss global logical patterns.
