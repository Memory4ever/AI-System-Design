B216: Consequently, TriGen adopts the MX data representation, which provides activation precision comparable to INT16 while significantly reducing memory traffic and bandwidth consumption. This design choice achieves a balanced trade-off between computational efficiency and accuracy preservation.

As a baseline configuration, we use one NPU operating at 1 GHz. The number of NPUs are varied from one to eight cores, and we present the trade-offs in implementing multi core NPU . Each NPU is engaged with 32 × \times 32 MPA . DRAM bandwidth is set up to 32 GB/s and, in multi- NPU setup, the average bandwidth for one NPU is (32 / number of NPUs) . Global buffer size is set to 1 MiB per NPU and it can be varied. We use MXINT8 data type for activation and UINT4 for weight.
