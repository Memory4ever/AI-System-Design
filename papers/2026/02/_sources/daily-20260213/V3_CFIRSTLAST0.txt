L1105: ## Appendix E Details on Experiments
L1106: Baselines. First, we include two controlled baselines that share the same overall algorithmic structure as NHGD (e.g., batch size and iteration budget), differing only in the Hessian-inverse approximation strategy: (1) CG [cite70†12 , cite68†40 ] solves the linear system $\nabla_{\theta}^{2}\ell\,x=\nabla_{\theta}f$ using $K$ iterations of the conjugate gradient method. (2) Neumann [cite65†16 , cite64†23 ] estimates the inverse Hessian via a truncated Neumann series.
L1107: Following standard practice, we apply a scaling parameter $\varphi$: $H^{-1}v\approx\varphi\sum_{t=0}^{T}(I-\varphi H)^{t}v$, $0<\varphi<2/{\lambda_{\max}(H)}$.
L1108: We also compare the NHGD with several representative hypergradient-based methods. (3) stocBiO [cite65†16 ] adopts a double-loop structure. It approximates the Hessian inverse using a truncated Neumann series with $K$ iterations and an exponentially decaying batch size $B_{\text{stocBiO}}K(1-\varphi\mu_{\text{stocBiO}})^{k}$ at the $k$-th Neumann step, where $\varphi$ also serves as the Neumann scaling parameter. (4) AmIGO [cite69†2 ] also follows a double-loop structure.
L1109: It approximates the Hessian inverse by performing $K$ additional SGD steps to solve the quadratic subproblem $\min_{x}\tfrac{1}{2}x^{\top}\nabla_{\theta}^{2}\ell\,x-x^{\top}\nabla_{\theta}f$, with stepsize $\beta_{\text{amigo}}$. (5) TTSA [cite82†15 ] is a single-loop, two-time-scale method. At each epoch, it performs $K\sqrt{1+\text{epoch}}$ Neumann-series iterations with scaling parameter $\varphi$ to approximate the Hessian inverse.
L1110: (6) SOBA [cite83†7 ] is another single-loop method that updates the inner and outer variables simultaneously.
L1111: Unless otherwise specified (e.g., the adaptive batch-size rule in stocBiO), all stochastic derivative estimates (including gradients, Hessian–vector products, and Jacobian–vector products) use a fixed batch size $D$.
L1112: 
L1113: Implementation Details for NHGD. In practice, we adopt a smoothed rank-one update for the Hessian inverse approximation, rather than the exact update in (cite95†3.2 ). Specifically, we use
L1114:  | $\displaystyle A_{k}^{t+1}=\frac{1}{\beta}A_{k}^{t}-\frac{\frac{1-\beta}{\beta^{2}}A_{k}^{t}\nabla_{\theta}l(v_{k},\theta_{k}^{t},\xi_{k}^{t})\left(A_{k}^{t}\nabla_{\theta}l(v_{k},\theta_{k}^{t},\xi_{k}^{t})\right)^{\top}}{1+\frac{1-\beta}{\beta}\nabla_{\theta}l(v_{k},\theta_{k}^{t},\xi_{k}^{t})^{\top}A_{k}^{t}\nabla_{\theta}l(v_{k},\theta_{k}^{t},\xi_{k}^{t})}.$  |
L1115: We denote by $M$ the batch size used to estimate the cross-partial derivative $\hat{L}_{k}^{M}=\frac{1}{M}\sum_{i=0}^{M-1}\nabla_{\theta,v}^{2}l(v_{k},\theta_{k}^{T},\xi_{k}^{i})$ as discussed in Section cite12†3 .
L1116: Parameters Setting. For all methods, we perform grid search over the inner stepsize $\eta$ and outer stepsize $\alpha$ in $\{0.001,\;0.005,\;0.01,\;0.05,\;0.1,\;0.5,\;1.0\}$. Additional hyperparameters are selected as follows: for NHGD, $\beta\in\{0.7,0.8,0.9,0.95,0.99\}$; for Neumann-series approximations, the scaling factor $\varphi\in\{0.001,0.005,0.01,0.05,0.1\}$; for AmIGO, $\beta_{\text{amigo}}\in\{0.001,0.01,0.1,1.0\}$; and for stocBiO, $B_{\text{stocBiO}}\in\{5,10,50,100,200,500\}$.
L1117: Hardware Setup. All experiments are conducted on NVIDIA A100-SXM4-80GB GPUs. The NHGD algorithm is implemented in a parallel two-GPU setting: the first GPU executes the inner-level SGD, while the second GPU simultaneously updates the Hessian inverse approximation.
L1118: The implementation adapts code from the open-source project cite199†https://github.com/Cranial-XIX/BOME†github.com [cite200†22 ]. For the PIML experiments, the code is further based on cite201†https://github.com/HaoZhongkai/Bi-level-PINN†github.com [cite59†13 ].

L1184: ### E.3  PDE Constrained Optimization
L1185: 
L1186: Experimental Setup. The spatio-temporal domain is $\Omega=[0,1]\times[0,1]$ over the time interval $[0,2]$. We sample 1024 interior collocation points and 256 boundary points on each spatial boundary $(x=0,x=1,y=0,y=1)$ across the full time interval using Sobol quasi-random sequences. An additional 256 points are sampled at $t=0$ to enforce the initial condition $u(x,y,0)=0$. For evaluating the outer-level objective, we use 512 uniformly spaced test points.
L1187: The state network $u_{\theta}$ is a fully connected neural network with architecture $[3,\,64,\,64,\,64,\,64,\,1]$ (approximately 12.8k parameters), which takes $(x,y,t)$ as input and outputs $u(x,y,t)$. The state network is pretrained for 2000 epochs before bilevel optimization. The control network $f_{v}$ has a smaller architecture $[1,\,32,\,32,\,1]$ and maps time $t$ to the source term $f(t)$.
L1188: Additional Results. We compare NHGD with the Broyden-based Hessian-inverse approximation method proposed in [cite59†13 ] for this challenging task. Table cite216†5 reports the outer objective (PDE-constrained optimization loss) averaged over the last 50 epochs. NHGD achieves a comparable final outer loss while requiring substantially less computation time.
