L144: ### 4.2 Confidence Metric
L145: We measure prediction confidence using the ratio between the top two predicted probabilities. At each masked position $i$, the model produces logits $\ell^{i}\in\mathbb{R}^{K}$, which we convert to a probability distribution via softmax without temperature scaling: $\pi_{\theta}^{i}(\mathbf{x}_{t})=\mathrm{softmax}(\ell^{i})\in\Delta^{K}$.
L146: By using unscaled logits, our confidence metric remains invariant to any temperature parameter applied during sampling, decoupling early-exit decisions from generation diversity settings. Denote the largest and second-largest probabilities as $p_{1}^{i}$ and $p_{2}^{i}$, respectively. The confidence score is defined as:
L147:  | $$r^{i}=\frac{p_{1}^{i}}{p_{2}^{i}+\epsilon},$$  |  | (4)
L148: 
L149: where $\epsilon>0$ is a small constant for numerical stability. This ratio captures how decisively the model favors its top prediction: $r^{i}\approx 1$ indicates uncertainty between alternatives, while $r^{i}\gg 1$ signals strong commitment to the leading candidate.
L150: ### 4.3 Spatial Modulation
L151: Recent work on diffusion language model training has shown that positions with stronger local context—particularly those near already-decoded tokens—tend to experience lower noise level [cite46†24 ]. Dream’s CART weighting exploits this during training by applying context-adaptive noise rescheduling at the token level.
L152: We draw inspiration from this finding and apply analogous reasoning to inference: positions adjacent to already-unmasked tokens benefit from richer local context, making their predictions more reliable even at earlier steps. We capture this through a spatial softening factor based on proximity to resolved positions.
L153: Let $\mathcal{M}_{n}$ denote the set of masked positions at step $n$. The spatial weight at position $i$ is computed using a geometric kernel over a window of radius $D$:
L154: 
L155:  | $$w^{i}=\sum_{\begin{subarray}{c}j\notin\mathcal{M}_{n}\\
L156: |i-j|\leq D\end{subarray}}\gamma^{|i-j|}$$  |  | (5)
L157: 
L158: where $\gamma\in(0,1)$ is the decay rate controlling how quickly influence diminishes with distance. The spatial softening factor is the normalized weight:
L159:  | $$\phi^{i}=\min\left(1,\frac{w^{i}}{w_{\max}}\right),$$  |  | (6)
L160: 
L161: where $w_{\max}=2\sum_{d=1}^{D}\gamma^{d}$ is the maximum possible weight. Positions at the boundary of masked regions receive higher $\phi^{i}$, reflecting their enhanced contextual support.
L162: ### 4.4 Adaptive Threshold
L163: 
L164: The spatial softening factor modulates a position-specific acceptance threshold. The threshold at position $i$ is interpolated between a maximum $\tau_{\max}$ and minimum $\tau_{\min}$:
L165: 
L166:  | $$\tau^{i}=\tau_{\max}-(\tau_{\max}-\tau_{\min})\cdot\phi^{i}.$$  |  | (7)
L167: Positions near unmasked tokens (high $\phi^{i}$) receive lower thresholds, making them easier to finalize. Positions in the interior of masked regions retain the stricter threshold $\tau_{\max}$, requiring higher confidence before commitment.
L168: ### 4.5 Early-Exit Decision
L169: 
L170: At each step $n$, a masked position $i\in\mathcal{M}_{n}$ is finalized if its confidence exceeds the adaptive threshold:
L171: 
L172:  | $$r^{i}\geq\tau^{i}.$$  |  | (8)
L173: 
L174: When this condition is met, position $i$ is assigned its top predicted token $\hat{x}^{i}=\arg\max_{v}\pi_{\theta}^{i}(\mathbf{x}_{t_{n}})_{v}$ and removed from the set of masked positions. Positions that do not meet the threshold continue through the standard transfer schedule.

L172: ###### Abstract
L173: Tabular foundation models, such as TabPFNv2 and TabICL, have recently dethroned gradient-boosted trees at the top of predictive benchmarks, demonstrating the value of in-context learning for tabular data.
L174: We introduce TabICLv2, a new state-of-the-art foundation model for regression and classification built on three pillars: (1) a novel synthetic data generation engine designed for high pretraining diversity; (2) various architectural innovations, including a new scalable softmax in attention improving generalization to larger datasets without prohibitive long-sequence pretraining; and (3) optimized pretraining protocols, notably replacing AdamW with the Muon optimizer.
L175: On the TabArena and TALENT benchmarks, TabICLv2 without any tuning surpasses the performance of the current state of the art, RealTabPFN-2.5 (hyperparameter-tuned, ensembled, and fine-tuned on real data). With only moderate pretraining compute, TabICLv2 generalizes effectively to million-scale datasets under 50GB GPU memory while being markedly faster than RealTabPFN-2.5.
L176: We provide extensive ablation studies to quantify these contributions and commit to open research by first releasing inference code and model weights at cite158†https://github.com/soda-inria/tabicl†github.com , with synthetic data engine and pretraining code to follow.

L216: To address attention fading, some work focuses on softmax alternatives (cite196†Peters et al., 2019 ; cite197†Ramapuram et al., 2024 ), which, however, requires specialized implementations incompatible with the softmax ecosystem, e.g., FlashAttention (cite198†Dao et al., 2022 ). We thus focus on a less invasive solution: temperature scaling.
L217: Standard attention (cite199†Vaswani et al., 2017 ) already incorporates a fixed scaling temperature factor $1/\sqrt{d}$ to prevent dot-product magnitudes from growing with dimension, but this does not address length-dependent fading. YaRN (cite200†Peng et al., 2023 ) scales temperature with context length for RoPE (cite201†Su et al., 2021 ) extension, but the scaling is fixed and requires positional encoding. Recent work proposes dynamic alternatives.
L218: Scalable Softmax (SSMax, cite195†Nakanishi 2025 ) scales attention logits by $s\log n$, where $s$ is a learnable per-head parameter. Concurrent theoretical analysis (cite202†Chen et al., 2025b ) establishes that $\log n$ scaling is necessary to maintain attention sharpness as context length $n$ grows. Adaptive-Scalable Entmax (ASEntmax, cite203†Vasylenko et al.
L219: 2025 ) extends this with content-aware scaling $\delta+\beta(\log n)^{\gamma}$, where $\delta$ is a length-independent constant offset, and $\beta=\mathrm{softplus}(\text{MLP}(X))$ and $\gamma=\tanh(\text{MLP}(X))$ are input-dependent. Selective Attention (cite204†Zhang et al., 2024 ) takes a different approach by introducing query-dependent temperature $\tau(q)$ via lightweight MLPs, decoupling the scaling from context length entirely.
L220: ## 3 Architecture
L221: The architecture of TabICLv2 is illustrated in cite205†Figure 2 . Following TabICL, TabICLv2 chains column-wise embedding, row-wise interaction, and dataset-wise ICL, thus preserving the efficiency of TabICL with a runtime complexity of $O(n^{2}+nm^{2})$ for tables with $n$ rows and $m$ columns. In addition, we introduce several improvements that significantly enhance performance without increasing model size (see the ablation study in cite36†Section 7 ).
L222: In the following, we mark these improvements with $\blacktriangleright$. We focus below on architectural innovations. For model configuration details (e.g., number of layers), refer to cite49†Section A.4 . We provide a short self-contained implementation of the TabICLv2 architecture for educational and experimental purposes, inspired by nanoTabPFN (cite206†Pfefferle et al., 2025 ), at
L223: cite207†https://github.com/soda-inria/nanotabicl†github.com .
L224: $\blacktriangleright$ Repeated feature grouping. TabICL embeds each feature independently, which can lead to representation collapse when features share similar distributions. TabPFNv2 and TabPFN-2.5 mitigate this collapse by grouping multiple columns into single tokens, which also reduces the number of effective features to improve efficiency, but this reduction may lose fine-grained feature information.
L225: We propose repeated feature grouping, which places each feature into multiple groups via circular shifts while preserving the number of effective features. Specifically, for a table with $m$ columns, we create $m$ groups where the $j$-th group contains columns at positions $(j,j+1,j+3)\bmod m$. Each group is encoded by a shared linear layer $\mathrm{Lin}:\mathbb{R}^{3}\to\mathbb{R}^{d}$:
L226:  | $$E_{1}[i,j]=\mathrm{Lin}\big(x_{i,j},\,x_{i,(j+1)\bmod m},\,x_{i,(j+3)\bmod m}\big).$$  |
L227: 
L228: The shift pattern $(0,1,3)$ ensures that for $\geq 7$ columns, no pair of columns appears together in more than one group. We show in cite41†Section A.1 that this pattern generalizes to arbitrary group sizes, although we did not observe consistent improvements from larger groups.

L230: QASSMax, our query-aware scalable softmax, is applied in the part of $\text{TF}_{\text{col}}$ where inducing points aggregate input information and $\text{TF}_{\text{icl}}$ to mitigate attention fading and improve long-context generalization.

L237: $\blacktriangleright$ Target-aware embedding. We find it beneficial to inject target information early. After repeated feature grouping produces input data representation $E_{1}\in\mathbb{R}^{n\times m\times d}$, we add target embeddings to each training token:
L238: 
L239:  | $$E_{2}[i,j]=E_{1}[i,j]+\mathrm{Embed_{\text{TAE}}}(y_{i}),\quad i\in\mathcal{D}_{\mathrm{train}},$$  |
L240: where $\mathrm{Embed_{\text{TAE}}}$ is a linear layer for regression or a learnable lookup table for classification. Unlike TabPFNv2 appending the target as an additional column, we directly add target embeddings to all features. This also helps mitigate representation collapse because even when two features share similar distributions, their association with target values often differs across samples.
L241: Compression then ICL. TabICLv2 processes $E_{2}$ in three stages: (1) column-wise embedding applies a set transformer $\text{TF}_{\text{col}}$ (cite209†Lee et al., 2019 ) to each column; (2) row-wise interaction uses a transformer $\text{TF}_{\text{row}}$ with [CLS] tokens to collapse feature embeddings per row into a single vector; (3) dataset-wise ICL combines row embeddings with target embeddings and uses a transformer $\text{TF}_{\text{icl}}$ where test samples attend to training samples for prediction.
L242: See cite42†Section A.2 for details. $\blacktriangleright$ Compared to TabICL, our key innovation here is applying a novel scalable softmax to $\text{TF}_{\text{icl}}$ and to the part of $\text{TF}_{\text{col}}$ where inducing points aggregate input information.
L243: $\blacktriangleright$ Query-aware scalable softmax. To improve generalization to larger datasets, we extend Scalable Softmax (SSMax, cite195†Nakanishi 2025 ), a temperature scaling method that sharpens attention distributions by rescaling queries before computing logits. Let $q_{h}=(q_{hi})$ be a query vector at head $h$ with head dimension indexed by $i$, and let $n$ be the size of the training set. SSMax rescales queries with a learnable per-head scalar $s_{h}$:
L244:  | $$\tilde{q}_{hi}=q_{hi}\cdot s_{h}\log n~.$$  |
L245: 
L246: We propose query-aware scalable softmax (QASSMax), which rescales each query element as:
L247: 
L248:  | $$\tilde{q}_{hi}=q_{hi}\cdot\underbrace{\mathrm{MLP}_{\mathrm{base}}(\log n)_{hi}}_{\text{base scaling}}\cdot\underbrace{\big(1+\tanh(\mathrm{MLP}_{\mathrm{gate}}(q_{h})_{i})\big)}_{\text{query-aware gating}}$$  |
L249: where for $H$ attention heads, $\mathrm{MLP}_{\mathrm{base}}:\mathbb{R}\to\mathbb{R}^{H\times d_{\mathrm{head}}}$ and $\mathrm{MLP}_{\mathrm{gate}}:\mathbb{R}^{d_{\mathrm{head}}}\to\mathbb{R}^{d_{\mathrm{head}}}$ are two-layer MLPs with 64 hidden neurons and GELU activation.
L250: We design QASSMax based on the following rationale: (a) The $\log n$ factor is critical as it counteracts the linear growth of the softmax denominator with respect to $n$ (cite195†Nakanishi, 2025 ; cite202†Chen et al., 2025b ); (b) ASEntmax (cite203†Vasylenko et al., 2025 ) uses learnable $\delta+\beta(\log n)^{\gamma}$, inspiring us to generalize to $\mathrm{MLP}_{\mathrm{base}}(\log n)$; (c) Element-wise scaling increases expressiveness beyond per-head scalars; (d) Selective Attention (cite204†Zhang et al., 2024 ) introduces query-awareness in temperature scaling, which motivates us to use the bounded query-aware gating $\in(0,2)$ that modulates the base scaling without dominating the $\log n$ trend.
L251: In addition, our gating design shares similar insights with Gated Attention (cite210†Qiu et al., 2025 ), which applies gating to attention outputs and finds query-dependent, element-wise gating most effective.
L252: QASSMax applied to $\text{TF}_{\text{col}}$ and $\text{TF}_{\text{icl}}$ yields substantially performance improvements, as shown in the ablation study (cite36†Section 7 ). To study its effect on attention fading, we design a toy needle-in-haystack classification task (cite211†Figure 3 ): the model must focus on a single anchor sample (the needle) among increasing negative samples (the haystack). Without scalable softmax, attention entropy rises and accuracy drops.
L253: However, QASSMax maintains low entropy and 100% accuracy even with 15K negatives, outperforming SSMax which largely degrades at extreme scales.
L254: Many-class classification. Like many TFMs, TabICLv2 is pretrained with up to 10 classes. We use hierarchical classification (cite174†Qu et al., 2025 ) at the ICL stage for more classes. However, target-aware embedding introduces labels before hierarchical partitioning.
L255: $\blacktriangleright$ To address this, we propose mixed-radix ensembling : for $C>10$ classes, we compute balanced bases $[k_{0},\ldots,k_{D-1}]$ with each $k_{i}\leq 10$ and $\prod_{i}k_{i}\geq C$, then decompose each label $y$ into $D$ digits $y^{(i)}\in\{0,\ldots,k_{i}{-}1\}$ via mixed-radix representation. Each digit defines a coarser grouping of the original classes. We run $\text{TF}_{\text{col}}$ once per digit and average the outputs:
L256:  | $$O_{\mathrm{avg}}=\frac{1}{D}\sum_{i=0}^{D-1}\text{TF}_{\text{col}}(E_{1}+\mathrm{Embed_{\text{TAE}}}(y^{(i)}))~.$$  |
L257: 
L258: Combined with hierarchical classification in $\text{TF}_{\text{icl}}$, this enables TabICLv2 to handle an arbitrary number of classes. See cite43†Section A.3 for details.
L259: $\blacktriangleright$ Quantile predictions for regression. Existing TFMs adopt different strategies for regression: TabPFNv2 and TabPFN-2.5 model the full predictive distribution by discretizing the target space into bins and applying cross-entropy loss, while Mitra and TabDPT predict point estimates using MSE loss. In addition, like most TFMs except LimiX, we train separate models for classification and regression.
L260: TabICLv2 instead predicts 999 quantiles at probability levels $\alpha\in\{0.001,0.002,\ldots,0.999\}$, trained with pinball loss summed across all quantiles. In preliminary experiments using RMSE evaluation, we found that quantile regression outperforms MSE and the bin-based approach of TabPFNv2.
L261: At inference, for point estimation we simply average the predicted quantiles, which proves both fast and effective. For probabilistic predictions, we construct a full distribution from the quantiles by enforcing monotonicity via sorting (the default) or isotonic regression (cite212†Barlow & Brunk, 1972 ; cite213†Busing, 2022 ), extrapolating tails with parametric exponential models, and deriving closed-form PDF, CDF, and moments. See cite108†Appendix I for details.

L559: Column-wise embedding. Column-wise embedding processes each column through a set transformer $\text{TF}_{\text{col}}$ (cite209†Lee et al., 2019 ). Its core is induced self-attention with $k$ inducing vectors that proceeds in two stages: the first stage aggregates input information into inducing vectors and the second broadcasts back to the input, reducing complexity from $O(n^{2})$ to $O(nk)$.
L560: We make three improvements: (a) we directly use the outputs of $\text{TF}_{\text{col}}$ as feature embeddings, while TabICL applies an additional transformation; (b) we apply our query-aware scalable softmax (QASSMax) to the first stage of induced self-attention; and (c) $\text{TF}_{\text{col}}$ is essentially an in-context learner operating within each column thanks to target-aware embedding.
L561: Row-wise interaction. Following TabICL (cite174†Qu et al., 2025 ), we prepend four learnable [CLS] tokens to each row and process them through a transformer $\text{TF}_{\text{row}}$ with RoPE (cite201†Su et al., 2021 ). The outputs of the [CLS] tokens are concatenated to form a $4d$-dimensional row embeddings, effectively collapsing the feature dimension.
L562: Dataset-wise in-context learning. Training row embeddings are combined with target embeddings. A transformer $\text{TF}_{\text{icl}}$ processes all embeddings, where test samples attend only to training samples. A two-layer MLP converts the outputs into target predictions. We apply QASSMax to $\text{TF}_{\text{icl}}$ to improve its long-context generalization.
L563: ### A.3 Many-class classification
L564: Like many tabular foundation models, TabICLv2 is pretrained on classification tasks with up to 10 classes. For tasks with more classes, TabICL (cite174†Qu et al., 2025 ) proposed hierarchical classification during the ICL stage, which recursively partitions classes into subproblems with at most 10 classes each. However, our target-aware embedding introduces label information before hierarchical partitioning occurs.
L1098: ##### Layer normalization reuse.
L1099: 
L1100: We adopted the pre-norm setting in the transformer block. To avoid redundant computation, we first apply layer normalization to the full input sequence, then perform slicing to extract the required subset for query, key, or value computation. This ensures that normalization statistics are computed once over the complete sequence, and the sliced representations remain properly normalized without requiring separate normalization passes for different subsets.

L1103:

L1114: ##### Memory bottleneck analysis.
L1115: Given an input $X\in\mathbb{R}^{b\times n\times m}$, where $b$, $n$, and $m$ represent the number of datasets, the number of samples, and the number of features respectively, $X$ is first reshaped to $\mathbb{R}^{(b\times m)\times n}$ and processed by $\text{TF}_{\text{col}}$ to produce feature embeddings $E\in\mathbb{R}^{(b\times m)\times n\times d}$. The memory bottleneck lies in storing this intermediate tensor $E$.
