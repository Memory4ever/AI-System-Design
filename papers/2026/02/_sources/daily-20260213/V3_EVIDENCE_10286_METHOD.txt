L102: ## 2 Related Work
L103: #### Bradley–Terry and representability.
L104: The Conditional Pairwise Preference Distribution (CPRD) corresponds to what is referred to as a choice probability in classical paired-comparison models (cite42†Thurstone, 1927 ; cite37†Bradley and Terry, 1952 ; cite43†Luce and others, 1959 ; cite50†Plackett, 1975 ), ranking from pairwise comparisons (cite51†Hüllermeier et al., 2008 ; cite39†Fürnkranz and Hüllermeier, 2010 ; cite52†Shah et al., 2016 ; cite53†Heckel et al., 2018 ; cite54†Heckel et al., 2019 ), and dueling bandits (cite55†Yue et al., 2012 ; cite56†Dudík et al., 2015 ; cite57†Jamieson et al., 2015 ; cite58†Sui et al., 2018 ).
L105: The Bradley–Terry model is a popular approach for learning preferences from such data; see (cite59†Hamilton et al., 2023 ) for a comprehensive review.
L106: Prior work has characterized when a distribution can be represented by the BT model (cite60†Good, 1955 ; cite43†Luce and others, 1959 ; cite61†Buhlmann and Huber, 1963 ; cite62†Yellott, 1977 ; cite63†Falmagne, 1978 ; cite64†Breitmoser, 2021 ), with transitivity being a well-known limitation that several methods attempt to address (cite65†Chen and Joachims, 2016 ; cite66†Bower and Balzano, 2020 ; cite67†Tatli et al., 2024 ; cite68†Zhang et al., 2025a ).
L107: In contrast, we study BT representability starting from a given triplet distribution rather than assuming data follows the BT model.
L108: #### Statistical analysis.
L109: A large body of work has analyzed the consistency of maximum likelihood estimation for the Bradley–Terry model, showing that MLE recovers the true parameters when data follows the BT model (cite69†Hunter, 2004 ; cite70†Huang et al., 2006 ; cite71†Yan et al., 2012 ; cite72†Han et al., 2020 ; cite73†Bong and Rinaldo, 2022 ; cite74†Gao et al., 2023a ).
L110: Many works provide sample complexity bounds for parameter recovery (cite75†Negahban et al., 2012 ; cite76†Hajek et al., 2014 ; cite77†Chen and Suh, 2015 ; cite52†Shah et al., 2016 ; cite73†Bong and Rinaldo, 2022 ; cite78†Li et al., 2022 ), with extensions to parametric settings where scores are linear (cite79†Zhu et al., 2023 ; cite80†Fan et al., 2024 ) or parameterized by neural networks (cite81†Sun et al., 2025 ).
L111: We show that under positive–negative conditional independence, BT recovers the log density ratio between the positive and negative distributions. This quantity also appears in noise contrastive estimation (NCE), where one distinguishes data from noise (cite82†Gutmann and Hyvärinen, 2010 ; cite83†Gutmann and Hyvärinen, 2012 ; cite84†Mnih and Kavukcuoglu, 2013 ); the related InfoNCE loss has become widely used in representation learning (cite85†Oord et al., 2018 ; cite86†Chen et al., 2020 ; cite87†Wang and Isola, 2020 ).
L112: Prior work has proposed metrics for evaluating preference dataset quality, including information content based on embedding similarity (cite88†Shen et al., 2024 ) and truncated influence functions (cite89†Zhang et al., 2025b ).
L113: More broadly, choosing which comparisons to collect for efficient preference recovery relates to experimental design (cite90†Graßhoff and Schwabe, 2008 ; cite91†Guo et al., 2018 ) and active learning (cite92†Jamieson and Nowak, 2011 ; cite93†Houlsby et al., 2011 ; cite54†Heckel et al., 2019 ; cite94†Das et al., 2025 ; cite95†Shen et al., 2025 ).
L114: #### Preference learning for large language models.
L115: Preference learning from pairwise comparisons is central to aligning language models with human preferences (cite45†Christiano et al., 2017 ; cite46†Ouyang et al., 2022 ; cite47†Bai et al., 2022b ; cite48†Bai et al., 2022a ). The standard approach learns a reward model from pairwise comparisons, then uses it to align the language model via reinforcement learning.
L116: Recent work also aligns the language models directly from pairwise comparisons (cite49†Rafailov et al., 2023 ; cite79†Zhu et al., 2023 ; cite96†Ethayarajh et al., 2024 ; cite97†Li et al., 2024 ; cite98†Chen et al., 2024 ). This paper focuses on the reward learning step: characterizing the reward learned from a given dataset.
L117: A separate question is what makes a good reward model: ideally, high reward should correspond to good downstream performance.  However, reward hacking, where the model achieves high scores without improving on downstream tasks, remains a challenge (cite99†Skalse et al., 2022 ; cite100†Gao et al., 2023b ).
L118: Several benchmarks evaluate reward model quality (cite101†Lambert et al., 2025 ; cite102†Liu et al., 2025 ; cite103†Zhou et al., 2025 ), and theoretical work has sought to characterize what makes a good reward (cite104†Razin et al., 2025 ). Recent findings suggest that rewards with high variance are more effective at teaching an LLM (cite104†Razin et al., 2025 ; cite105†Xu et al., 2025 ; cite106†Guo et al., 2025 ). Our results provide a complementary perspective: a target reward with large margin is also easier to learn.
L119: ## 3 Setup
L120: Let $\mathcal{X}$ be a context space and $\mathcal{Y}$ be a set of outcomes. We are interested in learning which outcome $y$ is preferable for a given context $x$. We focus on learning this preference from pairwise comparisons. Formally, we assume that there exists a joint distribution $P$ over $\mathcal{X}\times\mathcal{Y}\times\mathcal{Y}$ where each triplet $(x,y^{+},y^{-})\sim P$ represents that for a given context $x$, an outcome $y^{+}$ is preferable to an outcome $y^{-}$.
L121: We use $\succ$ to denote the preference relation, i.e., $y\succ y^{\prime}$ means that $y$ is preferable to $y^{\prime}$. For convenience, we write $P(x,y,y^{\prime}):=P(x,y^{+}=y,y^{-}=y^{\prime})$ for the probability (or density) of the oriented triple $(x,y,y^{\prime})$.
L122: First, we observe that the distribution $P$ over triplets induces a preference distribution over any pairs of outcomes for a given context. We formalize this as the conditional preference distribution (CPRD) which is defined as follows:
L123: ###### 3.1 Conditional Preference Distribution (CPRD).
L124: 
L125: For a distribution $P$ over $\mathcal{X}\times\mathcal{Y}\times\mathcal{Y}$, the conditional preference distribution (CPRD) of $P$ is defined on any unordered pair $\{y,y^{\prime}\}$ with $y\neq y^{\prime}$ and $x\in\mathcal{X}$ as follows:
L126: 
L127:  | $$\omega_{P}(y\succ y^{\prime}\mid x)=P(y\succ y^{\prime}\mid x,\{y,y^{\prime}\}).$$  |  | (2)
L128: 
L129: In fact, by Bayes’ rule, we have
L130:  | $$\omega_{P}(y\succ y^{\prime}\mid x)=\frac{P(x,y,y^{\prime})}{P(x,y,y^{\prime})+P(x,y^{\prime},y)}.$$  |  | (3)
L131: 
L132: CPRD directly captures the preference structure of the distribution $P$ and is the target distribution that we aim to learn.
L133: 
L134: Next, we introduce the Bradley–Terry model which is a popular model for preference learning from pairwise comparisons.
L135: ###### 3.2 Bradley–Terry Model.
L136: 
L137: Bradley–Terry model assumes that there exists a score function $r:\mathcal{X}\times\mathcal{Y}\to\mathbb{R}$ such that for any context $x\in\mathcal{X}$ and any unordered pair $\{y,y^{\prime}\}\in\mathcal{Y}$, the probability of preferring $y$ over $y^{\prime}$ is given by:
L138: 
L139:  | $$P(y\succ y^{\prime}\mid x)=\sigma(r(x,y)-r(x,y^{\prime}))$$  |  | (4)
L140: 
L141: where $\sigma(t)=\frac{1}{1+e^{-t}}$ is the sigmoid function.
L142: In practice, one often fits this Bradley–Terry model by minimizing the negative log-likelihood of the observed triplets $(x,y^{+},y^{-})\sim P$. Concretely, for a set of triplets $S=\{(x_{i},y_{i}^{+},y_{i}^{-})\}_{i=1}^{n}$, the empirical risk is given by:
L143: 
L144:  | $$\widehat{\mathcal{L}}_{\text{BT}}(r)=\sum_{i=1}^{n}\log\sigma(r(x_{i},y_{i}^{+})-r(x_{i},y_{i}^{-})).$$  |  | (5)
L145: and the learned score function is given by $\hat{r}\in\arg\min_{r}\widehat{\mathcal{L}}_{\text{BT}}(r)$. We can use $\hat{r}$ to predict the preference between any two outcomes for a given context using equation (cite107†4 ). We remark that the score function $r$ is not unique and is determined up to a constant shift since adding any constant to $r$ still preserves the difference $r(x,y)-r(x,y^{\prime})$ for any $x$ and $y\neq y^{\prime}$.
L146: While this gives us a convenient way to learn the preference, it is not clear whether the Bradley–Terry model is able to recover the correct CPRD of the distribution $P$ since the assumption on the structure of the preference (equation (cite107†4 )) may not hold. Our first contribution is to identify when a CPRD can be represented with a Bradley–Terry model.
L147: ## 4 When does a CPRD admit a Bradley–Terry model?
L148: 
L149: In this section, we characterize when a CPRD is representable by a BT model.
L150: ###### 4.1.
L151: 
L152: A CPRD $\omega_{P}$ is representable by a Bradley–Terry model if there exists a score function $r:\mathcal{X}\times\mathcal{Y}\to\mathbb{R}$ such that for all $x$ and all $y\neq y^{\prime}$ with $P(x,y,y^{\prime})+P(x,y^{\prime},y)>0$,
L153: 
L154:  | $$\omega_{P}(y\succ y^{\prime}\mid x)=\sigma\!\big(r(x,y)-r(x,y^{\prime})\big).$$  |  | (6)
L155: 
L156: We can show that a CPRD is representable by a BT model when the ratio of the probability has a certain structure.
L157: ###### 4.2 CPRD BT factorization.
L158: 
L159: For a distribution $P$ over $\mathcal{X}\times\mathcal{Y}\times\mathcal{Y}$, the CPRD $\omega_{P}$ is representable by a BT model if and only if there exists a strictly positive function $h:\mathcal{X}\times\mathcal{Y}\to\mathbb{R}$ such that for all $x$ and all $y\neq y^{\prime}$ with $P(x,y,y^{\prime})+P(x,y^{\prime},y)>0$,
L160: 
L161:  | $$\frac{P(x,y,y^{\prime})}{P(x,y^{\prime},y)}=\frac{h(x,y)}{h(x,y^{\prime})}.$$  |  | (7)
L162: 
L163: Proof in Appendix cite30†A .
L164: This proposition shows that not every $P$ induces a CPRD that is representable by a BT model; BT representability requires the probability ratios to have a specific structure. While the condition involves the ratio of $P(x,y,y^{\prime})$ and $P(x,y^{\prime},y)$, which seems to be difficult to verify in practice, we will show that data generating process does provide a nice alternative view. First, we introduce a positive–negative conditional independence assumption.
L165: ###### 4.3 Positive–negative conditional independence.
L166: 
L167: A distribution $P$ is said to satisfy positive–negative conditional independence if there exist a marginal $P_{X}$ on $\mathcal{X}$ and conditional distributions $p_{+}(\cdot\mid x)$ and $p_{-}(\cdot\mid x)$ on $\mathcal{Y}$ such that
L168: 
L169:  | $$P(x,y^{+},y^{-})=P_{X}(x)\,p_{+}(y^{+}\mid x)\,p_{-}(y^{-}\mid x).$$  |  | (8)
L170: Equivalently, to generate a triplet $(x,y^{+},y^{-})\sim P$, we first sample $x\sim P_{X}$ and then we sample $y^{+}\sim p_{+}(y^{+}\mid x)$ and $y^{-}\sim p_{-}(y^{-}\mid x)$ independently.
L171: ###### 4.4 CPRD of conditionally independent distribution and BT model.
L172: 
L173: Let $P$ be a distribution over $\mathcal{X}\times\mathcal{Y}\times\mathcal{Y}$, then the following holds;
L174: 
L175:   1. 1.
L176: 
L177: If $P$ satisfies positive–negative conditional independence, then the CPRD $\omega_{P}$ is representable by a BT model.
L178: 
L179:   2. 2.
L180: 
L181: If the CPRD $\omega_{P}$ is representable by a BT model, then there exists a positive–negative conditional independence distribution $Q$ such that $\omega_{Q}=\omega_{P}$.
L182: In addition, the suitable score function $r$ for a positive–negative conditional independence distribution $P$ is given by
L183: 
L184:  | $$r(x,y)=\log\frac{p_{+}(y\mid x)}{p_{-}(y\mid x)}.$$  |  | (9)
L185: 
L186: Proof in Appendix cite30†A .
L187: This generative perspective yields a clean sufficient route to BT: if $P$ is generated by independently sampling $y^{+}\sim p_{+}(\cdot\mid x)$ and $y^{-}\sim p_{-}(\cdot\mid x)$ given $x$, then $\omega_{P}$ is automatically representable by a BT model, with score $r(x,y)=\log\frac{p_{+}(y\mid x)}{p_{-}(y\mid x)}$. This ratio has appeared in the noise contrastive estimation framework (cite82†Gutmann and Hyvärinen, 2010 ) and also resembles the implicit reward function (cite49†Rafailov et al., 2023 ).
L188: Importantly, this assumption is not merely descriptive, in many modern settings we can enforce it by design, e.g., when we control data collection by synthesizing comparisons via separate “good” and “bad” generators. Nevertheless, our goal is not only to verify if the CPRD is representable with a BT model but to learn the CPRD. This motivates the next section where we analyze the learning objectives.
L189: ## 5 Learning CPRD
L190: 
L191: We now turn to a question of more immediate practical relevance: given i.i.d. triplets $(x,y^{+},y^{-})$ drawn from $P$, what objective should we optimize, and what does that objective actually recover and when it matches the ground-truth CPRD? We study two canonical approaches, generative modeling via MLE of the triplet distribution, and discriminative BT training via pairwise log-likelihood.
L192: First, we will introduce the generative and discriminative learning objectives for learning the CPRD.
L193: 
L194: The generative learning objective. For a class of parametric distribution $P_{\phi}$ over triplets $(x,y^{+},y^{-})$, the generative learning objective is
L195: 
L196:  | $$\min_{\phi}\mathcal{L}_{\text{gen}}(\phi)=\mathbb{E}_{P}\left[-\log P_{\phi}(x,y^{+},y^{-})\right].$$  |  | (10)
L197: where $P_{\phi}(x,y^{+},y^{-})$ is the probability of the triplet $(x,y^{+},y^{-})$ under the distribution $P_{\phi}$. Here, we are trying to fit the full generative model for the triplet distribution $P$. Once we have $\hat{P}_{\phi}$, the learned preference distribution for any unordered pair $\{y,y^{\prime}\}$ is given by
L198: 
L199:  | $$\hat{\omega}_{\phi}(y\succ y^{\prime}\mid x)=\frac{\hat{P}_{\phi}(x,y,y^{\prime})}{\hat{P}_{\phi}(x,y,y^{\prime})+\hat{P}_{\phi}(x,y^{\prime},y)}.$$  |  | (11)
L200: Since minimizing the generative learning objective is equivalent to minimizing the KL divergence between the true distribution $P$ and the generative model $P_{\phi}$ (cite108†White, 1982 ), the generative learning objective have a CPRD recovery guarantee; the learned preference distribution would converge to the true CPRD when the true CPRD belongs to the model space (realizable).
L201: On the other hand, the discriminative objective works directly at the preference level without explicitly modelling the triplet distribution $P$.
L202: The discriminative BT learning objective. For a class of parametric score functions $r_{\theta}:\mathcal{X}\times\mathcal{Y}\to\mathbb{R}$, the discriminative BT learning objective is
L203: 
L204:  | $$\min_{\theta}\mathcal{L}_{\text{BT}}(\theta)=\mathbb{E}_{P}\left[-\log P_{r_{\theta}}(y^{+}\succ y^{-}\mid x)\right].$$  |  | (12)
L205: where $P_{r_{\theta}}(y^{+}\succ y^{-}\mid x)=\sigma(r_{\theta}(x,y^{+})-r_{\theta}(x,y^{-}))$ is the probability of preferring $y^{+}$ over $y^{-}$ given $x$ under the BT model with score function $r_{\theta}$. Once we have $\hat{r}_{\theta}$, the learned preference distribution for any unordered pair $\{y,y^{\prime}\}$ is given by
L206: 
L207:  | $$\hat{\omega}_{\theta}(y\succ y^{\prime}\mid x)=\sigma(\hat{r}_{\theta}(x,y)-\hat{r}_{\theta}(x,y^{\prime})).$$  |  | (13)
L208: In contrast with the generative objective, it is not straightforward to see how this objective would recover the true CPRD. In the next result, we show that this objective is also equivalent to minimizing the KL divergence between the true distribution and the preference distribution induced by the BT model but at the preference level instead of the triplet level.
L209: ###### 5.1 Comparison distribution.
L210: 
L211: For any distribution $P$ over $\mathcal{X}\times\mathcal{Y}\times\mathcal{Y}$, the comparison distribution $\widetilde{P}$ is a distribution over $x$ and an unordered pair $\{y,y^{\prime}\}$ with $y\neq y^{\prime}$ with density
L212: 
L213:  | $$\widetilde{P}(x,\{y,y^{\prime}\})\propto P(x,y,y^{\prime})+P(x,y^{\prime},y).$$  |  | (14)
L214: This distribution essentially captures how often a pair of outcomes $y$ and $y^{\prime}$ are compared together given the context $x$ in the data, regardless of the outcome.
L215: ###### 5.2 Decomposition of the discriminative BT learning objective.
L216: 
L217: The discriminative BT learning objective (cite109†12 ) can be decomposed as
L218: 
L219:  | $\displaystyle\mathcal{L}_{\text{BT}}(\theta)=C+Z\mathop{\mathbb{E}}_{(x,\{y,y^{\prime}\})\sim\widetilde{P}}\Big[D_{\mathrm{KL}}\big(\operatorname{Bern}($  | $\displaystyle\omega_{P}(y\succ y^{\prime}\mid x))$  |
L220:  | $\displaystyle\|\operatorname{Bern}(P_{r_{\theta}}(y\succ y^{\prime}\mid x))\big)\Big]$  |  |  | (15)
L221: where $C$ is independent of $\theta$ and $\operatorname{Bern}(p)$ is the Bernoulli distribution with parameter $p$. $\widetilde{P}$ is a compairson distribution induced by $P$ and $Z$ is its normalizing constant. The CPRD $\omega_{P}$ in equation (cite110†15 ) is well-defined whenever $\widetilde{P}(x,\{y,y^{\prime}\})>0$.
L222: 
L223: Proof in Appendix cite31†B .
L224: The KL divergence term in equation (cite110†15 ) is independent of the ordering of $y$ and $y^{\prime}$ and therefore it is well-defined for any $(x,\{y,y^{\prime}\})$. As a direct consequence of this Theorem, whenever the CPRD is BT model, the minimizer of the discriminative BT learning objective (cite109†12 ) would recover the true CPRD almost surely.
L225: ###### 5.3.
L226: 
L227: For any distribution $P$ such that its CPRD is representable by a BT model, the global minimizer $\hat{r}_{\theta}$ of the discriminative BT learning objective (cite109†12 ) satisfies
L228: 
L229:  | $$P_{\hat{r}_{\theta}}(y\succ y^{\prime}\mid x)=\omega_{P}(y\succ y^{\prime}\mid x)$$  |  | (16)
L230: 
L231: for $\widetilde{P}$-almost every unordered comparison $(x,\{y,y^{\prime}\})$.
L232: 
L233: Proof in Appendix cite31†B .
L234: Combining with the previous result (Theorem cite111†4.4 ), we have a recovery guarantee under the conditional independence assumption.
L235: ###### 5.4 Consistency under conditional independence.
L236: 
L237: Assume that $P$ satisfies positive–negative conditional independence. If the BT model family contains a parameter $\theta^{*}$ such that $P_{r_{\theta}^{*}}(y\succ y^{\prime}\mid x)=\omega_{P}(y\succ y^{\prime}\mid x)$, then
L238: 
L239:   1. 1.
L240: 
L241: $\theta^{*}$ minimizes the discriminative BT learning objective (cite109†12 )
L242: 
L243:   2. 2.
L244: 
L245: Any global minimizer $\hat{\theta}$ of the discriminative BT learning objective (cite109†12 ) satisfies
L246:  | $$P_{\hat{r}_{\theta}}(y\succ y^{\prime}\mid x)=\omega_{P}(y\succ y^{\prime}\mid x)$$  |  | (17)
L247: 
L248: for $\widetilde{P}$-almost every unordered comparison $(x,\{y,y^{\prime}\})$.
L249: 
L250: Proof in Appendix cite31†B .
L251: To summarize, the generative and discriminative learning objectives both have a clean statistical interpretation of minimizing the KL divergence between the true distribution and the preference distribution induced by our model. The former is on the triplet level, while the latter is on the preference level. Whenever the model space is realizable, both objectives would recover the true CPRD almost surely.
L252: When the assumption fails, they converge to an explicit projection of the true CPRD on to the model family. For discriminative objective, this is a positive–negative conditional independent distribution.
L253: ## 6 Learning Score Functions from Pairwise Comparisons
L254: 
L255: We have established that the BT objective is a consistent learning objective for CPRD. However, in practice, we only have access to a finite number of triplets, it is not clear how fast the learned score function converges to the target score function (sample complexity).
L256: In this section, we fix a score function $r^{*}:\mathcal{X}\times\mathcal{Y}\to\mathbb{R}$ as a target and study the impact of the data distribution $P$ on the sample complexity for recovering $r^{*}$. The first natural question is how to design a distribution of triplets to learn a desired score function.
L257: Recall from Theorem cite111†4.4 that if a distribution $P$ satisfies positive–negative conditional independence, then its CPRD is given by a BT model with a score function $r(x,y)=\log\frac{p_{+}(y\mid x)}{p_{-}(y\mid x)}$. We can reverse engineer this: for any target score function $r^{*}(x,y)$, any positive–negative conditional independence distribution $P$ that satisfies $p_{+}(y\mid x)=\exp(r^{*}(x,y))p_{-}(y\mid x)$ would recover $r^{*}$ with the BT model.
L258: We call this pair of conditional distributions BT-consistent (with respect to $r^{*}$).
L259: ###### 6.1.
L260: 
L261: Let $r^{*}:\mathcal{X}\times\mathcal{Y}\to\mathbb{R}$ be a target score function. A pair of conditional distributions $p_{+}(\cdot\mid x)$ and $p_{-}(\cdot\mid x)$ is BT-consistent with respect to $r^{*}$ if
L262: 
L263:  | $$p_{+}(y\mid x)=\exp(r^{*}(x,y))p_{-}(y\mid x)$$  |  | (18)
L264: 
L265: for all $x$ and $y$.
L266: The score function from fitting a BT model on any pair $(p_{+},p_{-})$ that is BT-consistent would recover $r^{*}(x,y)$. This answers our first question on how to design a distribution of triplets to learn a desired score function. Since, $p_{-}$ is not necessarily unique, do different choices of $(p_{+},p_{-})$ lead to different sample complexity? We will address this question in the following subsections. We start by defining the accuracy of a score function.
L267: Here, we measure the accuracy in terms of the agreement of the ordering of scores.
L268: ###### 6.2 Margin.
L269: 
L270: For any score function $r$ and any context $x$ and responses $y,y^{\prime}$, the pairwise margin of $r$ is given by
L271: 
L272:  | $$\Delta_{r}(x;y,y^{\prime}):=r(x,y)-r(x,y^{\prime})$$  |  | (19)
L273: ###### 6.3 Accuracy of a score function.
L274: 
L275: Let $Q$ be a distribution over $(x,y)$, we define $Q_{\text{pair}}$ as a distribution over $(x,y,y^{\prime})$ where $x\sim Q_{x}$ and $y,y^{\prime}\sim^{iid}Q_{y}(y\mid x)$. The accuracy of a score function $r$ with respect to the target score $r^{*}$ and $Q$ is defined as
L276: 
L277:  | $$\operatorname{Acc}_{Q}(r)=\Pr_{\begin{subarray}{c}x,y,y^{\prime}\sim Q_{\text{pair}}\end{subarray}}[\operatorname{sign}(\Delta_{r})=\operatorname{sign}(\Delta_{r^{*}})]$$  |  | (20)
