L63: In this paper, we bridge the gap between LLM knowledge and robotic planning by proving that agents capable of achieving task-agnostic, language-conditioned intents necessarily possess predictive partial-world models (Theorem 1). We show that these models, informed by distribution-robust affordances, enable provably efficient search by focusing only on relevant state-action transitions (Theorem 2).

L74: ## 2 Preliminaries
L75: #### Problem Setting.
L76: We consider table-top robotics tasks $T^{1},T^{2},\dots T^{N}$ drawn from a distribution of related tasks i.e.
L77: $T^{i}\sim\text{Dist}(\mathcal{T})$, where each task $T^{i}=\langle{\cal S},{\cal A},r^{i},P^{i},\gamma\rangle$ can be viewed as a Markov Decision Process (MDP), comprised of a set of states ${\cal S}$, a set of actions ${\cal A}$, transition dynamics model $P^{i}(s^{\prime}|s,a)\sim\text{Dist}(\mathcal{P})$ and reward function $r^{i}(s)\sim\text{Dist}(\mathcal{R})$, with a fixed distribution of initial states. Robotic tasks typically use fine-grained primitive actions e.g.
L78: joint angles of a robot arm, resulting in a complex action space. Therefore, it is common in practice to work with abstract actions (i.e., controllers or options) $o\in{\cal O}$ consisting of predefined low level policies for achieving short term goals, e.g. pick up an orange block and place it at location $x,y$. The coordinates associated with block locations depend on the bounds of the physical workspace of the robot gripper.
L79: For a task $T^{i}$, the dynamics models in this paper focuses on $P^{i}(s^{\prime}|s,o)$, that is, the state $s^{\prime}$ after execution of the abstract action (or option) $o$ is completed starting at state $s\in{\cal S}$. Equivalently we will use $P^{i}(\tau|s,o))$ for full trajectories (i.e. all state-actions from the start to the end of an abstract action execution).
L80: Model-based Reinforcement Learning (MBRL) usually considers models of the environment that approximate the true model $r^{i},P^{i}$. The focus is typically on models that can produce samples of future states. An approximate model $\hat{M}:\langle\hat{r},\hat{P}\rangle$^{1}^{1} 1 For simplicity, in this paper we only model transition dynamics $\hat{P}$ and assume the reward function is known through the simulator.
L81: can be leveraged to approximate the optimal policy of the corresponding approximate MDP $\hat{M}$ through a planning or search process. Starting at any state $s$, the model can be used to generate ‘rollouts‘ or trajectories modeled with $\langle\hat{r},\hat{P}\rangle$ and these are used to provide value estimates for action choices $(s,o)$ starting at $s$. The corresponding policy would then select the action with the highest value estimate.
L82: Traditionally, world models have been learned from data; during planning, in the setting of a generative model, the model is called repeatedly to generate samples of next states from given states and actions, with the number of calls referred to as the sample complexity.
L83: Partial Models. Learning an accurate model can be quite difficult, requiring a lot of data. Moreover, the model does not need to be accurate everywhere, as long as it is accurate in relevant places, and/or it provides useful information for identifying good actions. A useful approach is to build partial models (cite35†Talvitie and Singh, 2009 ), which only make predictions for specific parts of the state-action space.
L84: Partial models come in two flavors: predicting only the outcome of a subset of state-action pairs, or making predictions only about certain parts of the state space.
L85: Affordances. Building on work from cite40†Khetarpal et al. (2021) , we consider partial models of the world that make predictions about the consequences of abstract actions in a given state ${\hat{P}}(s^{\prime}|s,o)$ for which we leverage the notions of intents and affordances.
L86: Definition 1 (Temporally Extended Intent ${\rm I}_{o}$ (cite40†Khetarpal et al., 2021 )): A temporally extended intent of abstract action $o\in\mathcal{O}$, ${\rm I}_{o}:\mathcal{S}\to\text{Dist}(\Gamma)$ specifies for each state $s$, a probability distribution over the space of trajectories ${\Gamma}$, describing the intended result of executing $o$ in $s$. The associated intent model (i.e.
L87: the intended probability of a trajectory $\tau$ when option $o$ is executed from state $s$) is denoted by $P_{I}(\tau|s,o)=I_{o}(s,\tau)$.
L88: Definition 2 (Degree of intent satisfiability $\zeta$): A temporally extended intent ${\rm I}_{o}$ is satisfied to degree $\zeta$ iff $d(P_{I}(\tau|s,o),P_{truth}(\tau|s,o))\leq\zeta,\forall(s,o,\tau)$^{2}^{2} 2 In the context of multi-task setting, $P_{truth}$ is the true distribution associated to a specific task $P_{truth}(\cdot|T_{i})$., where $d$ is a user-specified metric between probability distributions and $\tau$ denotes the trajectory starting in state $s$ and following the abstract action $o$.
L89: A set of intents ${\cal I}$ has satisfiability $\zeta$ iff all its elements have satisfiability $\zeta$.
L90: Definition cite8†2 describes what an agent expects to happen when it executes an abstract action (e.g. pick-up-orange-block). Rather than defining a single success state, the intent is a distribution over entire trajectories, allowing variability into how a task might be completed. This view is essential in evaluating whether abstract actions are afforded. An intent is "satisfied" (Definition cite51†2 )) only when the realized outcome is sufficiently "close" to the true distribution (i.e.
L91: true agent-environment specification).
L92: Definition 3 ($\zeta$-affordance (cite40†Khetarpal et al., 2021 )): Given a set of temporally extended intents ${\cal I}=\bigcup_{o\in\mathcal{O}}{\rm I}_{o}$, a $\zeta$-affordance set is a subset ${{\mathcal{A}\mathcal{F}}_{{\cal I}}}\subseteq{\cal S}\times\mathcal{O}$, such that $d(P_{I}(\tau|s,o),P_{truth}(\tau|s,o))\leq\zeta,\forall(s,o)~\in~{{\mathcal{A}\mathcal{F}}_{{\cal I}}}$.
L93: An affordance is equivalent to a selection of state-action pairs that are likely to achieve corresponding intents (Definition cite8†2 ). For example, the robot hand is right next to the block; if it runs the pick-up-block action, the block ends up in the gripper, the intent is met and pick-up-block is an affordance. The robot hand is across the room; if it runs the pick-up-block action, it grabs thin air. The intent (block in hand) is not met, hence pick-up-block is not an affordance.
L94: Large Language Models (LLMs) are trained to learn a distribution of the next tokens conditioned on the contexts from the training data. Interestingly, language generation has been well studied as a sequential decision-making problem and language modeling can indeed be understood as an instance of imitation learning (cite52†Arora et al., 2022 ). LLMs have the potential to do well on various reasoning problems (cite53†Valmeekam et al., 2022 ), albeit using reasoning traces generated in an autoregressive manner.
L95: They have also been hypothesized to encode knowledge akin to world models (cite33†Hao et al., 2023 ), due to extensive pre-training on vast amounts of human data. In the following section, we leverage LLMs as approximate dynamics world models $\hat{P}(s^{\prime}|s,o)$, to predict future states given start state $s$ and an abstract action $o$. Experimental work will be reported on table top tasks and we assume access to low-level policies for a set of abstract actions.
L96: This is departure from prior work (cite26†Khetarpal et al., 2020 ; cite40†Khetarpal et al., 2021 ), where the impact of using affordances to learn partial models was studied in toy domains with hand-designed programs that specified intent-completion functions and learned tabula rasa. The latter is unfeasible in table-top domains, making it an interesting setting for LLMs as partial models in search and planning.
L97: ## 3 Generalized Affordance Framework
L98: We extend the theoretical framework of affordances (cite26†Khetarpal et al., 2020 ) from single-task to multi-task RL. Our approach, illustrated in Fig. cite42†1 , centers on three primary axes: the agent defined by the robot embodiment e.g. a robot arm gripper, the environment defined by the bounds of the robot’s physical workspace e.g. a table top, and the distribution of tasks.
L99: In this setting, sequential decision making tasks are sampled from this distribution $\mathcal{T}^{i}\sim\mathcal{T}$ comprising a set of tasks related to each other. Once defined, the distribution is used for planning and evaluation. While affordances are fundamentally a function of both the agent and the environment (cite54†Chemero, 2003 ; cite36†Gibson, 1977 ), this dependency becomes uniquely pronounced in multi-task scenarios, as detailed in the following sections.
L100: Intents. Formally, we characterize the set of all intents ${\cal I}={\cal I}_{agn}\cup{\cal I}_{task}$ in two classes; 1) task-agnostic intents ${\cal I}_{agn}$, which are based on an agent’s internal dynamics, e.g. a robot embodiment, whereas, 2) task-specific intents ${\cal I}_{task}$ captures the set of intents that the environment or the physical workspace poses, depending on the task presented to the agent.
L101: Task-agnostic intents are the robot’s basic skills (what it can physically do), and Task-specific intents are specific desiderata in specific context (what it is trying to achieve right now). Task-agnostic intents can be achieved simply because of how the robot is built (its embodiment) and what is physically in front of it. These intents are general because they do not depend on what the specific task is. When the robot sees a red block, the pick up red block intent is task-agnostic.
L102: It does not matter if the robot’s job today is to build a tower, clean the table, or sort by color. As long as the red block is visible and nothing is on top of it, the robot can pick it up. Task-specific intents depend heavily on the high-level task with a certain reward specification. These actions are usually complex combinations that lead to a high reward but are only afforded (possible/valid) in very specific situations.
L103: If a the robot is tasked to stack-blocks-while-holding-red-block, and there is a blue block on the table, stack red block on top of blue block intent is task-specific. This action is only meaningful if the current task is build-a-stack. If the task changed to put-all-blocks-in-a-box, stacking them might be useless or even wrong.

L109: Affordances for Multi-Task Setting. We now characterize the set of state-options pairs, namely affordances, that facilitate the completion of task-agnostic or task-specific intents. Prior research  (cite40†Khetarpal et al., 2021 ) has typically ignored the case where we’d need to work with affordances across multiple tasks selected from a fixed distribution.
L110: Ideally, affordances would allow the agent to transfer knowledge between tasks with shared underlying structure. We extend here the definition to a probabilistic statement regarding the satisfiability of particular intents, grounded directly in the sampling distribution for the given tasks.
L111: This allows us to distinguish between distribution-robust agent affordances, which remain achievable with high probability across diverse task configurations (e.g., grasping an unobstructed block), and task-specific affordances, which may only be satisfied in restricted scenario.
L112: For example, in the table-top domain, achieving the intent of grasping a block that has nothing on top should be possible with high probability, consistently across tasks (Fig. cite57†2(a) ), regardless of the block configuration present or desired. However, placing a block inside another one may only be possible in a small number of situations in which there are hollow blocks around of appropriate sizes (Fig. cite58†2(b) ).
L113: Intuitively, knowledge that is shared across the distribution facilitates transfer to improve learning speed, whereas task-specific knowledge ensures the agent can maximize value for the current objective. Formally,
L114: Definition 4 (Distribution-Robust Agent Affordances): Given a distribution of tasks $\text{Dist}(\mathcal{T})$, a set of temporally extended intents ${\cal I}=\bigcup_{o\in\mathcal{O}}{\rm I}_{o}$, and constants $\zeta,\delta\in(0,1)$, a $\zeta$-affordance set ${{\mathcal{A}\mathcal{F}}_{{\cal I}}}$ (see Def. cite8†2 ) is $\delta$-robust to distribution $\text{Dist}(\mathcal{T})$ iff the probability that the affordance does not satisfy the intent ${\rm I}_{o}$ to a degree $\zeta$ in task $T\sim\text{Dist}(\mathcal{T})$ is bounded by $\delta$.
L115: That is, $\forall s,o\in{{\mathcal{A}\mathcal{F}}_{{\cal I}}}$
L116:  | $\displaystyle\begin{split}P\Big(d(P_{I}(\tau|s,o,T),P_{truth}(\tau|s,o,T))&\geq\zeta\;\Big|\\
L117: \;T\sim\text{Dist}(\mathcal{T})\Big)\leq\delta\;.\end{split}$  |  | (1)
L118: 
L119: To illustrate, we refer the reader to Fig. cite59†2 , which depicts a task agnostic intent that satisfies Def. cite9†3 grounded in the distribution of tasks, and an intent which doesn’t meet the desired criteria resulting in a task-specific intent.
L120: Building on the multi-task affordance formalism, we realize generalized framework depicted in Fig. cite42†1 , where an agent accesses an imperfect abstract world dynamics model $P(s^{\prime}|s,o)$. Unlike naive full world models that inefficiently predict over the entire state-action space—often leading to inaccurate Monte-Carlo planning results (Sec. cite14†5.1 )—we induce a partial world model to restrict predictions to a relevant subset.
L121: We input the current state and a set of $k$ pre-defined intents ${\cal I}$ into an affordance model to yield distribution-robust affordances ${{\mathcal{A}\mathcal{F}}_{{\cal I}}}$ (Def cite9†3 ). These affordances constrain the world model’s predictions, substantially reducing the search branching factor and improving action-value estimates for the policy $\pi$.
L122: While the distribution-robust affordances are relevant across tasks, the agent is implicitly informed of task-specific intents via the reward signal during the subsequent environment interaction.
L123: cite60†Image: Refer to caption Figure 3: Improvements in affordance model accuracy results in better performance of the search policy. Given a fixed budget for search, a perfect world model, any errors in affordance prediction translates to catastrophic failures in the search policy.
L124: Illustration. To demonstrate the utility of the generalized affordance framework, we evaluate the pipeline shown in Fig. cite42†1 on a 3-block stacking task using a simulated robot arm. By employing a perfect world model (the simulator) alongside programmatic affordances derived from task-agnostic intents, we examine how varying the accuracy of affordable actions affects search efficacy.
L125: As shown in Fig. cite61†3 , higher affordance model accuracy directly correlates with improved search policy performance (green star). Conversely, mis-specified affordances lead to catastrophic failures regardless of the world model’s fidelity, particularly under constrained search budgets (red star). This highlights that since affordances emerge at the boundary of agent-environment interaction, grounding the agent’s affordance beliefs in an adaptive fashion is critical for robust planning.
L126: ## 4 Theoretical Analysis
L127: 
L128: We now provide a theoretical analysis of the multi-task affordance framework. In Sec. cite11†4.1 , we establish that achieving a set of intents implies the existence of an underlying partial world model through Theorem cite49†1 . In Sec. cite12†4.2 , we study the efficiency in search enabled by partial world models. We show that at a small price, adapting the model enjoys the potential exponential speedup of the partial model, while being robust to missing intents from the full model.
L129: ### 4.1 Distribution-Robust Agent Intents induce Partial World Models
L130: To facilitate the theoretical analysis of our generalized framework, we specialize the class of sequential tasks under consideration. We follow the standard formalism for expressing sequential tasks using linear temporal logic, with a focus on three simple types of tasks: i) actions, taking an (abstract) action $O=o$, ii) outcomes, achieving a desired outcome from an action, denoted $X(s\in g)$ where $g\subseteq\mathcal{S}$, iii) goals, reaching a goal state $F(s\in g)$.
L131: Here $X(s\in g)$ requires the desired state(s) $s$ to be reached as an immediate outcome of the previous (abstract) action $O=o$, and $F(s\in g)$ requires only that the goal state is reached at some point in the future. For example, stack blocks in r / g / b order, $F(S\in g_{rgb})$. To denote tasks comprising of sequences of these primitives we use angular brackets e.g. $T^{i}=\langle o,X(s),\ldots\rangle$. See cite23†Section B.1 for details.
L132: For the purposes of our analysis, we define depth-n tasks (cite62†Nangue Tasse et al., 2020 ).
L133: Definition 5 (Depth-n tasks): Given a set of abstract actions $\mathcal{O}$ and states $\mathcal{S}$, we consider the set of depth-$n$ tasks $\mathcal{T}(n)$ to be the set of tasks $T^{i}$ that can be solved by achieving a sequence of at most $n$ actions, outcomes, or goals e.g. $T^{i}=\langle o_{i,0},\ldots,o_{i,m}\rangle$ where $m\leq n$.
L134: ###### Assumption 1.
L135: 
L136: The MDP with transition function $P(s^{\prime}\mid o,s)$ is communicating (i.e. there exists a policy that gets you from any one state to any other state in a finite number of steps with non-zero probability) (cite63†Bartlett and Tewari, 2012 ), and there exists a state $s$ such that at least two actions are afforded to the agent.
L137: To ground this formulation in planning, an agent is said to be a competent planner when it can achieve high depth-n tasks with a high probability. Formally, the optimal planner for depth-n tasks satisfies,
L138: 
L139:  | $$\pi^{*}(o\mid s,T)=\argmax\limits_{\pi}P_{\pi}(\tau\models T\mid s),\forall\,s\in\mathcal{S},T\in\mathcal{T}(n),$$  |
L140: where $P_{\pi}(\tau\models T\mid s)$ is the probability that the trajectory generated by $\pi$ from initial state $s$ corresponds to achieving the task $T$.
L141: We can then define an agent’s distribution-robust competence for tasks in line with Def. cite9†3 , by choosing the distance metric $d({\rm I}_{o}(s,\tau\mid T),P(\tau\mid\pi,s,T))$ to be the difference in probability mass over trajectories that satisfy the task $T^{i}\in\mathcal{T}$ for the agent, and the corresponding probability mass for the optimal agent with the same affordance set.
L142: We also choose $\text{Dist}(\mathcal{T})$ to be an arbitrary task distribution that includes $\mathcal{T}(n)$, and assume there is some upper bound $\delta$ on the probability that the agent violates the $\zeta$-regret bound for any given task $T^{i}\sim\mathcal{T}(n)$ independent of the agent’s performance on any other task $T^{j}\sim\mathcal{T}(n)$.
L143: Definition 6 ($(n,\zeta,\delta)$-optimal agent): Given affordances ${{\mathcal{A}\mathcal{F}}_{{\cal I}}}$ (Def. cite9†3 ), an $(n,\zeta,\delta)$-optimal agent is such that
L144: 
L145:  | $$P(\mathbf{R}(\pi_{i},T^{i})\geq\zeta\,\mid\;T^{i}\sim\mathcal{T}(n))\leq\delta.$$  |
L146: 
L147: where, $\pi_{i}$ is the policy of the agent for a depth-$n$ task $T^{i}\sim\mathcal{T}(n)$ and
L148: 
L149:  | $$\mathbf{R}(\pi,T^{i}):=\max\limits_{\pi^{\prime}}\left\{P_{\pi^{\prime}}(\tau\models T^{i})\right\}-P_{\pi}(\tau\models T^{i}).$$  |
L150: We can interpret $\mathbf{R}(\pi,T^{i})$ as the agent’s expected regret for task $T^{i}$, where the reward function is $+1$ if the agent achieves the task and $0$ otherwise. Therefore, a $(n,\zeta,\delta)$-optimal agent describes an agent that is a competent planner to depth $n$, where the probability the agent violates a $\zeta$-regret bound for any depth-n task is bounded by some $\delta$.
L151: ###### Theorem 1 (Distribution-Robust Affordances induce Partial World Models).
L152: 
L153: Let $\pi$ be the policy of a deterministic $(n,\zeta,\delta)$-optimal agent (Def. cite11†4.1 ), in an environment satisfying Assumption cite64†1 . $\pi$ encodes a partial world model $\hat{P}_{\mathrm{par}}(s^{\prime}\mid o,s)$, and the worst case error for this world model is bounded by,
L154:  | $$P(\big|\hat{P}_{\mathrm{par}}(s^{\prime}\mid o,s)-P(s^{\prime}\mid o,s)|\big|\geq\phi+\epsilon)\leq\frac{\rho^{n\,\epsilon}}{1-\rho}\;,$$  |
L155: 
L156: $\forall(s,o)\in{{\mathcal{A}\mathcal{F}}_{{\cal I}}}$, where
L157: 
L158:  | $$\phi=\frac{1}{2}\sqrt{\frac{(1+\zeta)}{n\,(1-\zeta)}}\,,\quad\rho=2\sqrt{\delta(1-\delta)}\,\text{, and }\epsilon>0.$$  |
L159: Proof is in Appendix cite23†B.1 . Theorem cite49†1 implies that there is a characteristic scale for the error in the partial world model we can recover from the agent’s policy, given by $\phi$, which scales with $\mathcal{O}(n^{-1/2})$, but increases rapidly for higher intent mis-specification i.e. $\zeta$ close to 1 (where the regret bound becomes very weak).
L160: For $\delta<1/2$ the probability that the error is $\epsilon$ larger than the characteristic error $\phi$ decays exponentially in $\epsilon$, with an exponent given by $n$. From this we conclude that for agents that perform well on a task distribution involving planning over its afforded actions to high depth (n), the agent’s policy encodes an accurate partial world model with respect to those afforded actions.
L161: Specifically, we can recover a partial world model from the agent’s policy that deviates from the true transition probabilities with an error that decays exponentially.
L162: ### 4.2 Partial World Models Enable Provably Efficient Search
L163: We are interested in understanding the increase in search efficiency when using a partial world model $P_{\mathrm{par}}$ as opposed to a full model $P_{\mathrm{full}}$. When sampling from $P_{\mathrm{full}}$, the agent considers all $n=|\mathcal{O}|$ possible actions, which translates to $n=|\mathcal{I}|$ intents.
L164: Alternatively, sampling from $P_{\mathrm{par}}$ is based on a predefined set of $k$ task-agnostic and -specific intents from ${\cal I}$, all independently achievable and satisfied to degree $\zeta$ (Def. cite8†2 ) across a distribution of tasks (Def. cite9†3 ). In other words, $P_{\mathrm{par}}$ has access to $k=|\mathcal{I}_{\mathrm{par}}|$ intents ($\mathcal{I}_{\mathrm{par}}\subseteq\mathcal{I}$).
L165: ###### Assumption 2.
L166: 
L167: The size of the set of task-agnostic agent intents $\mathcal{I}_{\mathrm{par}}$ is finite and much smaller than the number of all possible abstract actions $n=|\mathcal{O}|$ to be considered at any state in the search process: $k\ll n$.
L168: The appeal of a partial model is due to the potential gigantic exponential speedup that can be obtained by greatly reducing the branching factor of complex combinatorial environments: suppose a task can only be solved in the full model by a single specific sequence of $L$ abstract actions, thus having an expected time to success of $n^{L}$. If this task can also be solved with the $k$ intents of the partial model, the latter would take $k^{L}$ steps to success in expectation.
L169: Using Assumption cite65†2 , the speed up from the partial model can be so large as to make the intractable task tractable.
L170: However, the pre-specified intents might not be perfectly aligned, or worse, if the partial model misses any necessary intent to solve any task, the expected number of trials to solve every task by the partial model $N^{\mathrm{par}}$ is infinite. To protect against this, we define a corrected partial model $P_{\mathrm{cor}}$ which assigns a small probability $\varepsilon_{\mathrm{cor}}{}$ to account for missing intents from the full model: for each intent $I_{j}$,
L171:  | $$P_{\mathrm{cor}}(I_{j}\mid\varepsilon_{\mathrm{cor}}{})\\
L172: =(1-\varepsilon_{\mathrm{cor}}{})\frac{1}{k}\left\llbracket{I_{j}\in\mathcal{I}_{\mathrm{par}}}\right\rrbracket+\varepsilon_{\mathrm{cor}}{}\frac{1}{n-k}\left\llbracket{I_{j}\notin\mathcal{I}_{\mathrm{par}}}\right\rrbracket\,.$$  |
L173: Note that setting $\varepsilon_{\mathrm{cor}}{}=0$ recovers the partial model, while $\varepsilon_{\mathrm{cor}}{}=(n-k)/n$ recovers the full model. Moreover, we develop an adaptive model $P_{\mathrm{ada}}$ (see cite24†Section B.2 ) that automatically competes with the optimal $\varepsilon_{\mathrm{cor}}{}$ for each task, at the cost of a small $O(L)$ factor:
L174: ###### Theorem 2 (Provably Efficient Search with a Partial Model).
L175: 
L176: The expected number of samples necessary for the adaptive corrected partial model to solve every task is at most a factor $O(L)$ of the best corrected model for each task:
L177: 
L178:  | $$N^{\mathrm{ada}}\leq e(2L+3)\sum_{i\leq|\mathcal{T}|}\frac{1}{\max_{\varepsilon_{\mathrm{cor}}{}\in[0,1]}P_{\mathrm{cor}}(\mathrm{success}_{i}|\varepsilon_{\mathrm{cor}}{})}$$  |
L179: 
L180: where $L$ is the length of the sampled sequences of intents.
L181: Proof is in cite24†Section B.2 . The intuition here is that at the price of a small factor $(2L+3)e$, the adaptive corrected model enjoys the potential exponential speedup of the partial model, while being robust to missing intents from the model.
