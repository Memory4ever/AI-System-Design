The next theorem makes this explicit by upper-bounding the Forget Error of the untempered estimator, showing that it may degrade even when the Retain Error is small.

L256: ### 4.2 Empirical Results
L257: We use the OpenUnlearning [cite100†DMZMKLM25 ] implementation of TOFU along with the baseline methods GradAscent, GradDiff, IdkDPO [cite72†MFSLK24 ]; WGA [cite80†WZZSHW25 ]; SatImp [cite81†YWHLZH25 ]; UnDIAL [cite82†DLBHV25 ]; RMU [cite83†LPGYBGLDGM+24 ]; ULD [cite87†JLZLKLC24 ]; NPO [cite84†ZLBM24 ]; and SimNPO [cite85†FLLJZML25 ]. We use the Llama 3.1 8B model [cite101†Lla24 ] and evaluate the tasks of forgetting 5% and 10% of the authors.
L258: To evaluate each method, we tune hyperparameters using random seeds 1 and 2 and select the best-performing configuration. In this multi-objective setting, we prioritize Forget Quality, since a utility-focused method could simply return the original model. See Appendix cite36†F.3 for details.
L259: Average results over 5 trials are reported in Table cite102†1 (see Appendix cite38†F.3.2 for per-trial results). The summary metrics FQ and MU-ROUGE are shaded, with T3-Unlearning highlighted in the bottom row. T3-Unlearning consistently outperforms all baselines in Forget Quality, and achieves highest MU-ROUGE among methods with competitive Forget Quality, demonstrating a favorable utility–forgetting tradeoff.
L260: Baselines like SimNPO can achieve higher Model Utility, as the tempering of T3-Unlearning can lower absolute probabilities without degrading the generation quality, indicated by the strong MU-ROUGE scores. We thus find Model Utility to be an unreliable utility metric, as it can even exceed the utility of the original model before unlearning without corresponding improvements in its generations.
L261: In contrast, MU-ROUGE provides a more faithful measure of utility, as it does not meaningfully exceed the original model’s performance after unlearning.

L906: ### F.3 TOFU Experiments
L907: 
L908: We explain our experimental setup in detail. To evaluate each unlearning method, we perform a grid search over hyperparameter configurations using random seeds 1 and 2, selecting the configuration that achieves the best performance. Since we aim to maximize multiple objectives, we select the parameter configuration that maximizes the Forget Quality, since a method optimized for a model utility metric could simply return the original model without any unlearning.
L909: We used the OpenUnlearning [cite100†DMZMKLM25 ] implementation of TOFU and all baselines except for ULD which does not have an official OpenUnlearning implementation. For consistency, we implemented ULD within the OpenUnlearning codebase. We used the Llama 3.1 8B model.
L910: All experiments were conducted on a single NVIDIA GH200, using the AdamW optimizer [cite142†LH19 ] and a linear learning rate scheduler with both warmup and decay for all methods. For the parameter-efficient methods ULD and T3-Unlearning, we use a batch size of 32 with no gradient accumulation and ZeRO stage 0 [cite143†RRRH20 ]. For all other methods, we use a batch size of 8 with gradient accumulation over 4 steps (effective batch size 32) and ZeRO stage 3.
