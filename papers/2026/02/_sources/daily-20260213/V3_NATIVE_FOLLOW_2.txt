## [2.3.6] - 2026-02-14

### Added

  * `--live` heartbeat: Shows `[AI Runner] Working... Ns` on stderr during silent gaps (tool calls, model thinking). Auto-hides when AI output streams, auto-restarts after 3s of silence. Bash 3.2 compatible via file-based signaling.
  * `--quiet` / `-q` flag: Suppresses `--live` status messages for clean CI/CD output. Overrides `--live` from shebangs. `print_error` and `print_warning` are NOT suppressed.
  * Composable scripts docs: New section in `docs/SCRIPTING.md` covering `--cc` tool selection, dispatcher pattern, chaining, and long-running scripts.
  * Andi-promote guide: `resources/ANDI-PROMOTE.md` with entry patterns and progress visibility.

### Fixed

  * Nested `claude -p` calls: Clear `CLAUDECODE` env var in process isolation block, allowing child `ai` scripts to call `claude -p` (prompt mode) from within a parent `--cc` session.
  * Setup model update prompt: No longer triggers on comment-only changes in `config/models.sh`. The "model overrides in secrets.sh" warning now only fires for uncommented (active) overrides.

### Changed

  * Ollama cloud models: Updated `glm-4.7:cloud` → `glm-5:cloud` (recommended for coding), added `minimax-m2.5:cloud`. Updated across README, PROVIDERS.md, ollama.sh, and model recommendations.

## [2.3.5] - 2026-02-13

### Fixed

  * `--live` YAML frontmatter support: Split pattern now recognizes `---` (frontmatter) in addition to `#` (heading) as a content marker, so scripts generating YAML frontmatter output correctly send it to stdout when redirected to a file

## [2.3.4] - 2026-02-12

### Fixed

  * `--live` output splitting: System prompt no longer hints at markdown headings, improving non-markdown output (code, JSON, plain text)
  * `--live` "Done" message: Changed "written to file" to "written" — the message appears for pipes too, not just file redirects

### Improved

  * `--live` documentation: Explain turn-level streaming granularity and the need for narration instructions in prompts (e.g., "print your findings as you go") for intermediate output to stream

## [2.3.3] - 2026-02-12

# Announcement

Since next week is holiday for China, we will be skipping next week's call on February 19.

# Agenda

  * Preparation for training ML models for Trucks, including selection of models that we use and dataset for training/evaluation
  * Development plan for vehicle adaptor

# Meeting Updates

  * Truck reference design document
    * Dexin is working on the reference design document
    * We want to see the size of the vehicle, sensor configurations (numbers, placement, FOV)
    * We will focus on heavy duty truck
    * @mitsudome-r shared the write access to Shared Google Drive to Dexin.
  * Dataset Evaluation
    * Mitsudome ran used trained model from PoV WG against Man Truck Dataset.
    * Since the cameras for the dataset was placed at the right corner for the vehicle, the detection of left/right lane lines were unstable for many scenes.
    * Mitsudome will continue to try inference on other dataset shared in the previous call.

  * ODD Discussion
    * Talked with Diego-san
    * Diego-san will create a draft for Truck ODD
  * Competitor investigation
    * @dexinli20 has created a summarized document for different truck companies in the market.
    * After Dexin shares the document on Google Drive we will discuss about which companies to have a deeper investigation.
      * Aurora, Gatik, and Kodiak could be good candidates
