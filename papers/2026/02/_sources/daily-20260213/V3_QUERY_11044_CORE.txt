L168: ## 3 Method: Differentiable language models
L169: 
L170: Let $\mathbf{x}$ be a prompt containing a sequence of $N$ tokens and $\mathbf{y}=f_{\theta}(\mathbf{x})$ be the corresponding $M-$token output of a pretrained, frozen LM $f_{\theta}$ with parameters $\theta$. Denoting $\mathcal{V}$ as the vocabulary over which $f_{\theta}$ is defined, then $\mathbf{x}\in\mathcal{V}^{N}$, $\mathbf{y}\in\mathcal{V}^{M}$ and $f_{\theta}:\mathcal{V}^{*}\rightarrow\mathcal{V}^{*}$.
L171: Given a target output $\mathbf{y}$ and a distance function $d:\mathcal{V}^{*}\times\mathcal{V}^{*}\rightarrow\mathbb{R}$ defined over the space of tokens, Language Model Inversion (LMI) aims to recover a prompt $\mathbf{x}$ such that
L172: 
L173:  | $\displaystyle\,\,\mathbf{x}=\underset{\mathbf{p}\in\mathcal{V}^{N}}{\mathrm{argmin}}\;d(f_{\theta}(\mathbf{p}),\;\mathbf{y})$  |  | (4)
L174: ### 3.1 From tokens to distributions over tokens
L175: We redefine LMs from their traditional view as functions from sequences of prompt tokens $\mathbf{x}$ to sequences of output tokens $\mathbf{y}$. Instead, we treat it as a function $\tilde{f}_{\theta}:\mathcal{P}^{*}(\mathcal{V})\rightarrow\mathcal{P}^{*}(\mathcal{V})$ from and to the space of probability distributions $\mathcal{P}(\mathcal{V})$ over vocabulary $\mathcal{V}$. We refer to $\tilde{f}_{\theta}$ as a Differentiable Language Model (DLM).
L176: In this context, rather than discussing input prompt $\mathbf{x}$ or target sequence $\mathbf{y}$, we deal with sequences of distributions over tokens (SDoT) $\tilde{\mathbf{x}},\tilde{\mathbf{y}}\in\mathcal{P}^{*}(\mathcal{V})$.
L177: The key insight is that it facilitates differentiation through the hard embedding and next-token sampling modules, which in turn leads to end-to-end differentiability.
L178: Given an SDoT input $\tilde{\mathbf{x}}$, we can swap the hard embedding module for a soft embedding module $\tilde{E}:\mathcal{P}(\mathcal{V})\rightarrow\mathbb{R}^{d}$ which is implemented as: $\tilde{E}(\tilde{\mathbf{x}}_{i})=\mathbf{W}_{E}\cdot\tilde{\mathbf{x}}_{i}$ where $\mathbf{W}_{E}\in\mathbb{R}^{|\mathcal{V}|\times d}$ is the embedding matrix and the resulting implementation acts like a soft attention over the vocabulary embeddings, with weightings proportional to the likelihood of each token in the $i$-th distribution over tokens in the SDoT input $\tilde{\mathbf{x}}$.
L179: ### 3.2 Gradients: Next-token samples, learnable prompts
L180: With the input interface of LMs addressed via the soft embedding module, it remains to update its output interface, i.e. the next-token sampling module. We use the Gumbel-Softmax (GS) reparameterization trick (cite50†Jang et al., 2017 ; cite49†Maddison et al., 2017 ) to build a GS-based next-token sampling module that is differentiable. As detailed in Section cite7†2 , the GS distribution is designed to enable gradient-based optimisation through discrete, stochastic operations.
L181: The GS distribution approaches the true categorical distribution it simulates as $\tau\to 0$ or a uniform distribution as $\tau\to\infty$.
L182: Moreover, within the context of the LMI problem, we represent the $N$-token long learnable prompt $\mathbf{x}\in\mathcal{V}^{N}$ as a sequence of categorical distributions over tokens with a sequence of unnormalized logits $\mathbf{z}\in\mathbb{R}^{N\times V}$. We thus allow gradient backpropagation into $\mathbf{z}$ by means of another GS gradient estimator.
L183: ### 3.3 Learnable Temperature Parameters for Gradients
L184: Within the context of the GS gradient estimator over the learnable prompt $\mathbf{x}$ along, we follow  cite52†Havrylov and Titov (2017) and derive the temperature $\tau$ from a learnable parameter $\phi$, optimized alongside the learnable logits $\mathbf{Z}$ representing the learnable prompt $\mathbf{x}$, as $\tau_{\text{eff}}=\epsilon+\tau_{0}\cdot(1+\tanh(\phi))$ where $\tau_{0}$ is an initial temperature parameter.
L185: This allows the optimization to automatically navigate the bias-variance trade-off inherent to GS-based gradient estimators. We expand this trick by decoupling the temperature for each learnable logit in $\mathbf{Z}$, thus learning a vector $\mathbf{\Phi}\in\mathbb{R}^{N}$, that enables automatically navigating the bias-variance trade-off for each logit’s GS-based gradient estimation.
L186: ### 3.4 Algorithm: Differentiable LM Inversion (DLMI)
L187: 
L188: Our approach combines four elements: The distributional viewpoint via soft embedding & GS-based next-token sampling; GS gradient estimator for the learnable prompt; decoupled, learnable temperature parameters; and and Teacher Forcing (TF -  cite70†Williams and Zipser (1989) ).
L189: We jointly optimise learnable input logits $\mathbf{Z}\in\mathbb{R}^{N\times|\mathcal{V}|}$ and learnable parameters $\mathbf{\Phi}\in\mathbb{R}^{N}$ such that a frozen LM $f_{\theta}$ produces a given target output $\mathbf{y}\in\mathcal{V}^{*}$, via gradient descent through its differentiable counterpart $\tilde{f}_{\theta}$.
L190: The input logits represent the $N$-token prompt to be recovered and $\mathbf{\Phi}$ (one for each input logit’s GS gradient estimation) is used to derive decoupled temperatures $\mathbf{\tau}\in\mathbb{R}^{N}$.
L191: Algorithm cite71†1 presents the optimisation procedure with a GS gradient estimator on the sampling computational branch that stems from the learnable logits $\mathbf{z}$.
L192: Line $10$ implements Teacher-Forcing (TF) where the returned distribution over tokens $\hat{\mathbf{y}}\in\mathcal{P}^{M}(\mathcal{V})$ uses a $\tau=1$-tempered softmax operation without Gumbel noise injection. In the ablation study, we test this algorithm without TF (line 10 is replaced with $\hat{\mathbf{y}}$ computed as the softmax over the unnormalized logits return by the Vocabulary Projection module - cf. Figure cite45†1 ).
