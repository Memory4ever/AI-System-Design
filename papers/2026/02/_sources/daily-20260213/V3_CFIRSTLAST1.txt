L665: ## Appendix G Subword Tokenizers
L666: 
L667: In recent large language models (LLMs), subword tokenizers such as GPT-2 and LLaMA are often used; these differ significantly from word-level tokenizers such as GloVe. Accordingly, we also conducted experiments using meta-llama/Llama-2-7b-hf model cite123†Touvron et al. [2023] , a subword tokenizer, on FineWeb-Edu/sample-10BT dataset (8.6B tokens with the GloVe tokenizer, 11.2B tokens with the LLaMA-2 tokenizer).
L668: Qualitative Evaluation. cite216†Table 13 shows the results when we searched for “gold medal” and “chocolate”. For the first query, the results are as expected, although the similarity is lower than that of the GloVe tokenizer, and many case-substitutions are displayed because the LLaMA-2 tokenizer is case-sensitive. For the second query, however, the output includes many spurious matches.
L669: This is because, in LLaMA-2, the word “chocolate” is tokenized as [“ch”, “oc”, “olate”], and the top-$K$ patterns are determined by the cosine similarities of individual tokens. However, more than 83% of word occurrences in this corpus were not split into multiple tokens, and cases such as “chocolate” are rare. Therefore, we expect our method to work reasonably well (especially after aligning uppercase and lowercase letters).
L670: Latency. When we set the similarity threshold to 0.1, we achieved a median latency of 57.86 ms and a p95 latency of 145.90 ms for outputting the top $K=20$ patterns, which is comparable to that of the word-level tokenizer. Of the 400 cases, 8 failed because the number of tokens exceeded the upper limit of 12 (see cite38†Appendix H ). Of the remaining 392 cases, the program returned the maximum of 20 patterns in 199 cases (51%) and at least 1 pattern in 341 cases (87%).
L671: ## Appendix H Details of the Fast Disk-Aware Suffix Array in cite13†§​ 3.2 L672: 
L673: As explained in cite13†§​ 3.2 , we also improve the suffix array to further improve the efficiency of exact lookup. The core ideas are (1) to exploit the fact that queries are usually short (10 tokens or fewer) and (2) to store some indices in RAM to reduce the number of random disk accesses.
L674: Let $L$ be the maximum query length (in our experiments, we used $L=12$). The first step is to record a sorted array of all contiguous $L$ patterns in the corpus (i.e., the array has length $\lvert\mathcal{C}\rvert-L+1$), instead of the suffix array; we denote this array by $X$. By binary search on $X$, we can count the number of occurrences of the query string $\bar{q}$ in the corpus. However, it still requires $O(\log\,\lvert\mathcal{C}\rvert)$ random disk accesses.
L675: We further reduce the number of accesses using a two-level indexing strategy, similar to Google’s BigTable cite114†Chang et al. [2008] , described below.
L676: Let $B$ be a constant.^{14}^{14} 14 In our experiments, we use $B$ between 128–256. In addition to $X$, we construct a sparse array $Y=[X_{0},X_{B},X_{2B},\dots]$, where $X_{i}$ is the $i$-th element of the array $X$. This array is stored in RAM.
L677: When we search for the position of an occurrence of query $\bar{q}$, we first find the approximate position (i.e., such $i$ that $\bar{q}$ occurs in $Z=[X_{iB},X_{iB+1},\dots,X_{(i+1)B-1}]$ if it exists in $X$) using $Y$, and then find the exact position in $X$ using $Z$.
L678: Surprisingly, only a single random disk access is required, significantly fewer than the $O(\log\,\lvert\mathcal{C}\rvert)$ accesses required by a standard suffix array if $B$ is set appropriately so that $B/2$ is smaller than the page size of operating systems. This is because the range of the array $X$ examined (in the second step of binary search) is at most $B/2$ entries.
L679: Example. An example is shown in cite217†Figure 14 . To find the position of “pattern match”, we first search $Y$ and determine that the position lies between indices 3 and 6. We then search $X$ and find that the exact position is index 4.
L680: 
L681: Figure 14: The sketch of our fast suffix array for the text “pattern match for a trillion scale corpus”, with $L=2$ and $B=3$.
L682: Compression. This method requires substantial disk space. Let $V$ be the vocabulary size; then the size of $X$ is $n\lceil(L\log_{2}V)/8\rceil$ bytes (e.g., $29n$ bytes when $L=12$ and $V=400\text{K}$). To address this problem, we apply run-length compression to $X$, exploiting the many duplicate sequences that arise primarily from citations.
L683: ## Appendix I Details of Dynamic Corpus-Aware Pruning in cite14†§​ 3.3 L684: 
L685: As explained in cite14†§​ 3.3 , we introduced two additional techniques, in addition to iterative pruning.
L686: ### I.1 $k$-gram Pruning: Caching 2-gram and 3-gram Existence
L687: To reduce the number of corpus-existence check that requires disk access, we store precomputed 2-gram and 3-gram existence tables in RAM. Specifically, we record (1) all 2-grams both of whose constituent words rank among the top 100K most frequent words and (2) all 3-grams whose three constituent words have frequency ranks that sum to 10K or less.
L688: When calculating $L_{1},L_{2},\dots$ (see cite14†§​ 3.3 ), if a 2-gram or 3-gram meets the frequency-rank conditions above (and thus would appear in the table if it existed in the corpus), we skip the corpus lookup when it is absent from the tables.
L689: ### I.2 Last-Bits Pruning: For Patterns with Low Frequencies
L690: Suppose the situation that in cite115†Algorithm 1 , the current pattern $w\in L_{i-1}$ appears only once in the corpus. In this case, it is inefficient to search for $w\cdot w^{\prime}$ for all $w^{\prime}\in\mathcal{V}^{*}$ with similarity $\alpha$ or more. Instead, it is better to look at the corpus directly and find the next tokens. We applied this method when the number of occurrences (after run-length compression of array $X$ in cite38†Appendix H ) is 50 or less.
L691: ### I.3 Effects on Pruning
L692: Next, we show the effectiveness of each pruning in terms of latency. cite218†Figure 15 shows the p95 and p99 latencies (1) when we only applied iterative pruning; (2) when we applied iterative pruning and $k$-gram pruning; and (3) when we applied all of iterative pruning, $k$-gram pruning, and last-bits pruning. It works well in smaller corpora; the p99 latencies improved by 1.45x or more for corpora smaller than 20B tokens.
L693: Note that the improvement in latency was not as strong as the improvement in the number of searches (see cite19†§​ 5.3 ), mainly due to the page cache.
L694: Figure 15: The improvement on p95 and p99 latencies when we applied pruning for FineWeb-Edu dataset. Note that if we do not even apply the iterative pruning, both p95 and p99 latencies were 10+ sec (timeout) for all of the corpus sizes.

L697: Correctness.

L699: We note the following lemma, which is vital for the correctness of cite115†Algorithm 1 .
L700: 
L701: ###### Lemma 1.
L702: 
L703: $L_{i}=\{w\in S_{i}\mid w\ \text{occurs in}\ \mathcal{C}\}$ for each $i$.
L704: ###### Proof.
L705: 
L706: By induction over $i$. ∎
L707: 
L708: Basics.
L709: 
L710: We use $\mathbf{E}\left[\cdots\right]$ for the expected value (over some appropriate stochastic space).
L711: 
L712: We introduce the following hypothesis to evaluate $\mathbf{E}\left[\lvert L^{\prime}_{i}\rvert\right]$.
L713: 
L714: ###### Hypothesis 2 (Evaluate $\lvert L^{\prime}_{i}\rvert$).
L715: 
L716: $\mathbf{E}\left[\lvert L^{\prime}_{i}\rvert\right]\approx O\left\lparen\mathbf{E}\left[\lvert L_{i-1}\rvert\right]\right\rparen$ in cite115†Algorithm 1 .
L717: ###### Justification.
L718: 
L719: Let $W_{w}$ be $W$ for each $w\in L_{i-1}$ in cite115†Algorithm 1 . Then
L720: 
L721:  | $\displaystyle\mathbf{E}\left[\lvert L^{\prime}_{i}\rvert\right]\ $  | $\displaystyle\leq\ \mathbf{E}\left[\sum_{w\in L_{i-1}}\lvert W_{w}\rvert\right]$  |
L722:  |  | $\displaystyle\approx\ O\left\lparen\mathbf{E}\left[\lvert L_{i-1}\rvert\right]\right\rparen.$  |
L723: 
L724: In the last equation, we assume that $\lvert W_{w}\rvert$ on average is approximately up to constant order. ∎
L725: We write $\mathit{Total}$ for the total number of exact lookups in cite115†Algorithm 1 . Note that $\mathit{Total}=\sum_{i=1}^{m}\lvert L^{\prime}_{i}\rvert$ holds by definition. Assuming cite219†Hypothesis 2 , we can prove the following lemma, which is used for cite220†Theorems (Informal) 1 and cite221†2 .
L726: ###### Lemma 2 (Evaluate $\mathit{Total}$, in a general setting).
L727: 
L728: $\mathbf{E}\left[\mathit{Total}\right]\approx\sum_{i=0}^{m-1}O\left\lparen\mathbf{E}\left[\lvert L_{i}\rvert\right]\right\rparen$.
L729: ###### Proof.
L730:  | $\displaystyle\mathbf{E}\left[\mathit{Total}\right]\ $  | $\displaystyle=\ \mathbf{E}\left[\sum_{i=1}^{m}\lvert L^{\prime}_{i}\rvert\right]\quad(\because\text{Definition})$  |
L731:  |  | $\displaystyle=\ \sum_{i=1}^{m}\mathbf{E}\left[\lvert L^{\prime}_{i}\rvert\right]\quad(\because\text{Linearity of $\mathbf{E}\left[\cdot\right]$})$  |
L732:  |  | $\displaystyle\approx\ \sum_{i=0}^{m-1}O\left\lparen\mathbf{E}\left[\lvert L_{i}\rvert\right]\right\rparen\quad(\because\text{\lx@cref{creftype~refnum}{hypothesis:pre-candidates}}).$  |
L733: ∎
L734: 
L735: On cite222†Hypothesis 1 .
L736: 
L737: We formally state cite222†Hypothesis 1 as follows: $\mathbf{E}\left[\lvert L_{i}\rvert\right]\approx O\left\lparen\mathbf{E}\left[\lvert S_{i}\rvert\lvert\mathcal{C}^{*}_{i}\rvert/\lvert\mathcal{V}\rvert^{i}\right]\right\rparen$. Here, we use $\lvert\mathcal{V}\rvert^{i}=\lvert\mathcal{V}^{i}\rvert$.
L738: 
L739: On cite220†Theorem (Informal) 1 .
L740: The assumption that $\gamma$ is moderate is formally stated as follows: there exists $r<1$ such that $\mathbf{E}\left[\lvert S_{i}\rvert/\lvert\mathcal{V}\rvert^{i}\right]=O\left\lparen r^{i}\right\rparen$. This roughly says that $\lvert S_{i+1}\rvert/\lvert S_{i}\rvert$ is averagely bounded by $r\lvert\mathcal{V}\rvert$.
L741: ###### Proof of cite220†Theorem (Informal) 1 .
L742: 
L743: The key observation is $\lvert\mathcal{C}^{*}_{i}\rvert\leq\lvert\mathcal{C}\rvert$ for each $i$. Therefore, by cite222†Hypothesis 1 ,
L744:  | $\displaystyle\mathbf{E}\left[\lvert L_{i}\rvert\right]\ $  | $\displaystyle\approx\ O\left\lparen\mathbf{E}\left[\lvert S_{i}\rvert\lvert\mathcal{C}^{*}_{i}\rvert/\lvert\mathcal{V}\rvert^{i}\right]\right\rparen$  |
L745:  |  | $\displaystyle\leq\ O\left\lparen\mathbf{E}\left[\lvert S_{i}\rvert\lvert\mathcal{C}\rvert/\lvert\mathcal{V}\rvert^{i}\right]\right\rparen$  |
L746:  |  | $\displaystyle=\ \lvert\mathcal{C}\rvert\cdot O\left\lparen\mathbf{E}\left[\lvert S_{i}\rvert/\lvert\mathcal{V}\rvert^{i}\right]\right\rparen$  |
L747:  |  | $\displaystyle=\ \lvert\mathcal{C}\rvert\cdot O\left\lparen r^{i}\right\rparen$  |
L748:  |  | $\displaystyle=\ O\left\lparen r^{i}\right\rparen,$  |
L749: which decreases exponentially over $i$.
L750: 
L751: Hence, by cite223†Lemma 2 , we have
L752:  | $\displaystyle\mathbf{E}\left[\mathit{Total}\right]\ $  | $\displaystyle\approx\ \sum_{i=0}^{m-1}O\left\lparen\mathbf{E}\left[\lvert L_{i}\rvert\right]\right\rparen$  |
L753:  |  | $\displaystyle\approx\ \sum_{i=0}^{m-1}O\left\lparen r^{i}\right\rparen$  |
L754:  |  | $\displaystyle=\ O\left\lparen\sum_{i=0}^{m-1}r^{i}\right\rparen$  |
L755:  |  | $\displaystyle=\ O\left\lparen\frac{1-r^{m}}{1-r}\right\rparen$  |
L756:  |  | $\displaystyle=\ O\left\lparen 1\right\rparen.$  |

L758: ∎

L760: On cite221†Theorem (Informal) 2 .
L761: Assuming Zipf’s law of the $n$-gram distribution, we can say that $\lvert\mathcal{C}^{*}_{i}\rvert$ on average is approximately up to the order of $\lvert\mathcal{C}\rvert^{1/\delta}$. This is essentially Heaps’ law generalized for $n$-grams. Derivation of Heaps’ law from Zipf’s law has been well studied cite224†Baeza-Yates and Navarro [1997] , cite225†van Leijenhorst and van der Weide [2005] .
L762: ###### Lemma 3.
L763: 
L764: Assume that, for each $n$, the occurrence probability of the $k$-th most frequent $n$-gram is $O\left\lparen k^{-\delta}\right\rparen$ for $\delta>1$. Then $\mathbf{E}\left[\lvert\mathcal{C}^{*}_{i}\rvert\right]\approx O\left\lparen\lvert\mathcal{C}\rvert^{1/\delta}\right\rparen$.^{15}^{15} 15 We assume that $\lvert\mathcal{V}\rvert$ grows unboundedly as $\lvert\mathcal{C}\rvert$ grows, to make the statement non-trivial.
L765: ###### Proof.
L766: 
L767: We can take a constant $p$ such that the occurrence probability of the $k$-th most frequent $n$-gram is at most $pk^{-\delta}$ for large $k$. Let $\mathsf{Occurs}(w)$ be 1 if $w$ occurs in the corpus $\mathcal{C}$ and 0 otherwise. Then we have:
L768:  | $\displaystyle\mathbf{E}\left[\lvert\mathcal{C}^{*}_{i}\rvert\right]\ $  | $\displaystyle=\ \mathbf{E}\left[\sum_{w\in\mathcal{V}^{i}}\mathsf{Occurs}(w)\right]$  |
L769:  |  | $\displaystyle=\ \sum_{w\in\mathcal{V}^{i}}\mathbf{E}\left[\mathsf{Occurs}(w)\right]$  |
L770:  |  | $\displaystyle=\ \sum_{k=1}^{\lvert\mathcal{V}\rvert^{i}}\,\mathbf{E}\left[\mathsf{Occurs}(\text{$k$-th most frequent $i$-gram})\right]$  |
L771:  |  | $\displaystyle\approx\ O\left\lparen\sum_{k=1}^{\lvert\mathcal{V}\rvert^{i}}\,\Big\lparen 1-(1-pk^{-\delta})^{\lvert\mathcal{C}\rvert}\Big\rparen\right\rparen$  |
L772:  |  | $\displaystyle\approx\ O\left\lparen\sum_{k=1}^{\lvert\mathcal{V}\rvert^{i}}\,\min\big\lparen 1,\,pk^{-\delta}\cdot\lvert\mathcal{C}\rvert\big\rparen\right\rparen$  |
L773:  |  | $\displaystyle=\ O\left\lparen\int_{0}^{\infty}\min\big\lparen 1,\,px^{-\delta}\cdot\lvert\mathcal{C}\rvert\big\rparen\,dx\right\rparen$  |
L774:  |  | $\displaystyle=\ O\left\lparen\lparen p\,\lvert\mathcal{C}\rvert\rparen^{1/\delta}-\Big[\frac{p\,\lvert\mathcal{C}\rvert}{\delta-1}px^{1-\delta}\Big]_{x=\lparen p\,\lvert\mathcal{C}\rvert\rparen^{1/\delta}}^{\infty}\right\rparen$  |
L775:  |  | $\displaystyle=\ O\left\lparen\lvert\mathcal{C}\rvert^{1/\delta}+\lvert\mathcal{C}\rvert^{(1-\delta)/\delta}\cdot\lvert\mathcal{C}\rvert\right\rparen$  |
L776:  |  | $\displaystyle=\ O\left\lparen\lvert\mathcal{C}\rvert^{1/\delta}\right\rparen.$  |
L777: Here, $\lparen p\,\lvert\mathcal{C}\rvert\rparen^{1/\delta}$ is the solution to $px^{-\delta}\cdot\lvert\mathcal{C}\rvert=1$ for $x$. ∎
L778: 
L779: Now we are ready to prove cite221†Theorem (Informal) 2 .
L780: ###### Proof of cite221†Theorem (Informal) 2 .
L781: 
L782: By cite222†Hypothesis 1 and cite226†Lemma 3 ,
L783:  | $\displaystyle\mathbf{E}\left[\lvert L_{i}\rvert\right]\ $  | $\displaystyle\approx\ O\left\lparen\mathbf{E}\left[\lvert S_{i}\rvert\lvert\mathcal{C}^{*}_{i}\rvert/\lvert\mathcal{V}\rvert^{i}\right]\right\rparen$  |
L784:  |  | $\displaystyle=\ O\left\lparen\mathbf{E}\left[\lvert\mathcal{C}^{*}_{i}\rvert\right]\right\rparen$  |
L785:  |  | $\displaystyle\approx\ O\left\lparen\lvert\mathcal{C}\rvert^{1/\delta}\right\rparen.$  |
