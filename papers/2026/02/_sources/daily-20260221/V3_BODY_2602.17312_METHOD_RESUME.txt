Performance maximization. The phase of learning safety is as in most offline safe RL algorithms (xu2021crpo; koirala2024latent) where a feasible policy set is identified first. In the performance maximization phase, they either separately trained another model to extract the optimal policy respecting the learned safety, or directly optimized a policy and projected back to the feasible set. While the former complicates the learning process, the latter may lead to overly conservative behaviors. Instead, we fine-tune the model θ\theta learned from the previous safety learning phase by assuming that the model has preserved safety requirements. This should empirically hold as we have minimized the same cumulative cost 𝔼τ∼π​[C​(τ)]\mathbb{E}_{\tau\sim\pi}[C(\tau)]. The same dataset 𝒟\mathcal{D} is reused for maximizing performance, so the proximity constraint is still required.
Thereby, IQL is utilized to learn the optimal policy, by only fine-tuning θ\theta. Similarly, the value net and Q-net are updated by minimizing the losses in Eq. 2 and 3 respectively. To extract the policy, we have

4.1. Theoretical Analysis
In this section, we detail the theoretical analysis for LexiSafe-SC, while deferring all necessary proof to the Appendix.
Safety constraint violation bound. This work aims to search for an safe optimal policy π∈(𝒮→Δ⁡(𝒜))\pi\in(\mathcal{S}\to\Delta(\mathcal{A})), where Δ⁡(⋅)\Delta(\cdot) is a probability simplex, with the help of Q-function class ℱν⊂(𝒮×𝒜→[0,Qmν]),Qmν=νm1−γ,ν∈{r,c}\mathcal{F}_{\nu}\subset(\mathcal{S}\times\mathcal{A}\to[0,Q^{\nu}_{m}]),Q^{\nu}_{m}=\frac{\nu_{m}}{1-\gamma},\nu\in\{r,c\}.
