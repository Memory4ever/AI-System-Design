3 Lipschitz Convex Loss: Connectivity and Path Construction
We extend the connectivity result to a much broader class of loss functions. Specifically, let ℒ⁡(Y,Y^)\mathcal{L}(Y,\hat{Y}) be any loss that is convex in the prediction Y^\hat{Y} and LL-Lipschitz continuous in Y^\hat{Y}. For instance, the logistic loss and binary cross-entropy are convex in Y^\hat{Y} and Lipschitz on any compact domain (in classification tasks Y^\hat{Y} often lies in [0,1][0,1] after a sigmoid). We assume an ℓ1\ell_{1} regularization κ​‖θ‖1\kappa\|\theta\|_{1} on the second-layer weights, with κ>0\kappa>0 (note this is usually present or can be added without hurting performance).
Before stating the main theorem, we prove a useful lemma that bounds the size of the optimal second-layer weights in terms of the Lipschitz constant LL and κ\kappa. This will ensure that neurons cannot have arbitrarily large influence, which helps control the loss when we perturb or remove neurons.
Lemma 1 (Control of ℓ1\ell_{1}-norm).
Let ℒ⁡(Y,Y^)\mathcal{L}(Y,\hat{Y}) be convex in Y^\hat{Y} and LL-Lipschitz, and let κ>0\kappa>0. For any fixed first-layer W1W^{1}, consider the optimization problem
θ∗∈arg​minθ∈ℝm⁡{𝔼⁡[ℒ⁡(Y,Φ⁡(X,W1,θ))]+κ​‖θ‖1}.\theta^{*}\in\mathop{\mathrm{arg\,min}}_{\theta\in\mathbb{R}^{m}}\Big\{\,\mathbb{E}[\mathcal{L}(Y,\Phi(X;W^{1},\theta))]\,+\,\kappa\|\theta\|_{1}\,\Big\}.
Then the optimal solution θ∗\theta^{*} satisfies ‖θ∗‖1≤L/κ\|\theta^{*}\|_{1}\leq L/\kappa. In fact, if κ≥L\kappa\geq L then θ∗=0\theta^{*}=0 (that is, the minimum is achieved by the zero output weights).

This implies:
•
For any coordinate ii such that θi∗≠0\theta^{*}_{i}\neq 0, we must have ∇θi𝔼​[ℒ]=−κ​sign​(θi∗)\nabla_{\theta_{i}}\mathbb{E}[\mathcal{L}]=-\kappa\,\mathrm{sign}(\theta^{*}_{i}). In particular, |∇θi𝔼​[ℒ]|=κ|\nabla_{\theta_{i}}\mathbb{E}[\mathcal{L}]|=\kappa.
•
For any coordinate ii such that θi∗=0\theta^{*}_{i}=0, we have ∇θi𝔼​[ℒ]∈[−κ,+κ]\nabla_{\theta_{i}}\mathbb{E}[\mathcal{L}]\in[-\kappa,\,+\kappa] (the subgradient of |θi||\theta_{i}| at 0 is any value in [−1,1][-1,1]).
Next, Lipschitz continuity of ℒ\mathcal{L} in Y^\hat{Y} implies a bound on the gradient norms: since |ℒ⁡(y,y^1)−ℒ⁡(y,y^2)|≤L​|y^1−y^2||\mathcal{L}(y,\hat{y}_{1})-\mathcal{L}(y,\hat{y}_{2})|\leq L|\hat{y}_{1}-\hat{y}_{2}|, we have ‖∇θ𝔼​[ℒ]‖∞≤L\|\nabla_{\theta}\mathbb{E}[\mathcal{L}]\|_{\infty}\leq L. In particular |∇θi𝔼​[ℒ]|≤L|\nabla_{\theta_{i}}\mathbb{E}[\mathcal{L}]|\leq L for every ii. Combining this with the first optimality condition above for coordinates where θi∗≠0\theta^{*}_{i}\neq 0, we get κ=|∇θi𝔼​[ℒ]|≤L\kappa=|\nabla_{\theta_{i}}\mathbb{E}[\mathcal{L}]|\leq L. Thus a necessary condition for θi∗\theta^{*}_{i} to be nonzero is κ≤L\kappa\leq L. Equivalently, if κ>L\kappa>L then the only feasible solution is θ∗=0\theta^{*}=0 (because any nonzero coefficient would violate the condition). This proves the second statement.
Finally, to bound ‖θ∗‖1\|\theta^{*}\|_{1} when κ≤L\kappa\leq L, we can use convexity of 𝔼⁡[ℒ]\mathbb{E}[\mathcal{L}]: for any θ\theta,
𝔼⁡[ℒ⁡(Y,Φ⁡(X,W1,θ))]≥𝔼⁡[ℒ⁡(Y,Φ⁡(X,W1,θ∗))]+⟨∇θ𝔼​[ℒ]|θ∗,θ−θ∗⟩.\mathbb{E}[\mathcal{L}(Y,\Phi(X;W^{1},\theta))]\geq\mathbb{E}[\mathcal{L}(Y,\Phi(X;W^{1},\theta^{*}))]+\langle\nabla_{\theta}\mathbb{E}[\mathcal{L}]|_{\theta^{*}},\theta-\theta^{*}\rangle\,.
Plugging in θ=0\theta=0 and using ∇θ𝔼​[ℒ]|θ∗=−κ​sign​(θ∗)\nabla_{\theta}\mathbb{E}[\mathcal{L}]|_{\theta^{*}}=-\kappa\,\mathrm{sign}(\theta^{*}) (for each component where θ∗\theta^{*} is nonzero, and bounded in [−κ,κ][-\kappa,\kappa] where θ∗\theta^{*} is zero), we get
𝔼⁡[ℒ⁡(Y,Φ⁡(X,W1,0))]≥𝔼⁡[ℒ⁡(Y,Φ⁡(X,W1,θ∗))]−κ⁡⟨sign⁡(θ∗),θ∗⟩==𝔼⁡[ℒ⁡(Y,Φ⁡(X,W1,θ∗))]+κ​‖θ∗‖1,\begin{gathered}\mathbb{E}[\mathcal{L}(Y,\Phi(X;W^{1},0))]\geq\mathbb{E}[\mathcal{L}(Y,\Phi(X;W^{1},\theta^{*}))]-\kappa\,\langle\mathrm{sign}(\theta^{*}),\,\theta^{*}\rangle=\\
=\mathbb{E}[\mathcal{L}(Y,\Phi(X;W^{1},\theta^{*}))]+\kappa\,\|\theta^{*}\|_{1}\,,\end{gathered}
(4)
since ⟨sign⁡(θ∗),θ∗⟩=‖θ∗‖1\langle\mathrm{sign}(\theta^{*}),\theta^{*}\rangle=\|\theta^{*}\|_{1}. On the other hand, by LL-Lipschitz continuity,

and since κ>0\kappa>0 we can cancel ‖θ∗‖1\|\theta^{*}\|_{1} to obtain ‖θ∗‖1≤L/κ\|\theta^{*}\|_{1}\leq L/\kappa (and this inequality trivially holds if θ∗=0\theta^{*}=0 as well).
∎
Lemma 1 implies that throughout the training landscape (and in particular for any local or global minimum), the sum of the absolute output weights is bounded by L/κL/\kappa. In the special case κ≥L\kappa\geq L, the only optimum is the trivial zero network—which in practice one would avoid by choosing κ<L\kappa<L so that the network can actually learn.
