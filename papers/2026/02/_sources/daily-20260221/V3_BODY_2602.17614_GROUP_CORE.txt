IV-B2 K-Annonymity
Once noise is added to the data of each individual client, we apply model-level k-anonymity to further enhance privacy. The process, illustrated in Figure 2, proceeds as follows. In each training epoch, the parameter server partitions the set of clients 𝒞\mathcal{C} into groups 𝒢={g1,g2,…,gm}\mathcal{G}=\{g_{1},g_{2},\dots,g_{m}\}, where each group gig_{i} contains at least kk clients, i.e., |gi|≥k|g_{i}|\geq k. For a client c∈gic\in g_{i}, the forward pass produces smashed head representations 𝒮ℋc=wℋc​(x^c(i))\mathcal{S}_{\mathcal{H}_{c}}=w_{\mathcal{H}_{c}}(\hat{x}_{c}^{(i)}), where x^c(i)\hat{x}_{c}^{(i)} is the privatized input after Gaussian perturbation.
The parameter server then performs microaggregation on the smashed data for each group. Specifically, for a group gig_{i}, the aggregated representation is given by:
𝒮ℋgi=1|gi|​∑c∈gi𝒮ℋc\mathcal{S}_{\mathcal{H}_{g_{i}}}=\frac{1}{|g_{i}|}\sum_{c\in g_{i}}\mathcal{S}_{\mathcal{H}_{c}}
(11)
This ensures that the smashed representation of any single client is indistinguishable from at least k−1k-1 other clients in the same group, thereby satisfying kk-anonymity at the model level.
The micro-aggregated representation 𝒮ℋgi\mathcal{S}_{\mathcal{H}_{g_{i}}} is then passed through the server body network wℬw_{\mathcal{B}} to generate the server smashed data 𝒮ℬgi=wℬ​(𝒮ℋgi)\mathcal{S}_{\mathcal{B}_{g_{i}}}=w_{\mathcal{B}}(\mathcal{S}_{\mathcal{H}_{g_{i}}}). This output is subsequently distributed back to the clients in group gig_{i}, where each client’s tail network w𝒯cw_{\mathcal{T}_{c}} computes the final prediction y^c=w𝒯c​(𝒮ℬgi)\hat{y}_{c}=w_{\mathcal{T}_{c}}(\mathcal{S}_{\mathcal{B}_{g_{i}}}). The loss l⁡(y(i),y^c(i))l(y^{(i)},\hat{y}_{c}^{(i)}) is then computed locally to update the client’s head and tail networks, as well as the group’s body network.
In this way, the micro-aggregation process ensures that individual client representations are obfuscated within a group of size kk, making it challenging for an adversary at the server to reconstruct any single client’s data. The two-level privacy mechanism, operating at both the data level and the model level, enhances the overall framework’s privacy. Alg. 2 provides a detailed overview of the KD-UFSL framework.
