3.3 Event-based Video Scene Graph Generation
To provide explicit reasoning structure and temporal dependency cues for event causal thinking, we construct an Event-based Video Scene Graph (EVSG) for each video. The EVSG serves as a structured event relation representation that encodes spatial relations and temporal dependencies among objects and events, providing an intermediate thinking process to constrain MLLM reasoning, thus mitigate hallucinations.
Given an input video, we first employ an MLLM to generate multi-grained dense captioning for each video. To achieve it, we set different upper limits on the number of events and allow the MLLM to automatically produce captions under these constraints.
Specifically, we define three event limits (e.g., 5, 10, and 15, based on the results in Tab. 4
) and let the model segment the video accordingly into 5, 10, or 15 consecutive and non-overlapping temporal segments. For each segment, the model generates a corresponding caption. Finally, the MLLM generates dense captions at three levels of granularity: coarse, middle, and fine, denoted as CcoarseC^{\text{coarse}}, CmiddleC^{\text{middle}}, and CfineC^{\text{fine}}, respectively. The goal of producing multi-grained dense captions is to mitigate potential hallucinations during caption generation. Cross-level comparison of coarse and fine-grained captions detects inconsistencies, suppressing hallucinated details before graph construction.
Next, we employ the MLLM to construct the Event-based Video Scene Graph using the self-generated multi-grained dense captions. The process of building the graph from captions consists of two stages: generation and refinement.
In the generation stage, the model primarily uses the middle-grained captions to build the initial event graph. Guided by predefined instructions and templates, the MLLM extracts the start and end timestamps for each event from the captions. It then identifies key object interactions described in each event and converts them into a set of video scene graph triplets, following the conventional ⟨subject–relation–object⟩ format used in traditional video scene graph representations.

Our GraphThinker integrates EVSGs into the GRPO post-training method, where the graph provides structured event relations that guide and constrain the model’s reasoning process, serving as an intermediate thinking process to reduce hallucinations. The input to the MLLM consists of the video vv, its corresponding EVSG 𝒢∗\mathcal{G}^{*}, and a downstream question qq. The reward design plays a crucial role in shaping the model’s optimization objective within the GRPO framework. To encourage both accurate temporal grounding and interpretable reasoning, we design a composite reward function consisting of three components: a temporal accuracy reward racc​(⋅)r_{\text{acc}}(\cdot), a format consistency reward rform​(⋅)r_{\text{form}}(\cdot), and a visual attention reward rattn​(⋅)r_{\text{attn}}(\cdot).
