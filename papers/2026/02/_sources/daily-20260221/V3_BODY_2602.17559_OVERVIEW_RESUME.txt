3.3 Overview of EWC-LoRA
Figure 1: Overview of learning task 𝒯t\mathcal{T}_{t} at a specific layer of the ViT model. (a) Prior low-rank CL methods structurally isolate task-specific LoRA parameters by adding a new LoRA branch for each task. (b) The proposed EWC-LoRA employs a shared LoRA module that is learned across all tasks and regularized according to parameter importance measured by a Fisher Information Matrix, which is updated after learning each task.
Figure 1 illustrates the difference between EWC-LoRA and existing state-of-the-art low-rank CL methods, in the context of learning task 𝒯t\mathcal{T}_{t} at a specific layer of the Vision Transformer (ViT).
For task 𝒯t\mathcal{T}_{t}, we initialize the shared LoRA branch, and the forward computation is given by: 𝐟=𝐖t−1​𝐱+𝐀𝐁𝐱\mathbf{f}=\mathbf{W}_{t-1}\mathbf{x}+\mathbf{A}\mathbf{B}\mathbf{x}. Specifically, 𝐀\mathbf{A} is zero-initialized, while 𝐁\mathbf{B} is drawn from a uniform distribution. During training on 𝒯t\mathcal{T}_{t}, only 𝐀\mathbf{A} and 𝐁\mathbf{B} are updated, while the base weights 𝐖t−1\mathbf{W}_{t-1} keep frozen. After completing task 𝒯t\mathcal{T}_{t}, the learned parameters are integrated to the base weight as 𝐖t=𝐖t−1+𝐀𝐁\mathbf{W}_{t}=\mathbf{W}_{t-1}+\mathbf{A}\mathbf{B}. For any sample from a previous task, the forward computation becomes 𝐟=𝐖t​𝐱\mathbf{f}=\mathbf{W}_{t}\mathbf{x}.
During training, the update of the low-rank matrices 𝐀\mathbf{A} and 𝐁\mathbf{B} are regularized using the accumulated Fisher matrix 𝐅t−1cum\mathbf{F}_{t-1}^{\text{cum}} from step t−1t-1. Accordingly, EWC-LoRA maintains only two states after learning step tt:
(1) the updated model parameters 𝐖t\mathbf{W}_{t} obtained from the current task 𝒯t\mathcal{T}_{t}, and
(2) the accumulated Fisher matrix 𝐅tcum\mathbf{F}_{t}^{\text{cum}}, a diagonal matrix that aggregates information from all previous tasks 𝒯1:t\mathcal{T}_{1:t}.
The dataset 𝒟t\mathcal{D}_{t} and the task-specific Fisher matrix 𝐅t\mathbf{F}_{t} can then be discarded. For clarity, we outline the learning procedure of EWC-LoRA in Algorithm 1, provided in Appendix A.2.1. For computational and memory efficiency, the only additional memory cost of EWC-LoRA comes from storing the FIM. However, due to the low-rank parameterization, EWC-LoRA incurs only a modest memory overhead while achieving higher computational efficiency than existing low-rank CL methods. A detailed efficiency analysis is provided in Section 4.2.

4.1 Benchmarks
Datasets.
In line with existing continual learning methods (Wang et al., 2023; Liang & Li, 2024; Wu et al., 2025), we evaluate the performance of EWC-LoRA under two settings:
(1) Four widely used CL vision benchmarks, including CIFAR-100 (Krizhevsky et al., 2009), DomainNet (Peng et al., 2019; Wang et al., 2022a), ImageNet-R (Hendrycks et al., 2021a; Wang et al., 2022b), and ImageNet-A (Hendrycks et al., 2021b); and (2) A standard language CL benchmark with five text classification datasets: AG News, Amazon Reviews, Yelp Reviews, DBpedia, and Yahoo Answers. Following Wang et al. (2023), we evaluate the models under three different task orders. The detailed task order is provided in Appendix A.3.
CIFAR-100 consists of 100 natural image classes and is the most commonly used dataset in continual learning.
DomainNet includes 345 classes across six diverse visual domains, making it a challenging multi-domain benchmark. Note that similar to Liang & Li (2024), DomainNet is split as a class-incremental learning problem.
ImageNet-R contains 200 ImageNet classes (Deng et al., 2009) rendered with various artistic styles, introducing significant distribution shifts. ImageNet-A consists of 200 natural adversarial examples that are frequently misclassified by standard ImageNet-trained models. We follow the mostly used task splits for continual learning benchmarks: CIFAR-100 is divided into 10 tasks (10 classes per task); DomainNet into 5 tasks (69 classes per task); ImageNet-A into 10 tasks (20 classes each); ImageNet-R into 5, 10, and 20 tasks (with 40, 20, and 10 classes per task, respectively).
Evaluation metrics.
We adopt accuracy as our evaluation metric, in line with standard practice (Lopez-Paz & Ranzato, 2017; Chaudhry et al., 2019).
