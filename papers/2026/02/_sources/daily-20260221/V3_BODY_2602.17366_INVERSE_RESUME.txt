3.2 Training an Inverse Model
The inverse model Morris et al. (2023) is designed to reconstruct original text from an embedding. Specifically, given an embedding ee generated by a specified embedding model, our goal is to recover the corresponding text xx. This can be formulated as generating text whose embedding is maximally similar to the ground-truth embedding as:
x^=arg⁡maxx⁡cos⁡(ϕ⁡(x),e).\hat{x}=\arg\max_{x}\cos(\phi(x),e).
(6)
Given a dataset 𝒟={x1,…​xn}\mathcal{D}=\{x_{1},\dots\,x_{n}\}, we train an
inverse mapping of the encoder ϕ\phi by modeling the conditional distribution of text given their embeddings p⁡(x∣e;θ)p(x\mid e;\theta). We achieve this by optimizing θ\theta via maximum likelihood estimation:
θ=arg⁡maxθ^​𝔼x∼𝒟​[p⁡(x∣ϕ⁡(x);θ^)].\theta=\arg\max_{\hat{\theta}}\mathbb{E}_{x\sim\mathcal{D}}\big[p(x\mid\phi(x);\hat{\theta})\big].
(7)
For technical details, readers can refer to Morris et al. (2023) for more information.
3.3 Data Selection with Round-trip Prediction
After training the inverse model, we select easy-to-learn augmented data for training dense retriever models. For each question-answer sample, we first apply an off-the-shelf dense retriever (Izacard et al., 2021) on the question xx to get an embedding e⁡(x)e(x), then we adopt the trained inverse embedding model for the reconstructed text x^\hat{x}. Specifically, we define a reconstruction quality score S⁡(x)S(x) for xx as follows:
S⁡(x)=1−‖ϕ⁡(x^)−ϕ⁡(x)‖2‖ϕ⁡(x)‖2.S(x)=1-\frac{\|\phi(\hat{x})-\phi(x)\|^{2}}{\|\phi(x)\|^{2}}.
(8)
A higher value of S⁡(x)S(x) indicates better reconstruction quality. We then select the top kk samples in an augmented set DselectedD_{\text{selected}}, where the reconstruction score S⁡(x)S(x) is above a threshold θ\theta:
Dselected={x∣S(x)≥θ,x∈Daug}.D_{\text{selected}}=\{x\mid S(x)\geq\theta,\,x\in D_{\text{aug}}\}.
(9)

4.1 Experimental Setup
Baselines.
We selected two basic retrieval methods as baselines for experimental comparison: the text-based approach BM25 (MacAvaney et al., 2020) and the widely used embedding-based approach Contriever (Izacard et al., 2021). Besides, we selected three state-of-the-art embedding-based retriever models, BGE (Chen et al., 2024), gemma (Team et al., 2024), and NV-Embed (Lee et al., 2024). We include details in Appendix A.
Metrics.
Following (Mallen et al., 2023; Wang, 2025; Yu et al., 2024), for retrieval evaluation, we mainly use Retrieval Accuracy, denoted as R@k, which measures whether at least one answer string appears in the top-kk retrieved passages. For answer evaluation, we use Exact Match, which measures the exact string match between the predicted and the gold answer.
To provide a systematic study, we partition the PopQA and EntityQuestions test set with different entity frequencies. Specifically, we split dataset into three categories: Long-Tail that represents queries with corresponding entity frequencies between 10 and 100, capturing extreme rare cases; Infrequent that corresponds to entity frequencies between 100 and 10,000, offering a moderately rare queries; Frequent that with frequencies exceeding 10,000, correspond to high-frequency queries involving well-known entities.
