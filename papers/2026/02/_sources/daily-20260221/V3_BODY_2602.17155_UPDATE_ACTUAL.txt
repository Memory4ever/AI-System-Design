ZO-Muon: How and why.
As motivated above, it is nontrivial to effectively leverage Muon’s spectral advantages in the ZO setting. In what follows, we show that the subspace ZO formulation in Sec. 3 is more suitable for integration with Muon.
Our rationale is that Subspace RGE (5) induces a low-rank structure by estimating gradients in a low-dimensional subspace. When combined with GO, this effectively acts as a low-rank spectral filter that suppresses non-informative noise in the RGE. From an efficiency standpoint, the cost of the msign\mathrm{msign} operation in (9) scales with the matrix rank (He et al., 2025), so integrating GO with subspace ZO also improves computational efficiency. As confirmed by ZO-Muon in Fig. 5, an accuracy-efficiency win-win emerges when GO meets subspace ZO.
We next formally develop ZO-Muon.

Design choices in ZO-Muon: Query number NqN_{q} and projection rank rr.
First, we find that setting the query number Nq>1N_{q}>1 is crucial for ZO-Muon, e.g., Nq=4N_{q}=4 works well in our experiments, indicating that the RGE (10) should be implemented in its multi-query form.
Recall from (10) that in the absence of msign\mathrm{msign}, the method reduces to Subspace RGE, yielding Subspace-MeZO as examined in Fig. 3. For both Subspace-MeZO and its full-space baseline MeZO (Malladi et al., 2023), the default choice is Nq=1N_{q}=1. This is due to the multi-query paradox (Lin et al., 2025): Although using multiple queries per iteration can reduce the variance of the gradient estimate, whether it improves optimization performance depends on how the queries are aggregated. In particular, simple averaging with Nq>1N_{q}>1 can lead to diminishing returns (i.e., the multi-query paradox) compared to using a single query per iteration.
However, unlike Subspace-MeZO, when Nq=1N_{q}=1 is used in ZO-Muon, the GO step (10) reduces to

Therefore, ZO-Muon benefits from using Nq>1N_{q}>1.
In addition, it can effectively overcome the multi-query paradox compared to Subspace-MeZO (see Appendix E for empirical validation).
For the other key hyperparameter, the projection rank rr that defines the subspace via 𝐏\mathbf{P}, we find that ZO-Muon remains effective as long as it is set to a reasonably reduced dimension (e.g., r∈{64,128}r\in\{64,128\}). This is roughly aligned with the effective rank of FO gradients shown in Fig. 3(a). As shown in Fig. 6(a), ZO-Muon consistently outperforms Subspace-MeZO across all rank choices (indicating the usefulness of GO in ZO-Muon) and achieves the best performance with a moderate rank such as r=64r=64.
