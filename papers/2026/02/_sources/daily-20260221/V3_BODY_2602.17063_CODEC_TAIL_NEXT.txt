E.3.6 Preconditioning Variants for Magnitude SVD.
For SVD |Wlockin||W_{\mathrm{lockin}}|-naive, we apply truncated SVD directly to the magnitude matrix
A:=|Wlockin|∈ℝ≥0m×nA:=|W_{\mathrm{lockin}}|\in{\mathbb{R}}^{m\times n}_{\geq 0}.
For SVD |Wlockin||W_{\mathrm{lockin}}|-zscore, we normalize AA column-wise before SVD and invert the
normalization after reconstruction.
Let A:=|Wlockin|∈ℝ≥0m×nA:=|W_{\mathrm{lockin}}|\in{\mathbb{R}}^{m\times n}_{\geq 0}.
Define the per-column mean and (population) standard deviation by
ζj:=1m∑i=1mAi​j,ωj:=1m​∑i=1m(Ai​j−ζj)2,j=1,…,n.\zeta_{j}:=\frac{1}{m}\sum_{i=1}^{m}A_{ij},~~\omega_{j}:=\sqrt{\frac{1}{m}\sum_{i=1}^{m}(A_{ij}-\zeta_{j})^{2}},~~j=1,\ldots,n.
Let ζ:=(ζ1,…,ζn)⊤∈ℝn\zeta:=(\zeta_{1},\ldots,\zeta_{n})^{\top}\in{\mathbb{R}}^{n},
ω:=(ω1,…,ωn)⊤∈ℝ≥0n\omega:=(\omega_{1},\ldots,\omega_{n})^{\top}\in{\mathbb{R}}^{n}_{\geq 0},
and let 𝟏m∈ℝm\mathbf{1}_{m}\in{\mathbb{R}}^{m} and 𝟏n∈ℝn\mathbf{1}_{n}\in{\mathbb{R}}^{n} denote all-ones vectors.
Introduce a small numerical stabilizer ϵzs>0\epsilon_{\mathrm{zs}}>0 and define
Dzs:=diag⁡(ω+ϵzs​𝟏n)∈ℝn×n.D_{\mathrm{zs}}:=\mathrm{diag}(\omega+\epsilon_{\mathrm{zs}}\mathbf{1}_{n})\in{\mathbb{R}}^{n\times n}.
The column-wise z-score normalized matrix is
Azs:=(A−𝟏m​ζ⊤)​Dzs−1∈ℝm×n.A^{\mathrm{zs}}:=(A-\mathbf{1}_{m}\zeta^{\top})\,D_{\mathrm{zs}}^{-1}\in{\mathbb{R}}^{m\times n}.
We compute a rank-rr truncated SVD
Azs≈Ur​Σr​Vr⊤,A^{\mathrm{zs}}\approx U_{r}\Sigma_{r}V_{r}^{\top},
fold the singular values into the left factor U~r:=Ur​Σr\widetilde{U}_{r}:=U_{r}\Sigma_{r},
apply the main-text symmetric uniform bb-bit quantizer Qb​(⋅)Q_{b}(\cdot) to the factors, and reconstruct
Abzs:=Qb​(U~r)​Qb​(Vr⊤).A^{\mathrm{zs}}_{b}:=Q_{b}(\widetilde{U}_{r})\,Q_{b}(V_{r}^{\top}).
Finally, we invert the normalization and enforce nonnegativity (element-wise):
Ab:=Abzs​Dzs+𝟏m​ζ⊤,Ab←max⁡(Ab,0).A_{b}:=A^{\mathrm{zs}}_{b}\,D_{\mathrm{zs}}+\mathbf{1}_{m}\zeta^{\top},~~A_{b}\leftarrow\max(A_{b},0).
We then form the sign-fixed weight using the fixed sign template 𝐓\mathbf{T}:
Wb:=T⊙Ab.W_{b}:=T\odot A_{b}.
Bit-budget Grid.
We evaluate a sweep of target effective budgets
bpwtarget∈{0.075, 0.125, 0.25, 0.5, 0.75, 1.0, 1.58, 2.0}.\mathrm{bpw}_{\mathrm{target}}\in\{0.075,\,0.125,\,0.25,\,0.5,\,0.75,\,1.0,\,1.58,\,2.0\}.

Bit accounting of SVD-based storage for dense matrices (ours and SVDW baseline).
Given a target matrix M∈ℝm×nM\in{\mathbb{R}}^{m\times n} and rank rr, we store quantized SVD factors
(Ur∈ℝm×rU_{r}\in{\mathbb{R}}^{m\times r}, Σr∈ℝr×r\Sigma_{r}\in{\mathbb{R}}^{r\times r} as a diagonal vector, and Vr∈ℝn×rV_{r}\in{\mathbb{R}}^{n\times r})
using symmetric uniform bb-bit quantizers (Eq. (23)).
Following Eq. (24), the amortized bit cost per original weight is approximated by
bpweff≈b⋅(m​r+n​r+r)m​n,\mathrm{bpw}_{\mathrm{eff}}\approx\frac{b\cdot(mr+nr+r)}{mn},
with b=4b=4 in our experiments (i.e., 4-bit quantization for the stored factors).
For the zero-template method, sign bits are not stored (Eq. (20));
for SVDW baseline, the same SVD method is applied directly to WW.
Bit accounting of CSR storage for unstructured sparsity (pruning and WANDA).
For pruning-based methods, we assume CSR storage for each pruned matrix:
bpweff≈nnz⋅bval⏟stored values+nnz⋅bidx+(m+1)⋅bptr⏟indices/row pointersm​n,\mathrm{bpw}_{\mathrm{eff}}\approx\frac{\underbrace{\mathrm{nnz}\cdot b_{\mathrm{val}}}_{\text{stored values}}+\underbrace{\mathrm{nnz}\cdot b_{\mathrm{idx}}+(m+1)\cdot b_{\mathrm{ptr}}}_{\text{indices/row pointers}}}{mn},
where nnz\mathrm{nnz} is the number of nonzeros, bval=4b_{\mathrm{val}}=4 bits for quantized nonzero values, and
we use 32-bit indices/pointers (bidx=bptr=32b_{\mathrm{idx}}=b_{\mathrm{ptr}}=32).
This accounting explains why pruning can be unfavorable at extreme densities: index overhead dominates.
We also impose a practical start threshold and only run pruning methods when the implied keep ratio exceeds
prune_start_keep_frac=0.005.\texttt{prune\_start\_keep\_frac}=0.005.
Baselines.
We summarize the baselines shown in Figure 20. All results shown in Figure 20 are computed using three seeds (0, 1, 2) and reported as mean±\pmstd.
We log per-method bpweff\mathrm{bpw}_{\mathrm{eff}} along with its decomposition (e.g., sign/index overhead vs. value bits) to ensure
bit-budget correctness for each storage model.
•
HashedNets: weight sharing through hashing into a budget-dependent number of buckets; bucket values are stored
with the same value-bitwidth used elsewhere (4-bit in our implementation). No task-specific fine-tuning is employed.
•
OneBit: explicit 1-bit sign storage with a small overhead for scale information.
•
Pruning: magnitude-based unstructured pruning with CSR accounting; prune-only (no recovery fine-tuning applied).
•
WANDA: activation-aware pruning utilizing the standard WANDA score; prune-only; CSR accounting.
•
QAT (reference): we include 1-bit and ternary QAT as reference points. In our code, QAT employs a STE with a short fine-tuning schedule applied to the targeted tensors; KD tasks utilize the same teacher as the KD student training.
