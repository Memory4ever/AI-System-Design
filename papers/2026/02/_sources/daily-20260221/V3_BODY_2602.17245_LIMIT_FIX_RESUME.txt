Abstract.
The Web is evolving from a medium that humans browse to an environment where software agents act on behalf of users.
Advances in large language models (LLMs) make natural language a practical interface for goal-directed tasks, yet most current web agents operate on low-level primitives such as clicks and keystrokes. These operations are brittle, inefficient, and difficult to verify. Complementing content-oriented efforts such as NLWeb’s semantic layer for retrieval, we argue that the agentic web also requires a semantic layer for web actions.
We propose Web Verbs, a web-scale set of typed, semantically documented functions that expose site capabilities through a uniform interface, whether implemented through APIs or robust client-side workflows. These verbs serve as stable and composable units that agents can discover, select, and synthesize into concise programs.
This abstraction unifies API-based and browser-based paradigms, enabling LLMs to synthesize reliable and auditable workflows with explicit control and data flow. Verbs can carry preconditions, postconditions, policy tags, and logging support, which improves reliability by providing stable interfaces, efficiency by reducing dozens of steps into a few function calls, and verifiability through typed contracts and checkable traces. We present our vision, a proof-of-concept implementation, and representative case studies that demonstrate concise and robust execution compared to existing agents. Finally, we outline a roadmap for standardization to make verbs deployable and trustworthy at web scale.
1. Introduction
The Web is rapidly shifting from a place where people browse to a platform where software acts (Ning et al., 2025).
With the problem-solving capabilities of modern large language models (LLMs), it is increasingly realistic for natural language (NL) to serve as a primary user interface to online services (Liu et al., 2024; Plaat et al., 2025).
Web agents interpret an NL task and operate a browser or APIs to fulfill goals such as booking trips, completing purchases, or submitting applications (Nakano et al., 2021; Yao et al., 2022). This vision of an agentic web has catalyzed a surge of research and prototyping (Qin et al., 2025; Agashe et al., 2025a; Agashe et al., 2025b).
Figure 1. The pillar of NLWeb: a semantic layer that improves retrieval and grounding for agents.
Realizing this vision requires coordinated progress on two complementary directions. First, agent capabilities continue to advance, including perception, planning, tool use, and self-monitoring at web scale, as represented by recent systems and benchmarks.
Second, the Web itself must evolve to be hospitable to agents, not only to human eyes. A notable step toward the latter is NLWeb (Microsoft, 2025), an open initiative that wraps the “raw” Web with a semantic layer for agent interaction (Figure 1). Using mechanisms such as RSS (Hammersley, 2003) and Schema.org (Schema.org Community Group, 2011), website developers can create entities such as typed objects, lists, updates, and references from unstructured content. NLWeb tooling embeds these entities and ingests them into a vector database.
However, NLWeb currently focuses only on web content. It demonstrates that a semantic layer improves accuracy, completeness, freshness, and grounding for agent queries. Yet the agentic web consists not only of content but also of actions. In this paper, we present our vision for a semantic layer for web actions and show that it is both necessary and achievable.
