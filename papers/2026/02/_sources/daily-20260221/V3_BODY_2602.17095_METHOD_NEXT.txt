3 Methodology
3.1 FLoRG
In this section, we propose FLoRG, a federated fine-tuning framework.
FLoRG employs a single low-rank matrix and aggregates Gram matrices to eliminate the error induced by the separate aggregation as in conventional LoRA.
FLoRG performs Procrustes alignment to the decomposed matrix to minimize the decomposition drift.
A schematic illustration is shown in Fig. 1.
Figure 1: System model of our proposed FLoRG.
We consider a central server and NN clients.
Let 𝒯={1,2,…,T}\mathcal{T}=\{1,2,\ldots,T\} and 𝒩={1,2,…,N}\mathcal{N}=\{1,2,\ldots,N\} denote the set of TT fine-tuning rounds and the set of NN clients, respectively.
At the beginning of the first fine-tuning round, each client n∈𝒩n\in\mathcal{N} has the same pretrained weight matrix 𝐖0∈ℝdout×din\mathbf{W}^{0}\in\mathbb{R}^{d_{\mathrm{out}}\times d_{\mathrm{in}}}.
Note that 𝐖0\mathbf{W}^{0} is kept frozen and will not be updated during fine-tuning.
We consider that each client n∈𝒩n\in\mathcal{N} has a local dataset 𝒟n\mathcal{D}_{n}.
Let 𝝃n∼𝒟n\bm{\xi}_{n}\sim\mathcal{D}_{n} denote a mini-batch of training samples.
Let Fn​(𝐖t,𝝃n)F_{n}(\mathbf{W}^{t};\bm{\xi}_{n}) denote the local loss function of client n∈𝒩n\in\mathcal{N} on 𝝃n\bm{\xi}_{n} with model 𝐖t\mathbf{W}^{t} in the tt-th fine-tuning round.
We denote the expected loss of client nn with model 𝐖t\mathbf{W}^{t} as Fn​(𝐖t)=𝔼𝝃n∼𝒟n​[Fn​(𝐖t,𝝃n)]F_{n}(\mathbf{W}^{t})=\mathbb{E}_{\bm{\xi}_{n}\sim\mathcal{D}_{n}}[F_{n}(\mathbf{W}^{t};\bm{\xi}_{n})].
Let ∇Fn​(𝐖t,𝝃n)\nabla F_{n}(\mathbf{W}^{t};\bm{\xi}_{n}) denote the local stochastic gradient of 𝐖t\mathbf{W}^{t} of client nn in the tt-th fine-tuning round.
The learning procedure of FLoRG can be summarized as the following steps.
(i) Local Update with Low-rank Gram Matrices:
Different from LoRA, FLoRG uses a single matrix 𝐀∈ℝr×k\mathbf{A}\in\mathbb{R}^{r\times k} for fine-tuning, where r≪min⁡{din,dout}r\ll\min\{d_{\mathrm{in}},d_{\mathrm{out}}\} denotes the rank of 𝐀\mathbf{A}.
Let k=min⁡{din,dout}k=\min\{d_{\mathrm{in}},d_{\mathrm{out}}\}.
Matrices 𝐋∈ℝdout×k\mathbf{L}\in\mathbb{R}^{d_{\mathrm{out}}\times k} and 𝐑∈ℝk×din\mathbf{R}\in\mathbb{R}^{k\times d_{\mathrm{in}}} are initialized and shared across all clients.
Both matrices 𝐋\mathbf{L} and 𝐑\mathbf{R} are semi-orthogonal, i.e., 𝐋⊺​𝐋=𝐈k\mathbf{L}^{\intercal}\mathbf{L}=\mathbf{I}_{k} and 𝐑𝐑⊺=𝐈k\mathbf{R}\mathbf{R}^{\intercal}=\mathbf{I}_{k}.
Note that matrices 𝐋\mathbf{L} and 𝐑\mathbf{R} remain unchanged during fine-tuning.
The fine-tuning matrix in the tt-th fine-tuning round is
Δ​𝐖t=𝐋𝐐t​𝐑=𝐋​(𝐀t)⊺​𝐀t​𝐑,t∈𝒯,\displaystyle\Delta\mathbf{W}^{t}=\mathbf{L}\mathbf{Q}^{t}\mathbf{R}=\mathbf{L}(\mathbf{A}^{t})^{\intercal}\mathbf{A}^{t}\mathbf{R},\quad t\in\mathcal{T},
(1)
where 𝐐t\mathbf{Q}^{t} denotes the square Gram parameter matrix in the tt-th fine-tuning round.
By leveraging 𝐋\mathbf{L} and 𝐑\mathbf{R}, FLoRG is compatible with parameter matrices of any dimensions.
Thus, the full model can be expressed as 𝐖t=𝐖0+Δ​𝐖t\mathbf{W}^{t}=\mathbf{W}^{0}+\Delta\mathbf{W}^{t}.
In the tt-th fine-tuning round, the central server broadcasts 𝐀t\mathbf{A}^{t} to all clients.
Client n∈𝒩n\in\mathcal{N} updates 𝐀t\mathbf{A}^{t} using its local dataset.
Let ∇𝐀Fn​(𝐖t,𝝃n)∈ℝr×k\nabla_{\mathbf{A}}F_{n}(\mathbf{W}^{t};\bm{\xi}_{n})\in\mathbb{R}^{r\times k} denote the gradient of the low-rank matrix, which is given by
∇𝐀Fn​(𝐖t,𝝃n)=𝐀t​(𝐇nt+(𝐇nt)⊺),n∈𝒩,t∈𝒯,\displaystyle\nabla_{\mathbf{A}}F_{n}(\mathbf{W}^{t};\bm{\xi}_{n})=\mathbf{A}^{t}\left(\mathbf{H}_{n}^{t}+(\mathbf{H}_{n}^{t})^{\intercal}\right),\quad n\in\mathcal{N},t\in\mathcal{T},
(2)
where 𝐇nt=𝐋⊺∇Fn(𝐖t;𝝃n)𝐑⊺\mathbf{H}_{n}^{t}=\mathbf{L}^{\intercal}\nabla F_{n}(\mathbf{W}^{t};\bm{\xi}_{n})\mathbf{R}^{\intercal}.
Client nn performs stochastic gradient descent to update matrix 𝐀t\mathbf{A}^{t}.
We define η\eta as the learning rate.
Let 𝐀nt+12\mathbf{A}_{n}^{t+\frac{1}{2}} denote the locally updated low-rank matrix of client nn in the tt-th fine-tuning round, which is given by
𝐀nt+12=𝐀t−η​∇𝐀Fn​(𝐖t,𝝃n),n∈𝒩,t∈𝒯.\displaystyle\mathbf{A}_{n}^{t+\frac{1}{2}}=\mathbf{A}^{t}-\eta\nabla_{\mathbf{A}}F_{n}(\mathbf{W}^{t};\bm{\xi}_{n}),\quad n\in\mathcal{N},t\in\mathcal{T}.
(3)
(ii) Model Aggregation:
When compared with the conventional federated LoRA schemes, in which clients must upload both locally-updated low-rank matrices, client nn in FLoRG only needs to transmit 𝐀nt+12\mathbf{A}_{n}^{t+\frac{1}{2}} to the central server, thereby reducing the per-round uplink communication overhead by more than half.
Let 𝐐nt+12=(𝐀nt+12)⊺​𝐀nt+12\mathbf{Q}_{n}^{t+\frac{1}{2}}=\left(\mathbf{A}_{n}^{t+\frac{1}{2}}\right)^{\intercal}\mathbf{A}_{n}^{t+\frac{1}{2}} denote the locally updated Gram matrix for client nn in the tt-th training round.
After receiving the locally updated parameter matrices from all clients, the central server performs model aggregation with respect to 𝐀nt+12\mathbf{A}_{n}^{t+\frac{1}{2}} as
𝐐t+1=1N​∑n∈𝒩𝐐nt+12,t∈𝒯,\displaystyle\mathbf{Q}^{t+1}=\frac{1}{N}\sum_{n\in\mathcal{N}}\mathbf{Q}_{n}^{t+\frac{1}{2}},\quad t\in\mathcal{T},
(4)
where 𝐐t+1∈ℝk×k\mathbf{Q}^{t+1}\in\mathbb{R}^{k\times k} is the aggregated Gram matrix at the end of the tt-th fine-tuning round.
Due to the Gram matrix design, aggregating (𝐀nt+12)⊺​𝐀nt+12\left(\mathbf{A}_{n}^{t+\frac{1}{2}}\right)^{\intercal}\mathbf{A}_{n}^{t+\frac{1}{2}} is linear and preserves the positive semi-definite (PSD) property.
Therefore, the central server can obtain the true aggregated matrix.
This removes the bilinear inconsistency induced by aggregating matrices 𝐁n\mathbf{B}_{n} and 𝐀n\mathbf{A}_{n} separately as in conventional federated LoRA schemes (i.e., aggregation error).
Let r′r^{\prime} denote the rank of 𝐐t+1\mathbf{Q}^{t+1}, which satisfies
rank⁡(𝐐nt+12)≤r′=rank⁡(𝐐t+1)​≤(a)​min⁡{k,N​r},\displaystyle\mathrm{rank}(\mathbf{Q}_{n}^{t+\frac{1}{2}})\leq r^{\prime}=\mathrm{rank}(\mathbf{Q}^{t+1})\overset{(\mathrm{a})}{\leq}\min\left\{k,Nr\right\},
(5)
where inequality (a) follows from the subadditivity property of rank operator.
(iii) Decomposition with Procrustes Alignment:
Since 𝐐t+1\mathbf{Q}^{t+1} is a square PSD Gram matrix, the central server performs eigendecomposition to 𝐐t+1\mathbf{Q}^{t+1} as follows:
𝐐t+1=(𝐏t+1)⊺​Λt+1​𝐏t+1,t∈𝒯,\displaystyle\mathbf{Q}^{t+1}=(\mathbf{P}^{t+1})^{\intercal}\Lambda^{t+1}\mathbf{P}^{t+1},\quad t\in\mathcal{T},
(6)
where 𝐏t+1∈ℝr′×k\mathbf{P}^{t+1}\in\mathbb{R}^{r^{\prime}\times k}.
Λt+1∈ℝr′×r′\Lambda^{t+1}\in\mathbb{R}^{r^{\prime}\times r^{\prime}} denotes the eigenvalue matrix of 𝐐t+1\mathbf{Q}^{t+1}.
Thus, a canonical decomposition which satisfies (𝐀~t+1)⊺​𝐀~t+1=𝐐t+1(\tilde{\mathbf{A}}^{t+1})^{\intercal}\tilde{\mathbf{A}}^{t+1}=\mathbf{Q}^{t+1} is
𝐀~t+1=(Λt+1)12​𝐏t+1,t∈𝒯,\displaystyle\tilde{\mathbf{A}}^{t+1}=(\Lambda^{t+1})^{\frac{1}{2}}\mathbf{P}^{t+1},\quad t\in\mathcal{T},
(7)
where 𝐀~t+1\tilde{\mathbf{A}}^{t+1} is a valid decomposition of 𝐐t+1\mathbf{Q}^{t+1}.
However, directly applying 𝐀~t+1\tilde{\mathbf{A}}^{t+1} for the subsequent fine-tuning round (i.e., 𝐀t+1:=𝐀~t+1\mathbf{A}^{t+1}:=\tilde{\mathbf{A}}^{t+1}) may yield sub-optimal performance since the decomposition yields two challenges: non-unique decomposition and rank mismatch.
First, the above expression of matrix 𝐀~t+1\tilde{\mathbf{A}}^{t+1} provides a canonical representation of the decomposition of 𝐐t+1\mathbf{Q}^{t+1}, which is non-unique.
This is because for any matrix with orthogonal columns 𝐎∈ℝr′×r′\mathbf{O}\in\mathbb{R}^{r^{\prime}\times r^{\prime}}, we have (𝐎​𝐀~t+1)⊺​𝐎​𝐀~t+1=𝐐t+1(\mathbf{O}\tilde{\mathbf{A}}^{t+1})^{\intercal}\mathbf{O}\tilde{\mathbf{A}}^{t+1}=\mathbf{Q}^{t+1}.
Furthermore, although the decomposition guarantees that (𝐀~t+1)⊺​𝐀~t+1(\tilde{\mathbf{A}}^{t+1})^{\intercal}\tilde{\mathbf{A}}^{t+1} preserves the aggregated Gram matrix, there exist many such decompositions due to the non-uniqueness of decompositions (e.g., Cholesky decomposition or SVD) when the rank is deficient or the eigenvalues have multiplicities.
However, this non-uniqueness affects the future fine-tuning.
