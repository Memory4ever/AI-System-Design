We seek a
single gate g∗∈𝒢1g^{*}\in\mathcal{G}_{1} robust to the worst-case mixture
λ∈Δ\lambda\in\Delta. We formulate this as a minimax game:
ming∈𝒢1maxλ∈Δ⁡([1,p])𝖣KL(𝗉^λ∥πg).\min_{g\in\mathcal{G}_{1}}\max_{\lambda\in\Delta([1,p])}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{g}).
We use the relative entropy rather than cross-entropy because the
entropy term H⁡(𝗉^λ)H(\widehat{\mathsf{p}}_{\lambda}) varies with the adversarial choice
of λ\lambda. Minimizing the worst-case cross-entropy
maxλ⁡𝔼𝗉^λ[−log⁡π]\max_{\lambda}\E_{\widehat{\mathsf{p}}_{\lambda}}[-\log\pi] is thus not equivalent
to minimizing the divergence
maxλ𝖣KL(𝗉^λ∥π)\max_{\lambda}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\|\pi), which ensures the model
approximates the distribution 𝗉^λ\widehat{\mathsf{p}}_{\lambda} itself.
Given the setup, our objective is to find a single
gating function g∈𝒢1g\in\mathcal{G}_{1} such that the resulting model πg\pi_{g}
is a high-quality approximation of any data mixture 𝗉^λ\widehat{\mathsf{p}}_{\lambda}. We use the relative entropy, 𝖣KL\mathsf{D}_{\mathrm{KL}} divergence, as our
measure of dissimilarity. This leads to two primary formulations.
First, as a preliminary question, we can ask what performance is
achievable for a single, fixed mixture λ\lambda. This
corresponds to the standard convex optimization problem:
ming∈𝒢1𝖣KL(𝗉^λ∥πg).\min_{g\in\mathcal{G}_{1}}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{g}).
Finding a solution to this problem would provide an optimal gate for a
known, static test distribution.
Second, and more central to our goal of modularity and robustness, we
ask for a single gate g∗g^{*} that performs well against the
worst-case mixture λ∈Δ\lambda\in\Delta. This is a robust
optimization problem that can be formulated as a minimax game:
ming∈𝒢1maxλ∈Δ⁡([1,p])𝖣KL(𝗉^λ∥πg).\min_{g\in\mathcal{G}_{1}}\max_{\lambda\in\Delta([1,p])}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{g}).
The solution g∗g^{*} to this game would be a truly robust model,
providing a uniform performance guarantee across the entire ambiguity
set of possible data mixtures.
Our use of the relative entropy, rather than the
cross-entropy loss, is essential. While minimizing KL is equivalent
to minimizing cross-entropy for a fixed target distribution
(since entropy is constant), this equivalence breaks down in the
robust setting. The entropy term H⁡(𝗉^λ)H(\widehat{\mathsf{p}}_{\lambda}) varies with the
adversarial choice of λ\lambda. Consequently, minimizing the
worst-case cross-entropy
maxλ⁡𝔼𝗉^λ[−log⁡π]\max_{\lambda}\E_{\widehat{\mathsf{p}}_{\lambda}}[-\log\pi] is not equivalent to
minimizing the worst-case divergence
maxλ𝖣KL(𝗉^λ∥π)\max_{\lambda}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\|\pi). We target the latter to
ensure the model approximates the distribution 𝗉^λ\widehat{\mathsf{p}}_{\lambda}
itself, rather than merely covering its support.
Our work aims to answer several fundamental theoretical and
algorithmic questions arising from these formulations:
1.
Fixed-mixture performance: For a fixed mixture λ\lambda, does
there exist a gated solution πg\pi_{g} with small divergence
𝖣KL(𝗉^λ∥πg)\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{g})? More specifically, how does
this optimal error
ming∈𝒢1𝖣KL(𝗉^λ∥πg)\min_{g\in\mathcal{G}_{1}}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{g}) compare
to the baseline errors ϵk\epsilon_{k}?
2.
Robust guarantee: Does there exist a robust gated
solution πg∗\pi_{g^{*}} that achieves small divergence for all
λ∈Δ\lambda\in\Delta? This is a question of existence for the
minimax problem
mingmaxλ𝖣KL(𝗉^λ∥πg)\min_{g}\max_{\lambda}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{g}).
3.
Construction and bounds: If such a robust solution exists, how
can we construct it algorithmically? What explicit, non-asymptotic
guarantees can we provide for its worst-case performance,
maxλ𝖣KL(𝗉^λ∥πg∗)\max_{\lambda}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{g^{*}}), in terms
of the individual expert guarantees ϵk\epsilon_{k}?
4.
Comparison to aggregate training: For a fixed mixture λ\lambda, how does the performance of our
modular solution πg\pi_{g} compare to that of a model π^λ\widehat{\pi}_{\lambda}
trained from scratch on the aggregate data
𝗉^λ=∑k=1pλk​𝗉^k\widehat{\mathsf{p}}_{\lambda}=\sum_{k=1}^{p}\lambda_{k}\widehat{\mathsf{p}}_{k}? Understanding this trade-off is key to justifying the modular
approach over the expensive, non-adaptive retraining baseline.
In Section 4, we will address these questions,
starting with the existence and bounds for the fixed and robust
solutions.
4 Theoretical Analysis
We now establish the existence of a robust gate and quantify its
advantages over monolithic retraining.
4.1 Fixed Mixture
First, we consider a simple non-adaptive baseline. If we fix the
mixture weights λ\lambda, a constant gate
gλ​(x,k)=λkg_{\lambda}(x,k)=\lambda_{k} (which belongs to 𝒢1\mathcal{G}_{1}) achieves an
average error bound.
Proposition 2 (Fixed Mixture Guarantee).
For any fixed λ∈Δ\lambda\in\Delta, the constant gate
πλ=∑kλk​π^k\pi_{\lambda}=\sum_{k}\lambda_{k}\widehat{\pi}_{k} satisfies
𝖣KL(𝗉^λ∥πλ)≤∑k=1pλkϵk≤maxkϵk\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{\lambda})\leq\sum_{k=1}^{p}\lambda_{k}\epsilon_{k}\leq\max_{k}\epsilon_{k}.
Proof.
The result follows directly from the joint convexity of the KL divergence:
𝖣KL(𝗉^λ∥πλ)=𝖣KL(∑k=1pλk𝗉^k∥∑k=1pλkπ^k)≤∑k=1pλk𝖣KL(𝗉^k∥π^k)≤∑k=1pλkϵk.\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{\lambda}\parallel\pi_{\lambda})=\mathsf{D}_{\mathrm{KL}}\left(\sum_{k=1}^{p}\lambda_{k}\widehat{\mathsf{p}}_{k}\parallel\sum_{k=1}^{p}\lambda_{k}\widehat{\pi}_{k}\right)\leq\sum_{k=1}^{p}\lambda_{k}\mathsf{D}_{\mathrm{KL}}(\widehat{\mathsf{p}}_{k}\parallel\widehat{\pi}_{k})\leq\sum_{k=1}^{p}\lambda_{k}\epsilon_{k}.
This completes the proof.
∎
This proposition guarantees average performance for a known mixture
λ\lambda using a simple non-adaptive gate. (We derive the exact,
though complex, optimal gate for a fixed λ\lambda in
Appendix A). However, we prove in
Appendix B
(Theorem 14) that any static weighting scheme is
fundamentally limited by a capacity lower bound of
log⁡(∑keϵk)\log(\sum_{k}e^{\epsilon_{k}}), for disjoint domains. To overcome this
barrier and achieve robustness to unknown λ\lambda, we require
an input-dependent gate.

Here, we show the existence of a gate model with a favorable guarantee
for any target mixture λ\lambda. We will use the linearized
game, which is defined by the payoff

Jensen-Shannon Divergence (JSD), which is a measure of
diversity. For a mixture
