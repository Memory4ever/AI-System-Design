In this stage, we use Qwen2.5-VL as a vision-language model to map (st,at)(s_{t},a_{t}) to a textual transition description Δt\Delta_{t}.

A.2.3 Stage 2: Qwen-Image-Edit supervised training (visual realization)
In this stage, we use Qwen-Image-Edit as a conditional image editing model to generate the next UI screenshot.
The model is conditioned on the current UI screenshot and the predicted textual transition:
s^t+1=fimage​(st,Δt)\hat{s}_{t+1}=f_{\mathrm{image}}(s_{t},\Delta_{t}).
We fine-tune the model with a pixel-wise reconstruction objective using the mean squared error (MSE) loss:
ℒEDIT=‖s^t+1−st+1‖22\mathcal{L}_{\mathrm{EDIT}}=\|\hat{s}_{t+1}-s_{t+1}\|_{2}^{2},

A.2.4 Stage 1 RL Refinement: Qwen2.5-VL + GRPO
Although SFT provides a faithful initialization, it does not guarantee that the generated textual transition Δt\Delta_{t} consistently captures the most decision-critical UI structures.
To address this, we further refine the Stage 1 model using Group Relative Policy Optimization (GRPO), treating the VLM as a policy πθ\pi_{\theta} that generates Δt\Delta_{t} conditioned on (st,at)(s_{t},a_{t}).
During training, for each input tuple (st,at)(s_{t},a_{t}), we sample a group of K=5K=5 candidate descriptions {Δt(k)}k=1K\{\Delta_{t}^{(k)}\}_{k=1}^{K} from the current policy using a temperature of 1.0 and top-pp of 1.0.
