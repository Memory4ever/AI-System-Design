Rather than relying on a single refusal mechanism, we encode refusal as a collection of causally redundant directions, each capable of independently triggering refusal on harmful queries.

Overview.
Algorithm 1 presents the pseudo-code for our method, which proceeds iteratively.
At each iteration, we (Lines 4–6) identify the model’s dominant refusal direction, then (Lines 7–8) construct an operator to remove all previously identified refusal directions from the activation space, and finally (Lines 10–14) fine-tune the model to preserve refusal behavior under the operator while maintaining benign utility.
This procedure is repeated for a fixed number of iterations (KK), after which the fine-tuned model is returned.
Each iteration encourages the emergence of a new refusal direction that is robust to the removal of previously learned ones, yielding a model whose refusal behavior does not depend on any single mechanism.
The result is a multi-feature instantiation of fail-closed alignment, in which refusal cannot be bypassed by suppressing just a few directions.
3.1 Identifying the Next Dominant Refusal direction
We aim to encode refusal as a set of meaningful, redundant feature directions, any of which can independently enforce refusal once others are suppressed.
This section describes our iterative procedure for identifying these directions.
Prior work proposes two approaches for identifying refusal directions: activation-space methods (Arditi et al., 2024; Piras et al., 2025), which estimate directions from collected activations, and gradient-based methods (Wollschläger et al., 2025), which learn them through optimization.
We adopt gradient-based identification, as recent work shows it outperforms activation-space approaches (Wollschläger et al., 2025); a direct empirical comparison is provided in §4.5.
Gradient-based direction identification.
To identify refusal directions, we leverage the state-of-the-art Refusal Direction Optimization (RDO) (Wollschläger et al., 2025) algorithm.
Given a target model fθf_{\theta}, RDO optimizes a direction 𝐫∈ℝd\mathbf{r}\in\mathbb{R}^{d} to have a strong causal influence under addition (Eq. 2) and ablation (Eq. 3).
By re-optimizing at each iteration, RDO yields directions that are locally optimal for the current model, enabling continued discovery even after earlier mechanisms have been suppressed.
We refer readers to the original study for implementation details.
Implementation.
We use RDO as our direction identification subroutine, using the provided dataset splits from SaladBench (Li et al., 2024) and Alpaca (Taori et al., 2023).
At each iteration, we initialize the refusal direction using a DIM estimate to provide a stable starting point, then optimize it with RDO, saving candidate directions after each gradient update.
To enforce linear independence across iterations, we project each candidate onto the span of previous directions and retain only those with residual norm exceeding 10−510^{-5} (all directions are ℓ2\ell_{2}-normalized).
We then select the candidate with the lowest training loss.
Algorithm 1 denotes this procedure as IdentifyRefusalDirection(fθf_{\theta}), where fθf_{\theta} is the target language model we aim to train.
3.2 Constructing the Ablation Operator
Our method is the first framework to explicitly remove multiple previously learned refusal mechanisms during training, thereby creating conditions for new mechanisms to emerge.
This section defines our mechanism for removing all previously identified refusal feature directions during training.
At iteration kk, we have identified independent refusal directions {r1,…,rk}⊂ℝd\{r_{1},\dots,r_{k}\}\subset\mathbb{R}^{d}.
Our goal is to prevent the model from relying on any of these during training.
However, existing ablation techniques suppress only a single direction (Xie et al., 2025; Yu et al., 2025), allowing the model to use previously learned mechanisms.
We address this by constructing an operator that jointly suppresses all identified features.
Multi-feature ablation.
To prevent usage of {r1,…,rk}\{r_{1},\dots,r_{k}\}, we ablate their span from the model’s hidden states.
We first form the matrix Rk=[r1⋯rk]∈ℝd×kR_{k}=[\,r_{1}\ \cdots\ r_{k}\,]\in\mathbb{R}^{d\times k} and compute an orthonormal basis Qk∈ℝd×kQ_{k}\in\mathbb{R}^{d\times k} for span⁡({r1,…,rk})\mathrm{span}(\{r_{1},\dots,r_{k}\}) via a reduced QR decomposition.

We apply this operator at all layers and token positions during forward passes on harmful prompts, ensuring no component can leverage {r1,…,rk}\{r_{1},\dots,r_{k}\}.
This encourages the model to develop a new, independent refusal direction by iteration k+1k{+}1. In Algorithm 1, we denote BuildMfaOperator(ℛ\mathcal{R}) as the subroutine that constructs MFAk\mathrm{MFA}_{k} from the set of refusal directions ℛ\mathcal{R} identified so far.
3.3 Training to Learn New Refusal Under Ablation
The final stage of our method is to construct new refusal mechanisms.
Unlike prior alignment approaches that reinforce a single refusal direction (Xie et al., 2025; Yu et al., 2025), we explicitly train the model under interventions that disable all previously identified refusal mechanisms.
As a result, each iteration must yield a new refusal mechanism that remains effective even after earlier ones are removed.
This section introduces our training objective for encoding new refusal mechanisms without compromising utility.
Training data curation.
Our objective balances two goals: enforcing refusal on harmful inputs while preserving benign behavior.
We curate separate datasets for each.
To model safe behaviors, we follow prior work (Yu et al., 2025; Xie et al., 2025) and use the CircuitBreaker adversarial training dataset (Zou et al., 2024), which contains 5,000 harmful prompts across diverse topics.
For benign utility, we sample 4,500 prompts from Alpaca (Taori et al., 2023), a curated instruction-following dataset, and 200 prompts from XSTest (Röttger et al., 2024), a benchmark of benign prompts that resemble harmful requests but are safe in intent.
Including XSTest is critical to discourage trivial refusal strategies, such as indiscriminately refusing all inputs with certain tokens.
We keep all training prompts disjoint from those used for refusal direction identification (§3.1).
Most prior work pairs training prompts with pre-generated completions sampled from static models (e.g., Llama3 or GPT-4) (Yu et al., 2025; Xie et al., 2025; Xhonneux et al., 2024; Zou et al., 2024; Sheshadri et al., 2025).
However, such content can suffer from response drift: static responses often differ in tone or structure from the target LLM, impeding development of new refusal mechanisms (see §4.5).
To avoid this, we generate all training completions directly from the base model fθ0f_{\theta_{0}}: refusal responses for harmful queries and compliant responses for Alpaca and XSTest prompts.
To ensure correct content, we apply keyword-based filtering (Röttger et al., 2024) to remove non-refusals from the safety set and refusals from the benign set.
This yields two datasets: 𝒟safe={(xi,yi)}i=1Nsafe\mathcal{D}_{\mathrm{safe}}=\{(x_{i},y_{i})\}_{i=1}^{N_{\mathrm{safe}}} with Nsafe=5,000N_{\mathrm{safe}}=5{,}000 harmful prompts paired with refusal responses, and 𝒟util={(xi,yi)}i=1Nutil\mathcal{D}_{\mathrm{util}}=\{(x_{i},y_{i})\}_{i=1}^{N_{\mathrm{util}}} with Nutil=4,700N_{\mathrm{util}}=4{,}700 benign prompts paired with compliant responses, both generated by fθ0f_{\theta_{0}}.

Our goal is to learn a refusal mechanism that remains effective even when previously identified refusal directions are removed.

Optimizing this objective forces the model to learn to refuse harmful inputs via a new, redundant refusal mechanism.

4.1 Experimental Setup
Jailbreaking benchmarks.
We evaluate robustness to jailbreaks by randomly sampling 200 prompts from HarmBench (Mazeika et al., 2024) and AdvBench (Zou et al., 2023).
Following recent work (Yu et al., 2025), we generate prompt-based jailbreaks using four attacks: GCG (Zou et al., 2023), AutoDAN (Liu et al., 2024), PAIR (Chao et al., 2024), and HumanJailbreaks (Shen et al., 2024).
See Appendix A.3 for a description of each attack and Appendix D for example prompts.
We include both white- and black-box algorithms to evaluate robustness under auditing-only settings and against practical adversaries.
We use the official HarmBench implementations and default hyperparameters for all attacks.
We also assess robustness to feature ablation by independently ablating the DIM (Arditi et al., 2024) and RDO (Wollschläger et al., 2025) refusal features, followed by generating responses to the unmodified harmful prompts.
For each attack (and the unmodified prompts), we report the attack success rate (ASR), defined as the fraction of model responses classified as harmful.
