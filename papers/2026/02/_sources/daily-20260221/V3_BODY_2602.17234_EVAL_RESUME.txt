6.3. Evaluation Metrics
We evaluate agents along two complementary dimensions: task performance and temporal leakage. This dual evaluation reveals whether high performance stems from legitimate reasoning or inadvertent use of future information.
Performance Metrics.
Each task employs a standard metric appropriate to its prediction type:
•

6.4. Implementation
All agents use Claude-sonnet-4 as the backbone LLM with temperature 0 for deterministic outputs. For TimeSPEC, we use Perplexity API with the sonar model for temporally-filtered search, retrieving up to 5 results per query. Maximum regeneration iterations is set to 1, bounding computational cost at two generation cycles. The evaluation pipeline uses Claude-sonnet-4 for claim extraction and Shapley value estimation, with 100 Monte Carlo permutations per instance. Temporal verification queries the Perplexity API to retrieve source publication dates. Additional details are provided in Appendix A.

Our analysis reveals that the relationship between these dimensions varies substantially across tasks, validating both our detection framework and TimeSPEC’s mitigation strategy.
