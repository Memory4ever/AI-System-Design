5 Adaptive Evaluator Hardness
5.1 Setup
The key insight is that an adaptive evaluator’s advantage comes from choosing queries
based on past responses. An mm-wise independent hash construction eliminates this
advantage: every query, however chosen, hits the trigger set with the same probability ε\varepsilon.

Remark 5.2 (Why the Bound Uses ε\varepsilon, Not δ\delta).
The bound (3) is parameterized by ε\varepsilon because the hash
construction forces the expected risk separation to be ε​L\varepsilon L
(Lemma 3.6). The larger gap δ​L\delta L arises only when deployment
has privileged information—a computational phenomenon established in
Theorem 7.3. The two results address distinct threat models and
are complementary, not redundant.
Remark 5.3 (Tightness and Matching Upper Bounds).
Theorem 5.1 is a worst-case lower bound. Whether matching upper bounds
(achievability results showing error o⁡(ε​L)o(\varepsilon L) for m≫1/εm\gg 1/\varepsilon) exist
under our model class is an open question. In the passive setting, once m=Θ⁡(1/ε)m=\Theta(1/\varepsilon),
an empirical mean estimator achieves error O⁡(δ​L⋅e−Ω⁡(m​ε))O(\delta L\cdot e^{-\Omega(m\varepsilon)})
by Theorem 6.1, so the lower bound is tight in the regime m=O⁡(1/ε)m=O(1/\varepsilon).
For adaptive evaluators, the hash construction shows no adaptive strategy can improve the
m​εm\varepsilon detection barrier in the worst case; whether adaptive strategies outperform
passive sampling for specific (non-worst-case) model classes is an interesting open direction.
6 Query Complexity
Theorem 6.1 (Query Complexity Bounds).
Suppose triggers occur independently with probability ε\varepsilon for each i.i.d. sample from 𝒟eval\mathcal{D}_{\mathrm{eval}}. Let N=min⁡{i:xi∈Strigger}N=\min\{i:x_{i}\in S_{\mathrm{trigger}}\}

(a)
𝔼⁡[N]=1/ε\mathbb{E}[N]=1/\varepsilon.
(b)

Proof.
(a). Each query independently hits StriggerS_{\mathrm{trigger}} with probability
ε\varepsilon, so N∼Geometric⁡(ε)N\sim\mathrm{Geometric}(\varepsilon) (number of trials to first
success). The mean of a geometric(ε)(\varepsilon) random variable is 1/ε1/\varepsilon.
Explicitly: P[N=k]=(1−ε)k−1εP[N=k]=(1-\varepsilon)^{k-1}\varepsilon for k=1,2,…k=1,2,\ldots. Then:
𝔼[N]=∑k=1∞k(1−ε)k−1ε=ε⋅dd⁡(1−ε)[−∑k=0∞(1−ε)k]−1\mathbb{E}[N]=\sum_{k=1}^{\infty}k(1-\varepsilon)^{k-1}\varepsilon=\varepsilon\cdot\frac{d}{d(1-\varepsilon)}\!\left[-\sum_{k=0}^{\infty}(1-\varepsilon)^{k}\right]^{-1}

𝔼⁡[N]=ε⋅1/ε2=1/ε\mathbb{E}[N]=\varepsilon\cdot 1/\varepsilon^{2}=1/\varepsilon.

Remark 6.2 (Scope: i.i.d. vs. Adaptive Settings).
Theorem 6.1 applies to i.i.d. sampling where trigger hits are independent
Bernoulli(ε)(\varepsilon) trials. In the adaptive/hash setting, Lemma 3.3(ii)
guarantees only P⁡[∃hit]≤m​εP[\exists\,\text{hit}]\leq m\varepsilon via a union bound. The
exponential tail bound (1−ε)m≤e−m​ε(1-\varepsilon)^{m}\leq e^{-m\varepsilon} does not apply without
the independence structure of i.i.d. sampling.
