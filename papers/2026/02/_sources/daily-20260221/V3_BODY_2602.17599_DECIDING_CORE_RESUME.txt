4.2. Visual Conditioning Extractor
AudioLDM 2 was originally designed to handle only textual conditioning, meaning its internal LoA representation lacks a native mechanism for incorporating visual information. Simply fine-tuning the model with image–audio pairs does not enable cross-modal alignment, because the denoiser and GPT-2 expect conditioning expressed in a tokenized text space. To overcome this architectural limitation, 𝒜​rt2​ℳ​us\mathcal{A}\textit{rt2}\mathcal{M}\textit{us} introduces the Visual Conditioning Extractor, a new component that establishes a dedicated path for visual semantics to enter the LoA space (Figure 4a).
Given an artwork image, a pretrained vision encoder extracts an embedding of dimension 512 (CLIP) or 1024 (ImageBind). These embeddings are then passed to the Image Aligner (Figure 4b), composed of:
•
Upscaler: expands 512-dimensional CLIP embeddings to 1024 dimensions;
•
Projection Layer: maps each 1024-dimensional embedding to NN tokens in GPT-2’s 768-dimensional embedding space.
This modular design ensures compatibility with heterogeneous visual encoders and provides a stable intermediate representation. Empirically, using a 1024-dimensional staging space before projection yielded more faithful, stylistically coherent music than directly projecting lower-dimensional embeddings.
4.3. Music Generation Process
Given an artwork, the Visual Conditioning Extractor produces image-derived conditioning tokens, which GPT-2 transforms into LoA embeddings cvisc_{\text{vis}}. In parallel, the textual prompt “Music representing the content of this artwork” is encoded using FLAN-T5 (Chung et al., 2024), producing ctextc_{\text{text}}. The final conditioning vector cc combines both modalities.

4.4. Training Algorithm
Training 𝒜​rt2​ℳ​us\mathcal{A}\textit{rt2}\mathcal{M}\textit{us} requires learning a cross-modal alignment that is fundamentally absent in AudioLDM 2: the model must associate fine-grained visual embeddings with the structure of music encoded in the LoA space. This constitutes a new learning problem, since AudioLDM 2 is never exposed to images and lacks any prior for relating visual semantics to musical attributes.
Specifically, training relies on triplets composed of an artwork, its paired music track, and a fixed guiding prompt, which is the same one used at inference time (i.e., “Music representing the content of this artwork”). Classifier-free guidance is enabled by also providing a negative prompt (e.g., “Low quality”), optionally augmented to discourage unwanted genres. The negative prompt helps the model steer the generation away from undesired aspects, improving overall quality and ensuring the output aligns more closely with the desired intent. Each paired music track is converted into a mel-spectrogram and encoded into a clean latent vector z0z_{0} using the AudioLDM 2 VAE. A timestep tt is sampled uniformly, and noise is added to obtain ztz_{t}. The diffusion model is trained to predict the added noise following Equation (5), conditioned on the visual LoA tokens and auxiliary textual embeddings.
Crucially, only the parameters of the Image Aligner are updated. All AudioLDM 2 components, including the denoiser and the GPT-2 LoA translator, remain frozen. This preserves the pretrained generative prior while enabling the system to learn a robust mapping from artworks to LoA conditioning features. Through this reformulation, 𝒜​rt2​ℳ​us\mathcal{A}\textit{rt2}\mathcal{M}\textit{us} demonstrates that a text-conditioned diffusion prior can be repurposed for direct visual-to-music generation via representation alignment, without altering the underlying generative architecture.
