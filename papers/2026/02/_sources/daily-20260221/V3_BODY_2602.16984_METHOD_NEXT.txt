2 Formal Framework
2.1 Notation
Let 𝒳\mathcal{X} denote input space, 𝒴\mathcal{Y} output space. A model is
fθ:𝒳→𝒴f_{\theta}:\mathcal{X}\to\mathcal{Y} with parameters θ∈Θ\theta\in\Theta.
Distributions: 𝒟eval\mathcal{D}_{\mathrm{eval}} (evaluation), 𝒟dep\mathcal{D}_{\mathrm{dep}}
(deployment). All losses take values in [0,1][0,1].
Core parameters.
•
ε\varepsilon: trigger probability under 𝒟eval\mathcal{D}_{\mathrm{eval}}
•
δ\delta: trigger probability under 𝒟dep\mathcal{D}_{\mathrm{dep}}, δ>ε\delta>\varepsilon
•
Δ:=δ−ε\Delta:=\delta-\varepsilon: trigger prevalence gap
•
ℓ0,ℓ1∈[0,1]\ell_{0},\ell_{1}\in[0,1]: expected conditional losses on non-trigger/trigger inputs
•
L:=|ℓ1−ℓ0|L:=|\ell_{1}-\ell_{0}|: loss gap
•
γ:=α0+α1−1∈(0,1]\gamma:=\alpha_{0}+\alpha_{1}-1\in(0,1]: probe quality (white-box section)
•
εR>0\varepsilon_{R}>0: risk estimation tolerance (white-box section; distinct from ε\varepsilon)
•
η∈(0,1)\eta\in(0,1): failure probability
Definition 2.1 (Total Variation Distance).
For distributions PP, QQ on a measurable space (Ω,𝒜)(\Omega,\mathcal{A}):
TV⁡(P,Q):=supA∈𝒜|P⁡(A)−Q⁡(A)|=12​∫|𝑑P−𝑑Q|.\mathrm{TV}(P,Q)\;:=\;\sup_{A\in\mathcal{A}}|P(A)-Q(A)|\;=\;\frac{1}{2}\int|\,dP-dQ\,|.
Equivalently, TV(P,Q)=inf(X,Y):X∼P,Y∼QP[X≠Y]\mathrm{TV}(P,Q)=\inf_{(X,Y):X\sim P,\,Y\sim Q}P[X\neq Y],
where the infimum is over all couplings. The coupling achieving this infimum always exists
for discrete or Polish spaces, which we assume throughout.
Assumption 2.2 (Evaluator Access).
The evaluator queries fθf_{\theta} on inputs from 𝒟eval\mathcal{D}_{\mathrm{eval}} (or chosen
adaptively), observing outputs only. The evaluator has no direct access to parameters
θ\theta (except in the white-box setting) and no access to 𝒟dep\mathcal{D}_{\mathrm{dep}}.
2.2 Latent Context-Conditioned Models
Definition 2.3 (Latent Context Conditioning).
Model fθf_{\theta} implements latent context conditioning if
fθ​(x)=gθ​(x,zθ​(x))f_{\theta}(x)=g_{\theta}(x,\,z_{\theta}(x)),
where zθ:𝒳→{0,1}z_{\theta}:\mathcal{X}\to\{0,1\} is a latent function and
gθ:𝒳×{0,1}→𝒴g_{\theta}:\mathcal{X}\times\{0,1\}\to\mathcal{Y}.
The trigger set is Strigger:={x:zθ​(x)=1}S_{\mathrm{trigger}}:=\{x:z_{\theta}(x)=1\}.
Definition 2.4 (Unobservability).
Latent zθz_{\theta} is unobservable if
gθ​(x,0)=gθ​(x,1)g_{\theta}(x,0)=g_{\theta}(x,1) for all x∉Striggerx\notin S_{\mathrm{trigger}}.
That is, the model’s output distribution is identical for safe and unsafe parameter
settings on all non-trigger inputs.
Assumption 2.5 (Perfect Distinguishability on Triggers).
For all x∈Striggerx\in S_{\mathrm{trigger}}:
TV⁡(gθ​(x,0),gθ​(x,1))=1\mathrm{TV}(g_{\theta}(x,0),\,g_{\theta}(x,1))=1.
That is, the model’s output distribution on trigger inputs under the safe parameterization
is completely disjoint from its output distribution under the unsafe parameterization.
Remark 2.6.
Assumption 2.5 is used only to derive TV⁡(P0,P1)≤ε\mathrm{TV}(P_{0},P_{1})\leq\varepsilon
in Step 1 of Theorem 4.1. Proposition 9.1 relaxes it to
TV⁡(gθ​(x,0),gθ​(x,1))≥c\mathrm{TV}(g_{\theta}(x,0),g_{\theta}(x,1))\geq c for c∈(0,1]c\in(0,1].
Definition 2.7 (Trigger Separation).
Latent zθz_{\theta} exhibits (ε,δ)(\varepsilon,\delta)-trigger separation if:
peval:=Px∼𝒟eval[zθ(x)=1]≤εandpdep:=Px∼𝒟dep[zθ(x)=1]≥δ.p_{\mathrm{eval}}:=P_{x\sim\mathcal{D}_{\mathrm{eval}}}[z_{\theta}(x)=1]\leq\varepsilon\qquad\text{and}\qquad p_{\mathrm{dep}}:=P_{x\sim\mathcal{D}_{\mathrm{dep}}}[z_{\theta}(x)=1]\geq\delta.
2.3 Risk and Evaluation Goals
Definition 2.8 (Deployment Risk).
Rdep​(θ)=pdep​ℓ1+(1−pdep)​ℓ0,R_{\mathrm{dep}}(\theta)\;=\;p_{\mathrm{dep}}\,\ell_{1}+(1-p_{\mathrm{dep}})\,\ell_{0},
where ℓz:=𝔼⁡[ℓ⁡(fθ​(X))∣zθ​(X)=z]\ell_{z}:=\mathbb{E}[\ell(f_{\theta}(X))\mid z_{\theta}(X)=z] for z∈{0,1}z\in\{0,1\}.
Goal: Estimate Rdep​(θ)R_{\mathrm{dep}}(\theta) to within absolute error εR>0\varepsilon_{R}>0.
2.4 Evaluator Types
Definition 2.9 (Evaluator Types).
(a) Passive: Draws mm i.i.d. samples from 𝒟eval\mathcal{D}_{\mathrm{eval}}, observes
model outputs, produces an estimate R^dep\hat{R}_{\mathrm{dep}}.
(b) Adaptive: Chooses each query xix_{i} as a deterministic or randomized
measurable function of the previous transcript (x1,fθ​(x1),…,xi−1,fθ​(xi−1))(x_{1},f_{\theta}(x_{1}),\ldots,x_{i-1},f_{\theta}(x_{i-1})); queries need not come from 𝒟eval\mathcal{D}_{\mathrm{eval}}.
(c) White-box: Inspects parameters θ\theta via a probe function; may access
samples from 𝒟dep\mathcal{D}_{\mathrm{dep}}.
3 First-Principles Supporting Lemmas
We collect and prove from scratch all mathematical primitives used in the main theorems.
No result in this section is cited without a self-contained proof.

Lemma 3.2 (Tensorization of Total Variation).
For any distributions PP, QQ on a common measurable space:
1−TV⁡(P⊗m,Q⊗m)≥(1−TV⁡(P,Q))m.1-\mathrm{TV}(P^{\otimes m},Q^{\otimes m})\;\geq\;\bigl(1-\mathrm{TV}(P,Q)\bigr)^{m}.
Proof.
Let τ=TV⁡(P,Q)\tau=\mathrm{TV}(P,Q). By Definition 2.1, there exists a coupling
(X,Y)(X,Y) with X∼PX\sim P, Y∼QY\sim Q, and P[X≠Y]=τP[X\neq Y]=\tau. (Such an optimal coupling
exists for all distributions on Polish spaces; see e.g. Villani [26].)
Form mm independent copies of this coupling: (X1,Y1),…,(Xm,Ym)(X_{1},Y_{1}),\ldots,(X_{m},Y_{m}),
all independent, each with P[Xi≠Yi]=τP[X_{i}\neq Y_{i}]=\tau. Then
(X1,…,Xm)∼P⊗m(X_{1},\ldots,X_{m})\sim P^{\otimes m} and (Y1,…,Ym)∼Q⊗m(Y_{1},\ldots,Y_{m})\sim Q^{\otimes m}.
This is a valid coupling of P⊗mP^{\otimes m} and Q⊗mQ^{\otimes m}.
For any coupling (U,V)(U,V) of distributions P′P^{\prime}, Q′Q^{\prime}, we have
TV(P′,Q′)≤P[U≠V]\mathrm{TV}(P^{\prime},Q^{\prime})\leq P[U\neq V] (the optimal coupling achieves equality;
any other coupling gives an upper bound). Therefore:
TV⁡(P⊗m,Q⊗m)\displaystyle\mathrm{TV}(P^{\otimes m},Q^{\otimes m})
≤P[(X1,…,Xm)≠(Y1,…,Ym)]\displaystyle\;\leq\;P\!\left[(X_{1},\ldots,X_{m})\neq(Y_{1},\ldots,Y_{m})\right]
= 1−P⁡[X1=Y1,…,Xm=Ym]\displaystyle\;=\;1-P[X_{1}=Y_{1},\ldots,X_{m}=Y_{m}]
= 1−∏i=1mP[Xi=Yi](by independence)\displaystyle\;=\;1-\prod_{i=1}^{m}P[X_{i}=Y_{i}]\quad\text{(by independence)}
= 1−(1−τ)m.\displaystyle\;=\;1-(1-\tau)^{m}.
Rearranging: 1−TV⁡(P⊗m,Q⊗m)≥(1−τ)m=(1−TV⁡(P,Q))m1-\mathrm{TV}(P^{\otimes m},Q^{\otimes m})\geq(1-\tau)^{m}=(1-\mathrm{TV}(P,Q))^{m}.
