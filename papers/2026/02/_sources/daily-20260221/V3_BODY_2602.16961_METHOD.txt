3 Single-Path Information-Agnostic LP
We first formally define the class of single-path verification algorithms. We denote 𝒱≤k=𝒱0∪𝒱1∪…∪𝒱k\mathcal{V}^{\leq k}=\mathcal{V}^{0}\cup\mathcal{V}^{1}\cup\ldots\cup\mathcal{V}^{k}, where 𝒱k\mathcal{V}^{k} is the set of length-kk sequences of tokens in 𝒱\mathcal{V}, and thus 𝒱≤k\mathcal{V}^{\leq k} is the set of sequences of length ≤k\leq k. We use LL to denote the draft block length. For the remainder of the paper, we use notation from Section 2, omitting the context 𝒄\boldsymbol{c} and subscripts on p,qp,q when they are clear.
Definition 3.1 (Single-path draft verification algorithm).
A single-path verification algorithm Φ\Phi takes in a sampled draft block X1:L∼qL(⋅)X_{1:L}\sim q_{L}(\cdot), and the full LL-step target and draft distributions pLp_{L} and qLq_{L}, and returns a nonempty sequence in 𝒱≤L+1\mathcal{V}^{\leq L+1}. It is valid under:
•
Prefix-matching: the algorithm returns a (possibly empty) prefix X1:τX_{1:\tau} of the draft block followed by an additional correction token YY, for some τ∈{0,…,L}\tau\in\{0,\ldots,L\}.
•
Target-matching: for any context 𝒄\boldsymbol{c}, any draft and target models MpM_{p} and MqM_{q}, and any block length LL, when we generate L−τL-\tau additional tokens Z∼pL−τ(⋅|X1:τ,Y)Z\sim p_{L-\tau}(\cdot|X_{1:\tau},Y), we have (X1:τ,Y,Z)∼ppL+1(⋅)(X_{1:\tau},Y,Z)\sim_{p}p_{L+1}(\cdot), where ∼p\sim_{p} denotes equality of distributions.
If we also require that Φ\Phi can only take in the on-path target and draft distributions p(⋅|X1:i),q(⋅|X1:i)p(\cdot|X_{1:i}),q(\cdot|X_{1:i}) for i∈{0,…,L}i\in\{0,\ldots,L\}, then it is called information-restricted.
Target-matching means that sampling from MpM_{p} autoregressively after verification, until a total of L+1L+1 tokens are generated, gives the same result as just sampling L+1L+1 tokens from MpM_{p} autoregressively without verification. This guarantees that running the verification algorithm and appending its output to the context iteratively maintains the target distribution, even as τ\tau varies: see Lemma 2 in Appendix B of Sun et al. (2024b) for a formal proof.
Prefix-matching forces the verification output to only deviate from the draft block at its last token. This is a strict modeling requirement, not a technical convenience. To bypass prefix-matching while maintaining the target distribution, one must access the next-token target distribution p(⋅|𝒄)p(\cdot|\boldsymbol{c}) for contexts 𝒄\boldsymbol{c} outside the draft tree. This is not possible without performing another MpM_{p} forward pass, which would defeat the goal of speculative decoding: generating multiple tokens in one target call.
Importantly, our definition is less strict than in Sun et al. (2024b), because they only consider the class of valid single-path information-restricted verification algorithms, and prove that block verification is optimal in this class. Surprisingly, we find that block verification is optimal in the class of all valid single-path verification algorithms. To prove this, we first define node budgets, which represent how much mass a verification algorithm has allocated along a path relative to the target distribution.

Block verification, which is a valid single-path verification algorithm ΦB​V\Phi_{BV}, achieves the highest block efficiency of any valid single-path verification algorithm.

These results show that prefix-matching is the key barrier to improving acceptance: even with access to the full joint target and draft distributions, prefix-matching (pointwise upper bounds on DΦ​pD_{\Phi}p terms) prevents us from getting better block efficiency (the sum of DΦ​pD_{\Phi}p terms) than block verification. This motivates us to explore verification algorithms that draft multiple candidate paths in the next section. In this setting, the valid prefix output space grows, thereby loosening the prefix-matching requirement and improving block efficiency.
4 Multi-Path Information Agnostic LP
Now, we show that off-path distribution information can improve block efficiency when K>1K>1 draft paths are generated, even with prefix-matching and target-matching requirements. We first define the class of multi-path verification algorithms, and extend Theorem 3.3 to these algorithms.
Definition 4.1 (KK-path draft verification algorithm).
A KK-path verification algorithm Φ\Phi takes in KK i.i.d. sampled draft blocks X1:L(1),…,X1:L(K)∼qL(⋅|𝒄)X^{(1)}_{1:L},\ldots,X^{(K)}_{1:L}\sim q_{L}(\cdot|\boldsymbol{c}), and the full LL-step distributions pLp_{L} and qLq_{L}, and returns a nonempty sequence in 𝒱≤L+1\mathcal{V}^{\leq L+1}. It is valid under:
•
Prefix-matching: the algorithm returns a (possibly empty) prefix X1:τX_{1:\tau} of some draft block followed by a correction token YY, for some τ∈{0,…,L}\tau\in\{0,\ldots,L\}.
•
Target-matching: this is the same as in Definition 3.1.
If Φ\Phi can only take in the on-path target and draft distributions, which are p(⋅|X1:i(k)),q(⋅|X1:i(k))p(\cdot|X^{(k)}_{1:i}),q(\cdot|X^{(k)}_{1:i}) for k∈[K]k\in[K] and i∈{0,…,L}i\in\{0,\ldots,L\}, then it is called information-restricted.
To the best of our knowledge, all existing valid multi-path verification algorithms (Section 2.2) are information-restricted. We are the first to consider theoretical efficiency limits in the absence of information-restriction, and encode prefix-matching and target-matching into an LP.
To extend the single-path LP from Theorem 3.3 to this setting, we first define node budgets DΦD_{\Phi} in the same way as Definition 3.2. We also require the notion of an antichain, which is a set of variable-length paths in 𝒱≤L\mathcal{V}^{\leq L} where no path is a prefix of another. Antichains are useful because the mass of an autoregressive distribution over an antichain can be computed by summing its probabilities at all antichain elements, due to the disjointness of autoregressively sampling antichain elements.
Definition 4.2.
An antichain of 𝒱≤L\mathcal{V}^{\leq L} is a subset of 𝒱≤L\mathcal{V}^{\leq L} where no sequence in the antichain is a prefix of another. We denote the set of all antichains in 𝒱≤L\mathcal{V}^{\leq L} by 𝒜⁡(𝒱≤L)\mathcal{A}(\mathcal{V}^{\leq L}).
Now, to form the multi-path information-agnostic LP in Theorem 4.3, we replace the pointwise upper bounds on DΦ​pD_{\Phi}p by subset-sum upper bounds over antichains. As mentioned at the end of Section 3, this corresponds to altering the prefix output space. The proof uses Hall-type feasibility constraints, and is fairly involved. 5 Greedy Multi-Path Block Verification
We now design an explicit path selection rule Γ\Gamma where the skewed draft distribution qΓq^{\Gamma} is heuristically close to pp and simple to compute, using only on-path probability values. This leads to our main algorithm: greedy multi-path block verification (GBV). We first define the class of greedy verification algorithms, which contains GBV.
Definition 5.1.
A greedy multi-path valid verification algorithm forms a global ranking on paths in 𝒱L\mathcal{V}^{L}, and always selects the highest-ranked drafted path in the path selection rule Γ\Gamma (Lemma 4.4).
In the context of the multi-path LP, each greedy multi-path valid verification algorithms can be viewed as the output of a greedy polymatroid algorithm (Schrijver and others, 2003) on the submodular feasibility constraints in Theorem 4.3, with the algorithm-selected order being the same as the global ranking. Due to space constraints, we expand on this connection in detail in Appendix H.
