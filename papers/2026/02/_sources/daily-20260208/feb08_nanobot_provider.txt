L754: Adding a New Provider (Developer Guide)
L755: nanobot uses a Provider Registry (`nanobot/providers/registry.py`) as the single source of truth. Adding a new provider only takes 2 steps — no if-elif chains to touch.
L756: Step 1. Add a `ProviderSpec` entry to `PROVIDERS` in `nanobot/providers/registry.py`:
L757: 
L758:     ProviderSpec(
L759:         name="myprovider",                   # config field name
L760:         keywords=("myprovider", "mymodel"),  # model-name keywords for auto-matching
L761:         env_key="MYPROVIDER_API_KEY",        # env var for LiteLLM
L762:         display_name="My Provider",          # shown in `nanobot status`
L763:         litellm_prefix="myprovider",         # auto-prefix: model → myprovider/model
L764:         skip_prefixes=("myprovider/",),      # don't double-prefix
L765:     )
L766: Step 2. Add a field to `ProvidersConfig` in `nanobot/config/schema.py`:
L767: 
L768:     class ProvidersConfig(BaseModel):
L769:         ...
L770:         myprovider: ProviderConfig = ProviderConfig()
L771: 
L772: That's it! Environment variables, model prefixing, config matching, and `nanobot status` display will all work automatically.
L773: 
L774: Common `ProviderSpec` options:
L775: Field  | Description  | Example
L776: --- | --- | ---
L777: `litellm_prefix`  | Auto-prefix model names for LiteLLM  | `"dashscope"` → `dashscope/qwen-max`
L778: `skip_prefixes`  | Don't prefix if model already starts with these  | `("dashscope/", "openrouter/")`
L779: `env_extras`  | Additional env vars to set  | `(("ZHIPUAI_API_KEY", "{api_key}"),)`
L780: `model_overrides`  | Per-model parameter overrides  | `(("kimi-k2.5", {"temperature": 1.0}),)`
L781: `is_gateway`  | Can route any model (like OpenRouter)  | `True`
L782: `detect_by_key_prefix`  | Detect gateway by API key prefix  | `"sk-or-"`
L783: `detect_by_base_keyword`  | Detect gateway by API base URL  | `"openrouter"`
L784: `strip_model_prefix`  | Strip existing prefix before re-prefixing  | `True` (for AiHubMix)
L785: ### MCP (Model Context Protocol)
L786: 
L787: Tip
L788: 
L789: The config format is compatible with Claude Desktop / Cursor. You can copy MCP server configs directly from any MCP server's README.
L790: 
L791: nanobot supports cite124†MCP†modelcontextprotocol.io — connect external tool servers and use them as native agent tools.
L792: Add MCP servers to your `config.json`:
L793: 
L794:     {
L795:       "tools": {
L796:         "mcpServers": {
L797:           "filesystem": {
L798:             "command": "npx",
L799:             "args": ["-y", "@modelcontextprotocol/server-filesystem", "/path/to/dir"]
L800:           },
L801:           "my-remote-mcp": {
L802:             "url": "https://example.com/mcp/",
L803:             "headers": {
L804:               "Authorization": "Bearer xxxxx"
L805:             }
L806:           }
L807:         }
L808:       }
L809:     }
L810: 
L811: Two transport modes are supported:
L812: Mode  | Config  | Example
L813: --- | --- | ---
L814: Stdio  | `command` + `args`  | Local process via `npx` / `uvx`
L815: HTTP  | `url` + `headers` (optional)  | Remote endpoint (`https://mcp.example.com/sse`)
L816: 
L817: Use `toolTimeout` to override the default 30s per-call timeout for slow servers:
L818: 
L819:     {
L820:       "tools": {
L821:         "mcpServers": {
L822:           "my-slow-server": {
L823:             "url": "https://example.com/mcp/",
L824:             "toolTimeout": 120
L825:           }
L826:         }
L827:       }
L828:     }
L853: Interactive mode exits: `exit`, `quit`, `/exit`, `/quit`, `:q`, or `Ctrl+D`.

L867: Heartbeat (Periodic Tasks)
L868: The gateway wakes up every 30 minutes and checks `HEARTBEAT.md` in your workspace (`~/.nanobot/workspace/HEARTBEAT.md`). If the file has tasks, the agent executes them and delivers results to your most recently active chat channel.
L869: 
L870: Setup: edit `~/.nanobot/workspace/HEARTBEAT.md` (created automatically by `nanobot onboard`):
L871: 
L872:     ## Periodic Tasks
L873: 
L874:     - [ ] Check weather forecast and send a summary
L875:     - [ ] Scan inbox for urgent emails
L876: The agent can also manage this file itself — ask it to "add a periodic task" and it will update `HEARTBEAT.md` for you.
L877: 
L878: > Note: The gateway must be running (`nanobot gateway`) and you must have chatted with the bot at least once so it knows which channel to deliver to.
