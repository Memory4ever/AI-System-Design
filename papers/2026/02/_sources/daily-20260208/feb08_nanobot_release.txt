L237: ## 🚀 Quick Start
L238: 
L239: Tip
L240: 
L241: Set your API key in `~/.nanobot/config.json`. Get API keys: cite100†OpenRouter†openrouter.ai (Global) · cite101†Brave Search†brave.com (optional, for web search)
L242: 
L243: 1. Initialize
L244: 
L245:     nanobot onboard
L246: 
L247: 2. Configure (`~/.nanobot/config.json`)
L248: 
L249: Add or merge these two parts into your config (other options have defaults).
L250: Set your API key (e.g. OpenRouter, recommended for global users):
L251: 
L252:     {
L253:       "providers": {
L254:         "openrouter": {
L255:           "apiKey": "sk-or-v1-xxx"
L256:         }
L257:       }
L258:     }
L259: 
L260: Set your model (optionally pin a provider — defaults to auto-detection):
L261: 
L262:     {
L263:       "agents": {
L264:         "defaults": {
L265:           "model": "anthropic/claude-opus-4-5",
L266:           "provider": "openrouter"
L267:         }
L268:       }
L269:     }
L270: 
L271: 3. Chat
L272: 
L273:     nanobot agent
L274: 
L275: That's it! You have a working AI assistant in 2 minutes.
L276: ## 💬 Chat Apps
L277: 
L278: Connect nanobot to your favorite chat platform.
L279: 
L280: Channel  | What you need
L281: --- | ---
L282: Telegram  | Bot token from @BotFather
L283: Discord  | Bot token + Message Content intent
L284: WhatsApp  | QR code scan
L285: Feishu  | App ID + App Secret
L286: Mochat  | Claw token (auto-setup available)
L287: DingTalk  | App Key + App Secret
L288: Slack  | Bot token + App-Level token
L289: Email  | IMAP/SMTP credentials
L290: QQ  | App ID + App Secret
L291: Telegram (Recommended)
L292: 
L293: 1. Create a bot
L294:   * Open Telegram, search `@BotFather`
L295:   * Send `/newbot`, follow prompts
L296:   * Copy the token
L297: 
L298: 2. Configure
L299: 
L300:     {
L301:       "channels": {
L302:         "telegram": {
L303:           "enabled": true,
L304:           "token": "YOUR_BOT_TOKEN",
L305:           "allowFrom": ["YOUR_USER_ID"]
L306:         }
L307:       }
L308:     }
L309: 
L310: > You can find your User ID in Telegram settings. It is shown as `@yourUserId`. Copy this value without the `@` symbol and paste it into the config file.
L311: 
L312: 3. Run
L313: 
L314:     nanobot gateway
L315: 
L316: Mochat (Claw IM)
L317: Uses Socket.IO WebSocket by default, with HTTP polling fallback.
L318: 
L319: 1. Ask nanobot to set up Mochat for you
L320: 
L321: Simply send this message to nanobot (replace `xxx@xxx` with your real email):
L322: 
L323:     `Read https://raw.githubusercontent.com/HKUDS/MoChat/refs/heads/main/skills/nanobot/skill.md and register on MoChat. My Email account is xxx@xxx Bind me as your owner and DM me on MoChat.
L324:     `
L325: 
L326: nanobot will automatically register, configure `~/.nanobot/config.json`, and connect to Mochat.
L327: 2. Restart gateway
L328: 
L329:     nanobot gateway
L330: 
L331: That's it — nanobot handles the rest!
L332: 
L333: Manual configuration (advanced)
L334: 
L335: If you prefer to configure manually, add the following to `~/.nanobot/config.json`:

L337:

L339:       "channels": {

L341:           "enabled": true,

L345:           "claw_token": "claw_xxx",
L346:           "agent_user_id": "6982abcdef",
L347:           "sessions": ["*"],
