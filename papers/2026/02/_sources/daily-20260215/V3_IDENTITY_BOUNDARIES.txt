L169: ## Introduction
L170: ### Qwen3.8
L171:
L172: For the first time, Qwen3.8 brings a Qwen-Max-class model to open release. Built on the architectural foundation of Qwen3.5, Qwen3.8 delivers substantial gains across coding, professional work, research, and long-horizon agentic tasks. Beyond answering harder questions, Qwen3.8 is designed to carry complex, multi-step tasks through to completion with greater reliability.
L173:
L174: Qwen3.8 features the following enhancements:
L175:   * Core Capabilities: Comprehensive improvements across coding, professional work, research, and long-horizon agentic tasks.
L176:   * Agent Execution: Stronger autonomous planning and better handling of environment feedback, leading to more reliable end-to-end task completion.
L177:   * Downstream Compatibility: Broader support for popular harnesses and development tools, making it easier to integrate into your existing stack.
L178:   * Flexible Thinking Control: Reasoning depth can be tuned with `reasoning_effort`, and reasoning context from historical messages is retained via `preserve_thinking`.
L179: ### Qwen3.6
L180:
L181: Building upon the fundamental breakthroughs of Qwen3.5, Qwen3.6 prioritizes stability and real-world utility. It offers developers a more intuitive, responsive, and genuinely productive coding experience, shaped by direct community feedback. This update delivers substantial upgrades, particularly in:
L182:   * Agentic Coding: The model now handles front-end workflows and repository-level reasoning with greater fluency and precision.
L183:   * Thinking Preservation: A new feature retains thinking context across conversation history, streamlining iterative development and reducing overhead.
L184: ### Qwen3.5
L185:
L186: Over recent months, we have intensified our focus on developing foundation models that deliver exceptional utility and performance. Qwen3.5 represents a significant leap forward, integrating breakthroughs in multimodal learning, architectural efficiency, reinforcement learning scale, and global accessibility to empower developers and enterprises with unprecedented capability and efficiency.
L187:
L188: Qwen3.5 features the following enhancements:
L189:   * Unified Vision-Language Foundation: Early fusion training on trillions of multimodal tokens achieves cross-generational parity with Qwen3 and outperforms Qwen3-VL models across reasoning, coding, agents, and visual understanding benchmarks.
L190:   * Efficient Hybrid Architecture: Gated Delta Networks combined with sparse Mixture-of-Experts deliver high-throughput inference with minimal latency and cost overhead.
L191:   * Scalable RL Generalization: Reinforcement learning scaled across million-agent environments with progressively complex task distributions for robust real-world adaptability.
L192:   * Global Linguistic Coverage: Expanded support to 201 languages and dialects, enabling inclusive, worldwide deployment with nuanced cultural and regional understanding.
L193:   * Next-Generation Training Infrastructure: Near-100% multimodal training efficiency compared to text-only training and asynchronous RL frameworks supporting massive-scale agent scaffolds and environment orchestration.

L244: ### Local Use
L245: #### Hugging Face Transformers
L246:
L247: cite101†`transformers`†huggingface.co acts as the model-definition framework in the current open-weight LLM landscape. It also includes functionalities for LLM inference and training. The addition of serving capabilities in `transformers` makes it much easier to integrate new models in your development.
L248:
L249: To launch a server, simply use the `transformers serve` command:
L250:
L251:     transformers serve Qwen/Qwen3.8-27B --port 8000 --continuous-batching
L252: An OpenAI-compatible API will be available at `http://localhost:8000/v1`. See cite102†the Serve CLI guide†huggingface.co for more information.
L253: #### llama.cpp
L254:
L255: cite103†`llama.cpp` enables LLM inference with minimal setup and state-of-the-art performance on a wide range of hardware. llama.cpp supports the Qwen3.5 open model series (text & vision). Look for models ending with GGUF on Hugging Face Hub.

L264: ### Deployment
L265:
L266: The Qwen3.5 open model series is supported by multiple inference frameworks. Here we demonstrate the usage of SGLang, vLLM, and TokenSpeed.
L267: #### SGLang
L268:
L269: cite108†SGLang is a fast serving framework for large language models and vision language models. SGLang can be used to launch a server with an OpenAI-compatible API service.
L270:
L271:     sglang serve --model-path Qwen/Qwen3.8-27B --port 8000 --tp-size 4 --context-length 262144 --reasoning-parser qwen3 --tool-call-parser qwen3_coder
L272:
L273: An OpenAI-compatible API will be available at `http://localhost:8000/v1`.
L274:
L275: Also see SGLang Cookbook on cite109†serving Qwen3.8†docs.sglang.io .
L276: #### vLLM
L277:
L278: cite110†vLLM is a high-throughput and memory-efficient inference and serving engine for LLMs. vLLM can be used to launch a server with an OpenAI-compatible API service.
L279:
L280:     vllm serve Qwen/Qwen3.8-27B --port 8000 --tensor-parallel-size 4 --max-model-len 262144 --reasoning-parser qwen3 --enable-auto-tool-choice --tool-call-parser qwen3_coder
L281:
L282: An OpenAI-compatible API will be available at `http://localhost:8000/v1`.
L283:
L284: Also see vLLM Recipes on cite111†serving Qwen3.8†recipes.vllm.ai .
L285: #### TokenSpeed
L286:
L287: cite112†TokenSpeed is a speed-of-light LLM inference engine. TokenSpeed can be used to launch a server with an OpenAI-compatible API service.
L288:
L289:     tokenspeed serve Qwen/Qwen3.8-27B --port 8000 --tensor-parallel-size 4 --max-model-len 262144 --reasoning-parser qwen3 --enable-auto-tool-choice --tool-call-parser qwen3_coder
L290:
L291: An OpenAI-compatible API will be available at `http://localhost:8000/v1`.
L292:
L293: Also see TokenSpeed Recipes on cite113†serving Qwen3.8†lightseek.org .
