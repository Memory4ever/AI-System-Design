827: A.2 Training and Evaluation Details
828: Training Setting
829: We conduct experiments using the Qwen3 family at both 4B and 8B scales. All training processes are executed on 16 NVIDIA H20 141GB GPUs.
830: •
831: Supervised Fine-tuning We conduct our training using LLaMA-Factory 22
832: 2
833: https://github.com/hiyouga/LLaMA-Factory. For the cold-start phase, we utilize 20k open-source instruction-following samples from AM-DeepSeek-R1-0528-Distilled 33
834: 3
835: https://huggingface.co/datasets/a-m-team/AM-DeepSeek-R1-0528-Distilled and we employ a cosine learning rate scheduler with a peak rate of 2e-5 and a warmup ratio of 0.03. We set the maximum sequence length to 16,384, with sequence packing and training for 900 steps.
836: •
837: Reinforcement Learning We use verl 44
838: 4
839: https://github.com/volcengine/verl for RL and use DAPO (Yu et al., 2025b).
840: Curriculum Learning: We adopt a two-stage curriculum strategy, with each stage comprising 100 training steps and a constant learning rate of 1e-6. The context length is limited to 16K in the initial stage (m=0m=0) and extended to 32K in the subsequent stage (m=1m=1).
841: Data: Following MemAgent (Yu et al., 2025a), we synthesize 1,000 samples for each length configuration (16K and 32K). To further bolster reasoning capabilities, we incorporate the DocQA-RL-1.6K dataset 55
842: 5
843: https://huggingface.co/datasets/Tongyi-Zhiwen/DocQA-RL-1.6K during the second stage (m=1m=1).
844: Reward Configuration: The format reward rf​m​tr_{fmt} is set to 1.0 for valid <think>...</think> and <answer>...</answer> structure, and the accuracy reward ra​c​cr_{acc} is set to 2.0 for correct answers. The contextual density reward rc​t​xr_{ctx} is computed using a frozen Qwen3-4B verifier.
845: Hyperparameters: We set the learning rate to 1e-6, the batch size 8, and the rollout number to 16. The maximum sequence length is 32,768, and we allow a maximum output length of 4096 tokens and Ulysses sequence parallel 2 (Jacobs et al., 2023).
846: Evaluation Setting We employ a comprehensive suite of long-context benchmarks to rigorously evaluate model performance:
847: •
848: LongBench v2 (Bai et al., 2025a): A challenging benchmark focused on realistic long-context deeper understanding. It employs a multiple-choice question format to facilitate rigorous and objective evaluation.
849: •
850: RULER (Hsieh et al., 2024): A benchmark designed to evaluate the effective context window size through diverse synthetic tasks.
851: •
852: InfiniteBench (Zhang et al., 2024): A dataset targeting diverse long-context capabilities, covering heterogeneous tasks such as retrieval (Re.Pa, Re.Nu), summarization (En.Sum), QA (En.QA, Zh.QA), and multi-choice reasoning (En.MC).
853: For inference, we utilize vLLM 66
854: 6
855: https://github.com/vllm-project/vllm with a decoding temperature of 1.0. We set maximum generated tokens to 16384. All evaluations are conducted using official scripts with a fixed random seed of 42 to ensure reproducibility.
856: Baselines. We conduct comparisons using the Qwen3 family at both 4B and 8B scales. The baselines include: (1) the officially released Qwen3-Base models; (2) our reproduced Qwen3-SFT models obtained from the Cold Start phase; and (3) the Qwen3-SFT w/ DAPO variants, which undergo standard full-parameter RL training (Outcome-only) using the same data and steps as LongR with template Figure 5 for comparison.
