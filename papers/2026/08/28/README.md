### 从局部算子优化到运行时状态所有权

固定 pipeline、dense generation、静态 KV 保留和逐 token drafting 在结构稳定时简单可靠。MoE imbalance、并行 refinement、长上下文与 block proposal 使新瓶颈落到 stage movement、state repair、launch/communication critical path 和 proposal information。新机制获得的是并行度或容量，付出的是更多 mutable state、调度与恢复路径；旧方案在 workload 规则、规模较小或验证成本高时仍成立。作者实验只能证明各自配置中的受限收益，不能共享一套性能常数。
<!-- analysis:DA-RUNTIME-STATE:end -->

<!-- analysis:DA-EVIDENCE-ACTION:start -->
### 从一个 confidence 到 evidence、risk 与 action 的分层合同

单一 judge 分数假设 metric、事实正确性和 action safety 可以共用一个信号。新的证据链把人工标签、automatic metric、conformal abstention、task DAG、persistent information-flow 和 effect-time authorization 分层：传感器估计风险，provenance 说明证据来自哪里，policy 决定能否执行。收益是可审计的升级/拒绝路径；代价是 calibration drift、相关误差、false reject 与更多持久状态。任何分数都不能自动成为授权。
<!-- analysis:DA-EVIDENCE-ACTION:end -->

<!-- analysis:DA-PERSISTENT-LEARNING:start -->
### 从一次轨迹到可继承但可撤销的能力状态

离线训练把能力封装在 weight 中，episode 结束后再统一更新；在线 supervisor、skill pretraining、lineage-bound continuous update 与 executable retrieval plan 开始把中间产物变为可复用状态。系统因此必须记录 parent、data、environment、verification 与 adoption decision，并保留 bounded trial、rollback 和隔离。能力复用提高效率，也放大污染、错误继承和 artifact theft；没有可靠 verifier 时，一次性或人工批准的旧流程仍更安全。
