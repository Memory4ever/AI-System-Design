Abstract
Data preparation is a foundational yet notoriously challenging component of the machine learning lifecycle, characterized by a vast combinatorial search space of potential operator sequences. While reinforcement learning (RL) offers a promising direction, existing approaches are inefficient as they fail to capture the structured, hierarchical nature of the problem. We argue that Hierarchical Reinforcement Learning (HRL), a paradigm that has been successful in other domains, provides a conceptually ideal yet previously unexplored framework for this task. However, a naive HRL implementation with a ‘hard hierarchy’ is prone to suboptimal, irreversible decisions. To address this, we introduce CogniQ-H, the first framework to implement a soft hierarchical paradigm for robust, end-to-end automated data preparation. CogniQ-H formulates action selection as a Bayesian inference problem. A high-level strategic prior, generated by a Large Language Model (LLM), guides exploration probabilistically. This prior is synergistically combined with a fine-grained operator quality score from a supervised Learning-to-Rank (LTR) model and a long-term value estimate from the agent’s own Q-function. This hybrid architecture allows CogniQ-H to balance strategic guidance with adaptive, evidence-based decision-making.
Through extensive experiments on 18 diverse datasets spanning multiple domains, we demonstrate that CogniQ-H achieves up to 13.9% improvement in pipeline quality and 2.8× faster convergence compared to state-of-the-art RL-based methods. The codes and datasets are available at (xxx).

Introduction
Data preparation is a foundational, yet notoriously labor-intensive, component of the machine learning (ML) lifecycle

The process of transforming raw, often messy data into a clean, well-structured format suitable for model training is not a single action but a multi-stage workflow encompassing tasks like data cleaning, integration, transformation, feature engineering, and feature selection. However, many of these approaches, especially early applications of reinforcement learning, treat the search space as “flat.” , where every operator is an atomic action at every step. This leads to critical limitations: (1) Inefficient and Unguided Exploration: Agents waste resources exploring semantically nonsensical sequences (e.g., scaling data before encoding). (2) Poor Sample Efficiency: The agent is forced to learn fundamental data science principles from scratch through costly trial-and-error.
To address this structural challenge, we consider the Hierarchical Reinforcement Learning Framework is a natural fit for this problem, as its core principles directly align with the desired structured decision-making process. However, to the best of our knowledge, the application of HRL to construct entire data preparation pipelines remains an unexplored frontier.
Pioneering the use of HRL for this task introduces a critical design dilemma. A straightforward implementation would employ a hard hierarchy: a high-level policy selects one option (e.g., ‘Encoder’), and a low-level policy is then strictly confined to operators (Figure 1b). While this reduces complexity, suboptimal high-level choice can irrevocably prune the optimal path. For instance, if the high-level policy commits to “Encoder” when “Imputer” was necessary, the agent cannot recover. This brittleness makes a naive HRL application potentially unreliable.
To harness the power of HRL while mitigating its inherent risks, we introduce
CogniQ-H
, a novel framework that implements a
soft hierarchical paradigm
(Figure 1c). To our knowledge, it is the first HRL-based framework specifically designed for robust and efficient end-to-end automated data preparation. CogniQ-H leverages a Large Language Model (LLM) to provide high-level, strategic guidance in the form of a
probabilistic distribution
. This distribution acts as a flexible prior in a Bayesian framework, influencing but not constraining the final action selection. The final action selection in CogniQ-H is a synergistic fusion of three complementary signals: (1)
LLM Strategic Prior:
A high-level probability distribution derived from an LLM. (2)
LTR-based Operator Score:
A supervised Learning-to-Rank (LTR) model provides a precise, fine-grained quality score for each individual operator. (3)
RL-based Value Estimation:
The agent’s own Q-value function, learned from past experience, represents the long-term expected reward.
This hybrid architecture allows CogniQ-H to balance pre-existing knowledge, supervised signals, and adaptive learning, leading to more robust and efficient pipeline discovery. Our contributions are:
•
We are the first to formalize and tackle the end-to-end data preparation pipelines problem within a Hierarchical Reinforcement Learning framework.
•
We propose CogniQ-H, a novel soft hierarchical paradigm that avoids the pitfalls of rigid HRL by using a probabilistic, LLM-driven prior for strategic guidance.
•
We introduce a hybrid architecture that synergistically combines LLM-based planning, LTR-based refinement, and HRL-based learning.

The challenge of automating data preparation has garnered significant attention in the machine learning community

Reinforcement Learning (RL) has emerged as a promising approach for AutoML tasks due to its natural formulation as a sequential decision process

,

. Early successes, particularly in Neural Architecture Search (NAS)

. However, the majority of these applications adopt a "flat" RL formulation. In this setup, the agent confronts the entire library of operators at each step, with no inherent structure guiding its choices.
Hierarchical Reinforcement Learning
Hierarchical Reinforcement Learning (HRL) provides a formal framework for learning and planning at multiple levels of temporal abstraction
[
24
]
. Seminal works like the Options Framework
[
25
]
and Feudal RL
[

established the core principles of decomposing a task into a hierarchy of sub-tasks, enabling more efficient exploration and the learning of reusable skills. Modern HRL methods have extended these ideas with deep learning, achieving success in complex domains like robotics and navigation
[
27
]
. Despite its success in other fields, and tis profound conceptual alignment with the nature of AutoDP, to the best of our knowledge, HRL has not been applied to the problem of constructing data preparation pipelines in an end-to-end fashion.

. These approaches typically operate in an “open-loop” fashion: the LLM receives a prompt and generates a static pipeline or script. While impressive, this paradigm lacks the ability to adapt based on feedback from executing the operations.

Implementation Details.
For RL-based methods, we use a Q-Learning architecture where the action space consists of 26 available operators and a DQN architecture with a 3-layer MLP for the Q-network and a replay buffer of size 5,000. The LLM used is Llama3.3, prompted with a structured description. The LTR model is a LightGBM ranker trained on an offline dataset of (state, action, performance) tuples collected from a wide range of previous experiments. The operator library consists of 26 common operators for imputation, encoding, scaling, feature preprocessing, selection, and engineering. The downstream ML model for evaluation is Logistic Regression.

Conclusion
We introduced CogniQ-H, the first framework to apply a soft hierarchical paradigm to the challenging task of end-to-end Automated Data Preparation. By pioneering the use of Hierarchical Reinforcement Learning in this domain, we addressed the exploration inefficiencies of flat RL while avoiding the pitfalls of rigid hierarchies. CogniQ-H achieves this through a synergistic fusion of a probabilistic LLM prior, a supervised LTR score, and an RL value function, allowing it to balance strategic guidance with adaptive, evidence-based learning. Extensive experiments demonstrate that our approach significantly outperforms a wide array of baselines. This work not only provides a state-of-the-art solution for AutoDP but also opens a new research avenue for applying structured RL to complex data science automation, with future possibilities in dynamic pipeline generation and meta-learning.
