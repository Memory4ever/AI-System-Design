L180: # Omnilingual ASR: Open-Source Multilingual Speech Recognition for 1600+ Languages
L181: Omnilingual ASR is an open-source speech recognition system supporting over 1,600 languages — including hundreds never previously covered by any ASR technology. Designed for broad accessibility, it enables new languages to be added with just a few paired examples without requiring specialized expertise or large datasets.
L182: By combining scalable zero-shot learning with a flexible model family, Omnilingual ASR aims to make speech technology more inclusive and adaptable for communities and researchers worldwide.
L183:   * cite90†Huggingface Demo†huggingface.co L184:   * cite91†Huggingface Dataset†huggingface.co L185:   * cite92†Paper†ai.meta.com L186:   * cite93†Blogpost†ai.meta.com L187: 
L188: Our 7B-LLM-ASR system achieves state-of-the-art performance across 1,600+ languages, with character error rates (CER) below 10 for 78% of those languages. Per language CER results, plus training hours can be found in cite86†this csv L189: ## December 2025 Update
L190: 
L191: We release two suites of models:
L192:   * Checkpoints of improved accuracy (CER) for the CTC and LLM-ASR models compared to our existing LLM-ASR model (`omniASR_{CTC,LLM}_{300M,1B,3B,7B}_v2`).
L193:   * A new variant of the LLM-ASR model that supports decoding on unlimited audio length (`omniASR_LLM_Unlimited_{300M,1B,3B,7B}_v2`). The unlimited audio length models are briefly described in the cite94†architecture overview section . It's accuracy is comparable to limited audio length models, however finetuning recipies for this model are currently not supported.

L212: ## Installation
L213: 
L214: The models were developed using cite102†fairseq2 , a research-focused sequence modeling toolkit. While we provide a reference inference pipeline that works across platforms, audio support requires cite103†libsndfile (Mac: `brew install libsndfile`; Windows may need an additional cite104†setup ).
L215: 
L216:     # using pip
L217:     pip install omnilingual-asr
L218: 
L219:     # using uv
L220:     uv add omnilingual-asr
L221: ## Inference
L222: 
L223:     from omnilingual_asr.models.inference.pipeline import ASRInferencePipeline
L224: 
L225:     pipeline = ASRInferencePipeline(model_card="omniASR_LLM_Unlimited_7B_v2")
L226:     audio_files = ["/path/to/eng_audio1.flac", "/path/to/deu_audio2.wav"]
L227:     lang = ["eng_Latn", "deu_Latn"]
L228:     transcriptions = pipeline.transcribe(audio_files, lang=lang, batch_size=2)

L230: More details on running specific models can be found in the cite96†src/omnilingual_asr/models/inference directory.
L231: > ⚠️ Important: Currently only audio files shorter than 40 seconds are accepted for inference on CTC and LLM model suites.

L246: ### Using the HuggingFace Dataset 🤗
L247: We provide a large-scale multilingual speech dataset on HuggingFace under CC-BY-4.0 License: cite91†`facebook/omnilingual-asr-corpus`†huggingface.co . This dataset can be directly used with our inference pipeline for evaluation or testing:
L248: 
L249:     pip install "omnilingual-asr[data]"
L250: 
L251:     from datasets import load_dataset
L252:     from omnilingual_asr.models.inference.pipeline import ASRInferencePipeline
L253: 
L254:     # Load dataset for a specific language (e.g., Ligurian)
L255:     omni_dataset = load_dataset("facebook/omnilingual-asr-corpus", "lij_Latn", split="train", streaming=True)
L256:     batch = next(omni_dataset.iter(5))
L257: 
L258:     # Convert to pipeline input format
L259:     audio_data = [{"waveform": x["array"], "sample_rate": x["sampling_rate"]}
L260:                   for x in batch["audio"]]
L261: 
L262:     # Run inference
L263:     pipeline = ASRInferencePipeline(model_card="omniASR_LLM_7B_v2")
L264:     transcriptions = pipeline.transcribe(audio_data, batch_size=2)
L265: 
L266:     # Display results
L267:     for i, (transcription, original_text) in enumerate(zip(transcriptions, batch["raw_text"]), 1):
L268:         print(f"\n Sample {i}:")
L269:         print(f"   Ground Truth: {original_text}")
L270:         print(f"   Predicted:    {transcription}")
