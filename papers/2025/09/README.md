### 精确外部缺口

官方 arXiv catchup 拒绝超过 90 天的历史日列表。提交时刻、月份 ID、名义公告日程和 DOI 创建时刻各自不等于实际公开时刻；当前 DOI 上界越过日窗截止，无法把相交范围写成确定当窗候选。[2025 年官方日程原始版本](./_sources/official-calendar/availability-before-20250903.md) 已从官方 GitHub 精确 commit 恢复；它不消除实际公告是否延迟这一缺口。

优先需要 **2025-08-31 Eastern 批次的实际公开时间与原始日列表**，或足以证明该批身份在 2025-09-01 01:00 UTC 前已公开的官方记录；另可提供解释 Updated:v1 真实公开语义与后期刷新的官方材料。收到后仅重开对应日期/家族，复用有效快照。

网络现已大部可用，部分重定向、状态页与 CDN 的具体请求仍遭代理拒绝；草稿保留原 36 个域名并补入 7 个实际必要域名（共 43 个），工具确认已保存但仍要求在环境设置中审阅保存并发布。保存草稿不证明运行时生效，也不能解除 catchup 的历史保留期限。
