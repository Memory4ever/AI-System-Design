## 12746：离散滤波模型与任务验证是两层判断

论文把已学习的八类 depthwise master filters 与离散 Gaussian smoothing、小支撑差分和 sharpening 联系起来。四个非中心水平/垂直差分、两个中心差分、一个 sharpening、一个 smoothing 构成待拟合的理想形式，不是任意网络必有的八种语义职能。Method B 的具体差额是：细尺度下连续 Gaussian 近似会受离散化影响，因此按离散滤波器的加权水平/垂直空间方差匹配各自尺度，而不是直接把连续模型估计当离散真值。窗口、幅度/DC 归一和拟合准则会改变尺度估计；§6 的窗口尺度仍有粗略视觉选择，不能宣称唯一最优参数。

§4 的 half-grid 差分组合与方向导数解释提供一个受限的表示视角：前后差分可形成中心一阶/二阶形式。但 depthwise 的不同通道作用在不同输入 feature maps 上，随后 pointwise 才混合输出。因此不能把人口层面的滤波器形状关系升级为“八个滤波器对同一个输入构成完备基”或每个通道固定存一种知识。任意方向二阶导数所需 mixed derivative 尚缺，作者提出第九个滤波器作为后续方向，不是已验证的九滤波器网络。生物 receptive-field 类比也不是神经因果证据。

直接对照分两种，不能混为一条免训练结论：

- §5.1 将 fully trained ConvNeXt-v2 Tiny 的 depthwise kernels 分类到八类并拟合 `a f' + b`，不再微调；Table15 Method A/B/C1/C2/D1/D2 的 Top1 分别为 63.958/65.700/62.697/60.972/62.330/63.804。B 在这一直接替换设置较好，不代表不经训练即可保持原 82.7。
- §5.2～5.3 固定滤波类型分配并训练其余网络 300 epochs，Table16 原网络 82.7、八 learned master filters 82.7、八 ideal Method-B filters 82.5、再学习尺度 82.6。虽文中使用“from scratch”，同节又明确其余参数由 FCMAE pretrained model 初始化，类型分配来自已 fully trained 的 ConvNeXt，不能写成无预训练随机从零。0.1/0.2 个百分点没有 seeds/CI，不能签统计等价或可忽略损失。Table17 各类数量和尺度波动不同，尤其 smoothing 类尺度更散，也不支持所有通道共享一组固定尺度。

## 13178：协方差算子、有限投影与泛化不能互相替代

§2 假设可分 Hilbert space、随机信号平方可积，定义总体 covariance operator `C`。其 eigenbasis 中的 HVFT 等价于 recentering 口径下的 FPCA；这里把 covariance eigenvalues 称 frequencies 是该谱域约定，不等于通常时域频率。§3 的 `h(C)` 调制各特征子空间，多项式形式 `sum_j w_j C^j` 避免显式特征分解，再按通道混合并施非线性组成 HVN。不是凭空发现新的 FPCA 变换，也不是自动学到任务最优表示。

§4 的经验协方差来自 n 个 i.i.d. 样本，rank 至多 n−1。Theorem1 只针对有限个不同正特征值：在包含 0 的有限谱上构造次数至多 q 的 Lagrange 多项式，可以恢复对应整个 eigenspace projector。Appendix A Eq20 的 `t/alpha` 和各 `(t-beta)/(alpha-beta)` 直接给出该存在性；重复 eigenvalue 的子空间不能因此拆出唯一单个 eigenvector。Corollary1 仍需对指定正交基取内积得到 score，不是无需基选择就得到唯一、跨批稳定的 FPCA 坐标。Eq22 的印式与 Eq20～21 的系数索引/缩放表示未完整对应，不抄成可执行求解 recipe；有限谱插值也不证明实际 J=2 网络可恢复所有 rank，或 eigenvalues 接近时仍数值稳定。

离散化要求 `S_m` 是由有界线性泛函构成的算子，Proposition1 及证明得到 `C_discrete = S_m C_empirical S_m*`。这是 covariance 的压缩恒等式，不是“任意压缩都无损”，也不自动推出所有 `h`、非线性及整网络与压缩可交换。一般 `S*C*S*` 连乘中夹入 `S* S`；没有额外不变子空间/等距条件，不能当作 `S C^j S*`。B 的 normalized-bin 积分是 `1/sqrt(bin measure)`，不是普通算术平均的 `1/bin measure`；普通 L2 点取样没有一般有界性，RKHS 例才另有 point-evaluation 条件。§6 把离散分辨率趋细的 convergence 和 transferability 定理明确留作未来工作，不写成本文已证无分辨率损失/跨分布稳定。

§5 的实验是有限机制示范，不是所有神经网络的能力判决：合成任务特意让两类 Gaussian-process bags 有相同各通道边际、只在跨通道相关结构不同，d=4、p=32，J=2、两层/32输出、GELU、Adam/CE、covariance normalization。比较的“MLP”通过把 covariance 换单位阵得到，不混合 m 个输入分量，故它的失败不能证明一般 fully connected MLP 无法表示相关性。FPCA 每 bag 独立旋转，坐标符号/排列漂移是这个基线接口的混杂，未比较明确对齐后的 FPCA/共同训练基底，不能把接近随机推广到 FPCA 本身不可用。参数数量匹配也不是构建 covariance/矩阵乘的计算匹配。

ECG5000 是 5000 条、length140、五类；作者在训练及推理时分别用整个 train/test set 估计 covariance，再分类各条，是使用未标注测试群体统计的 transductive 设置，不能称逐条独立 online inference 或标签泄漏已证。resolution 提升时的 Figure1(c) 结果没有 matched 在线重估费/独立部署漂移对照。未实际读曲线像素，故只保正文定性报告；未披完整 split/重复运行/CI、hardware/precision/batch、构建与更新 covariance、训练/推理总费用和 SLO。密集 m×m covariance 的存储和乘法不能被“省 eigendecomposition”掩盖，实际复杂度依实现/稀疏性/递推方式另验，不补实测加速。

有限支持为“在协方差承载判别信息、压缩算子和统计估计适用时，直接对 covariance 作多项式滤波可保留原坐标接口，区别于逐样本重新取谱坐标”。它不证明无监督获得因果语义、所有模型都需该层，或替代当前 Transformer。保留原 5 分及候选；Books owner 比较和独立实际采用仍待作者进行，不因这些限制降分、删除候选或预记 No Change。
