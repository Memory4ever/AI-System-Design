L206: # ScaleCUA: Scaling Open-Source Computer Use Agents with Cross-Platform Data
L207: 
L208:   📑 【94†Paper†arxiv.org】   |   🤗 【95†Dataset†huggingface.co】   |   🤖 【96†Model†huggingface.co】   |   🖥️ 【97†Model Demo】
L209: Vision-Language Models (VLMs) have enabled computer use agents (CUAs) that operate GUIs autonomously with great potential. However, developing robust CUAs requires extensive in-domain knowledge about software interfaces and operations. Unlike image–text pairs that are widely available on the Internet, computer-use data, particularly operation trajectories, are rare, costly to collect.
L210: Consequently, progress in this field remains constrained by both data scale and the limited transferability of existing VLMs. In this work, we introduce ScaleCUA, a step toward scaling open-source CUAs. It offers a large-scale dataset spanning 6 operating systems and 3 task domains, via a closed-loop pipeline uniting automated agents with human experts. Trained on this scaled-up data, ScaleCUA can operate seamlessly across platforms.
L211: Specifically, it delivers strong gains over baselines (+26.6 on WebArena-Lite-v2, +10.7 on ScreenSpot-Pro) and sets new state-of-the-art results (94.4% on MMBench-GUI L1-Hard, 60.6% on OSWorld-G, 47.4% on WebArena-Lite-v2). These findings underscore the power of data-driven scaling for general-purpose cross-platform CUAs.

L235: ## 🚀 Key Features
L236:   * ScaleCUA-Data: A large-Scale cross-platform dataset spanning 6 operating systems and 3 GUI-centric task domains.
L237:   * ScaleCUA-Models: An cross-platform general-purpose agent that excels at GUI-centric task completion on various environments.
L238:   * SFT Codebase: A comprehensive training framework that supports training computer use agent based on Qwen2.5-VL and InternVL.
L239:   * Interactive Playground: A series of realistic, interactive environments across Ubuntu, Android, and Web.

L258: ## 🎮 Playground
L259: 
L260: The Playground allows you to interactively experience the ScaleCUA agent's capabilities firsthand across Ubuntu, Android, and Web platforms. For a complete guide, please see the 【113†[Playground]】.
L261: 
L262: Follow these two steps to begin:
L263:   1. Deploy the ScaleCUA models with 【114†vLLM】 following our 【115†[Model Deployment]】. We support two modes of operation: Native Agentic Model using a single model for both UI grounding and planning, and Agentic Workflow supporting two different models for UI planning and grounding.
L264: 
L265:   2. Set up your environment following 【116†[Playground Environment]】. We provide pre-configured, interactive virtual machines for Ubuntu, Android, and Web to simplify this process.
L266: Now, you can try our agent in the interactive environment!
L267: ## 📊 Evaluation
L268: 
L269: We provide a suite of benchmarks for end-to-end agent evaluation using a vision-only setup. ScaleCUA support using 【114†vLLM】 to deploy and evaluate it through an OpenAI-compatible API. To run the evaluation benchmarks, please refer to the specific instructions within the 【117†[Evaluation]】.
L270: 
L271: Our evaluation suite covers desktop, mobile, and web environments:
L272:   * Android: `AndroidWorld`, `AndroidLab`
L273:   * Ubuntu: `OSWorld`
L274:   * macOS: `MacOSArena`
L275:   * Web: `WebArenaLite-v2` (A refined version of WebArena-Lite suitable for visual-based agents)
L276:   * Windows: `WindowsAgentArena`
L277: ## 🧠 Training
L278: 
L279: The directory `agent-sft/` contains all the necessary code and configuration files to train the ScaleCUA from scratch using our ScaleCUA-Data. We support training Computer Use Agents with both 【118†InternVL】 and 【119†Qwen-VL】.
