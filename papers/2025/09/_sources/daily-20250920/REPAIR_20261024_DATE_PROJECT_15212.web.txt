L223: ## 🌟 Introduction
L224: 
L225: RynnVLA-001 is a VLA model based on pretrained video generation model. The key insight is to implicitly transfer manipulation skills learned from human demonstrations in ego-centric videos to the manipulation of robot arms.
L226: 
L227: We finetune the baseline on the same dataset to evaluate the performance. The comparison results are shown in the following figure.

L244: ## 🗝️ Training
L245: 
L246: The training pipeline are shown as follows:
L247: 
L248: Here we provide instructions on how to finetune the model with your own LeRobot data （ActionVAE and Stage 3). We will release instructions on how to train models from scratch. Stay tuned!
L249: ### Step 1: Prepare Pretrained Models
L250: 
L251: Download 【105†Chameleon†huggingface.co】 Model and pretrained 【98†RynnVLA-001-7B-Trajectory†huggingface.co】 models, and put the downloaded model under `pretrained_models`. The structure of the folder `pretrained_models` should be:
L252: 
L253:     pretrained_models
L254:     ├── Chameleon
L255:     │   ├── original_tokenizers
L256:     │   │   ├── text_tokenizer.json
L257:     │   │   ├── vqgan.ckpt
L258:     │   │   └── vqgan.yaml
L259:     │   ├── config.json
L260:     │   └── ...
L261:     └── RynnVLA-001-7B-Trajectory
L262: ### Step 2: Prepare Training Data
L263: 
L264: If you have your own LeRobot data, please convert your LeRobot data into the hdf5 format. Here, we provide the conversion scripts. To execute the conversion successfully, we recommend you to install a seperate environment as suggested in 【106†LeRobot】 repo.
L265: 
L266:     python misc/lerobot_data_convert.py --dataset_dir path-to-raw-lerobot-data --task_name dataset-name --save_dir path-to-save-hdf5-files
L267: After the data conversion, you need to save the statistics and paths of all your data into a json file. You can use the following scripts to generate the json file. Before you run the scripts, please change the data path in the `misc/merge_data/config.yaml`.
L268: 
L269:     cd misc/merge_data
L270: 
L271:     python misc/data_process_with_configs.py -c misc/merge_data/config.yaml
L272: ### Step 3: Prepare training script
L273: 
L274: Before you start training, please change the paths in `./configs/actionvae/actionvae_lerobot.yml` and `./configs/lerobot/lerobot_exp.yml` to corresponding local paths.
L275: 
L276:     # ActionVAE
L277:     # Empirically, we train action_vae on our dataset for 300000 iterations with batch size of 16 * 8 (GPUs).
L278:     # You may visualize the reconstructed trajectory to check the quality.
L279:     bash scripts/actionvae/action_vae.sh
L280: 
L281:     # Stage 3
L282:     bash scripts/lerobot/lerobot.sh
