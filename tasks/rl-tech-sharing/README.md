## 一条主线

```text
示范没有覆盖所有情况
→ 自己尝试，得到反馈
→ 比较哪些行动值得加强
→ 更新参数，再次尝试
→ 用独立任务检查是否真正进步
```

算法在这条链上分工：PPO 学习回报预测并控制更新；GRPO 用同题多次尝试比较，换取不训练 Critic；离线 DPO 则从已有偏好对出发。不是 SFT→PPO→GRPO→DPO 的必经升级流程。

## 这次收敛了什么

原 28 页收敛为 16 页，不把删掉的正文塞进剩余页面。合并重复的概念、公式与实验解释；PPO 先给出完整训练循环，再解释约束；GRPO 连续讲清组内比较、共享参数与下一轮采样；三个框架合为一页。

完整梯度推导、评分器训练细节、Agent mask、RLOO/DAPO 等变体、框架后端与第二套 CPU 实验留在配套材料。独立迷宫仍保留 PPO 训练和五个机制，主讲只演示当前问题需要的部分。DAPO 动画不恢复。

最近讨论的 Critic 与最优性的区别、Group 迭代与全局参数共享，已融入第 06、09、13 页，不另加问答页。每页备注以一个尚未解决的问题引出下一页，结尾回到开场的训练循环。

第 14 页建立完整循环，第 15 页用三个分步动画继续解释：采样与权重、数据交接、异步与等待。异步场景明确区分第 1 批（Q1/Q2 各四答）和第 2 批（Q3/Q4 各四答），展示旧版本生成的数据如何用于下一次更新；也可切换到被拒绝后重新采样的结局。双轨时间线不表示实测速度，verl 也有异步模式。原表格与 SkyRL 对照保留作静态说明和打印回退。主讲只演重叠执行与数据去向的关键帧，其余细节按问题展开。

## 使用与边界

- HTML 可直接打开，不需要服务器或网络；方向键翻页，按钮查看讲者备注与打印。
- 迷宫页标题随算法标签和奖励规则同步变化；切回默认设置恢复本页原标题。打印使用原讲稿标题，打印结束后恢复当前选择。
- SFT 开始前标出蓝色虚线及 1～4 步示范，评估阶段撤去标记。采样、评分与更新是不同阶段。
- 逐格迷宫产生实际表格更新；第 04 页四候选动画是另一层简化；第 05 页 Value 为示意值。三者不拼接数值或曲线。
- PPO 教学版使用 Monte Carlo return 与表格 Critic，不含 GAE、reference KL。GRPO 每组八路线。DPO 使用固定偏好对。所有计算细节见实验说明。
- 没有进行真实 LLM 或未见地图训练，也没有复现三框架性能排名。第 15 页涉及的 verl/miles 机制于 2026-09-24 重新核验官方资料；两题八回答、概率与 token ID 为教学设定，不是框架运行记录。
- 不覆盖 Kubernetes、Kubeflow、镜像封装和平台部署；不修改 Books 或学习等级。

修改讲稿后，用具有 `marked`、`lucide` 依赖的 Node.js 执行 `render_slides.mjs`，生成两个离线 HTML。讲稿的“演示”字段指定动画，重排页码不再自动挂错动画。`verify-slides.mjs` 检查全部 16 页、演示状态、翻页和打印；独立迷宫由另外两个浏览器检查覆盖。
