# 项目背景

本项目要解决的是 AI 知识碎片化：知道许多算法和框架，却难以解释它们之间的联系，也难以在约束变化时判断应采用哪种设计。

目标是形成可用于系统设计的理解：模型能力如何通过训练、推理、基础设施与 Agent 转化为可运行、可评估、可控制的系统。

## 项目范围

书稿承载长期机制与设计取舍，研究报告提供证据，Lab 用于亲自实现和验证理解。
框架与论文是研究材料，不是目录组织原则；个人职业规划和具体业务平台交付不属于本项目的知识主线。
