注册表版本：2026-08-25
生效日期：2026-08-25

## 1. 使用方式

本文件是 Daily、Sunday Weekly 与 Historical Weekly 的唯一来源清单。Prompt 只引用本表，不再复制机构、venue 或工程项目名单。

`Source ID` 表示稳定扫描身份，不包含年份、cadence、venue 或 URL。品牌改名、endpoint 迁移和扫描频率变化只更新字段，不创建新 ID。同一论文、release 或 artifact 是否重复，由 Source Family 层判断，而不是把不同入口粗暴合并为同一个来源。

Cadence 分为：

- `Required Daily`：Daily 必须留下 Coverage Receipt。
- `Required Weekly`：Sunday Weekly 与 Historical Weekly 必须闭合；正式 release、security、breaking contract 或关联论文可触发 Daily。
- `Periodic / Venue Season`：只在结果轮次、出版季、规则或 suite 变化时执行。
- `Event Trigger`：由 release、RFC、decision、spec 或已发现候选触发。
- `Discovery / Recovery Backstop`：bounded discovery、身份、全文或 artifact 恢复；不可访问不阻塞确定性来源 Gate。

来源的 Authority Role 与 allowed claim 受 [RESEARCH_CONTRACT.md](./RESEARCH_CONTRACT.md) 约束。“权威机构”不意味着该机构的公告可以证明未披露机制，也不意味着作者 benchmark 可以外推到其他 workload。

注册表行序就是同一 cadence 内的 canonical scan order；调整行序属于合同变更。执行者不得按搜索排序临时改写扫描顺序。

`Fallback` 只声明下一跳恢复来源，不是无限递归搜索；允许写 `—`，整个 fallback graph 必须无环，避免两个 metadata 源相互跳转后伪装成恢复完成。

## 2. Closure 语义

`Pagination / Cursor` 同时声明来源是否可形成可复算分母：

- `Enumerable`：可以枚举完整时间窗和分页，允许参与 Coverage Gate。
- `Windowed query`：只有保存 query、filter、cursor、page count 与访问时间后才能参与 Gate。
- `Event triggered`：只证明触发事件已经检查，不证明常态全量召回。
- `Non-deterministic backstop`：排序或召回不可冻结，只能补检，不能参与 `Coverage Gate = Closed` 算术。

### 4.2 OpenReview selected venue groups

重放顺序：

```text

```

OpenReview 证明审稿流程记录，不替代 arXiv/作者稿的机制证据，也不替代 PMLR、NeurIPS Proceedings、TMLR/JMLR 等 formal publisher 的正式出版状态。

## 5. 不进入 Evidence Gate 的来源

以下内容可以提供线索，但不能作为技术结论的最终证据，也不参与 Coverage Complete 算术：

- 第三方 leaderboard；
- 媒体、newsletter、转载和社交平台；
- 搜索摘要或 AI-generated summary；
- Papers with Code、ResearchGate、Academia.edu 等聚合页；
- 没有绑定规则、版本和实验合同的 benchmark 宣传。

需要使用它们时，只建立 discovery lead，并回到本注册表中的 primary、publisher、benchmark owner 或 artifact source。
